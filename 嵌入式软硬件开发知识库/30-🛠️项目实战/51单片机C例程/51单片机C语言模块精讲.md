## 典型代码骨架（来自 `113-串口通讯/delay.c`）
```c
// 12M 晶振下的延时；精确延时用汇编
void DelayUs2x(unsigned char t){ while(--t); }
void DelayMs(unsigned char t){
  while(t--){ DelayUs2x(245); DelayUs2x(245); }
}
```

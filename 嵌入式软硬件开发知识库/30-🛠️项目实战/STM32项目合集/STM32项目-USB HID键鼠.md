# USB HID键鼠

> 基于 STM32L476 + MPU9250 的 USB HID 复合设备：把九轴姿态传感器的"倾斜/转动"映射成键盘、鼠标、游戏手柄的 HID 报文，插上电脑即被识别为免驱输入设备。核心价值是"用姿态代替手，做一个体感控制器"。

![[USB-HID-STM32CubeMX配置.pdf]]

## 1. 需求拆解
- 必须实现：
  - STM32 作为 [[USB]] Device（Custom HID 类），全速 12Mbps，免驱被 PC 识别。
  - HID 描述符同时声明键盘、鼠标、两个游戏手柄共 4 个 Report ID。
  - MCU 把 MPU9250（九轴姿态）读到的 roll/pitch/yaw 映射成对应的 HID 报文并定时发送。
  - USB 全局中断 + SysTick 时基，PA11/PA12 作 D+/D-。
- 可选实现：
  - USART2(PA2/PA3,115200) 打印调试信息。
  - PA5(LD2) 作状态指示。
  - 用 [[CubeMX]] 图形化配置外设并生成 HAL 工程(EWARM)。
- 硬约束（供电/尺寸/成本/通信）：
  - 主控 STM32L476RGTx（Nucleo-L476RG，LQFP64，Cortex-M4，低功耗）。
  - USB 收发器需 `VDDUSB` 单独供电（来自 [[线性电源LDO]]/板载）。
  - USB 全速要求 48MHz 时钟，由 `PLLSAI1` 专门产生（[[时钟树]] 要点）。
  - MPU9250 为九轴(加速度+陀螺仪+磁力计)姿态传感器，经 [[I²C]] 与 MCU 通信（白名单无 MPU9250，此处作普通器件描述）。

## 2. 功能框图
```
   MPU9250 (九轴姿态: accel+gyro+mag)
        │ I²C (SDA/SCL)
        ▼
   ┌──────────── STM32L476 ────────────┐
   │  读传感器 → 姿态解算(roll/pitch/yaw) │
   │        │ 映射                        │
   │        ▼                            │
   │  HID_Buffer[8] 组装报文             │
   │        │ USBD_CUSTOM_HID_SendReport │
   │        ▼                            │
   │  USB OTG FS (Device_Only)          │
   │   PA11=D-, PA12=D+  (VDDUSB供电)    │
   └───────────────┬────────────────────┘
                    │ USB 全速 12Mbps
                    ▼
             PC (识别为 键盘+鼠标+手柄)
   (调试: USART2 PA2/PA3 115200 ; 指示: LD2 PA5)
```

## 4. 原理图推导（逐个模块，讲清为何需要每个元件）
- **USB OTG FS（PA11=D-、PA12=D+）**：L4 片内集成全速 USB 设备 PHY，只需两根差分线到插座，外置 1.5k 上拉（全速在 D+）由片内或电阻实现。为何选 Custom HID？HID 类被所有 OS 免驱识别，且允许自定义报文，键盘/鼠标/手柄都能塞进一个复合描述符。
- **VDDUSB 供电**：USB 收发器模拟部分需要独立 `VDDUSB`（典型 3.3V），必须接到电源域，否则 PHY 不工作——这是 L4 USB 的常见漏点。
- **HID 报告描述符（4 个 Report ID）**：由 `CUSTOM_HID_ReportDesc_FS[]` 定义——
  - ID1 键盘：1B 修饰键 + 1B 保留 + 6B 键码（boot 协议风格）；
  - ID2 鼠标：3bit 按键 + 5bit 填充 + X/Y/Wheel 三字节**相对**量；
  - ID3/ID4 游戏手柄：16bit 按键 + X/Y/Z/Rx 四轴**绝对**量。
  描述符告诉 PC"设备会发什么格式的数据"，PC 据此解析，无需驱动。
- **MPU9250（[[I²C]]）**：九轴传感器，MCU 经 I²C 读原始加速度/角速度/磁场，做 [[姿态解算]]（如互补滤波/自平衡算法）得到倾斜角度。白名单无 MPU9250，按普通器件处理。
- **姿态→动作映射**：把 roll/pitch 映射为鼠标 X/Y（相对位移）、把按键/倾斜阈值映射为键盘码（如方向键/WASD）、把各轴映射为手柄 X/Y/Z/Rx。源码 `main.c` 预留 `HID_Buffer[8]` 与发送调用，工程骨架即此映射框架。
- **时钟（[[时钟树]]）**：系统时钟走 MSI→PLL 到 80MHz；USB 需要精确 48MHz，由 `PLLSAI1`（RCC_PLLSAI1_48M2CLK）专门提供，否则 USB 枚举失败。
- **NVIC**：开启 `USB OTG FS global interrupt`，HID 枚举/收发靠中断驱动；SysTick 作 1ms 时基。

## 5. 布局布线要点
- **USB 差分线**：D+/D-(PA11/PA12) 必须等长、平行、远离干扰源，做 90Ω 差分阻抗；D+ 全速需 1.5k 上拉到 3.3V（确认片内已使能或外部加上）。
- **VDDUSB**：务必接稳定 3.3V 且旁加 [[去耦电容]]，USB 枚举对电源纹波敏感。
- **48MHz 时钟精度**：USB 全速容忍 ±0.25% 漂移，[[晶振与时钟电路]] 与 PLLSAI1 配置要准，用内部 MSI 需确认足够稳。
- **I²C 上拉**：MPU9250 的 SDA/SCL 需 [[上拉电阻与下拉电阻]]（典型 4.7kΩ），速率标准 400kHz 即可。
- **ESD/保护**：USB 口建议加 ESD 器件，符合 [[EMC电磁兼容]] 与 [[硬件设计规范与评审]]。
- **去耦**：MCU 每组电源脚、MPU9250 电源旁加 0.1µF [[去耦电容]]。

## 6. 检查清单
- [ ] USB — PA11/PA12 差分走线等长阻抗到位，D+ 1.5k 上拉正确
- [ ] 电源 — VDDUSB 已接 3.3V 且去耦，USB 口 ESD 保护就位
- [ ] 时钟 — PLLSAI1 输出 48MHz 给 USB，系统时钟配置正确
- [ ] 描述符 — 4 个 Report ID（键/鼠/双手柄）格式与 PC 解析一致
- [ ] I²C — MPU9250 SDA/SCL 上拉到位，能读到器件 ID
- [ ] 中断 — USB OTG FS 全局中断、SysTick 已使能
- [ ] 枚举 — 插 PC 被识别为 HID 复合设备，设备管理器无感叹号
- [ ] 映射 — 姿态→HID 报文逻辑验证（倾斜出鼠标移动、按键出键盘码）

## 7. 复盘
- **企业/项目为什么这么设计**：用 Custom HID 把"姿态传感器"包装成标准输入设备，免驱、跨平台、即插即用——是体感外设/无障碍控制的经典思路。
- **为什么复合一个描述符**：键盘+鼠标+手柄同在一个接口里，PC 一次枚举全识别，省端点、省配置。
- **为什么 L4 + 片内 USB PHY**：低功耗且无需外部 USB 芯片，[[CubeMX]] 把时钟/描述符/中断都配好，工程重心只剩"姿态→报文"的映射算法。

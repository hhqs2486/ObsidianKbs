# 机智云智能家居

> 基于 NUCLEO-L073RZ + ESP8266-12F 的物联网 Demo：手机 APP 远程控制 RGB 灯、直流电机正反转，并上报温湿度与障碍物状态。核心价值是"用最少代码把 STM32 设备接入机智云云平台"。

![[机智云-图形化玩转智能硬件开发.pdf]]

## 1. 需求拆解
- 必须实现：
  - 手机 APP 远程控制 RGB LED 颜色（红/绿/蓝 + 黄/紫/粉三混色一键切换）。
  - 手机 APP 远程控制微型直流电机正转 / 反转。
  - 手机 APP 显示 DHT11 采集的温湿度（数值量上报）。
  - 红外障碍物检测状态上报（布尔量上报）。
- 可选实现：
  - 板载 2 个按键做本地配网 / 模式切换。
  - 用 [[CubeMX]] 图形化生成 HAL 工程，降低初始化代码量。
- 硬约束（供电/尺寸/成本/通信）：
  - 主控 STM32L073RZ（Cortex-M0+，超低功耗），跑在 NUCLEO-64 开发板上。
  - 联网靠 ESP8266-12F（Wi-Fi），模组里烧"GAgent"固件，对 MCU 表现为串口透传。
  - 设备 ↔ 云平台之间靠机智云"数据点"约定数据格式，MCU 不直接解析 TCP/TLS。
  - NUCLEO 板载 ST-LINK 虚拟串口与 Arduino UNO 串口引脚冲突，需对板子做"小手术"改线。

## 4. 原理图推导（逐个模块，讲清为何需要每个元件）
- **ESP8266-12F（GAgent）**：把"连云"复杂度下沉到模组。MCU 只需实现 3 个接口——串口发送、串口中断收 1 字节、1ms 定时器中断——即可与云平台互发数据点。为何不直接让 MCU 跑 TCP/TLS？L0 性能弱、Flash 小，下沉最省事。模组 RX/TX 接 MCU 的 [[UART]]（PA2/PA3，9600 8N1）。
- **DHT11（PB3）**：单总线器件，靠精确微秒时序读温湿度，故用普通 [[GPIO]] bit-bang（非 [[I²C]]）。为何单独占一个脚？它的时序不能被其他外设打断。
- **RGB 5050 LED（PB8=CLK、PB9=DAT、PA0=使能）**：不是标准 [[I²C]]，而是厂商自定义"时钟+数据"两线协议（见 `hal_rgb_led.c` 的 `clkProduce/datSend`）。PA0 是 LED 电源使能，省电时关掉。前 2 bit 为标志、后接反码校验，再是 B/G/R 各 8 bit。
- **直流电机（TIM3_CH1=PB4、CH2=PB5）**：用 [[定时器与PWM]] 输出 8kHz 左右 PWM 调速度；电机不能由 MCU 直驱（电流大），必须经电机驱动电路（三极管/桥）。正反转由两组 PWM 占空比方向决定（`motorStatus`：正转给 CCR1，反转给 CCR2）。
- **红外障碍（PA10）**：数字量输入，有障碍=低/高电平，直接 [[GPIO]] 读，作为布尔数据点上报。
- **按键（PB10、PA8）**：本地配网/模式键，消抖后触发；与云端控制并存。
- **NUCLEO 板载 ST-LINK**：既是下载器（SWD）也是虚拟串口，但与 Arduino 串口引脚复用，故对板子"动手术"断开冲突线，把 USART 留给 ESP8266。

## 5. 布局布线要点
- **串口冲突**：NUCLEO 的 ST-LINK 虚拟串口占 PA2/PA3，而 Gokit 扩展板也想用这组脚连 ESP8266——必须改线或跳帽，否则烧录/通信互相打架。
- **DHT11 时序**：单总线对延时极敏感，读取时关中断或保证不被 [[定时器与PWM]]/RTOS 抢占；线上拉 4.7kΩ。
- **ESP8266 电源**：Wi-Fi 发射瞬间电流大，VCC 旁必须 0.1µF + 大电容储能，且 [[电平转换]] 注意 3.3V 逻辑兼容（L073 与 ESP8266 同为 3.3V，无需转换）。
- **RGB LED 走线**：CLK/DAT 是高速开关信号，远离模拟/电源，必要时串小电阻抑振铃。
- **去耦**：MCU 每组电源脚加 [[去耦电容]]（0.1µF），保证 ADC/无线稳定。

## 6. 检查清单
- [ ] 串口 — ESP8266 接在独立 [[UART]]（非被 ST-LINK 占用的脚），波特率 9600 与 GAgent 一致
- [ ] 数据点 — 云端"数值/枚举/布尔"类型与 MCU 解析顺序一一对应（RGB/电机/温湿度/障碍）
- [ ] DHT11 — 上拉电阻到位，读时序未被中断打断
- [ ] 电机 — PWM 频率/占空比合适，驱动电路能承受堵转电流，续流二极管到位
- [ ] 电源 — ESP8266 储能电容充足，整板 [[去耦电容]] 齐全
- [ ] 移植 — `GizWits` 协议目录 + `Hal` 硬件驱动已拷入工程，堆/栈已调大（PDF 特别强调）
- [ ] 配网 — APP 能发现设备并绑定，数据点上下行联调通过

## 7. 复盘
- **企业/项目为什么这么设计**：用"GAgent 固件 + 数据点"把嵌入式工程师从后端、协议、加密里解放出来——写 3 个串口函数就能连云，是快速出 Demo 的典型套路。
- **为什么选 L0 + ESP8266**：教学/轻度场景要低功耗低成本，L0 够用；ESP8266 是机智云适配最成熟的 Wi-Fi 模组，固件现成。
- **工程权衡**：RGB 用自定义两线协议而非标准总线，是因为 5050 灯珠本身就是这种时序，驱动代码最简。

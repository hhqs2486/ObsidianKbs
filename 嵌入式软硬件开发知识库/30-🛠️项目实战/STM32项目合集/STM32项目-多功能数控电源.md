# STM32多功能数控电源

> 一台基于 STM32F334 + 同步 Buck 的数字控制电源：MCU 用高精度定时器（HRTIM）发互补 PWM 驱半桥 MOSFET，闭环采样输出电压/电流，跑 [[PID控制算法]] 实现恒压/恒流可调输出。原理图 PDF 见下方嵌入。

![[数控电源-原理图与PCB.pdf]]

## 1. 需求拆解
- 必须实现：
  - 可调直流输出（电压/电流可设），支持恒压（CV）与恒流（CC）两种工作模式。
  - 同步 Buck 降压：高边+低边 MOSFET 组成半桥，效率高于异步（二极管续流）。
  - 输出采样：电压分压 + 电流采样电阻，进 [[ADC]] 做数字闭环。
  - 过压/过流保护（TVS + 软件限幅）。
- 可选实现：
  - 多路/多档电感切换（L1 10uH/9A、L2 15uH/15A 对应不同电流档）。
  - 按键/显示设参、PID 参数在线整定。
- 硬约束（供电/尺寸/成本/通信）：
  - 主控 STM32F334C8T6：数字电源专用，内置 HRTIM（高精度 PWM，带死区），正好对口（见 [[定时器与PWM]]）。
  - 输入经整流/前级得到 PV 母线；栅极驱动需 12V；MCU/运放需 3.3V/5V 干净电。

## 4. 原理图推导（逐个模块，讲清为何需要每个元件）
- **STM32F334 + HRTIM**：数字电源的核心。为什么不用普通定时器？——HRTIM 分辨率高（亚 ns 级）、能出带死区的互补 PWM（PWM1A/PWM1B），防止半桥上下管"直通"炸管（见 [[定时器与PWM]]、[[MOS管与驱动电路]]）。
- **UCC27211 半桥栅驱**：MCU 的 PWM 是 3.3V 逻辑，MOS 栅极要 ~12V 才完全导通；高边管栅极还比源极高出一个 Vcc，需"自举"。UCC27211 用 HB/HS 自举电容（CT1 0.47µF）给高边供电，LO/HO 分别推低边/高边。没有它，MCU 直接推不动功率 MOS。
- **4× BSC123N08NS3G**：半桥上下管（高边 Q1、低边 Q2，另两颗 Q3/Q4 并联或组第二相扩流）。低 Rds(on) 让导通损耗小、效率高。
- **L1/L2 电感**：Buck 的"能量中转站"。开关管导通时电感储能、截止时经低边管续流，平滑出直流。10uH/9A、15uH/15A 对应不同输出电流档，感量小→纹波大但响应快。
- **R4 10mΩ 采样电阻**：串在回路低端，电流流过产生 mV 级压降 `V=I·R`，用来算输出电流。为什么这么小？——减小串联损耗与发热。
- **TLV2374 运放调理**：R4 上的 mV 信号太弱，需差分放大（Iout_Sense_N/P）到 ADC 量程；电压也经电阻分压后由运放缓冲（ADC_V_IN/ADC_V_OUT）再送 [[ADC]]。这就是"数字闭环的眼睛"。
- **SMAJ90A / SS14**：输入 TVS 钳位浪涌防后级击穿；肖特基管作续流/防反补充（同步 Buck 主要靠低边 MOS 续流）。
- **XL7005A + SPX3819**：把输入降到中间电压再 LDO 出 3.3V/5V，给 MCU 与模拟前端干净电源（见 [[开关电源DCDC]]、[[线性电源LDO]]）。

## 5. 布局布线要点
- **大电流环路最小化**：SW 点→电感→输出→采样电阻→回输入的环路面积要小，否则 EMI 大、效率低（见 [[EMC电磁兼容]]）。
- **功率地与信号地单点连接**：电流采样、运放参考地单独走，最后一点汇到功率地，避免大电流地弹干扰小信号。
- **栅极电阻 R1/R2/R3 (2Ω)**：串在栅极抑制驱动振荡与米勒尖峰，取值影响开关速度与发热。
- **自举电容 CT1 靠近 HB-HS**：高边自举电压稳，否则高边驱动掉电误开通。
- **[[去耦电容]]**：MCU、运放、UCC27211 的 VCC 旁 0.1µF；输入/输出 bulk 电容（226=22µF、106=10µF）稳住母线。
- **模拟采样走差分、远离开关节点**：采样走线平行等长、包地，远离 SW 高频跳变点。

## 6. 检查清单
- [ ] 死区：HRTIM 互补 PWM 死区时间 > MOS 关断延迟，确认上下管不会同时导通
- [ ] 自举：HB-HS 电容已焊、容值够，高边能持续导通
- [ ] 采样：电流采样电阻精度/温漂、放大倍数把满程电流映射到 ADC 量程
- [ ] 保护：SMAJ90A 钳位电压 < 后级耐压；软件限幅先于此动作
- [ ] 电感：额定电流 > 输出峰值电流，感量匹配纹波要求
- [ ] 电源：12V 栅驱、3.3V/5V LDO 上电时序；[[去耦电容]] 齐套
- [ ] 地：功率地/模拟地单点，采样参考正确
- [ ] PID：限幅输出占空比 0~100%，CV/CC 模式自动切换逻辑正确

## 7. 复盘
- **为什么用同步 Buck 而非异步**：低边用 MOS 代替续流二极管，导通损耗 `I²·Rds(on)` 远小于二极管压降损耗，效率大幅提升——电源的命脉就是效率与发热。
- **为什么必须 HRTIM + 死区**：半桥最怕上下管直通（瞬间短路炸管），高精度互补 PWM 自带死区是"保命"设计，普通定时器精度/功能不够。
- **为什么数字 PID 而非纯硬件**：电压/电流双闭环、CV/CC 切换、软启动、保护都在软件里，调参不用动硬件，量产和改指标都快。

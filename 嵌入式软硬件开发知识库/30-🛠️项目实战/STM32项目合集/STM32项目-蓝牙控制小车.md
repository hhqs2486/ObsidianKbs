# 蓝牙控制小车

> 基于 STM32F4 + FBT-06 蓝牙串口模组的遥控小车：手机/遥控器发字符指令，经蓝牙送达 MCU 串口中断，解析后驱动直流电机实现前进/后退/左转/右转/停车。核心价值是"用最少的代码打通 无线→MCU→电机 链路"。

## 1. 需求拆解
- 必须实现：
  - 手机/遥控端通过蓝牙向小车发送单字符指令：`f`前进、`b`后退、`l`左转、`r`右转、`s`停车。
  - MCU 串口接收中断实时解析指令，控制电机转向与转速。
  - 四路 PWM 调电机速度，四路 GPIO 控电机转向（可组成左右两轮差速或四驱）。
- 可选实现：
  - 上电自打印欢迎语（经同一串口回传，便于调试）。
  - 用延时函数做软件消抖、状态指示。
- 硬约束（供电/尺寸/成本/通信）：
  - 主控 STM32F4 系列（代码里 `delay_init(168)` → 系统时钟 168MHz，典型为 STM32F405/407）。
  - 蓝牙模组 FBT-06（上海移摩的蓝牙串口通讯模块，主从一体/分离式），与 MCU 走 [[UART]]，9600 8N1。
  - 电机功率大，MCU 引脚绝不能直接驱动，必须外置电机驱动电路。
  - 论文为 `.doc` 无法读取，以下均依据硬件资料(FBT-06 数据手册)与工程源码推导。

## 2. 功能框图
```
   手机 / 遥控器
        │ 蓝牙(SPP 串口透传)
        ▼
   ┌──────────┐  USART1(PB6 TX / PB7 RX, 9600)  ┌──────────────────────┐
   │ FBT-06   │◀───────────────────────────────│  STM32F4 (主控)       │
   │ 蓝牙模组  │    RX中断收1字节                 │                      │
   └──────────┘                                  │  解析: f/b/l/r/s      │
                                                 │      │               │
                                                 │      ▼               │
                                                 │  Direction(PA0~PA3)  │ 转向(4路GPIO)
                                                 │  Change_PWM(TIM3)    │
                                                 │      │               │
                                                 │      ▼               │
                                                 │  PC6~PC9 = TIM3_CH1~4│ 速度(4路PWM)
                                                 └──────────┬───────────┘
                                                            │
                                                  ┌─────────▼─────────┐
                                                  │  电机驱动(桥/三极管) │
                                                  │  → 直流电机 ×4(轮)   │
                                                  └────────────────────┘
```

## 3. 器件选型
| 模块 | 型号 | 选型理由 | 替代 |
| --- | --- | --- | --- |
| 主控 MCU | STM32F4 (168MHz) | 性能足、定时器/PWM 多，适合多路电机 | STM32F1 / F0 |
| 蓝牙模组 | FBT-06 / FBT-06M / FBT-06S | 嵌入式近距离蓝牙串口模块，TTL 直连 MCU，主从可配 | [[BLE蓝牙]] HC-05/06、[[NRF24L01]] |
| 电机驱动 | 桥式驱动(板上) | 放大 STM32 的 PWM/方向信号到电机电压电流 | L298N / TB6612 / [[直流电机驱动]] |
| 执行器 | 直流电机 ×4 | 小车轮毂电机，PWM 调速 | 步进电机 |
| 调试 | USART1 回传 | 同一串口既收指令又发状态，省一个口 | 独立调试串口 |

## 4. 原理图推导（逐个模块，讲清为何需要每个元件）
- **FBT-06 蓝牙模组（USART1，PB6/PB7，9600）**：它是"蓝牙转串口"透传模块，手机发的数据原样从 TX/RX 出来，MCU 当普通 [[UART]] 用即可，无需跑蓝牙协议栈。为何选串口透传模组？把无线协议下沉给模组，MCU 只认字节，开发量最小。
- **USART1 接收中断**：在 `USART1_IRQHandler` 里 `USART_ReceiveData` 取 1 字节，立即 `switch(Res)` 分支处理。为何用中断而非轮询？小车要"实时"响应遥控，轮询会漏帧。
- **Direction（PA0~PA3）**：4 个 [[GPIO]] 输出作 H 桥的方向控制线。`Direction(1)` 置 PA0/PA1/PA2/PA3 为 `0x55` 模式（正转），`Direction(0)` 置 `0xAA`（反转）。每个电机需"PWM+方向"两根线，4 路即覆盖四驱。
- **Change_PWM（TIM3，PC6/PC7/PC8/PC9）**：用 [[定时器与PWM]]，APB1 上 TIM3，PSC=83、ARR=10000 → 84MHz/84=1MHz，1M/10000=100Hz PWM。四个比较通道 CCR1~4 对应四轮占空比（0~2000/10000）。左转给左右轮不等占空比制造差速，停车全 0。
- **电机驱动电路**：STM32 的 PC6~9 / PA0~3 只是逻辑信号，电流小；电机的启动/堵转电流大，必须经 [[直流电机驱动]]（H 桥 + 续流二极管 + 可能的 [[MOS管与驱动电路]]）放大，否则烧 IO。
- **电源**：电机驱动需较高电压/电流，与 MCU 3.3V 逻辑电要隔离或 [[电平转换]]，驱动级加储能电容防掉电。

## 5. 布局布线要点
- **电机干扰**：直流电机是强干扰源，PWM 走线、电机线要远离 [[UART]] 与蓝牙天线；驱动级加续流二极管、[[去耦电容]]、磁珠抑制，否则蓝牙掉线、MCU 复位。
- **共地**：MCU 逻辑地与电机驱动功率地单点相连，避免大电流灌入逻辑地抬升电平。
- **PWM 频率**：100Hz 偏低，人耳可能听到啸叫；可在不超出桥响应范围时提到几 kHz。
- **蓝牙天线**：FBT-06 天线周围净空，远离电机金属与电源，保证遥控距离。
- **方向/速度信号隔离**：方向 GPIO(PA0~3) 与 PWM(PC6~9) 最好分组走线，减少交叉耦合。

## 6. 检查清单
- [ ] 串口 — 蓝牙模组接 USART1(PB6/PB7)，波特率 9600 与 MCU 一致，交叉接线(TX↔RX)
- [ ] 中断 — USART1 接收中断已开(`USART_IT_RXNE`)，优先级合理，解析在中断里快速完成
- [ ] PWM — TIM3 四路映射到 PC6~9，ARR/PSC 算出的频率符合电机/桥要求
- [ ] 方向 — PA0~3 输出模式正确，正/反转电平组合验证无误
- [ ] 驱动 — 电机驱动续流二极管、[[去耦电容]]、[[MOS管与驱动电路]] 齐套，能承受堵转电流
- [ ] 电源 — 逻辑 3.3V 与电机电源隔离/[[电平转换]]，共地单点
- [ ] EMC — 电机线滤波、[[EMC电磁兼容]] 措施到位，蓝牙实测不掉线

## 7. 复盘
- **企业/项目为什么这么设计**：用"蓝牙串口透传模组 + 单字符指令 + 中断解析"是教学/竞赛小车的经典极简方案——不碰蓝牙协议栈、不引 RTOS，几百行代码就能跑。
- **为什么四路 PWM + 四路方向**：电机需要"速度+方向"两自由度，桥式驱动每路两根线；四组即可做四驱或左右差速转向。
- **工程权衡**：把无线复杂度下沉给 FBT-06，把功率放大下沉给电机驱动，MCU 只做"收字节→设 PWM/IO"的薄逻辑，易读易改。

# 51智能车

> 基于 51 单片机的两轮小车：能遥控、超声避障、光电巡线，是讲"从需求反推原理图"最直观的入门项目。

## 1. 需求拆解
- 必须实现：
  - 三种运动模式可切换：遥控、避障、巡线（按键切换）。
  - 车速 40 档可调，可正反转（遥控或程序设定）。
  - 循迹：识别黑线（含弧线/直角/交叉/大锐角），沿轨迹行进。
  - 蓝牙控制：手机小程序遥控前进/后退/左右转。
  - 超声避障：检测范围 100mm–3000mm，距障碍 <300mm 顺时针旋转避障。
- 可选实现：
  - LCD1602 输出模式/距离/状态信息。
  - 独立按键在蓝牙无连接时本地操作小车。
  - LED / 蜂鸣器做额外输出与提示。
- 硬约束（供电/尺寸/成本/通信）：
  - 供电：两节锂电池串联（放电 4.2V–2.5V，整机 5–9V），覆盖 N20 的 6V 平台。
  - 成本：51 平台成本最低，适合教学与量产入门套件。
  - 通信：蓝牙透传走串口，波特率固定 9600。

## 4. 原理图推导（逐个模块，讲清为何需要每个元件）
- **STC89C52 主控**：整个小车的"大脑"。选 51 是因为资料多、GPIO 位寻址写起来极直观，适合入门讲原理。需外挂 **11.0592MHz 晶振**（[[晶振与时钟电路]]）——这个频率能让串口 9600 波特率整除、误差最小；配套 **复位电路** 与 **去耦电容**。
- **动力系统（为什么需要驱动芯片）**：N20 是大电流感性负载，而 51 的 IO 带负载能力很弱，不能直接驱。因此加 **TA6586 H 桥驱动**（[[直流电机驱动]]），两片各驱一个轮。MCU 用 **Timer0 输出 PWM 方波**（[[定时器与PWM]]）调占空比→控转速；BI/FI 电平决定正反转。
- **供电（双电压域）**：两节锂电串联得 5–9V，直接喂电机（N20 额定 6V、单电机额定 160mA、双电机满载 320mA，选 800mA 放电电池留余量）。MCU 逻辑侧的 5V 由 **LDO**（[[线性电源LDO]]）从电池取出，与电机电源域分开，避免电机启停干扰逻辑。
- **超声避障 SR04**（[[超声波测距]]）：TRIG 发 10µs 脉冲、ECHO 收回高电平脉宽 ∝ 距离。为什么用超声？非接触、成本极低。ECHO 接 P4.5、TRIG 接 P4.5 旁 GPIO；注意 P4.5 复用为 ALE，烧录须勾选"ALE 脚用作 P4.5 口"否则测距失效。
- **巡线光电（为什么用比较器而非 ADC）**：5 路 DY-ITR9909 弧形排布。红外发射 + 光敏接收，黑线吸收红外→接收弱→比较器翻转。51 片上 ADC 资源有限，故用 **XD393 双比较器**（[[比较器电路]]，3 片覆盖 5 路 + 余量）把模拟量直接变 0/1；电位器调阈值抗反光。读到黑线记 1、白记 0。
- **蓝牙 JDY-23**（[[BLE蓝牙]]）：串口透传，小程序发 `U/D/L/R/S`。为什么透传？把协议全下沉给模块，MCU 只解析 5 个字符，软件量最小。
- **LCD1602 / 按键 / 蜂鸣器 / LED**：全部 [[GPIO]] 直驱。按键靠 **上拉电阻**（[[上拉电阻与下拉电阻]]），读 1 为抬起、0 为按下，在定时器中断里做 8ms 消抖。
- **软件架构**：驱动层（GPIO/定时器/串口）→接口层（外设驱动）→中间层（功能封装）→应用层（模式控制），通用层放公共定义；Timer0 以"注册回调函数"方式集中调度（[[C语言]] 函数指针、[[结构体与位域]] 存轮状态）；UART 中断收数据。

## 5. 布局布线要点
- **ALE/P4.5 复用**：超声 ECHO 用到 P4.5，烧录必须勾选"ALE 脚用作 P4.5 口"，否则测距功能废掉。
- **串口唯一**：51 只有一个串口，烧录和蓝牙都占它。烧录时务必拔蓝牙、关内置电源，否则 PC 识别不到 USB 串口。
- **双电压域隔离**：电机 6V 与 MCU 5V 分开，驱动芯片电源端加足够储能/去耦电容，电机启停电流大易掉电。
- **光电抗反光**：传感器电位器需现场调，环境反光强会误判黑线；批量生产要统一校准阈值。
- **IO 不能直接带电机**：重申 N20 必须走 TA6586，绝不可直连 MCU IO。

## 6. 检查清单
- [ ] 晶振 11.0592MHz + 负载电容 + 复位电路焊接正确
- [ ] TA6586 电源/地/输出到 N20 接线无误，两路独立
- [ ] 超声 TRIG/ECHO 接对，烧录勾选"ALE 脚用作 P4.5 口"
- [ ] 5 路光电弧形排布、XD393 比较器阈值调好
- [ ] 蓝牙 JDY-23 改名避免混淆，串口 9600
- [ ] 按键上拉、LCD1602 对比度可调
- [ ] 烧录前拔蓝牙、关内置电源
- [ ] 电机域 / MCU 域隔离，去耦电容齐全

## 7. 复盘
- **为什么用 51 而不是 STM32**：教学项目，成本最低、资料最多、GPIO 位寻址写起来直观，最适合讲"需求→原理图"。
- **为什么电机必须加驱动芯片**：IO 带载弱、电机是大电流感性负载，H 桥功率放大必不可少。
- **为什么巡线用比较器而非 ADC**：51 片上 ADC 少，比较器 + 电位器方案更省 IO、阈值可调、更稳。
- **为什么蓝牙透传**：把复杂协议下沉给模块，MCU 只解析 `U/D/L/R/S`，软件量最小；巡线还用了 [[PID控制算法]] 把误差转成左右轮速差。

# 尚硅谷-心电监测仪

> 基于 STM32F103 + AD8232 单导联心电采集，经内置 ADC 采样后通过串口把波形数据上传到 PC 上位机实时显示，用于低成本便携式心电监测。

## 1. 需求拆解
- 必须实现
  - 采集人体心电信号并放大（微弱 mV 级生物电信号）。
  - 把模拟信号转数字并实时处理，上传 PC 上位机显示波形。
  - 用户通过上位机下发「采样率（次/分钟）」和「采样时长（秒）」控制采集起停。
  - 调试信息经 Debug 串口输出。
- 可选实现
  - 多导联（项目出于成本只做单导联，三导联/十二导联为可扩展方向）。
- 硬约束
  - 单电源 3.3V 供电，降低电源复杂度。
  - 数据量不大，选串口而非 USB，简化硬件。
  - 成本敏感：心电放大选高性价比 TI AD8232。

## 2. 功能框图
```
单导联电极(RA/LA/RL)
      │ 模拟心电信号
      ▼
   [AD8232] 生物信号放大器(3.3V单电源)
      │ OUTPUT 放大后模拟电压
      ▼
 STM32F103 ──ADC1_IN11(PC1)──► 数字心电值
      │                              │
      │ TIM6 定时采样节拍(1ms中断)   │ 应用层处理
      │                              ▼
      ├──── USART2(PA2/PA3) ──────► PC上位机(波形显示)
      └──── USART1(PA9/PA10) ─────► PC(Debug打印)
```

## 3. 器件选型
| 模块 | 型号 | 选型理由 | 替代 |
| --- | --- | --- | --- |
| 主控 MCU | STM32F103 | 内置 ADC1，教学/性价比高，HAL 或寄存器均可驱动 | — |
| 心电采集 | AD8232（TI） | 生物信号放大器，低噪声、单电源、集成电极脱落检测 | — |
| 导联 | 单导联电极 | 成本最低，满足基本监护 | 三导联/十二导联 |
| 调试串口 | USART1（PA9/PA10） | Debug 输出，不影响数据通道 | — |
| 数据串口 | USART2（PA2/PA3） | 上传心电数据到上位机 | — |
| 采样节拍 | TIM6 | 1ms 更新中断，控制采样率与采样时长 | — |

## 4. 原理图推导（逐个模块，讲清为何需要每个元件）
- **STM32F103 最小系统**：需要 [[复位电路]]（上电/手动复位）、[[晶振与时钟电路]]（8M 主晶振 + 32.768K 走时）、[[去耦电容]]（每片电源就近 0.1µF）、[[时钟树]] 把 8M 倍频到 72M 给各外设。它内部的 [[ADC]] 直接当心电采集的量化前端，省掉外置 ADC。
- **AD8232 为何必须存在**：人体心电仅 mV 级且混有工频/肌电噪声，MCU 的 ADC 量程和噪声都不允许直采。AD8232 是真·生物信号放大器，把微弱差分信号放大到 0~3.3V 范围；它单电源即可工作（不用双电源运放方案），还集成电极检测（判断电极是否脱落）。GND/3.3V 供电，OUTPUT 接 `ADC1_IN11(PC1)`。AD8232 本身还需少量 [[RC滤波]] 外围（导联线 + 高通/低通网络）才构成完整采集模块。
- **单导联电极（RA/LA/RL）**：只用 3 个电极，把心电相对「右腿驱动」测量。为何单导联：多导联布线/成本翻倍，便携监护没必要；这是成本与精度的取舍。
- **内置 ADC1 而非外置**：12 位精度（0~4095）对波形显示足够，又省一颗芯片和接口，符合低成本定位。
- **USART2 → PC**：心跳波形数据量小，串口即可；上位机用 Python 打包成 exe。为何不上 USB：省去 USB  PHY/协议栈，硬件最简。
- **USART1 专做 Debug**：把调试打印与数据通道分离，避免互相干扰，Release 时用一个 `DEBUG` 宏整体去掉打印。
- **TIM6 定时采样**：用更新中断做节拍——采样率(次/分钟)换算成「多少 ms 采一次」，采样时长(秒)换算成「中断多少次后停」，实现精确可控的采集窗口。
- **HAL / 寄存器版本差异**：两版硬件与引脚完全一致（ADC 均接 PC1/IN11；寄存器版文字误写「12 通道」，但代码 `SQR3=11` 仍是 IN11）。差异在软件：HAL 版 ADC 用 `HAL_ADC_Start_DMA` 让 [[DMA]] 自动转运结果；寄存器版直接读 `ADC1->DR`。寄存器版明确配置了波特率 USART2=57600、USART1=115200；HAL 版由 [[CubeMX]] 生成。分层架构两版相同：驱动层（ADC/USART/TIM）+ 应用层（通讯模块、心电采集模块）+ 公共层（Debug/延时），并用 weak 函数（HAL 回调思路）解决「中断服务函数在驱动层、业务逻辑在应用层」的跨层调用问题。

## 5. 布局布线要点
- AD8232 是模拟前端，走线要远离数字部分（尤其 USART、TIM 开关噪声），模拟地/数字地单点连接。
- 3.3V 电源每个芯片就近放 [[去耦电容]]，AD8232 对电源纹波敏感。
- 电极引线尽量短、用屏蔽线，减小 50Hz 工频干扰与运动伪迹。
- 全系统 3.3V，无需 [[电平转换]]；MCU 与传感器同电源域。
- 人体电极安全第一：单电源 3.3V 且电流极小，符合便携医疗设备低漏电流要求。

## 6. 检查清单
- [ ] STM32F103 最小系统（复位/晶振/去耦）完好
- [ ] AD8232 的 3.3V 与 GND 接对，OUTPUT 接 PC1（ADC1_IN11）
- [ ] 单导联电极（RA/LA/RL）与 AD8232 接线正确
- [ ] USART1（Debug）/ USART2（数据）波特率与上位机匹配
- [ ] TIM6 采样节拍（1ms 中断）配置正确
- [ ] 上位机按「串口→采样率→采样时长」顺序设置，否则报错
- [ ] 模拟走线远离数字部分，去耦电容到位

## 7. 复盘
- 这是典型的「需求反推原理图」案例：先定「便携、低成本、实时看波形」的需求，再选 AD8232（放大）+ 内置 ADC（量化）+ 串口（上传）的最小够用组合，而不是堆料。单导联是成本取舍，内置 ADC 省芯片，串口省协议栈。软件分层 + weak 回调是大型工程保证可维护性的标准做法——下层（驱动/ISR）不直接调上层，而是通过 HAL 风格的弱函数把业务逻辑「挂」回去。
- 心电原始信号含工频/肌电噪声，固件当前直接转发原始 ADC 值、由上位机绘图；若下位机做处理可参考 [[滤波算法]]。

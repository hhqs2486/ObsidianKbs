# 硬件设计规范与评审

> 大厂把"踩过的坑"写成规范。照规范做，第一次打板就能过的概率高一个数量级。

## 1. 为什么要有规范
硬件一旦打板，改一次就是钱 + 周期。规范把 [[布局与布线]] [[DRC设计规则]] [[差分对与等长]] [[阻抗控制]] [[电源分割]] 这些分散的知识点，固化成"必须做 / 禁止做"的 checklist。

## 2. 经典规范来源（见 [[硬件电路合集资料索引]] 必备资料）
- **华为硬件工程师手册**（必备 8）：器件选型、设计流程、评审清单的总纲。
- **华为 PCB 布线规范**（必备 22）/ **上海贝尔 PCB 标准**（必备 21）/ **华硕内部 PCB 设计规范**（必备 16）：层叠、线宽、间距、禁布区、测试点。
- **Cadence/Allegro 封装与流程**（必备 15/17/18）+ **Altium Designer 使用**（必备 14）：工具落地。
- **DDR3 布局布线规则与实例**（必备 20）+ **Si9000 阻抗计算**（必备 23）：高速实战。
- **PCB 经验（论坛多年整理）**（必备 19）：民间血泪总结。
- **硬件设计法规/标准**（必备 24，压缩包）/ **硬件设计规范**（必备 25，压缩包）：合规底线。

## 3. 一份评审 checklist（工程师思维）
- [ ] 电源树：每级电压/电流余量 ≥ 30%；上电时序正确（[[线性电源LDO]] [[开关电源DCDC]]）
- [ ] 去耦：每 IC 就近 0.1 µF + 大电容（[[去耦电容]]）
- [ ] 复位 / 时钟：复位时长、时钟源稳定（[[复位电路]] [[时钟树]] [[晶振与时钟电路]]）
- [ ] 接口保护：TVS / 磁珠 / 隔离（[[EMC电磁兼容]] [[二极管与光耦]]）
- [ ] 可测试性：关键信号留测试点、JTAG/串口可达
- [ ] 热设计：功率器件散热过孔 / 铺铜足够（[[铺铜]]）
- [ ] DRC/ERC 零违例 + 工艺能力（线宽/间距/孔径）符合板厂（[[DRC设计规则]]）

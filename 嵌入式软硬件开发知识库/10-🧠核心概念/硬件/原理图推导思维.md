# 原理图推导思维

## 一句话定义
拿到功能框图后，逐模块把"信号怎么流、每个电阻电容为什么必须存在"用文字/ascii 推出来的能力——这是「照教程画」和「独立设计」的分水岭。

## 它解决什么问题 / 为什么存在
新手能照开发板抄通，但面对陌生需求就卡住，因为只会"复制连线"不懂"为何这样连"。推导思维要求每个元件都有功能性理由：去掉它会怎样？这是工程师的核心素养。

## 核心原理（大二能懂的水平）
按模块逐个推导，对每个无源件问三句话：
1. 它干什么？（限流 / 分压 / 滤波 / 上拉 / 去耦 / 阻抗匹配）
2. 为什么是这个值？（欧姆定律算的？数据手册推荐的？）
3. 去掉会怎样？（LED 烧？信号振铃？MCU 读不稳？）

常见"必解释"元件清单：
- 上拉/下拉电阻：总线空闲态谁拉高/拉低（[[上拉电阻与下拉电阻]]）
- 去耦电容：每个 IC 电源脚旁 0.1µF 就近放，滤高频噪声（[[去耦电容]]）
- 滤波 RC：模拟信号前的 [[RC滤波]]，截止频率怎么定
- 晶振负载电容：[[晶振与时钟电路]] 两端各一电容到地
- 复位电路：[[复位电路]] 上电给 MCU 一个稳定复位脉冲

给 net 起有意义的名字（VDD_3V3 / I2C_SCL / ADC_TEMP），标关键电平。

## 关键参数 / 易错点
- **易错**：抄开发板但改了供电电压却没重新算分压电阻 → 电平错。
- **易错**：去耦电容放远了（靠近电源入口而非 IC 脚）→ 高频噪声压不住。
- **易错**：未用引脚悬空 → 可能振荡/耗电，需按手册处理（拉高/拉低/设输入）。

## 类比（帮助理解）
像写作文先列提纲再填句子：框图是提纲，每个元件是一句话，推导就是"这句为什么这么写"。

## 设计时怎么用（反推思维）
功能框图 → 选主芯片([[芯片选型]]) → 模块信号链逐段推 → 每个无源件三问 → 网络命名 → 对照 [[原理图符号与封装]] 落器件 → 进 [[布局与布线]]。

# 变压器与继电器

> 两个"隔离 + 切换"老将：变压器隔交流传能量，继电器用小电流控大电流。

## 1. 变压器
- **原理**：互感。原边交变磁通耦合到副边，变比 N₁:N₂ = V₁:V₂，功率守恒（升压降流、降压升流）。
- **电源里干啥**：
  - 工频变压器：市电隔离 + 降压（笨重，逐渐被 [[开关电源DCDC]] 反激/正激取代）；
  - 高频变压器：反激 / 正激 / LLC 的储能隔离元件（[[开关电源DCDC]]），计算见《多路输出反激变压器计算表格》。
- **选型参数**：匝比、功率、绝缘耐压、漏感（漏感大会产生尖峰，需 [[MOS管与驱动电路]] 的 RC Snubber）。
- 资料：[[硬件电路合集资料索引]] 05.电源/变压器资料（15 篇）。

## 2. 继电器
- **原理**：线圈通电 → 电磁吸合触点，用小电流（MCU GPIO + 三极管/[[MOS管与驱动电路]] 驱动）控制大电流 / 高电压负载的通断。
- **关键参数**：线圈电压（5/12/24 V）、触点容量（阻性/感性负载分开看）、触点形式（NO/NC/SPDT）、寿命次数。
- **驱动注意**：
  - 线圈是电感，关断产生反电动势 → **必须并续流二极管**（[[二极管与光耦]] 的整流/肖特基）保护驱动管；
  - 触点切换感性负载要加灭弧 / RC 吸收；
  - 机械动作有抖动，控制里要消抖 / 加延时。
- **vs 固态继电器 SSR**：SSR 无触点、快、静音、寿命长，但导通压降 / 漏电流大。

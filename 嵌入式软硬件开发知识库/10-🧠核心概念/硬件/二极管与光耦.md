# 二极管与光耦

> 二极管管整流/钳位/保护，光耦做隔离——两者都是"单向通道"，但一个导电一个导电+隔干扰。

## 1. 二极管（单向导电）
- **整流二极管（1N4007 等）**：工频整流，慢。
- **肖特基（SS14 等）**：低压降（~0.3 V）、快，适合电源续流 / 防反接（见 [[MOS管与驱动电路]] 的反接保护）。
- **快恢复 / 肖特基**：开关电源续流（[[开关电源DCDC]]）。
- **稳压管 Zener**：反向击穿恒压，做基准 / 过压钳位。
- **TVS 瞬态抑制**：防静电 / 浪涌，ESD 保护首选。
- **发光二极管 LED**：指示 + 光耦发射端；限流电阻计算见 [[硬件电路合集资料索引]]（01.元器件基础知识/LED）。

## 2. 三极管（双极型，电流驱动）
- NPN/PNP 做小信号放大与开关（[[三极管开关电路]]）；与 MOS 区别见 [[MOS管与驱动电路]]。
- 贴片三极管印字看不懂？→ 《贴片三极管上的印字与真实型号对照手册》（见索引）。

## 3. 光耦（隔离传输）
- 结构：LED（输入）+ 光敏管（输出），用光传递信号，**输入输出端电气隔离**（耐压常 2.5~5 kV）。
- **用途**：
  - 高压侧与 MCU 通信（如 [[直流电机驱动]] 的故障反馈、[[开关电源DCDC]] 的反馈隔离）；
  - 数字隔离（替代慢速变压器隔离）；
  - 模拟隔离放大（线性光耦如 HCNR200，配 [[运算放大器]]）。
- **注意**：CTR（电流传输比）随温度/老化衰减，设计留余量；速度比数字隔离器（如 ADuM）慢。

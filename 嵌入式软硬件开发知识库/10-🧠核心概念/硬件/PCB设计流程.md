# PCB设计流程

## 一句话定义
> 从「产品需求」到「能拿去工厂打样的板子」的完整链路：需求 → 功能框图 → 器件选型 → 原理图 → PCB布局布线 → 打样/SMT。

## 它解决什么问题 / 为什么存在
- 新手常「照着画」：不知道每一步产出什么、下一步拿什么接着干。流程把「画板子」拆成可检查的阶段，每一步有交付物。

## 核心原理（大二能懂的水平）
- 五~六阶段（对应 `PCB设计万能提示词` 的六阶段）：需求拆解 → 功能框图 → 器件选型 → 原理图推导 → 布局布线 → 检查清单。
- 原理图阶段产出 `.sch`：逻辑连接 + 给每个元件分配封装；PCB阶段产出 `.pcb`：物理坐标 + 层 + 铜皮；最后导出 Gerber + 坐标文件给工厂。

## 关键参数 / 易错点
- 原理图没分配封装 → 导入PCB报错；忘了DRC → 工厂做不出来；BOM和原理图不一致 → 贴片错料。

## 类比（帮助理解）
- 像盖楼：需求=甲方要什么，原理图=建筑图纸（房间关系），PCB=施工图（墙厚/管线/层高），打样=施工。

## 设计时怎么用（反推思维）
> 拿到需求先画功能框图，再选器件，再画原理图（每个元件写理由），最后才进PCB。别一上来就拖元件。

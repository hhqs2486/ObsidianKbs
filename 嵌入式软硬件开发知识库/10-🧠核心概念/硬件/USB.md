# USB

## 一句话定义
USB（Universal Serial Bus，通用串行总线）是一种**主从式、差分、可热插拔**的串行接口，同时传数据+供电，是设备连电脑/手机最通用的方式。

## 它解决什么问题 / 为什么存在
早期接口五花八门、不能热插拔、还得单独供电。USB 把"即插即用 + 统一供电 + 较高速率"做到一起，主机自动枚举设备。

## 核心原理（大二能懂的水平）
- 两线差分 `D+`/`D-`；低速(1.5Mbps)/全速(12Mbps)/高速(480Mbps)由信号特征区分。
- **枚举**：插入后主机复位设备 → 读描述符(设备/配置/接口/端点) → 分配地址 → 加载驱动。
- **端点(Endpoint)** 是通信管道的一端，分 IN(设备→主机)/OUT(主机→设备)，靠端点号区分。
- STM32 多数带 USB FS(全速) 或 USB OTG（可做主也可做从）。

## 关键参数 / 易错点
- **D+ 上拉电阻(1.5k 到 3.3V)** 决定是全速还是低速，漏了就枚举不上（最常见坑）。
- 差分线走线尽量等长、控制阻抗；全速一般可不严格等长但别太长。
- 总线供电限流(500mA/900mA)，大电流设备需自供电或配置。
- 描述符写错 → 枚举失败或"未知设备"。

## 类比（帮助理解）
像墙上的万能插座：插上之后配电箱(主机)自动识别你插的是冰箱还是台灯，并分配线路。

## 设计时怎么用（反推思维）
- 需求：跟 PC 通信/虚拟串口/做 DFU 固件升级 → 用 USB。
- STM32 用 USB 外设 + CubeMX 配**CDC 类**(虚拟串口)最常用；也可做 HID(免驱)、MSC(U 盘)。
- 记得 D+ 上拉与正确的端点配置。

## 典型应用
串口下载/调试、USB 转串口、键鼠、固件 DFU 升级、U 盘式数据导出。

# EMC电磁兼容

> 产品过不了 EMC 认证（辐射/传导/静电/浪涌）就出不了厂。EMC 是"设计出来的，不是整改出来的"。

## 1. 两个问题
- **EMI（电磁干扰）**：你的板子向外发射，干扰别人。来源：开关电源振铃（[[开关电源DCDC]]）、时钟边沿（[[时钟树]]）、快速 di/dt（[[MOS管与驱动电路]] [[IGBT]]）。
- **EMS（电磁抗扰）**：别人干扰你，你扛得住。静电 ESD、浪涌、快速脉冲群。

## 2. 设计层的抑制手段
- **滤波**：电源入口加 π 型滤波 / 共模电感 + X/Y 电容；信号线串磁珠（[[无源元件基础]]）。
- **屏蔽**：金属壳 / 屏蔽罩包住辐射源；缝隙小于 λ/20。
- **接地**：低阻抗地平面（[[铺铜]]）、模拟数字单点连接（[[电源分割]]）、机壳接地。
- **布局**：高速 / 大电流回路面积最小；时钟线远离开敏感模拟（[[布局与布线]] [[差分对与等长]]）。
- **去耦**：每 IC 就近去耦（[[去耦电容]]），抑制电源噪声。

## 3. 保护器件
- **TVS / 压敏电阻**：ESD、浪涌钳位（见 [[二极管与光耦]]）。
- **磁珠 / 共模电感**：滤除共模噪声。

## 4. 规范与法规
- 国标 / 出口法规合集见《硬件设计法规（标准）》（[[硬件电路合集资料索引]] 必备资料 24）。
- 厂规参考：[[硬件设计规范与评审]]（华为 / 贝尔 / 华硕 PCB 规范）。

# MOS管与驱动电路

> 功率电子的开关核心。比三极管能扛更大电流、驱动更简单，但**门极是电容**，驱动没做对会炸管或发热。

## 1. 它是什么
MOSFET 是电压控制型器件：门极 G 对源极 S 加 Vgs 超过阈值 Vgs(th) 即导通，漏极 D→S 导通电阻 RDS(on) 仅几~mΩ。与 [[三极管开关电路]]（电流驱动、β 受限）相比，MOS 输入几乎不取电流，更适合大电流开关。

## 2. 为什么需要"驱动电路"
门极不是纯电阻，而是**栅极电容 Cg（含 Ciss/Coss/Crss）**。导通要先把 Cg 充到 Vgs(th) 以上，关断要抽干。驱动电阻 Rg 决定充放电速度：
- Rg 太小 → di/dt 过大、振铃、EMI 差、易误触发；
- Rg 太大 → 开关慢、导通损耗（开关损耗）飙升、发热。
> 实例（《MOSFET驱动电阻及吸收电路选择计算》）：IPD50N04S4L-08，Id=50 A，Vgs=16 V，Qg=23 nC，Cg≈1.92 nF，Vg=12 V，fs=10 kHz → 计算 **Rg≈4.09 Ω**，Tr/Ton≈0.04（要求 < 1/20）。

## 3. 典型驱动结构
- **低端驱动**：N-MOS 在负载下方，G 直接由 MCU/驱动 IC 拉高即可（最常用，如 [[直流电机驱动]] 半桥下管）。
- **高端驱动**：N-MOS 在电源侧，S 极电位随开关跳动 → 需**自举电路 / 隔离电源 / 专用半桥驱动 IC（IR2104/2106、EG2130）**把 G 抬到 Vcc+Vgs。
- **栅极电阻 + 加速二极管**：开通用 Rg，关断并联二极管旁路一部分降低 Rg，实现"快关慢开"抑振铃。
- **门极负压关断 / 米勒钳位**：大功率场合防 dv/dt 误开通。

## 4. 吸收与保护（RC Snubber）
开关瞬间寄生电感 Lp 与 MOS 输出电容 Coss 谐振产生尖峰。RC 吸收设计（《MOSFET驱动电阻及吸收电路选择计算》）：
1. 从 datasheet 取寄生电容 Cp（用 Sync-FET 的 Coss 估算）；
2. 示波器测无吸收振铃频率 Fp；
3. Lp = (1 / (2π·Fp·√Cp))²；
4. Csnub 取 Cp 的 ½~2 倍；
5. **Rsnub = ½·√(Lp/Cp)**（并联 LCR 最优阻尼）。
另见 [[IGBT]] 类大功率驱动（《IGBT门极驱动设计规范》，见 [[硬件电路合集资料索引]] 必备资料 30；IGBT 基础另见该索引 §一 05.电源/IGBT基础知识及应用）。

## 5. 布局要点
- 驱动回路面积尽量小，G 走线短而粗，减少 Lw（走线寄生电感，实例取 20 nH）。
- 功率回路（D-S-负载-电源）独立铺铜、加足够过孔散热。
- 栅极 10~100 Ω 电阻紧贴 MOS 管引脚。

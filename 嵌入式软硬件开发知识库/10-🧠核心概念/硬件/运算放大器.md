# 运算放大器

> 模拟电路的基石。把微弱信号放大 / 加减 / 积分微分 / 比较，几乎所有模拟前端都绕不开它。

## 1. 它是什么
运算放大器（Op-Amp）是一个**高增益差分电压放大器**：输出 ≈ A₀·(V⁺ − V⁻)，开环增益 A₀ 通常 > 80 dB（≥ 10⁴ 倍），输出摆幅约 ±10~14 V。理想特性：输入电阻无穷大、输出电阻≈0、带宽无穷大、失调=0。

## 2. 两个核心武器：虚短 & 虚断
分析任何运放电路，先忘掉"同向/反向放大器"这些公式，只用这两招（来自《运算放大器应用介绍》）：
- **虚短**：线性区里 V⁺ ≈ V⁻（因 A₀ 极大，差模输入不足 1 mV 就饱和）。≠ 真短路。
- **虚断**：输入电流≈0（输入电阻 > 1 MΩ，偏置电流 < 1 µA）。≠ 真断路。
> 用虚短定电位、虚断列 KCL，所有经典电路都能现场推出来，不用背公式。

## 3. 经典电路（虚短虚断现场推）
| 电路 | 关系 | 要点 |
|---|---|---|
| 反向放大 | Vout = −(R2/R1)·Vin | 同相端接地=0，R1/R2 串流相等 |
| 同向放大 | Vout = (1+R2/R1)·Vin | 输入阻抗极高，常用做缓冲 |
| 加法器 | Vout = −(V1/R1+V2/R2)·Rf | 反相端虚地叠加 |
| 减法器 | Vout = (V2−V1)·R2/R1 | 需 R1=R2 对称 |
| 积分 | Vout = −(1/R1C1)∫Vin dt | 反馈电容，斜坡发生 |
| 微分 | Vout = −R1C1·dVin/dt | 噪声敏感，工程少用纯微分 |

## 4. 工程师必须懂的实战参数
- **输入失调电压 Vos / 偏置电流 Ib**：直流精度杀手，高精度先选低 Vos 运放 + 对称电阻。
- **带宽 GBW 与压摆率 SR**：大信号看 SR，小信号看 GBW；**增益带宽积恒定**，闭环增益↑则带宽↓。
- **稳定性**：容性负载 / 高反馈电阻易自激振荡 → 用「噪声增益」分析法，必要时输出端串 Riso 或加反馈超前补偿（《运算放大器稳定性分析》）。
- **电源去耦**：每片运放电源脚就近 0.1 µF + 1~10 µF，模拟地单点连接（参见 [[去耦电容]] [[铺铜]]）。
- **选型**：通用（LM358/OPA）、精密（OPA2188）、轨到轨（MCP6002）、高速（ADA4807）、仪表放大（AD620/INA），见《你好，放大器》《运算放大器权威指南》《运放参数详细解释合集 1-25》。

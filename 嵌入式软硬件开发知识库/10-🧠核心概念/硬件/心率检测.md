# 心率检测（Heart Rate / HR）

> 用嵌入式手段把「每一次心跳」变成一个数（BPM）。和 [[心电ECG采集]] 同源但更轻量：ECG 看 P-QRS-T 全波形，心率检测只取「每分钟几次」。

## 一句话定义
心率 = 每分钟心脏搏动次数（成人静息 60~100 bpm）。嵌入式里通常两条路线：
- **PPG 光电容积脉搏波**（最常用）：LED 照皮肤 → 血液容积随心跳变化 → 光电二极管收光强 → ADC 采样。
- **ECG R 波计数**：从 [[心电ECG采集]] 的 QRS 波群里找尖峰 R，数 R 的个数。

## 为什么存在
手表/手环/血氧仪都要「无创、持续」测心率；纯计时器做不了，必须靠生物信号。

## 核心原理（PPG 路线）
1. 绿光 LED（~530nm）透/反照皮下，血液吸光随心室泵血周期性变化 → 得到与脉搏同步的交流信号 + 直流基线。
2. 前端用 [[运算放大器]] 做 **I-V 转换 + 带通**（0.5~5Hz，滤掉呼吸/运动伪迹），再经 [[RC滤波]]。
3. MCU 用 [[ADC]] 以 ≥50Hz 采样（项目合集里「数据采集+心率检测仪」即用 STM32 ADC + DMA 抓波形）。
4. **峰值检测算法**：找局部极大值 → 相邻峰间隔 Δt → HR = 60/Δt；工程上常用「移动平均 + 阈值 + 反射窗」抑制双峰。
5. 运动干扰大时叠加 [[滤波算法]]（小波/自适应滤波）或靠加速度计补偿。

## 关键参数·易错点
- 采样率太低（<30Hz）会漏搏；绿光比红光 SNR 好但受肤色/ tattoo 影响。
- PPG 直流漂移严重 → 必须隔直（高通 ~0.5Hz），否则峰值检测锁不住。
- LED 驱动电流要稳，否则光强噪声直接进信号；常加 [[去耦电容]]。
- 指夹/腕部接触压力变化会产生运动伪迹，是心率检测第一难题。

## 类比
像 [[超声波测距]] 一样「发一个波、收一个回波、数间隔」——只不过这里发的是光、收的是血流容积波。

## 设计时怎么用（反推思维）
要测心率 → 选 PPG 还是 ECG？消费级选 PPG（省电、无创）；医疗级要 ECG。→ PPG 需要 LED 驱动 + 光电接收 + 低噪声运放 + ADC + 峰值检测固件。

## 典型应用
手环/手表、指夹血氧仪（SpO₂ 同源）、项目合集「数据采集+心率检测仪」「老人健康监测智能手表」。

# IGBT

> 绝缘栅双极晶体管。MOS 的输入 + BJT 的输出，扛得住高压大电流，是电机驱动 / 逆变器 / 充电桩的"主力开关"。

## 1. 它是什么
IGBT = 绝缘栅（MOS 栅极，电压驱动、输入阻抗高）+ 双极结（BJT 输出，导通压降低、耐大电流）。介于 [[MOS管与驱动电路]]（快、中小功率）和 GTR（耐流但电流驱动）之间，专攻 **600 V~6.5 kV、几十~几百 A** 的高压大功率场景（变频器、逆变焊机、电动汽车、光伏/储能逆变器）。

## 2. 为什么需要专门驱动（不像 MOS 随便推）
- 门极本质还是电容（有 QG 门极电荷），需要**隔离 + 电平转换 + 功率放大**的驱动电路。
- 经典比喻（IGBT 门极驱动规范）：控制电路是"大脑"，功率电路是"手脚"，**驱动电路是连接大脑和手脚的脊椎和神经**——驱动设计好坏直接决定整机可靠性。
- 开关瞬间 di/dt、dv/dt 极大 → 强 EMI（[[EMC电磁兼容]]）+ 易产生关断过压尖峰，必须精心设计。

## 3. 驱动设计实例（门极驱动规范，模块 SKM 400 GB 126 D）
- 开关频率 fsw = 10 kHz；门极电阻**不能小于厂家"测试过的最小值"**（该模块 = 2 Ω），否则振荡 / 过冲。
- **开通 / 关断用不同电阻**：Ron = 2 Ω（快开），Roff = 5 Ω（慢关，降低关断过压尖峰）。
- 门极电压：VGG+ = +15 V，VGG− = **−8 V**（负压关断，防米勒效应误开通）。
- 门极电荷 QG = 2230 nC；据此算驱动能力：
  - 平均门极电流 **IoutAV = QG · fsw = 2230 nC × 10 kHz = 22.3 mA**
  - 峰值门极电流 **Ig.puls ≈ ΔV / (RG + Rint) = 23 V / (2+2)Ω = 5.75 A**（ΔV = VGG+ − VGG− = 23 V）
- 选型底线：驱动 IC 须满足 QG / IoutAV / Ig.puls / fsw / VCE(1200 V) / 通道数。

## 4. 功率分级怎么选驱动
- 小功率（220 V 级）：自举驱动 / 高频脉冲变压器 / 直流电压驱动
- 中功率（400 V 级）：自举 + 光耦隔离
- 大功率（690 V 级）：隔离脉冲变压器 + 复杂驱动；用 **Vce 饱和压降做过流检测 + 软关断（soft turn-off）+ 开通/关断分阻**

## 5. 保护要点（与 [[MOS管与驱动电路]] 同源但更狠）
- **过压抑制**：关断 di/dt 在杂散电感上感应 L·di/dt 尖峰 → RC Snubber / 有源钳位。
- **短路 / 过流**：退饱和检测（desat）+ 软关断，避免直通炸管。
- **负压关断**防误触发；**米勒钳位**抑制 dv/dt 误开通。
- 散热：导通损耗 + 开关损耗大，需足够散热片 / 直接铜键合（DBC）基板。

## 6. 与库内其它卡
- 对比 [[MOS管与驱动电路]]：IGBT 稍慢但耐压/耐流高一个量级；MOS 适合高频中小功率（[[直流电机驱动]] [[开关电源DCDC]]）。
- 开关噪声 → [[EMC电磁兼容]]；驱动隔离 → [[二极管与光耦]]。

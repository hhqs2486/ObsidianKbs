# 芯片选型

## 一句话定义
在 STM8 / STM32 全系里，按"内核 / Flash / RAM / 外设 / 封装 / 价格"挑出最合适型号的过程——选型定生死，是硬件设计的第 0 步。

## 它解决什么问题 / 为什么存在
选小了后期加功能崩（Flash/RAM 不够），选少了要外加芯片（没 CAN/USB/以太网），封装错了板子画不下。选型表(Selection Chart)把全系参数拉成一横表，一眼比对。

## 核心原理（大二能懂的水平）
ST 选型表每行一个 Part Number，列是：CPU(内核+主频)、Program Memory(Flash)、RAM、定时器(通用/高级/16位 IC·OC·PWM)、通信接口(SPI/I²C/USART/USB/CAN/SDIO/以太网)、模拟(ADC 通道/DAC)、I/O 数、封装。
- 系列按内核分：**F0**(Cortex-M0, 48M) / **F1**(M3, 72M) / **F4**(M4+FPU, 168M)。
- F1 子系列：Access / USB / Performance / Connectivity Line；带 FSMC(外部存储控制器)、双看门狗、电池保持 RTC。
- 注意"型号尾巴"：C8T6=中等容量 LQFP48；xCxDxE=大容量；Z=144 脚。

## 关键参数 / 易错点
- 电压范围：F0 为 1.8~3.6V，F1/F4 为 2.0~3.6V。
- Flash 16K~1M，RAM 4K~192K+4K(CCM 内核耦合内存，F4)。
- 只有 F4 互联型带以太网/USB HS；CAN 为 2.0B。
- **易错**：只看主频不看 RAM → 跑 FreeRTOS 栈爆；只看引脚数不看封装焊接难度。

## 类比（帮助理解）
像配电脑——先定预算(价格)和用途(要以太网?要 FPU 做 DSP?要几路串口?)，再看 CPU/内存/接口够不够，最后定具体型号。

## 设计时怎么用（反推思维）
需求(要 FPU 做信号处理 / 要以太网 / 要多少路 UART) → 圈定系列(F4/F1) → 选型表比对 Flash/RAM/封装/引脚数 → 定 Part Number → 再查**数据手册**确认电气与引脚。

## 典型应用
学生项目(F103C8T6 最小系统)、带屏带网络的网关(F407+以太网)、低成本 M4(F411)。

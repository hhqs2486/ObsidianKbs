# 模拟电路基础

> 数字工程师的"另一半世界"：连续信号、噪声、带宽、反馈。不懂模电，传感器信号链就调不好。

## 1. 三大支柱
- **放大**：以 [[运算放大器]] 为核心，电压/电流/功率放大，增益由负反馈定（虚短虚断）。
- **负反馈**：把输出按比例送回输入，牺牲增益换**稳定、线性、带宽、低失真**。运放几乎所有实用电路都靠负反馈。
- **频率响应**：增益随频率变化，有转折频率 / 极点 / 零点；Bode 图是分析稳定与滤波的基本工具 → 与 [[RC滤波]] [[无源元件基础]] 紧密关联。

## 2. 信号链典型流程
传感器 → 调理（放大/滤波，[[运算放大器]] [[RC滤波]]）→ 采样（[[ADC]]）→ 数字处理。
例：[[心电ECG采集]] 用仪表放大 + 右腿驱动 + 50 Hz 陷波；[[ADS1115]] 是精密 ADC 前端。

## 3. 必懂的"坑"
- **噪声**：电阻热噪声、运放电压/电流噪声、1/f 噪声；低噪声先选低噪声运放 + 减小电阻值。
- **失调与温漂**：高精度直流放大先看 Vos / dVos/dT。
- **阻抗匹配**：信号源内阻 vs 放大器输入阻抗，否则分压失真。
- **电源与地**：模拟 / 数字地分离、单点连接（[[铺铜]] [[电源分割]]），否则数字噪声串进模拟。

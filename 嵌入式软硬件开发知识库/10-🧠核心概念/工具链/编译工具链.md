# 编译工具链

## 一句话定义
把 `.c` 源码变成可在芯片/电脑上跑的程序的**编译器 + 集成开发环境(IDE)** 组合。本卡覆盖资料包 `C语言编译软件及工具`（620MB 安装包）与嵌入式常用的 Keil/IAR。

## 为什么存在
不同目标平台用不同工具链：51 单片机认 Keil C51，STM32 认 ARM-GCC/Keil MDK，PC 学习用 CodeBlocks/Dev-Cpp/VS。选错工具链，代码根本编不过。

## 编译四步（所有工具链通用）
1. **预处理**：展开 `#include`、宏（`#define`）、条件编译 → `.i`
2. **编译**：C 语法→汇编 → `.s`
3. **汇编**：汇编→机器码 → `.o`/`.obj`
4. **链接**：把多个 `.o` + 库拼成可执行/固件（分配地址、解析符号）→ `.hex`/`.elf`/`.exe`

## 常见工具链对照
| 目标 | 工具链/IDE | 编译器后端 | 资料包里的安装包 |
|---|---|---|---|
| 51 单片机 | Keil μVision(C51) | C51 | — |
| STM32/ARM | Keil MDK / STM32CubeIDE / IAR | ARMCC / arm-none-eabi-gcc | — |
| PC 学习(C) | Code::Blocks | 自带 MinGW(GCC) | codeblocks-16/17-mingw |
| PC 学习(C) | Dev-Cpp | TDM-GCC 4.9.2 | Dev-Cpp 5.11 |
| 老教材 | VC6.0 | MSVC | VC6.0(32&64bit) |
| 现代 Windows | Visual Studio 2019 | MSVC | VS2019(+安装教程) |
| 交叉编译核心 | GCC | `arm-none-eabi-gcc` | — |

> 资料包含 `Devc++使用教程.docx`、`VC6.0安装教程.docx`、`Vs使用教程.docx` 等图文教程（见 [[C语言资料包索引]]）。

## 设计时怎么用（反推思维）
- 学 C 语法：Dev-Cpp/CodeBlocks 最轻量；
- 做嵌入式：直接上 Keil/STM32CubeIDE，因为要烧录+调试+配时钟（见 [[CubeMX]] [[STM32F103]]）；
- 理解"为什么改一行要重编整个工程"→ 回到 [[C语言编码规范]] 的头文件依赖。

## 烧录与调试（另一半）
编译器只管**生成**固件；真正把 `.hex`/`.bin` 灌进芯片、并单步看变量，要靠**下载器 / 调试器**（J-Link / ST-Link / DAP-Link / 串口 ISP）。详见 [[下载器与调试器]]。

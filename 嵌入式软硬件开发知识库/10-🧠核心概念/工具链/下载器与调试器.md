# 下载器与调试器

## 一句话定义
把编译好的固件（`.hex` / `.bin` / `.axf`）**写进 MCU 的 Flash**，并能在运行时**暂停 / 单步 / 看寄存器变量**的硬件 + 软件组合——即「下载器（编程器）+ 调试器」。

## 为什么存在
芯片出厂是空的，必须先灌固件才能跑；裸机调 bug 不能靠满屏 `printf`，得用调试器单步、看内存、设断点。「编译工具链」只管**生成**固件，下载 + 调试是另一半（见 [[编译工具链]]）。

## 核心原理
**调试接口**：Cortex-M 主流用 **SWD**（2 线：SWCLK + SWDIO，省引脚）；老标准是 **JTAG**（5 线，少用在小封装上）。两者都能烧录 + 调试，SWD 更省 IO。

**常见下载器 / 调试器对照**（均来自本资料包）：

| 名称 | 接口 | 适用 | 资料包位置 |
|---|---|---|---|
| J-Link（SEGGER） | SWD / JTAG | 全 Cortex-M，全功能调试，贵但稳 | `J-LINK驱动` |
| ST-Link V2 | SWD | STM32 官方调试器，便宜好用 | `ST-LINK_V2驱动` |
| DAP-Link / CMSIS-DAP | SWD + 虚拟串口 | 开源，常直接焊在开发板上 | （开发板内置） |
| 串口 ISP（mcuisp / FlyMcu） | UART | 免下载器烧录，**无调试能力** | `烧录工具/mcuisp.exe` |
| STVP（ST Visual Programmer） | SWD / JTAG | ST 官方编程器（随 STVD 工具集） | `烧录工具/sttoolset-STVD` |
| STC-ISP | UART | STC 系列 51 单片机 ISP | `烧录工具/stc-isp-15xx-v6.88.exe` |

**SWD 典型接线**：`SWCLK`、`SWDIO`、`GND` 必接；`3V3`（给下载器取电，可选）、`NRST`（复位，可选）。

## 关键参数·易错点
- **Boot0 / Boot1 电平决定启动源**：做串口 ISP 时需把 **Boot0 拉高**（从系统存储器启动），正常跑用户程序则拉低。
- 驱动没装 → IDE 找不到设备；`SWDIO` / `SWCLK` 接反 → 连不上；晶振没起振 → 连不上（先确认时钟）。
- 目标板务必与下载器**共地（GND 相连）**。

## 设计时怎么用（反推思维）
- 选开发板：带板载 DAP-Link / ST-Link 的最省事，一根 USB 又调又烧。
- 自己画板：一定要留 **4-pin SWD 座**（标 `SWCLK / SWDIO / GND / 3V3`），否则没法调试。
- 量产烧录：用 ST-Link 或串口 ISP（mcuisp）都可以，ISP 无需专用硬件。

## 典型应用
- 学习阶段：ST-Link V2 + STM32F103 最小系统（见 [[STM32F103]] [[CubeMX]]）。
- 量产：mcuisp 走 UART 批量烧录（ISP 走串口，见 [[UART]]）。

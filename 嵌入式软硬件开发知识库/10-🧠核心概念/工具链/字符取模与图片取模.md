# 字符取模与图片取模

## 一句话定义
把**汉字 / ASCII / 图片**变成 LCD 能直接刷的 **C 字节数组**的小工具——做显示屏 UI 的必备前处理。屏幕只认点阵数据，人只能写汉字，取模软件负责「翻译」。

## 为什么存在
`"中"` 字在屏上是一堆点，取模软件按你设的点阵把它编码成 16/32 字节的数组，驱动代码直接 `for` 循环刷出去就行。没有它，每个字都得手点。

## 核心工具（资料包里都有）
- **PCtoLCD2002**（字符取模）：汉字 / ASCII → 点阵数组（见 `字符取模软件`）
- **Image2Lcd**（图片取模）：bmp 图片 → C 数组（见 `字符取模软件/1-图片取模软件`）

## 关键设置（取自资料包内 3 篇取模教程 docx，均已入库）
**字符模式（PCtoLCD2002）**：
- 模式选「字符模式」；点阵按需求设：16×16 汉字、8×16 ASCII（字节数 = 宽×高÷8）。
- 「选项」里设：**阴码 / 阳码**（亮点为 1 还是 0）、**取模方向**（横向 / 纵向、顺向 / 逆向）、**行列式**（列行式 / 行列式）。
- 生成后复制到例程 `lcdfont.h` 的字模数组里（每个字模前加汉字名 + 双引号 + 逗号）。

**图片模式（Image2Lcd）**：
- 先用画图软件把图片转成 **16 色 bmp**；设输出数据类型 / 扫描模式 / 输出灰度；
- 16 位彩色数据排列为 **红-绿-蓝**；勾选**高位在前**；注意该软件**只能缩小不能放大**；
- 生成数组复制到例程 `pic.h`。

## 关键参数·易错点
- **取模方向**与 LCD 驱动代码读取方向不一致 → 显示乱码 / 错位；
- **阴 / 阳码**反了 → 字反白（黑底白字）；
- **字宽 × 字高**与数组字节数不匹配 → 整行错位。

## 设计时怎么用（反推思维）
- 先确定屏的驱动方式是「按列刷」还是「按行刷」，再设取模方向，二者必须对应；
- 常用字做一张 `lcdfont.h` 字库，特殊图单独 `pic.h`，别混在一起。

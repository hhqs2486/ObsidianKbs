# 链表

## 一句话定义
链表是用"节点 + 指针"串起来的线性结构：每个节点 = 一块数据 + 一个指向下一节点的地址（见 [[指针与内存]]）。

## 它解决什么问题 / 为什么存在
[[数组与字符串]]长度固定、插入删除要整体搬移元素。链表让"增删"只改指针（O(1)），且能动态 `malloc` 内存，不受固定大小限制——适合元素个数多变、频繁增删的场景。

## 核心原理（大二能懂的水平）
节点用 [[结构体与位域]] 定义：`{数据; struct node *next;}`。单链表像火车：车厢=节点，挂钩=next，访问某节要从车头遍历。三种变体：
- 单链表：next 单向。
- 单循环链表：尾节点 next 回头节点（尾->next=h）。
- 双链表：多一个 prior 指针，可前后遍历。
操作核心：头插法（`p->next=h->next; h->next=p`）和删除（前驱 next 跳过目标，再 `free`）。

## 关键参数 / 易错点
- 头结点通常**不参与运算**；循环链表头结点参与运算，删头结点要返回新头。
- `free` 之后必须停止访问该节点，否则非法内存访问。
- 改指针顺序写错会断链 / 丢节点。

## 类比（帮助理解）
一列火车车厢，每节记着下一节在哪；加 / 拆一节只改挂钩，不用把整列车重排。

## 设计时怎么用（反推思维）
要频繁增删、不在意按下标取数 → 选链表；要 O(1) 随机访问 → 反而用 [[数组与字符串]]。内存紧张怕碎片 → 倾向顺序表。

## 典型应用
约瑟夫问题（循环链表）、内核链表、栈 / 队列的链式实现（见 [[栈与队列]]）。

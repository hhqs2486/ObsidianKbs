# C语言
## 一句话定义
C 是一门贴近硬件、以"过程 + 内存"为核心的高级系统编程语言，由 Dennis Ritchie 在 1972–1973 年基于 B 语言为 UNIX 设计。

## 它解决什么问题 / 为什么存在
早期底层软件用汇编写，难移植、难维护。C 在"够贴近硬件"和"够好写"之间取得平衡：既能直接操作内存/寄存器，又有函数、类型等抽象，于是成为操作系统、驱动、嵌入式、数据库的事实标准语言。PDF 强调："去除指针，C 其实不难"——指针才是门槛。

## 核心原理（大二能懂的水平）
程序从 `main` 函数入口开始；编译四步（预处理→编译→汇编→链接）把 `.c` 变成可执行文件；变量本质是内存里带类型的一块空间；类型决定"占几个字节、怎么解释这些位"。C 标准演进 C89→C99→C11→C17，越新越多特性（如 C99 支持变量定长数组、`//` 注释）。

## 关键参数 / 易错点
- 指针是公认难点，需单独攻克（见 [[指针与内存]]）。
- `char` 越界会出错：`char c1=129;` 超出 -128~127；`unsigned char c2=-1;` 也会越界。
- 类型大小随平台/编译器变化：`long` 在 Windows MinGW 占 4 字节，在 Linux 64 位占 8 字节。写跨平台代码别假定长度。

## 类比（帮助理解）
把内存想成带编号的储物柜，变量是柜子，类型说明柜子多大，指针是写着柜子编号的纸条。C 让你既能直接用柜子，也能拿着纸条去别的柜子取东西。

## 设计时怎么用（反推思维）
嵌入式里 C 几乎绕不开：读写寄存器、做位操作、控制时序。学习路线建议——先吃透 [[指针与内存]] 和内存模型，再上 MCU；把重复操作封装成函数（[[函数与栈]]）。

## 典型应用
操作系统(Linux/Windows)、驱动、嵌入式固件、数据库(MySQL/Redis)、游戏引擎。

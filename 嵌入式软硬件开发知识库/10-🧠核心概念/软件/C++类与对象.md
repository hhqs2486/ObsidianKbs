# C++类与对象

## 一句话定义
> 类（class）是 C++ 将数据和对数据的操作封装在一起的核心语言机制，类是对象的模板，对象是类的实例。与 C 的结构体不同，类支持访问控制、成员函数、构造函数/析构函数和继承。

## 它解决什么问题 / 为什么存在
- C 语言的数据和操作是分离的（struct + 外部函数），大型项目中维护一致性困难，容易误改内部数据。
- 类通过封装（private/protected/public）强制"数据只能通过公开接口访问"，类是比 struct 更强的抽象边界。
- 嵌入式 C++ 项目中常用类封装驱动、协议栈、状态机，提高代码可维护性。

## 核心原理（大二能懂的水平）
- **类 = 数据成员（属性） + 成员函数（方法） + 访问控制**
- 构造函数在对象创建时自动调用（初始化），析构函数在对象销毁时自动调用（清理资源）。
- `public`：任何人都能访问；`private`：只有类的成员函数能访问；`protected`：只有类和子类能访问。
- 示例：GPIO 引脚类封装
  ```cpp
  class GpioPin {
  private:
      uint8_t pin_;
      GPIO_TypeDef* port_;
  public:
      GpioPin(uint8_t pin, GPIO_TypeDef* port) : pin_(pin), port_(port) {
          // 初始化时钟、模式
      }
      void setHigh() { port_->BSRR = (1 << pin_); }
      void setLow()  { port_->BSRR = (1 << (pin_ + 16)); }
  };
  ```

## 关键参数 / 易错点
- **this 指针**：每个非静态成员函数隐含一个指向当前对象的 `this` 指针。
- **栈对象 vs 堆对象**：`GpioPin p(13, GPIOA)` 在栈上，花括号结束自动析构；`new GpioPin(13, GPIOA)` 在堆上，必须 `delete`。
- **默认生成的函数**：如果没写构造/析构/拷贝，编译器会生成默认版本。嵌入式设备要考虑拷贝开销。
- **初始化列表 vs 赋值**：构造函数用 `: member_(val)` 初始化列表比在函数体赋值效率高（直接构造，避免先默认构造再赋值）。

## 类比（帮助理解）
- C 的 struct 像开放式工具箱 — 所有人都能直接拿工具、放工具。C++ 的 class 像封装的芯片 — 只有公开的引脚可以交互，内部实现被封装保护。

## 设计时怎么用（反推思维）
> 做嵌入式外设驱动封装时，每个外设（UART、SPI、I²C）用一个类封装，利用构造/析构自动管理时钟和 GPIO 初始化和去初始化（RAII 思想），降低漏关资源的 bug 风险。

## 典型应用 / 我在哪见过
- Arduino/C++ 库：`Serial.begin()`, `Wire.begin()` 都是类的静态/成员方法
- STM32 C++ HAL 封装：`class UART { void send(char* data); }`
- 状态机：用类的成员变量保存状态，成员函数处理状态转换
- ROS（机器人操作系统）中大量使用 C++ 类封装节点

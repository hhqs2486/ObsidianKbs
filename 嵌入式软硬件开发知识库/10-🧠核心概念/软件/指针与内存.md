# 指针与内存
## 一句话定义
指针是"存放内存地址的变量"；内存是按字节编号的连续存储，地址就是每个字节的编号。

## 它解决什么问题 / 为什么存在
C 让你绕过变量名直接操作地址：① 间接读改写数据；② 在函数间传递大块数据（不拷贝）；③ 动态分配内存；④ 映射并操作硬件寄存器。这是 C 区别于纯"值语义"语言的根本能力。

## 核心原理（大二能懂的水平）
- 每个字节一个地址；变量占多字节，取首地址作为变量地址。
- `&` 取地址、`*` 取值，二者互为逆运算。
- 指针加减 n 实际移动 `n * sizeof(指向类型)` 字节（如 int 指针 +1 走 4 字节）。
- 32 位系统指针占 4 字节、64 位占 8 字节，**与指向类型无关**。
- 两指针相减得到"相隔元素个数"，不是地址差值。
- 野指针（定义不初始化）写操作会触发段错误（非法内存）。

## 关键参数 / 易错点
- 指针类型决定"一次看几个字节、如何解释位"；不同类型指针不能直接运算，需强转。
- 指针运算只支持算术/关系/赋值；可与 0 比较判空。
- 数组名是地址**常量**（不可改），指针变量是**变量**（可改）。
- 字符指针指向字符串常量时**不能修改内容**（见 [[数组与字符串]]）。

## 类比（帮助理解）
内存是酒店楼层，每个房间(字节)有房号(地址)；指针是写着房号的房卡，`*` 是用房卡开门看房间里住的人。房卡本身也占一个位置（指针变量占 8 字节）。

## 设计时怎么用（反推思维）
- 数组名即首地址，遍历可用 `a[i]` / `p[i]` / `*(a+i)` / `*(p+i)` 四者等价（[[数组与字符串]]）。
- 函数想改实参 → 传指针（[[函数与栈]] 的地址传参）。
- 操作寄存器用 `volatile` 指针（补充：PDF 未详述 volatile，但嵌入式必用，防止编译器优化掉对硬件的重复读）。

## 典型应用
数组遍历、字符串处理、函数地址传参、[[链表]]/[[树]] 等动态结构、硬件寄存器映射。

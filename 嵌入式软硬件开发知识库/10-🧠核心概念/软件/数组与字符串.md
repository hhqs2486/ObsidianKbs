# 数组与字符串
## 一句话定义
数组是"同一类型、连续存储"的元素集合（下标从 0）；C 中字符串是以 `'\0'` 结尾的一维 `char` 数组。

## 它解决什么问题 / 为什么存在
需要批量存放同类型数据（矩阵、采样缓冲区、查表）时用数组；文本用"字符数组 + 结束符"统一处理，标准库据此提供一整套字符串函数。

## 核心原理（大二能懂的水平）
- 一维数组在内存中连续；数组名是首地址**常量**（不能 `a++`）；`a[i]` 等价于 `*(a+i)`。
- 二维数组按**行序优先**铺成一维存放（先填满第 0 行，再第 1 行…）。
- C **不检查数组越界**，越界访问可能引发段错误（且报错滞后、难定位）。
- 字符串靠 `'\0'` 标记结尾：`strlen` 遇 `'\0'` 停止且**不含** `'\0'`；`%s` 输出遇第一个 `'\0'` 结束。
- 三者的区别：`'\0'` = 字符 0 = ASCII 0；`'0'` = ASCII 48；`0` = 整数 0。

## 关键参数 / 易错点
- 字符串不能整体赋值，`str1 = str2` 非法，必须用 `strcpy`；比较必须用 `strcmp`（不能用 `==`）。
- 字符指针 `char *p="abc"` 指向**常量串**，不可通过 `*p` 修改；字符数组 `char s[]="abc"` 内容可改（见 [[指针与内存]]）。
- C99 允许用变量定长数组，但越界仍不报错。

## 类比（帮助理解）
数组像一排带号储物格；字符串是最后一格放"结束牌"(`'\0'`)的一排——别人看到结束牌就知道到头了。

## 设计时怎么用（反推思维）
- 遍历四种等价写法：`a[i]` / `p[i]` / `*(a+i)` / `*(p+i)`。
- 字符串处理用库：`strcat`(拼接)/`strcpy`(拷贝)/`strlen`(长度)/`strcmp`(比较)/`strncmp`(前 n 比较)。
- 缓冲区留 1 字节给 `'\0'`。

## 典型应用
数据缓冲区、查表、[[排序与查找]]（冒泡/选择排序）、字符串解析、协议帧。

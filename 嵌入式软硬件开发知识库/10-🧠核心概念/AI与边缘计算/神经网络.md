# 神经网络 (Neural Network / ANN)

## 一句话定义
受生物神经元启发的一类计算模型：由**层（输入层/隐藏层/输出层）+ 大量神经元 + 非线性激活函数**组成，通过学习把输入映射到输出。

## 核心结构
- **神经元 / 节点**：对加权输入做线性组合再经激活函数（如 ReLU、sigmoid）。
- **层**：输入层 → 若干隐藏层 → 输出层。
- **深度前馈网络 (Deep Feed-Forward Network, DNN)**：多层全连接，信息单向前向传播，是最基础的深度网络。
- **权重 (weights) / 偏置 (bias)**：可学习的参数。

## 怎么"学习"
1. 前向传播算预测；
2. 用 [[损失函数]] 算预测与真值的差距；
3. [[反向传播]] 用链式法则算每个参数对损失的梯度；
4. [[优化器]] 沿梯度更新参数。

## 变体（本书主线）
- [[卷积神经网络CNN]]：图像，利用稀疏连接、权值共享、等变表示。
- [[循环神经网络RNN]]：序列，隐藏状态跨时间步传递。
- [[二值神经网络]]：权重激活都 ±1 的极端量化网络。
- 训练细节见 [[反向传播]]、[[损失函数]]、[[优化器]]。

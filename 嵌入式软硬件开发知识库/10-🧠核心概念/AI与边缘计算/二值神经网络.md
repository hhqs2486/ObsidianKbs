# 二值神经网络 (Binary Neural Network / BNN)

## 一句话定义
权重**和**激活都被约束为 **+1 / −1** 的极端量化网络，是 QNN 的最简形式，专为超低功耗设计。

## 核心机制（书 ch6.1）
- 数字表示：`1b'0` = −1，`1b'1` = +1。
- 因为内部值只有 ±1，**乘法退化为一次 XNOR**，卷积输出可写成：
  `O[f][x][y] = POPCOUNT( XNOR(I, W) ) + B`
  即"异或非 + 人口计数"，极省硬件。
- **训练时仍用浮点**权重/激活算梯度（保证可学），推理时走 1-bit。

## 为什么重要
权重激活都 ±1 是 QNN 的**终极形式**，在 ultra-low-power 应用上带来显著能效收益（书 ch3 论证）。

## 典型芯片：BINAREYE（书 ch6）
- 面向 **always-on 可穿戴平台**的简单"唤醒"任务，单分类能耗是首要指标。
- 两种实现：**数字**版本（BinarEye digital, SX）与**混合信号**版本（MSBNN, 256× 实现）。

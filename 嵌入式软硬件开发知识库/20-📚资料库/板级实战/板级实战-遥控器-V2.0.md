# 遥控器 V2.0 — 原理图精讲

## 这块板是干嘛的（需求）

这块板的**核心需求**是：做一个**手持无线遥控器**，用来远程操控平衡车 / 智能车。它不是「开发板」而是一个**完整的嵌入式终端产品**：

| 用户需求 | 硬件实现 |
|---------|---------|
| 手持便携 | 内置锂电池 + Type-C 充电 |
| 双摇杆控制 | 两路摇杆（L/R 各 X/Y 轴）→ 4 路 ADC |
| 多按键功能 | 13 个按键（方向键 + 功能键） |
| 无线发送 | NRF24L01P + PA 功放（远距离 2.4GHz）|
| 实时显示 | 并行接口 OLED 显示电量/模式/参数 |
| 低功耗待机 | TP4057 充电管理 + LDO 供电 + 软件休眠 |

与平衡车控制板配对使用：遥控器发指令包（速度、转向、模式），车载板接收后执行 PID 控制。这是一套完整的「发射端 + 接收端」闭环系统。

**注意**：本板的主控 **STM32F103C8T6 是直接焊接在板上**的（不是像 PID/平衡车板那样用插座核心板），说明这是面向量产/成品的设计——省去连接器成本和接触不良风险。详见 [[STC32G144K246-数据手册]] 对比不同集成方式的选择逻辑。

## 关键模块

| 模块 | 核心器件 | 功能 |
|------|---------|------|
| **电源管理** | USB1 Type-C + U5 TP4057 + 锂电池 + U4 XC6206 LDO | 充电输入 → 锂电池充电管理 → 3.3V LDO 稳压输出 |
| **主控** | U1 STM32F103C8T6（直焊 LQFP48）+ 8MHz 晶振 + 复位电路 | 读摇杆/按键、打包协议、驱动 OLED、SPI 控制射频 |
| **人机输入** | 双摇杆（L/R 共 4 轴 ADC）+ SW1~SW13（13 键）+ SW13 拨杆开关 | 摇杆控制速度/转向；按键切模式；拨杆做紧急停止 |
| **无线发射** | U2 NRF24L01P-R + U3 AT2401C PA/LNA + SMA 天线 + 匹配网络 | 2.4GHz 数据发送，PA 功放将功率从 0dBm 提升至 ~20dBm |
| **显示** | OLED1 并口 OLED（AFC07-S30ECA-00, 30pin）| 8 位并行总线驱动的 OLED 屏幕 |
| **编程调试** | SWD 接口（SWDIO/SWCLK）+ UART 引出 | 在线下载程序 + 串口调试 |

## 原理图要点（每个关键元件为什么放）

### 1. TP4057 锂电池充电芯片：为什么不用简单的二极管限流

U5 是 TP4057（1A 线性锂电充电管理芯片），配合 Type-C 接口构成完整充电方案：

```
USB Type-C (VBUS)
    │
    ├──→ TP4057 VBUS pin
    │        │
    │        ├─→ BAT pin ──→ 锂电池正极
    │        │              │
    │        ├─→ CHRG# ──→ LED1（充电中亮）
    │        └─→ STDBY# ──→ LED2（充满亮）
    │
    └─→ （不直接给系统供电！）
```

**为什么不能 VBUS 直连系统？**

- **TP4057 做了 CC/CV 恒流恒压控制**：先恒流 1A 充到 4.2V，再恒压涓流充满。直接接会过充导致鼓包甚至起火。
- **CHRG#/STDBY# 指示灯**：用户一眼知道充电状态。
- **PROG 引脚（R16=5kΩ）设定充电电流**：`Ichg = 1200V / Rprog = 1200/5000 = 240mA`。用较小电流延长电池寿命并降低 Type-C 接口的电流应力。
- **电池路径优先**：系统由电池经 LDO 供电，不依赖 USB 插着才能工作。

详见 [[三极管开关电路]] 中关于线性稳压 vs 开关充电的区别。

### 2. NRF24L01P-R + AT2401C PA 功放：为什么加这颗 PA

普通的 NRF24L01 发射功率仅 **0dBm（1mW）**，室内有效距离约 10~20 米。加了 AT2401C（2.4GHz CMOS 射频前端）之后：

| 参数 | 无 PA | 有 AT2401C |
|------|-------|-----------|
| 发射功率 | 0dBm | ~20dBm (100mW) |
| 室外视距 | ~30m | ~300~500m |
| 接收灵敏度（LNA） | -94dBm | 提升 ~3~5dB |

**AT2401C 的工作原理**：
- TX 模式：NRF24L01 的 ANT1/ANT2 输出 → AT2401C 的 TXEN 使能 → 内部 PA 放大 → 通过匹配网络 → SMA 天线发射
- RX 模式：天线信号 → 匹配网络 → AT240LNA 放大（RXEN 使能）→ 送回 NRF24L01
- 控制引脚 TXEN/RXEN 由 MCU GPIO 切换（半双工）

原理图中完整的 **RF 匹配网络**（L1~L4 + C19~C26）是关键——2.4GHz 信号波长仅 125mm，任何阻抗不连续都会反射损耗。这些电感和电容值是 datasheet 或 Smith 圆图仿真调出来的，**不可随意更改**。详见 [[阻抗控制]] 中关于射频匹配的设计方法。

### 3. XC6206 LDO：为什么选它而不是 AMS1117

U4 是 XC6206P332MR-G（固定 3.3V 输出 LDO），相比常见的 AMS1117-3.3：

| 特性 | XC6206 | AMS1117 |
|------|--------|---------|
| 压差 (Dropout) | 0.2V (典型) | 1.1V (典型) |
| 静态电流 | <1μA | 5~10mA |
| 输出电容 | ≥1μF 即可（陶瓷 OK）| 需要 ≥10μF（通常钽电容）|
| 封装 | SOT-23（超小） | SOT-223/SOT-89 |

**为什么这对遥控器很重要？**

- **低压差**：锂电池电压降到 3.5V 时，XC6206 还能输出 3.3V；AMS1117 此时已退出稳压（需要 Vin > 4.4V）。相当于把可用电池容量多用了 ~15%。
- **低静态电流**：待机时 LDO 自身只耗 <1μA，对电池续航几乎无影响。
- **小封装**：SOT-23 只占极小 PCB 面积，对寸土寸金的遥控器很关键。

输入/输出各并联 1μF 陶瓷电容（C4、C5）满足稳定性要求。详见 [[线性电源LDO]] 选型对比。

### 4. 电池电压监测：R7(910kΩ)+R8(1MΩ) 分压器

```
VBAT ──┬── R7(910kΩ) ──┬── R8(1MΩ) ──┬── GND
       │                │               │
       └──(ADC采样点)────┘               C15(4.7uF滤波)
                                   
ADC 值 = VBAT × R8/(R7+R8) = VBAT × 1000/1910 ≈ VBAT × 0.524
```

STM32 ADC 参考电压 3.3V 时：
- 满电 4.2V → ADC 读数 ≈ 4.2×0.524/3.3 × 4095 ≈ 2726
- 欠压 3.3V（单节锂电截止）→ ADC ≈ 2145
- 分压比确保即使 4.2V 输入也不会超过 3.3V ADC 量程（4.2×0.524=2.2V < 3.3V ✓）

**为什么分压电阻取值这么大（MΩ 级）？**

为了减小待机功耗：`I_leakage = VBAT / (R7+R8) = 4.2V / 1.91MΩ ≈ 2.2μA`。若用 10kΩ+10kΩ，漏电流就是 210μA，一年就把电池耗光了。代价是 ADC 采样要考虑源阻抗大的问题（需加大 C15 滤波电容 + 增长采样时间）。详见 [[ADC]] 的输入阻抗要求。

### 5. 并行接口 OLED：为什么不用 I²C

OLED1 使用的是 **8 位并行 8080 接口**（D0~D7 + CS#/RES#/D/C#/R/W#/E），而非 PID/平衡车板上那种 4pin I²C OLED。原因：

| 对比项 | I²C OLED | 并行 OLED |
|--------|----------|-----------|
| 引脚占用 | 2 (SDA+SCL) | 14 (数据8+控制6) |
| 刷新速率 | ~400kHz（受总线带宽限制）| 可达数 MHz（取决于 GPIO 翻转速度）|
| 屏幕尺寸 | 通常 ≤0.96" 128×64 | 可支持更大分辨率（如 128×128）|
| 适用场景 | 简单状态显示 | 动画/菜单/实时波形 |

遥控器的 OLED 需要**频繁刷新画面**（摇杆位置实时显示、菜单切换动画、电池电量条等），I²C 的 400kHz 带宽传一帧 128×64 单色图需要 ~26ms，会有明显拖影。并行接口只需 ~1~2ms 就能刷完一帧，体验流畅得多。

代价是占用了大量 GPIO（至少 12 个），所以 STM32F103C8T6 的 48 个引脚资源在这里非常紧张——这也是遥控器板用直焊 MCU 而非核心板的另一个原因（可以自由分配所有引脚）。

### 6. 两个晶振：8MHz 主时钟 + 16MHz（或 RTC）

原理图中出现了两组晶体振荡电路（Y1/Y2 各带 22pF 负载电容 C17/C18）：

- **X1 = 8MHz**：标准 HSE 外部高速时钟，供 STM32 SYSCLK 经 PLL 倍频到 72MHz 运行。
- **X2 = 16MHz**：（根据文本提取结果）可能是为 NRF24L01 提供精确时钟基准，或作为备用高频时钟。也有可能实际为 **32.768kHz RTC 晶振**用于低功耗待机计时——具体以实物 BOM 为准。

无论哪种用途，晶振电路的关键设计原则相同：
- 负载电容 C17/C18（22pF）必须匹配晶体规格书要求的 CL 值
- 晶体紧靠 OSC_IN/OSC_OUT 引脚放置，走线尽量短且等长
- 晶体下方不走其他信号线（避免机械振动耦合噪声）

详见 [[晶振与时钟电路]]。

## PCB 设计亮点

### 1. 射频区域布局（最关键的难点）

NRF24L01 + AT2401C + 匹配网络 + SMA 天线构成了本板的 **RF 区**，设计规则：

```
┌──────────────────────────────────┐
│   SMA 天线 (板边)                 │
│      │                           │
│   匹配网络 (L1~L4, C19~C26)     │ ← 50Ω 特性阻抗微带线
│      │                           │
│   AT2401C (PA/LNA)               │
│      │                           │
│   NRF24L01P-R                    │
│      │                           │
│   SPI 信号 ←→ MCU                │
└──────────────────────────────────┘
```

- **RF 走线按 50Ω 阻抗控制设计**：根据板厚和介质常数计算线宽（一般 FR4 1.6mm 板上 50Ω 微带线约 2.8~3mil 宽度）。参见 [[阻抗控制]]。
- **天线放在板边缘**，朝向远离人体手握区域的方向，避免手掌吸收衰减信号。
- **RF 区下方完整地平面**（不要分割），保证回流路径。
- **数字信号不要穿越 RF 区**，防止谐波干扰。
- **NRF24L01 的 XC1/XC2 晶振**靠近芯片放置（16MHz 基准时钟）。

### 2. 电源完整性：电池路径粗 + 滤波分级

```
电池正极 ──[粗走线]──→ TP4057(BAT) ──[粗走线]──→ LDO(VIN) ──→ 3V3 平面
                                        │
                                   C14(10uF) 大电容
```

- 电池到 LDO 的主干走线应 ≥20mil，承载全部系统电流（MCU ~50mA + OLED ~20mA + NRF ~15mA + PA 发射峰值 ~100mA）。
- LDO 输出端放 **大容值钽/电解电容 C14(10uF)** 吸收瞬态电流尖峰（尤其是 PA 发射时的脉冲电流）。
- 每个 IC 电源脚旁放 **0.1uF 去耦电容**（C6~C11 等），就近接地。详见 [[去耦电容]]。

### 3. 模拟区隔离：摇杆 ADC 信号保护

两路摇杆共 4 个模拟量通道（LH/LV/RH/RV），信号特点：

- **直流/低频信号**（人手移动摇杆 <10Hz）
- **高阻抗源**（摇杆电位器通常 10kΩ）
- **易受噪声干扰**（尤其来自 RF PA 和电机 PWM）

防护措施：
- ADC 走线做**差分对包地**或两侧铺 GND 保护
- 入口处加 RC 低通滤波（如 1kΩ + 0.1μf 截止频率 ~1.6kHz）滤除高频噪声
- 远离 RF 区和数字高速信号（SPI 时钟、并行 OLED 数据线）
- ADC 采样时刻避开 PA 发射窗口（软件层时序调度）

### 4. 按键矩阵 vs 独立 IO

13 个按键（SW1~SW12 + SW13 拨杆）如果全用独立 IO 需要 13 个 GPIO，STM32F103C8T6 有足够余量（48pin 中可用 GPIO 约 40+），所以采用**独立 GPIO + 下拉/上拉**方案。优势：

- 软件简单（直接读 PIN 电平）
- 支持多键同时按下检测
- 可配置外部中断触发（下降沿唤醒休眠中的 MCU）

SW13 用的是 **MST22D18G2 三档拨动开关**（不是轻触开关），适合做「关机/待机/工作」三态选择。

### 5. Type-C 接口 & ESD 防护

USB1 采用 16pin Type-C 连接器（含 CC1/CC2 配置通道识别、SBU1/SBU2 辅助信号、VBUS/GND/SHELL）。Type-C 支持**正反插**（CC 引脚告知主机方向），用户体验优于 Mini/Micro USB。

建议在 VBUS 线上串联 **TVS 管**（原理图中可能未画出但量产板必备）防静电击穿 TP4057。SHELL 引脚接到外壳地形成屏蔽罩。

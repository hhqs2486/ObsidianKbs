## 这块板是干嘛的（需求）

**STC32G144K246 最小系统核心板**——把 STC 宏晶的 STC32G144K246（LQFP48）做成一块「即插即用」的 MCU 核心模块：USB-C 供电+下载、3.3V LDO 稳压、复位按键、状态 LED、晶振座，以及 **5 组不同规格的扩展排针**，让上层应用板只管接 IO 不用再搭最小系统。

> 典型用法：核心板插到智能车底板 / 电机驱动板上，通过 2×15P 或 2×11P 排针对接——**「核心板管 MCU，底板管外设」** 的分层架构。

## 关键模块

| 模块 | 核心器件 | 功能 |
|------|---------|------|
| USB-C 供电/下载 | P1 (USB_TypeC, 13Pin) | 5V VBUS 输入 + USB ISP 下载/调试 |
| 主控 MCU | U1 (STC32G144K246, LQFP48) | 8051 内核, 64KB Flash, 丰富外设 |
| 电源管理 | U2 (RT9013-33) + D1 + F1 | 5V→3.3V LDO, 反接保护, 过流保险丝 |
| 复位电路 | S1 (KEY-TS1199A) + R3(10K) + R9(100Ω) | 低电平复位, 上拉 + 限流 |
| 用户按键 | S2 (KEY-TS1199A) + R4(10K) | 接 P3.2, 低电平有效 |
| 时钟源 | Y1 (12MHz NC) + C13/C14 (20pF NC) | 外部晶振位（默认不焊, 用内部 IRC） |
| 状态指示 | LED1(P3.0) + LED2(P3.1), R7/R8(2.7K) | 电源/运行指示灯 |
| 扩展接口 | P2(1×4) / P3-P4(2×5) / P5-P6(2×11) / P7(2×15) | 多规格排针, 全引脚引出 |
| 去耦网络 | C2~C12 (10uF~100nF 多颗) | 分散式去耦, 覆盖各电源域 |

## 原理图要点（每个关键元件为什么放）

### 1. RT9013-33 LDO（U2）— 为什么选 LDO 不用 DCDC？

RT9013-33 是一款 **500mA 低压差线性稳压器**，输入 5V → 输出 3.3V：

- **低噪声**：LDO 输出纹波 < 几十 mV，远优于 DCDC 的几十~上百 mV。STC32G 内置 [[ADC]] 和模拟外设对电源噪声敏感；
- **成本低**：LDO 外围只需 1~2 颗电容（C1=47uF 输入 + C2/C4/C6=10uF 输出），BOM 比 DCDC 简单很多；
- **无 EMI 问题**：没有开关频率辐射，不会干扰板上的无线/高频信号；
- **够用即可**：核心板自身功耗通常 < 150mA，500mA 绰绰有余。

> 权衡：如果后续要驱动大功率外设（电机、屏），3.3V 电流不够时需要在外层板另加 DCDC。

### 2. 肖特基二极管 D1（1N5819HW）— 防反接的第一道防线

D1 串联在 `5V` 干线上（USB-C VBUS 之后、LDO 之前）：

- **正向压降低**：肖特基仅 ~0.3V@500mA（普通硅管 ~0.7V），保证 LDO 输入端仍有足够电压余量（5V - 0.3V = 4.7V > 3.3V + 0.2V dropout）；
- **反向阻断**：USB-C 插反或第三方供电极性错误时，二极管截止，保护后级所有芯片；
- **配合保险丝 F1**：极端短路时 F1 先熔断，D1 承受反向浪涌不损坏。

> 工程口诀：**「电源入口三件套：保险丝 + 肖特基 + TVS/稳压管」**——这块板做了前两件，属于基础但实用的防护级别。

### 3. 保险丝 F1（500mA）— 为什么不是更大？

选用 **500mA 自恢复/一次性保险丝**：

- 核心板正常工作电流约 50~150mA（MCU 运行 + LED + 少量外设）；
- 500mA 给了 ~3 倍裕量，瞬态（如电容充电浪涌、多 GPIO 同时翻转）不会误触发；
- 但一旦真正短路（比如 3V3 对 GND 短接），能在几秒内断开防止 PCB 烧毁或 USB 口烧坏；
- **保护的是 USB 口和电脑**，不只是板子本身——这是负责任的设计。

### 4. 去耦电容阵列（C3/C5/C7/C8/C9 = 100nF ×5 + C10/C11/C12 = 22uF ×3）— 为什么这么多？

这是教科书级的 **「大+小、分散布局」** 去耦策略：

| 电容 | 容值/封装 | 位置作用 |
|------|----------|---------|
| C3/C5/C7/C8/C9 | 100nF/0603/X7R | **高频去耦**：紧贴 MCU 各组 VCC/GND 引脚，滤除 10MHz~100MHz 开关噪声 |
| C10/C11/C12 | 22uF/0603/X5R | **中低频储能**：应对 MCU 突发高功耗模式（如 Flash 擦写、全 GPIO 翻转）时的瞬时电流需求 |
| C2/C4/C6 | 10uF/0603/X5R | LDO 输出滤波：稳定 3.3V 输出，抑制 LDO 自身纹波 |

> 为什么不用一颗大钽电容代替？**ESR（等效串联电阻）不同**：陶瓷 100nF 在 10~100MHz 区间 ESR 极低（<0.1Ω），而大容量钽/电解在此频段已呈感性，无法滤除高频噪声。必须大小搭配。

### 5. USB 数据线串联电阻 R5/R6（22Ω）— 为何在 D+/D- 上加电阻？

R5/R6 分别串在 USB D- 和 D+ 数据线上：

- **阻抗匹配**：USB 2.0 Full-Speed 要求 D+/D- 差分阻抗 90Ω ±15%。22Ω 串联电阻帮助调整传输线阻抗，减少信号反射；
- **ESD 保护缓冲**：静电击穿时电阻限制峰值电流，给后级 MCU 的内部 ESD 二极管争取反应时间；
- **限流**：防止 USB Host/MCU 引脚意外短路时烧毁 USB 收发器。

> 注意：这颗阻值是经验值（常见范围 22~47Ω），精确值取决于实际 PCB 走线长度和层叠结构。

### 6. 磁珠 FB1/FB2（0Ω / Ferrite Bead）— 电源隔离的意义

FB1 在 `3V3 → 3V3` 之间，FB2 在 `GND → GND` 之间：

- **磁珠 = 高频扼流圈**：直流电阻接近 0（不影响压降），但在 100MHz+ 呈现几十 Ω 阻抗；
- 用途：将 **MCU 数字核心的高频开关噪声**隔离在 Core_VCC 域内，不让其污染给外设供电的 3V3 总线；
- FB1 隔离 VCC，FB2 隔离 GND——**电源和地都要隔**才是完整的隔离思路。
- 默认标为 "0R" 说明可以 **用 0Ω 电阻代替磁珠**（成本敏感时降级方案），或者作为生产备选项。

从尺寸图和丝印图可以看出：

1. **紧凑型小尺寸**：整板尺寸约 28mm × 52mm（从位号图比例估算），属于「邮票孔核心板」规格——可以直接贴装到底板 PCB 上做 SMT，也可以插接使用。
2. **双排针对称分布**：
   - 左侧 P7（2×15P）：全引脚最大接口，适合做主对接；
   - 右侧 P5/P6（2×11P）：次级 IO 扩展；
   - 上方 P3/P4（2×5P）：精简接口；
   - 这种「一大两中两小」的分级设计适配不同的底板密度需求。
3. **Type-C 居中靠边**：USB-C 放在板子边缘中央位置——插入线缆后不会挡住其他接口，符合人机工程。
4. **LED 放在边缘可见处**：LED1/LED2 从丝印图看位于板子侧边区域，堆叠到底板后仍能从侧面看到状态灯。
5. **0603 统一封装**：所有阻容（除了 C1 是 3528 钽电容）都用 0603 封装——**统一封装 = 统一物料高度 = SMT 贴片一次过炉**，降低组装复杂度。
6. **版本迭代记录清晰**：原理图标题栏有 V1.0.0→V1.0.1→V1.0.2 三版变更日志（初始版 → 修改 MCU 原理图 → 删除 2×5 接口），体现规范的版本管理意识。

## 这块板是干嘛的（需求）

**STM32F103C8T6 最小系统板的「引脚扩展盾板」**——把底板 40Pin 排针一次性引出成 **4 组独立 2×20 排针**，同时板上集成 OLED（I²C）、串口屏（UART）、3 颗用户按键和螺丝端子，解决「IO 不够插、接线乱成一团」的痛点。

> 本身不带 LDO 和晶振——3.3V / 复位信号全部来自底层最小系统板，它是一个纯粹的「IO 扩展 + 外设接口」层。

## 关键模块

| 模块 | 核心器件 | 功能 |
|------|---------|------|
| 电源输入 | U2 + SW1 (SS-12F44-G5) | 接入底层 +5V_IN，总开关控制通断 |
| MCU 引脚扇出 | U1 (STM32F103C8T6 引脚定义) | 全部 GPIO/电源/复位映射到排针 |
| 排针扩展 | U3/U4/U5/U6 (PZ2.54-2×20 ×4) | 4 组 2.54mm 双排针，共 80 个焊盘位 |
| OLED 屏幕 | U40 (HS96L03W2C03, I²C) | 0.96"OLED，SCL→PB8, SDA→PB9 |
| 串口屏接口 | H5 (4Pin) | UART 串口屏, TX/RX → PA2/PA3 |
| 用户按键 | KEY1~3 (TS-KG01) | PB12/PB13/PB14, 低电平有效 |
| 螺丝端子 | SCREW1~4 | 大电流/外接设备用螺丝固定连接 |

## 原理图要点（每个关键元件为什么放）

### 1. 总开关 SW1（SS-12F44-G5）— 为什么扩展板也要开关？

底层最小系统板通常只有 USB 或 DC 口供电，没有板载开关。扩展板加一颗 **DPDT 拨动开关** 做总电源闸刀：
- 调试时频繁上电断电，不用拔线；
- 短路/异常时一键断电保护底板 MCU；
- 开关放在 `+5V_IN → +5V` 干线上，切断后整板无电。

> 工程思维：**「谁用电、谁管电」**——扩展板自己消耗的电流（OLED、LED、外设）应该有独立的通断能力。

### 2. 四组排针 U3~U6 — 为什么不合成一个大排针？

把 40 个引脚拆成 **4 组 2×20 排针**而非一个超长排针：

- **物理隔离**：不同外设接在不同组上，杜邦线不会打架；
- **电源冗余**：每组都重复引出 `+5V / GND / 3V3`，就近取电减少压降；
- **兼容面包板**：2×20 正好对应常见传感器模块宽度，直接插接无需转接。

> 从布局看：U3 偏 GND/3V3 侧重，U4 偏 +5V 侧重，U5/U6 混合 IO——这是按「电源域」分区的设计意识。

### 3. OLED 接口用硬件 I²C（PB8/PB9）— 为什么不选软件模拟？

STM32F103 的 **PB6/PB7 是默认 I²C1**，但这里选了 **PB8(SCL)/PB9(SDA)**：

- 底层最小系统板可能已经占用了 PB6/PB7（比如接了其他 I²C 设备）；
- PB8/PB9 可以复用为 **I²C1 重映射**或用软件 I²C，灵活性更高；
- OLED 只需 2 根线 + 电源，是性价比最高的人机交互方案。

### 4. 按键低电平有效（KEY 一端接 GND）— 为何这样设计？

三颗按键 KEY1~3 分别接 PB12/PB13/PB14，另一端全部拉到 **GND**：

- **低电平有效**：按下 = GPIO 读到 0，松手 = 内部上拉读到 1；
- 需要 MCU 配置 **GPIO 上拉输入模式**（或外部加 10K 上拉电阻），省去板载上拉元件降低 BOM 成本；
- 共地设计让多颗按键只需一根 GND 走线，节省布线资源。

> ⚠️ 注意：如果底层板的上拉能力不足，可能需要在外部补上拉电阻。这是「成本 vs 可靠性」的经典权衡。

### 5. 螺丝端子 SCREW1~4 — 什么时候用它们而不是排针？

螺丝端子适合 **大电流 / 高可靠性** 场景：
- 电机驱动板供电（电流 > 500mA 时杜邦线接触电阻会发热）；
- 外部电源引入（电池盒正负极不能松动）；
- 长期固定连接的传感器（振动环境下排针会脱开）。

> 设计原则：**「小信号走排针，大功率走端子」**——这是从无数翻车教训中总结出来的。

## PCB 设计亮点

> 以下基于原理图结构推断（本 PDF 仅含原理图，不含 PCB 布局文件）

1. **对称式排针布局**：U3~U6 在 U1 四周对称分布，类似 Arduino Shield 的「母板-子板」堆叠思路，方便叠在其他开发板上方使用。
2. **功能区域化**：左上电源+开关、右上 OLED、左下串口屏+按键、右下螺丝端子——每个功能块集中在一角，**走线短且互不交叉**。
3. **电源轨重复引出**：每组排针都有 +5V/GND/3V3，这是好习惯——避免单根 VCC 走线过长导致末端压降。
4. **丝印标注清晰**：「电源输入」「总开关」「OLED 屏幕接口」「串口屏接口」等中文丝印直接标在对应位置旁边，新手拿到板子不用查原理图就能接线。
5. **预留 BAT 引脚**：U1 引出了 BAT（VBAT）引脚到底层板，支持 RTC 电池备份功能——说明设计者考虑到了低功耗待机场景。

# PID 电机驱动及控制板 — 原理图精讲

## 这块板是干嘛的（需求）

这块板的**核心需求**是：让学习者用一块 PCB 完整跑通「PID 闭环控制」——从传感器读角度/位置 → MCU 算 PID → PWM 驱动电机 → 编码器反馈 → OLED 显示实时参数。它本质上是一个**教学级双电机 PID 控制实验平台**，适合做：

- 平衡车直立环 / 速度环 / 转向环 PID 调参
- 云台舵机/直流电机位置伺服
- 两轮差速小车闭环速度控制

设计者把「调参」这件事硬件化了：板上放了 **4 个卧式电位器 (RP1~RP4)**，分别对应 Kp、Ki、Kd 和目标值，旋一下电位器就能实时改参数，不用反复烧录程序——这对初学者理解「PID 参数如何影响系统响应」非常直观。

## 关键模块

| 模块 | 核心器件 | 功能 |
|------|---------|------|
| **电源** | DC1 桶形插座 + S1 电源开关 + U3 MP1584EN DCDC | 外部 VIN（典型 7~12V）→ 降压给系统供电 |
| **主控** | U1 STM32F103C8T6 最小系统板（40Pin 插座） | 运行 PID 算法、ADC 采集、定时器编码器接口 |
| **传感** | J1/J2 角度传感器接口 + M1~M4 编码电机 EA/EB 信号 | MPU6050 类 IMU 输出模拟量；AB 相编码器测速/测位置 |
| **执行** | U2 TB6612FNG 双 H 桥驱动 | 两路 PWM 控制正反转+刹车，驱动两个带编码器的直流电机 |
| **通信** | J3 UART 接口 | 与上位机串口通信（调参/调试/数据回传） |
| **人机交互** | U4 I²C OLED（4针脚）+ RP1~RP4 电位器 + K1~K4 按键 | 显示状态；电位器在线调参；按键切换模式 |

## 原理图要点（每个关键元件为什么放）

### 1. STM32F103C8T6 以「最小系统板」形式存在，而非裸片

U1 是一个 **40Pin 插座式最小系统板**（不是直接焊芯片）。为什么？

- **降低入门门槛**：学生不需要自己画晶振、复位、去耦、Boot0 电路——这些全在核心板里做好了。
- **可替换**：坏了一换就行，不用拆焊 LQFP48。
- **教学聚焦**：把精力放在「外设电路怎么接」而非「MCU 最小系统能不能起振」。

代价是多一层板对板连接，信号完整性稍差，但对 <100kHz 的编码器信号和几 kHz 的 PWM 来说完全够用。详见 [[STM32F103]] 最小系统的标准设计。

### 2. TB6612FNG 电机驱动：为什么选它而不选 L298N

TB6612FNG 是东芝的双 H 桥 MOSFET 驱动芯片，相比老款 L298N：

| 特性 | TB6612FNG | L298N |
|------|-----------|-------|
| 导通内阻 | ~0.5Ω（MOSFET） | ~2Ω（BJT 饱和） |
| 效率 | 高（发热小） | 低（需大散热片） |
| 待机引脚 STBY | 有（低功耗模式） | 无 |
| 单通道电流 | 1.2A（峰值 3.2A） | 2A（持续） |
| 封装 | SSOP16（小巧） | Multiwatt15（大） |

原理图中 STBY 引脚接到了网络标号（应接高电平使能），PWMA/PWMB 接 MCU 定时器 PWM 输出，AIN1/AIN2/BIN1/BIN2 控制方向。VM 接 VIN（电机电压），VCC 接 3.3V（逻辑电平）。详见 [[三极管开关电路]] 中关于 BJT vs MOSFET 驱动的对比。

### 3. 4 个卧式电位器 RP1~RP4：硬件化 PID 调参

这是本板最大的**教学设计亮点**。RP1~RP4 都是三端电位器，一端接 3V3、一端接 GND、中间抽头接 STM32 的 ADC 通道（PA0~PA3 或类似引脚）：

```
3V3 ──┬── RP1(滑动端) ──→ ADC1_CHx (Kp)
      │
     GND
```

程序里 `adc_read()` 直接读取电压值映射为浮点系数。**为什么用电位器而不是串口发指令？**

- **即时反馈**：转一圈就能看到电机反应变化，建立「P 大了会震荡」「D 太大会抖」的直觉。
- **无需电脑**：现场调试时只拿一把螺丝刀就能工作。
- **安全边界**：可以给 ADC 值设上下限 clamp，防止误拧到极端值导致电机飞车。

### 4. MP1584EN DCDC 降压模块：为什么不用 LDO

VIN 典型值 7~12V（锂电池或适配器），而系统需要 3.3V。压差最大可达 8.6V：

- 若用 [[线性电源LDO]]（如 AMS1117）：`P = (Vin - Vout) × I = 8.6V × 200mA = 1.72W`，LDO 会非常烫，甚至进入热保护。
- 用 [[开关电源DCDC]] MP1584EN（同步整流 Buck）：效率 >90%，发热极小，输出电流可达 3A。

原理图中 U3 的 IN± 接 VIN，OUT± 输出接 3V3 网络。输入/输出电容已在模块内部（或板载），外部只需大容量滤波。

### 5. 双规格编码电机接口：XH2.54 + PH2.0

板子同时提供两种连接器：
- **XH2.54**（M1、M2）：间距 2.54mm，常见于洞洞板/面包板项目，插拔方便。
- **PH2.0**（M3、M4）：间距 2.00mm，更紧凑，适合成品安装。

每个接口都是 6pin：M+/M−（电机动力线）、E+/E−（编码器电源）、EA/EB（AB 相信号）。E+/E− 给编码器光电传感器供电（通常是 3.3V 或 5V），EA/EB 接 MCU 的**定时器编码器接口**（如 TIM2/TIM3/TIM4 的 CH1/CH2），利用硬件计数 AB 相脉冲实现 4 倍频测速，不占用 CPU 周期。详见 [[定时器与PWM]]。

### 6. 角度传感器接口 J1/J2：为什么是三线制

J1/J2 只有 VCC/OUT/GND 三根线，说明接的是**模拟输出型** MPU6050 模块（或简单的单轴倾角传感器），OUT 直接输出与角度成正比的 0~3.3V 电压到 MCU ADC。这种接法比数字 I²C 简单得多：

- 不需要 I²C 地址配置
- 不需要 DMP 库
- 一根 ADC 线就能读角度

缺点是精度有限、易受噪声干扰。教学场景够用，工程产品建议用完整 I²C 数字接口的 MPU6050。详见 [[ADC]]。

## PCB 设计亮点

1. **电源分区清晰**：VIN（高压/大电流）→ DCDC → 3V3（低压/逻辑），走线时应将电源区与信号区物理分离，避免电机开关噪声耦合到敏感的 ADC 和编码器信号上。参考 [[电源分割]]。

2. **电机大电流路径短粗**：TB6612 的 VM→AO1/AO2/BO1/BO2→电机接口这段走线承载 1~2A 峰值电流，应加宽至 ≥20mil（0.5mm），优先走底层并铺铜。详见 [[布局与布线]]。

3. **差分编码器信号等长**：EA/EB 是一对差分-ish 信号（虽不是真差分但时序相关），两根线应等长、平行走线、远离 PWM 开关线，防止 crosstalk 导致计 数错误。参见 [[差分对与等长]]。

4. **电位器布局在人手易操作区域**：RP1~RP4 卧式贴片，放在板边，留出螺丝刀操作空间。丝印应标注每个电位器对应的参数名（Kp/Ki/Kd/Target）。

5. **OLED 用 I²C 只占 2 个 IO**：节省宝贵的 GPIO 资源。I²C 上拉电阻通常已集成在 OLED 模块上，原理图中 SCL/SDA 直接挂总线即可。

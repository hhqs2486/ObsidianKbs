# 平衡车控制板 V2.0 — 原理图精讲

## 这块板是干嘛的（需求）

这块板的**核心需求**是：作为**两轮自平衡车的「车载主控 + 驱动一体板」**——一块 PCB 搞定全部车载功能：

1. **直立闭环**：读 MPU6050 姿态 → PID 算角度修正 → PWM 驱动双电机
2. **速度闭环**：编码器测轮速 → 速度环叠加到直立环输出
3. **无线接收**：NRF24L01 接收遥控器发来的速度/转向指令
4. **人机交互**：OLED 显示状态，按键切换模式，蓝牙备用通信
5. **电源管理**：单电池输入 → DCDC 降 5V（电机）→ LDO 降 3.3V（MCU/传感器）

它不是通用开发板，而是为「智能车竞赛 / 平衡车项目」量身定制的**专用载板**。设计者把所有外设都集成在一块板上，减少飞线、提高可靠性——这正是工程思维中「从需求定义接口」的体现。

## 关键模块

| 模块 | 核心器件 | 功能 |
|------|---------|------|
| **电源** | J1 接线端子 (VIN) → U7 DCDC(5V) → U6 LDO(3.3V) | 两级降压：5V 给电机驱动 VM，3.3V 给 MCU/传感器 |
| **主控** | U1 STM32F103C8T6 最小系统板（40Pin 插座） | PID 运算、传感器融合、通信协议 |
| **传感** | U3 MPU6050 模块 (I²C) + M1/M2 编码器 EA/EB | 6 轴 IMU 测姿态角 & 角速度；AB 相编码器测速 |
| **执行** | U2 TB6612FNG 双 H 桥驱动 | 两路 PWM 正反转驱动直流减速电机 |
| **无线** | U5 NRF24L01 模块 (SPI) + J3 蓝牙模块接口 | 2.4GHz 收遥控指令；蓝牙作备用/调试通道 |
| **显示** | U4 I²C OLED (4针脚，O-SDA/O-SCL) | 显示角度、速度、PID 参数、电池电压 |
| **交互** | K1~K4 按键 + J2 UART 接口 | 模式切换、参数调整；串口调试 |

## 原理图要点（每个关键元件为什么放）

### 1. 两级电源架构：DCDC(5V) → LDO(3.3V)，为什么这样分

```
电池 VIN (7.4~11.1V)
    │
    ├──→ U7 DCDC ──→ 5V ──→ TB6612 VM（电机大电流）
    │                    │
    │                    └──→ （不直接给 MCU！）
    │
    └──→ U6 LDO(3.3V) ──→ 3V3 ──→ MCU / MPU6050 / OLED / NRF24L01
```

**为什么不给 MCU 直接用 DCDC 输出？**

- **噪声隔离**：[[开关电源DCDC]] 的开关频率（几百 kHz ~ MHz）会产生纹波和尖峰。电机启动/刹车时电流突变会在 5V 总线上引起电压跌落（可达 0.5~1V）。如果 MCU 和电机共用 5V，复位或 ADC 读数漂移是常事。
- **LDO 作「第二道滤波」**：[[线性电源LDO]] 有极高的 PSRR（电源抑制比），能抹平 DCDC 留下的纹波，给敏感的模拟电路（MPU6050 的 ADC、MCU 的 ADC）提供干净电源。
- **成本与面积 trade-off**：先 DCDC 降压到大压差（效率高），再 LDO 小压差 5V→3.3V（损耗小 `P = 1.7V × I`），两者配合兼顾效率和洁净度。

这是板级电源设计的经典套路：**大电流用开关电源，小电流敏感负载再加一级 LDO**。

### 2. TB6612FNG 的 VM 接 5V 而非 VIN：为什么

TB6612 的 VM（电机电源）在原理图中接的是 **5V（DCDC 输出）**，而不是原始的 VIN（7~12V）。原因：

- **保护电机**：教学用的微型减速电机额定电压通常就是 3~6V。直接接 VIN 可能烧线圈。
- **降低驱动应力**：TB6612 在低 VM 下 MOSFET 开关损耗更小。
- **与 MCU 逻辑解耦**：电机反电动势和电感尖峰被限制在 5V 域内，不会耦合回 3.3V 逻辑区。

如果需要更高电压驱动（如 12V 电机），只需改一根跳线把 VM 改接 VIN——这就是原理图中网络标号灵活性的好处。

### 3. MPU6050 用独立 I²C 总线（M-SDA/M-SCL），不和 OLED 共享

注意看网络标号：
- MPU6050 用 **M-SDA / M-SCL**
- OLED 用 **O-SDA / O-SCL**

两条 I²C 总线**物理分开**，各占一组 GPIO。为什么？

- **采样率不同**：MPU6050 在平衡车中通常跑 100~500Hz（甚至 DMP 200Hz），总线占用率高。OLED 刷新率只要 5~10Hz。共享总线时 OLED 刷新会阻塞 IMU 读取，导致 PID 抖动。
- **地址冲突风险**：虽然 MPU6050 地址 0x68 可通过 AD0 引脚切换到 0x69，OLED 通常也是 0x3C，但共享总线的时序管理增加软件复杂度。硬件上直接分开是最省心的做法。
- **走线布局友好**：MPU6050 靠近 MCU 放置（短走线减噪声），OLED 可以放板边靠近操作者——两条总线自然分区。

详见 [[I²C]] 总线的多从机设计与 [[GPIO]] 复用策略。

### 4. NRF24L01 无线模块：SPI 接口 + CE/CSN 控制

NRF24L01 是 Nordic 的 2.4GHz 射频收发芯片，通过 SPI 与 MCU 通信：

| 引脚 | 功能 | 为什么需要 |
|------|------|-----------|
| CE | 芯片使能 | 高电平时才能收/发；低电平进入 standby |
| CSN | SPI 片选 | 低电平选中芯片（SPI 从机选择） |
| SCK/MOSI/MISO | SPI 三线时钟+数据 | 高速传输配置字和 payload |
| IRQ | 中断请求 | 收完数据/发送完成/最大重试通知 MCU |

CE 和 CSN 用普通 GPIO 即可，不需要特殊外设。SPI 可以用 STM32 的硬件 SPI1 或 SPI2（PB13~15），也可以用 **软件模拟 SPI（bit-bang）**——NRF24L01 的速率不高（最高 10Mbps），软 SPI 完全够用且引脚分配更自由。详见 [[SPI]] 通信协议。

### 5. 蓝牙模块接口 J3：为什么要留这个

J3 是一个 6pin 接口（NC/VCC/RXD/TXD/GND），专门给 HC-05/HC-06 类蓝牙串口模块预留。有了 NRF24L01 还要蓝牙，原因：

- **调试利器**：蓝牙串口可以用手机 App 实时看 PID 参数、波形，不用插 USB 线。
- **NRF24L01 不支持「透传」**：NRF 是数据包模式，要自己组包/拆包。蓝牙模块直接当无线 UART 用，上位机程序零改动。
- **冗余备份**：NRF24L01 的 2.4GHz 频段在比赛场地可能干扰多，蓝牙作备用链路。

### 4 个按键 K1~K4：低电平有效 + 内部上拉

K1~K4 都是 2pin 轻触开关，一端接 GPIO（K1/K2/K4/K3），一端接 GND。STM32 GPIO 配置为**上拉输入**（`GPIO_Mode_IPU`）：未按下时内部上拉保持高电平，按下拉低触发中断或轮询检测。这种设计：

- 省 4 个外部上拉电阻（利用 MCU 内部 ≈40kΩ 上拉）
- 按键抖动靠软件消抖（10~20ms 延迟再读）
- 适合模式切换（K1=启动/停止，K2=显示切换，K3=参数加减，K4=蓝牙配对）等场景

详见 [[上拉电阻与下拉电阻]] 和 [[GPIO]] 输入模式。

## PCB 设计亮点

### 电源分割（重点）

本板的**最值得学的设计点**是电源分割：

```
┌─────────────────────────────────────┐
│         VIN 区 (高压域)              │
│   J1 → U7 DCDC                      │
│   ┌──────┬──────┐                   │
│   │ 5V  │      │                   │
│   │ 域  │      ▼                    │
│   └──────┤  U6 LDO                  │
│          │      │                   │
│          ▼      ▼                   │
│       3.3V 域（低压逻辑区）           │
│   U1(MCU) U3(IMU) U4(OLED) U5(NRF)  │
└─────────────────────────────────────┘
```

PCB 布局建议：
1. **5V 域和 3.3V 域用地平面隔离**（Power Split），只在 LDO 入口处单点连接。
2. **VM 走线加宽至 ≥30mil**，两侧铺铜并多打地过孔，减小阻抗和温升。
3. **电机回流路径**：TB6612 的 GND（PGND）应直接回电源入口，不要穿过 3.3V 信号区的地平面——否则电机的大电流 dI/dt 会抬升数字地电位，导致 MCU 复位或 ADC 噪声。参见 [[电源分割]] 和 [[铺铜]]。

### 布局分区建议

| 区域 | 内容 | 原则 |
|------|------|------|
| 板中央 | U1 核心板插座 | 缩短到所有外设的走线长度 |
| 一侧边缘 | U2 TB6612 + 电机接口 M1/M2 | 大电流集中，远离敏感模拟 |
| 另一侧边缘 | U3 MPU6050 | 远离电机驱动，减少振动&磁场干扰 |
| 操作侧 | U4 OLED + K1~K4 | 面向用户，便于观察和操作 |
| 天线区 | U5 NRF24L01 | 靠近板边，天线朝外无金属遮挡 |

### 编码器信号防护

EA/EB 信号频率 = (电机 RPM × 减速比 × 编码器线数 × 4) / 60。对 300RPM、20:1 减速、11 线编码器的电机，AB 相频率约 = 300×20×11×4/60 = **4.4kHz**。这不算高频，但关键是**边沿陡峭**（方波谐波丰富）。建议：
- 编码器线做**包地处理**（GND 走两侧或底层完整 GND）
- 靠近 MCU 侧加 22~47Ω 串联电阻（抑制振铃）
- 避免与 PWM 线长距离平行布线

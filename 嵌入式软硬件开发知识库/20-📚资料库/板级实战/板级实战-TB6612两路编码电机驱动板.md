## 这块板是干嘛的（需求）

**双路带编码器反馈的直流电机驱动板**——基于 TB6612FNG 双 H 桥驱动芯片，同时板上集成 **XL1509 DC-DC 降压模块**将电池电压（如 7.4V 锂电）降到稳定的 5V 给 MCU 逻辑供电，并 **透传两路 AB 相编码器信号**，做到「一块板搞定：电机驱动 + 电源变换 + 编码器信号中继」。

> 典型应用：智能小车 / 平衡车 / 遥控车的动力总成——接电池进来，输出两路 PWM 控制的电机 + 回传速度反馈。

## 关键模块

| 模块 | 核心器件 | 功能 |
|------|---------|------|
| 电机驱动 | U1 (TB6612FNG, SSOP-24) | 双路 H 桥, 每路 1.2A 峰值, PWM 调速 + 正反转 + 刹车 |
| DCDC 降压 | U42 (XL1509-5.0E1) + U43(68uH) + D2(SS34) | VIN → 5V@1.5A, 给 MCU/编码器/逻辑供电 |
| 电源输入 | U3 (KF301-5.0-2P) | 5mm 间距螺丝端子, 接电池正负极 |
| 总开关 | SW4 (SS-12F44-G5) | 整板电源通断 |
| MCU 输入接口 | H7 (10Pin) | PWMA/AIN1/AIN2/PWMB/BIN1/BIN2 + EA1/EB1/EA2/EB2 |
| 电源输出 | H8/H9 (各 8Pin) | 5V/GND 多组输出给上层板 |
| 电机+编码器接口 | U40/U41 (XH2.54-6P ×2) | AO1/AO2/EA1/EB1/GND + BO1/BO2/EA2/EB2/GND |
| 电源指示 | LED2 + R47(1K) | 5V 正常时点亮 |

## 原理图要点（每个关键元件为什么放）

### 1. TB6612FNG（U1）— 为什么不选更常见的 L298N？

TB6612FNG 是东芝（现属米兰）的双 MOSFET H 桥驱动，对比老牌 L298N：

| 特性 | TB6612FNG | L298N |
|------|----------|-------|
| 输出级 | **MOSFET**（低导通电阻） | BJT 达林顿（高饱和压降） |
| 单通道持续电流 | 0.9A / 峰值 1.2A | ~1A / 峰值 2~3A |
| 导通压降 | **~0.3V** @0.5A（发热小） | **~1.8V~2V** @0.5A（严重发热） |
| 待机功能 | STBY 引脚低电平 = 关断 | 无 |
| 封装 | SSOP-24（小体积） | Multiwatt-15（巨大 + 散热片） |
| 逻辑电平 | 兼容 3.3V 和 5V | 需要 5V 逻辑 |

> 结论：对于智能车这种「电流不大但要求效率、体积敏感」的场景，TB6612 是比 L298N 更现代的选择。L298N 的优势只在需要 >2A 大电流且不在乎散热的场合。

### 2. XL1509-5.0E1 DCDC 降压（U42）— 为什么电机板要自带电源？

这块板的输入是 **电池电压（VIN，通常 6V~12V）**，而 TB6612 的逻辑端（VCC）、编码器、MCU 都需要 **5V 或 3.3V**：

- **XL1509 是 buck（降压型）开关稳压器**：效率可达 85%~90%，远高于 LDO（效率 = Vout/Vin，7.4V→5V 只有 67%）；
- 68uF 电感 U43 是储能元件——开关管导通时存能量，关断时释放；
- **SS34 肖特基二极管 D2 是续流二极管**：电感电流不能突变，开关管关断瞬间 D2 提供续流回路，防止电感产生高压击穿开关管；
- 输入 C81(47uF) + 输出 C82(47uF) + 高频去耦 C2/C4(100nF)：完整的 buck 滤波网络。

> 工程思维：「**电机驱动板自带 DCDC = 解耦供电**」——电机启停时的电压尖峰不会通过电源线耦合到 MCU，提高系统稳定性。这是「共地不共源」的分层供电思路。

### 3. 续流二极管 D2（SS34）— 没有它会怎样？

SS34 是 **3A/40V 肖特基整流管**，并联在电感和输出之间：

- Buck 电路的开关管以 ~150kHz 频率反复通断。每次关断时，电感 U43 中的电流需要一个通路继续流动（电感的物理特性：**di/dt 不能无穷大**）；
- 如果没有 D2，电感两端会感应出 **几十伏甚至上百伏的尖峰电压**（V = L·di/dt），直接击穿 XL1509 内部的功率 MOSFET；
- 选肖特基而非普通整流管是因为肖特基 **正向恢复快（< 几十 ns）、正向压降低（~0.4V@1A）**，减少损耗和发热。

> 口诀：**「有电感必有续流二极管」**——这是开关电源设计的铁律。

### 4. 编码器信号透传（EA1/EB1, EA2/EB2）— 为何从电机接口旁引出？

U40/U41 是 **6Pin XH2.54 连接器**，每路包含：
- AO1/AO2（或 BO1/BO2）：H 桥输出 → 电机两根线
- EA1/EB1（或 EA2/EB2）：**编码器 A/B 相信号** → 直连到 H7 输入排针
- GND：公共地

这样设计的妙处：
- **减少接线**：电机和编码器共用一根 6 芯扁平线，插一个座子搞定；
- **编码器信号不经过 TB6612**：直接透传到 MCU 接口 H7，避免驱动芯片的高频开关噪声干扰编码器的微弱脉冲信号；
- 支持闭环控制：MCU 通过 [[定时器与PWM]] 的编码器接口模式读取 EA/EB 的正交脉冲，实现 **PID 速度闭环**。

> 这是智能车的标准做法——开环只能跑直线，闭环才能跑得又快又稳。

### 5. KF301 螺丝端子（U3）— 电源输入为什么不用杜邦线？

KF301-5.0-2P 是 **5.08mm 间距的插入式螺丝端子**：

- 智能车电池电流可达 **1~3A**（两个电机同时加速），杜邦线的弹簧触点接触电阻 ~50mΩ×2 = 100mΩ，在 2A 下压降 200mW、发热明显；
- 螺丝端子用 **螺栓压线**，接触面大且稳定，接触电阻 < 5mΩ，几乎不发热；
- 振动环境下（小车跑动）不会松脱——杜邦线则经常因振动脱落导致断电失控。
- 5.08mm 间距比 2.54mm 更粗壮，能承受更大线径（AWG18~22）。

### 6. 电源指示灯 LED2（R47=1K）— 小细节体现工程素养

一颗简单的 **5V 电源指示灯**：

- 上电后立刻知道「5V 是否正常」——调试时 80% 的故障第一步都是「有没有电」；
- R47=1K 限流：(5V - Vf)/1K ≈ (5-2)/1K = 3mA，亮度够用且省电；
- 放在 5V 输出侧而不是 VIN 侧——说明的是 **「逻辑电源 OK」** 而非「电池有电」，信息更有价值。

## PCB 设计亮点

> 以下基于原理图结构推断（本 PDF 仅含原理图，不含 PCB 布局文件）

1. **「左进右出」的电源流向**：左侧 U3 电源输入 → 中间 SW4 开关 → 右上角 U42 DCDC 降压 → 右侧 H8/H9 输出 5V。电源路径清晰，符合 **「从左到右、从上到下」** 的信号流布局惯例。
2. **驱动与逻辑分区**：
   - 左上区域：TB6612（大电流功率区）+ 电机接口（底部）
   - 右中区域：XL1509 DCDC（中等功率）
   - 右上区域：5V 输出头（纯逻辑）
   - 这种分区让 **大电流走线不穿过敏感模拟区**，避免串扰。
3. **电机接口放板边**：U40/U41 在原理图最下方——实际 PCB 上应该放在板边缘，方便电机引线向外伸出，不挡住其他元件。
4. **PGND 与 GND 分离**：TB6612 的 PGND1/PGND2（功率地）与 GND（逻辑地）在符号上是分开命名的。好的 PCB 设计会在一点做 **单点星形接地**，让大电流电机回流的噪声不污染逻辑地平面。
5. **STBY 引脚预留**：TB6612 的 STBY（待机）脚在第 19 脚——可以通过 MCU GPIO 控制，实现「软件级使能」。低功耗场景下拉低 STBY 让驱动芯片完全关断，待机电流 < 1μA。
6. **输入接口 H7 集中所有控制信号**：PWMA/AIN1/AIN2 + PWMB/BIN1/BIN2 + EA1/EB1/EA2/EB2 全部在一个 10P 排针上——MCU 只需一根 10芯扁线即可控制整块板，接线极简。

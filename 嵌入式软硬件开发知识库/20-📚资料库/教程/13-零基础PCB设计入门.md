# 13-零基础PCB设计入门

## 这条教程在解决什么

主讲人「李生」自己也是师范类院校电子信息专业出身，本科阶段实验室条件差、网上资料鱼龙混杂，靠「抄别人设计 + 嘉立创免费打样」摸索入门。这份教程定位很实在：**零基础、低成本（约 200 元预算）、用 [[嘉立创EDA]] 专业版，从原理图一路做到能焊接验证的实物板**。

它真正解决的是三件事：
1. **元器件恐惧**——先把电阻/电容/电感/二极管/三极管/MOS 这些「积木」认全，懂参数而不是死记封装。
2. **工具恐惧**——用全中文、免费、跟工厂直连的嘉立创 EDA，避开 Altium（¥1万+/年、英文、陡峭）的劝退曲线。
3. **流程恐惧**——把 [[PCB设计流程]] 拆成「画符号→画原理图→画封装→布局→布线」，用复刻降压模块、DCDC、电机驱动、STM32 核心板这些真实小项目串起来，让你「抄多了就会一点」。

核心心法一句话：**先抄后懂，从需求反推设计**。不要一上来就想原创，先复刻成熟模块，理解每个元件为什么在那里，再改需求做自己的板。

## 关键步骤（我照着做的）

教程给出的主线是「元件符号绘制 → 原理图绘制 → 元件封装绘制 → PCB 布局 → PCB 布线」，我把它对齐成工程师视角的 8 步，并补上教程里点到但没展开、而打样前必须做的铺铜/DRC：

1. **需求拆解**——先想清楚「这块板要干嘛、输入输出是什么、接什么电源、多大电流」。为什么：PCB 不是画图，是给真实电流修路，需求不清后面全错。
2. **功能框图**——把系统切成电源/主控/驱动/接口几个方块，标清谁给谁供电、谁控制谁。为什么：框图是原理图的前身，避免原理图变成一团乱麻。
3. **器件选型**——查数据手册选芯片，算功率、电流、封装（如 LDO 还是 DCDC、MOS 耐压）。为什么：选错型号板子直接不工作，选型错了原理图再漂亮也没用。
4. **原理图**——在 EDA 里放符号、用 [[网络标号]] 连线、标好电源和地。为什么：原理图描述的是「电气连接关系」，网络相同的引脚在 PCB 里必须连通，这是后续一切自动布线的依据。
5. **布局布线**——把元件摆到板子上（先放接口、电源、主控，再围周边），再走线。为什么：布局决定走线顺不顺，大电流回路要「最短最宽」，信号线要远离电感/开关节点防干扰（见 slide 59 的 DCDC 布局要点）。
6. **铺铜**——在电源/地网络铺铜皮（尤其完整 [[铺铜|地平面]]）。为什么：降低阻抗和发热、给信号提供低感回流路径、减小 EMI；地平面不能开槽切断回流。
7. **DRC**——跑 [[DRC设计规则]] 检查（线宽、间距、短路、未连接）。为什么：工厂只看 Gerber，软件帮你拦住「看起来连了其实没连」「间距太近会短路」这类低级致命错误。
8. **打样下单**——导出 Gerber/坐标文件，到嘉立创下单，免费/低价打样 + 可选 [[打样与SMT]]。为什么：设计的最终目的是拿到能焊、能跑的实物，打样是闭环验证。

> 教程里反复强调的「线宽-电流」经验值（slide 66，双层板 1oz，ΔT=10℃）直接抄：1A→15mil、2A→30mil、5A→75mil、10A→150mil。这是布局布线第 5 步的硬约束。

## 我卡住/没懂的地方

几个新手最容易绊倒的卡点，教程提到但讲得浅，需要自己补：

- **符号 vs 封装 vs PCB 封装分不清**。原理图里的「符号」只管连线逻辑，真正焊元件的是「封装/[[封装Footprint]]」；而「板子的 PCB 封装」指你要引插的核心板轮廓和排针间距（slide 70-71）。三者必须一一对应，否则原理图连对了、板子画出来元件却放不上去。
- **网络标号用不明白**。同一网络标号 = 电气相连，但新手常漏标或重名，导致「原理图看着连通、PCB 里却悬空」。这是 DRC 最容易揪出来的坑。
- **大电流与地平面**。slide 59 讲 DCDC 时提到「功率回路最短最宽、地平面不开槽、反馈线远离电感」，但没深讲 *为什么*——本质是减小环路面积和寄生电感，否则输出电压纹波大、EMI 超标。这块要结合 [[布局与布线]] 和 [[电源分割]] 自己啃。

## 它背后的原理

- **原理图的本质**：不是「画电路」，而是描述**元件引脚之间的电气连接关系**。每个网络（net）是一组逻辑上连在一起的引脚，[[网络标号]] 只是给这条网络起名字。PCB 阶段软件按网络把引脚「自动」连通——所以原理图错了，PCB 连得再漂亮也是错的。
- **封装的本质**：是「元件在板子上的物理脚印」，由 [[焊盘与过孔]]（导电连接点）+ [[丝印与位号]]（白色外框和 R1/C2 标识）组成。焊盘是元件引脚和铜箔唯一接触的地方，尺寸/间距/孔径直接决定能不能焊、接触好不好。0402 电阻焊盘中心距 0.8mm，DIP-8 直插焊盘间距 2.54mm，这些数字是行业约定，不能拍脑袋。
- **层的本质**：PCB 是多层「绝缘基板 + 铜箔」叠起来的（[[层叠与板层]]）。顶层/底层走线，中间层可走电源/地或信号；过孔（via）是打通各层铜箔的「垂直导线」。[[铺铜]] 本质是在某层整片填上铜，专门服务某个网络（通常是 GND/VCC）。
- **为什么从需求反推**：元件参数（阻值、耐压、电流）和拓扑（LDO 还是 DCDC、要不要 MOS 开关）都由需求算出来，不是抄来的。比如 12V→5V 用 LDO 还是 DCDC，要看压差和功耗——LDO 压差 7V 全变热量，大电流必用 DCDC（slide 50）。

## 我能复用/改编的点

这套「抄成熟模块 → 拆需求 → 改参数」的打法，换个需求直接套：

- **换电源需求**：把 slide 50 的 12V→5V DCDC，改成 12V→3.3V（改反馈电阻 R1/R2 比例），或 24V→5V（换更高耐压的芯片和电感）。功率预算按 slide 63 算：输入功率×效率 ≥ 总输出功率。
- **换主控**：教程复刻了 STM32F103C8T6/RCT6/VET6、STC32、TC264 多种核心板，骨架都是「电源(LDO 5V→3.3V) + 晶振(8M HSE + 32.768k LSE) + 复位(RC+按键) + 主控 + SWD 调试 + IO 引出 + BOOT 处理」（slide 73/83/84）。换芯片只要替换核心电路、核对引脚表。
- **换驱动**：TB6612 电机驱动板（slide 64-68）的「排针间距 15.24mm、线宽按电流查表」可直接搬到任意电机/功率驱动板。
- **万能起手式**：不确定怎么开始，直接用 [[PCB设计万能提示词]] 让 AI 帮你想框图和选型；做物联网项目时，这本教程的 STM32 核心板套路可对接 [[2026-OTA智能控制终端]] 的硬件底座。

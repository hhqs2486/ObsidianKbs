# 习题解析与实验指导（缪淮扣）· 索引卡

> 习题解答 + 实验指导配套书，**不是理论书**。本库不做全文 OCR，只在此索引其定位与用法。

## 这本书在解决什么
配合《数据结构（C++实现）》教材，提供：各章**习题的详细解答** + 上机**实验指导**（实验目的、步骤、参考代码）。适合「做完题对答案」和「上机实验没思路」时看。

## 关键内容（典型结构）
- **习题解析**：按章节给出教材习题的解法与代码（C++ 实现）。
- **实验指导**：每个实验含目的、内容、步骤、参考程序，覆盖线性表 / 栈队列 / 串 / 树 / 图 / 查找 / 排序 等核心结构。
- 与严蔚敏体系知识点高度重合，只是语言换成 C++。

## 我怎么用它（反推思维）
- 学完一个理论卡（如 [[图]]、[[哈希表]]、[[线性表]]）后，用它的习题来自测；卡住就看对应解析。
- 做课程实验时，按实验名找步骤与参考代码。
- 注意：代码是 **C++**（类 + 模板），与严蔚敏/高一凡的 C 实现风格不同，移植到嵌入式时注意去 STL 依赖。

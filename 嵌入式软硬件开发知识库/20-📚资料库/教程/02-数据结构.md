# 02-数据结构

## 这条教程在解决什么
解决"程序 = 数据结构 + 算法"里前半句的问题：当数据不是单纯数值计算（学生名单、文件目录、网络拓扑），怎么把数据**组织**起来、选对结构，让增删查改又快又省内存。这是航哥的 C 语言版数据结构入门，重实现、配代码，适合嵌入式学生打基础。

## 关键内容（按 PDF 章节提纲）
- 第01章 绪论：数据 / 数据元素 / 数据项 / 数据对象；逻辑结构（集合 / 线性 / 树形 / 图形）vs 存储结构（顺序 / 链式 / 索引 / 散列）。
- 第02章 算法：定义、设计要求（正确 / 可读 / 健壮 / 高效省存）；时间复杂度 `T(n)=O(f(n))` 与大 O 推导三步；空间复杂度。→ 见 [[时间复杂度]]。
- 第03章 线性表：顺序表（数组）与单链表 / 循环链表 / 双链表，插入删除对比；约瑟夫问题。→ 见 [[链表]]。
- 第04章 栈与队列：栈 LIFO（顺序栈 / 链式栈、上溢下溢）、队列 FIFO（循环队列判满、链式队列）。→ 见 [[栈与队列]]。
- 第05章 串：顺序串 / 链式串、字符串匹配（朴素 `O(mn)`、KMP `O(m+n)`）。
- 第06章 树：树与二叉树概念、遍历（前 / 中 / 后 / 层序）、二叉排序树、平衡二叉树、哈夫曼树。→ 见 [[树]]。
- 第07章 图：邻接矩阵 / 邻接表、DFS / BFS、最短路径（Dijkstra / Floyd）。
- 第08章 查找：顺序 / 折半 / 插值 / 斐波那契、索引、BST / AVL / B 树 / 红黑树、哈希表。→ 见 [[排序与查找]]。
- 第09章 排序：冒泡 / 选择 / 插入 `O(n²)`，希尔 / 堆 / 归并 / 快排 `O(nlogn)`。→ 见 [[排序与查找]]。

## 我卡住/没懂的地方
- KMP 的 next 数组为什么只和模式串自身有关、与主串无关（用"前缀 = 后缀最大长度"理解）。
- 循环队列"满"为什么故意留一个空位，判 `(rear+1)%MAX==front`。
- 递归建树 / 快排的"栈溢出"边界到底在哪。→ 见 [[递归]]。

## 它背后的原理
结构是"数据元素之间的关系"。逻辑结构决定形状（线性 / 树 / 图），存储结构决定落地方式（连续数组 or 指针串）。评价标准是**时间复杂度 + 空间复杂度 + 是否契合访问模式**：要随机访问用数组，要频繁增删用链表，要先进先出用队列。

## 我能复用/改编的点
- MCU 上用顺序表管理传感器采样缓冲；用环形队列（循环队列）做串口接收 FIFO。
- 菜单 / 目录用树；状态机可抽象成图。
- 写代码前先估复杂度、再选结构，别上来就硬写。

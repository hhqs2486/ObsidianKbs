# 算法实现及解析（高一凡）· 索引卡

> 这是一本**逐算法 C 语言实现**的配套代码集，**不是理论书**。本库不做全文 OCR（代码 OCR 质量差、价值低），只在此索引其定位与用法。

## 这本书在解决什么
严蔚敏《数据结构（C语言版）》讲原理，这本书把书里**每一个算法**都写成可编译运行的 C 代码，并配运行结果解析。适合「看懂伪代码但不会落地成 C」时对照。

## 关键内容（书的结构特点）
- 共 450 页，**每页一个算法，编号 1、2、3 … N**；目录仅为页码、无章节标题，因此无法按章检索，只能按算法号翻。
- 覆盖严蔚敏教材全部算法：线性表、栈队列、串（含 KMP）、数组与广义表、树与二叉树（遍历/线索/哈夫曼）、图（遍历/最小生成树/最短路径/拓扑）、查找（静态/动态/哈希）、排序（各类内排序）。
- 每个算法通常含：算法说明 → C 源码 → 运行示例输出 → 解析。

## 我怎么用它（反推思维）
- 写某个数据结构时，先在本库找对应理论卡（如 [[图]]、[[哈希表]]、[[KMP算法]]、[[线性表]]），再回到这本书按算法号抄/改 C 实现。
- 把它当「代码字典」：**需要某个算法的 C 落地**才翻，不要通读。
- 注意：代码基于严蔚敏教材的符号约定，变量名/结构与教材一致。

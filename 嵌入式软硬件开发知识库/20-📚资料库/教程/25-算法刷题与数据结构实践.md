# 25-算法刷题与数据结构实践

## 这条教程在解决什么
- 为嵌入式开发者整理算法与数据结构的学习路径、刷题方法论和常见错误。
- 覆盖：基础算法、数据结构、搜索与图论、数学方法、动态规划、贪心算法、时空复杂度分析、LeetCode/剑指Offer 刷题技巧。

## 关键步骤（我照着做的）

### 1. 算法学习路线
参考 [[数据结构]]、[[排序与查找]]、[[时间复杂度]]、[[递归]]：
- **第一层（基础）**：排序（快排/归并/堆排）、查找（二分/哈希）、递归、复杂度分析
- **第二层（数据结构）**：[[链表]]（单向/双向/循环）、[[栈与队列]]、[[树]]（二叉树/BST/堆/Trie）、[[哈希表]]、[[图]]（邻接表/邻接矩阵）
- **第三层（算法思想）**：[[动态规划DP]]、[[贪心算法]]、分治、回溯、双指针、滑动窗口、前缀和
- **第四层（专题）**：数学（质数/最大公约数/快速幂）、位运算（参考 [[位运算]]）、字符串（KMP 参考 [[KMP算法]]）

### 2. 刷题方法（剑指Offer + LeetCode）
- **剑指Offer**：适合入门，66 题覆盖高频面试题型，有标准解法
- **LeetCode**：按标签分类刷（数组→链表→树→DP→回溯），Hot 100 优先
- **三遍刷题法**：
  - 第 1 遍：看懂题目 → 5 分钟想思路 → 看题解 → 手写代码 → 提交通过
  - 第 2 遍：一周后不看题解重做，必须独立 AC
  - 第 3 遍：一个月后限时重做，5-10 分钟内 AC
- **笔记方式**：每道题记三行 — 思路一句话、核心代码、易错点

### 3. 笔试输入输出技巧
C 语言标准输入输出在笔试中非常重要（力扣模式不需要，ACM 模式需要）：
```c
// 读取整数
int n; scanf("%d", &n);

// 读取一行字符串
char line[1000]; fgets(line, sizeof(line), stdin);

// 读取多组测试数据
int a, b;
while (scanf("%d %d", &a, &b) != EOF) {
    printf("%d\n", a + b);
}

// 读取数组
for (int i = 0; i < n; i++) scanf("%d", &arr[i]);
```

### 4. 核心算法专题
**基础算法**：快速排序（partition + pivot）、归并排序（分治+合并）、二分查找（注意 while 条件 `l <= r` 还是 `l < r`）、前缀和、差分数组

**搜索与图论**：DFS（递归/栈）、BFS（队列，最短路径）、Dijkstra（堆优化）、拓扑排序（入度表）、并查集（连通性）

**数学知识**：筛法（埃氏筛/欧拉筛求质数）、快速幂（`pow(a, b, mod)` 二进分解）、最大公约数（辗转相除）

**动态规划**：参考 [[动态规划DP]]
- 线性 DP：最长递增子序列、最大子数组和
- 背包 DP：0-1 背包、完全背包
- 区间 DP：矩阵链乘
- 状态机 DP：股票买卖系列

**贪心算法**：参考 [[贪心算法]]
- 区间调度：按结束时间排序
- Huffman 编码：最小堆
- 跳跃游戏：维护最远可达距离

### 5. 常见错误汇总
- **数组越界**：`for(i=0; i<=n; i++) arr[i]` → 正确是 `i < n`
- **未初始化**：局部变量初始值是随机的
- **整数溢出**：`int mid = (l + r) / 2` → 安全写法 `int mid = l + (r - l) / 2`
- **递归栈溢出**：递归深度过大（如链表长度 10000 的递归反转）
- **while 死循环**：忘记更新循环变量
- **逻辑短路顺序**：`if (p != NULL && p->val == target)` — 必须先判空

### 6. 代码规范
参考 [[C语言编码规范]]：
- 变量命名有意义（`len` 而非 `l`）
- 函数功能单一
- 关键逻辑加注释
- 处理边界：空数组、单元素数组、负数

## 我卡住/没懂的地方
- DP 最难的永远是"定义 dp 数组的含义"，一旦定义对了，转移方程往往自然出来。建议从最简例子手算 dp 表。
- 二分查找的边界条件 `while (l <= r)` vs `while (l < r)` 经常搞混。记住：`l <= r` 适用于查找具体值，`l < r` 适用于查找插入位置或边界。
- 回溯算法（backtracking）的"选择 → 递归 → 撤销选择"模板是通用的，关键是搞清楚"选择列表"和"结束条件"。

## 它背后的原理（别只记操作）
- 快速排序的 partition 是关键：选一个 pivot，把小于它的放左边、大于的放右边，然后递归。平均 O(n log n)，最坏 O(n²)。
- BFS 求最短路径的原理：逐层扩展，每层步数相同，最先到达终点的就是最短路径。
- DP 的"状态转移"本质是把一个大问题拆成"已经解决的小问题+当前选择"。

## 我能复用/改编的点
> 掌握 DP/贪心/BFS 三板斧，嵌入式中的路径规划（扫地机器人、AGV 小车）、任务调度优化、传感器触发策略都能用算法思维建模。
> 刷题训练的"边界处理"习惯直接提升嵌入式代码质量（不多一行不少一行，每个 if 都有道理）。

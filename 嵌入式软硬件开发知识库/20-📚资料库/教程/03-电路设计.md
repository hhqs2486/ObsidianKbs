# 03-电路设计

## 这条教程在解决什么
一份面向嵌入式初学者的"电路设计入门到画板"讲义：从最基础的电学物理量（电流/电压/电阻/电感/电容/功率），到模拟器件（二极管、三极管、MOS管、电源），再到数字电路（门电路、施密特、555、ADC/DAC）、常用元器件（蜂鸣器、光耦、继电器、晶振、USB转串口、LDO、DCDC、TVS），最后落到"用 AD22 / 立创EDA 把一块多功能 USB 转串口板画出来并下单打样"。本质是帮你建立"元件为什么存在、原理图里每个东西干嘛用"的工程直觉，而不只是会拖库画连线。

## 关键内容（按 PDF 章节提纲）
### 第01章 电路基础
- 电流 = 电荷流动（类比水流），单位 A；直流 DC / 交流 AC。
- 电压 = 电势能，推动电流；I=U/R 欧姆定律（串联分压、并联分流）。
- 电阻封装：插针 / 贴片(0201~2512 英制) / 排阻 / 可调；贴片尺寸是"长宽高"毫米数。
- 电感：储能、阻碍电流变化、滤波、耦合；单位 H。
- 电容：储能、滤波、耦合隔离（通交流阻直流）；单位 F。
- 功率 P=VI；有功功率 W / 无功功率 VAR。

### 第02章 模拟电路基础
- 二极管：PN 结，正向导通反向截止；整流 / 保护 / 开关 / 稳压（稳压管、肖特基）。
- 三极管 BJT：E/B/C 三极，基极小电流控集电极大电流，ic=β·ib；三态：截止 / 放大 / 饱和。开关应用见 [[三极管开关电路]]。
- MOS 管：G/S/D，电压控型、输入阻抗高、速度快、功耗低，对比三极管更适合数字/开关。
- 直流电源：整流（半波 / 桥式）→ 滤波（电容 / 电感）→ 集成稳压器（W7800 三端稳压）。

### 第03章 数字电路基础
- 门电路：与 / 或 / 非 / 异或，类比"关卡"。
- 施密特触发器：双阈值(UTP/LTP)带迟滞，用于信号整形、开关去抖、正弦转方波。
- 555 定时器：外接 R+C 实现延时；无稳态(多谐振荡器)出方波，T≈0.7(R1+2R2)C。
- ADC：采样→保持→量化→编码；类型 Flash / 逐次逼近 / 双积分 / Σ-Δ / V-F；参数看分辨率、量化误差、转换速率。
- DAC：数字→模拟，开关树 / 权电阻 / 权电流型。

### 第04章 常用元器件
- 蜂鸣器：有源(自带振荡源，通电即响) / 无源(需 2~5kHz 方波驱动)；电流大需用三极管驱动。
- 光耦：LED + 光电三极管，电气隔离传信号。
- 继电器：小电流控大电流，电磁 / 固态 / 时间 / 热 / 功率继电器。
- 晶振：石英压电共振出时钟；有源 / 无源；见 [[晶振与时钟电路]]。
- USB 转串口芯片：CH340 / CP2102 / FT232 / PL2303。
- [[线性电源LDO]]（4.6）、[[开关电源DCDC]]（4.7）、TVS 静电保护（4.8）。

### 第05章 常用测量工具
- 万用表：测交直流电压 / 电流 / 电阻 / 电容 / 通断 / 二极管；大电流插 10A 孔、小电流插 mA 孔。
- 示波器、信号发生器（仅功能罗列）。

### 第06章 电路设计软件
- 对比 AD / Cadence / OrCAD / PADS / 立创EDA。
- AD22 安装、中文菜单、原理图/PCB 快捷键（g 切网格、q 切 mil/mm、Ctrl+M 测距）。
- 立创EDA 安装、注册嘉立创账号（后面用来下单）。

### 第07章 AD22 设计多功能串口（画板实战）
- 原理图 BOM：Type-C、CH340G、AMS1117-3.3、12MHz 晶振、RS485/RS232 芯片、LED、各种电阻电容 TVS 等。
- PCB 绘制：画板框(57×35mm) → 圆切角 → 布线规则(最小间距 6mil、线宽 10mil、过孔 0.3/0.45mm) → 布局 → 布线顺序(GND 最后走 + 铺铜)。
- 下单：生成 BOM + 坐标文件 → 嘉立创下单助手 → 选材质 / 颜色 / 孔径 → SMT 贴片 → 付款。
- 验证：插 USB 看电源灯、装 CH340 驱动、短接 TX/RX 自发自收测 TTL。

## 我卡住/没懂的地方
- 整流后的"滤波"具体波形怎么算、电容取值怎么定（PDF 只给了原理图名，没给公式）——待补 [[RC滤波]] 与电容储能计算。
- 无源晶振的"负载电容"为什么是 20pF、怎么算（PDF 只给了 C5/C6=20pF 没解释）——见 [[晶振与时钟电路]]。
- 复位电路、电平转换、去耦电容 PDF 没有专门章节，需自己补标准知识（见对应卡片）。
- 555 多谐振荡器充放电阈值(1/3、2/3 VCC)的来由。

## 它背后的原理
- 一切围绕"电压推动电流、阻抗决定电流分布、储能元件(L/C)决定动态"展开。
- 开关器件（三极管 / MOS）本质是"用小信号控制大电流的通断"，所以能驱动蜂鸣器、做电源、做逻辑门。
- 稳压本质是"用反馈把输出钉在设定值"：LDO 调功率管压降，DCDC 调开关占空比。
- 数字世界建立在"阈值 + 迟滞 + 采样量化"上，把连续模拟变成 0/1。

## 我能复用/改编的点
- 画任何 MCU 最小系统：电源(LDO) + 晶振 + [[复位电路]] + [[去耦电容]] 四件套，直接套第07章 BOM。
- 需要 5V↔3.3V 通信时用 [[电平转换]] 思路，别直接把 5V 接到 3.3V 引脚。
- 驱动大电流负载（蜂鸣器 / 继电器 / 电机）一律"IO → 限流电阻 → 三极管基极 → 负载"，别直驱。
- 按键 / 机械开关加 [[RC滤波]] + 施密特去抖。
- 板子直角改圆角、GND 铺铜、线宽 / 过孔规则可直接复用 7.3 的参数。

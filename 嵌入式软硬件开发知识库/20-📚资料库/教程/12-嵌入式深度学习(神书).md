# 12 · 嵌入式深度学习（神书）

## 这本书是什么
《Embedded Deep Learning》（B. Moons et al., Springer 2019）是一本**硬核学术专著**，讲如何把深度神经网络高效部署到资源受限的嵌入式/电池设备。它不教你怎么训练模型，而是教你怎么让已训练好的模型在**功耗、面积、精度**之间取得最优权衡。全书 216 页、7 章。

## 主线：从"算法"到"硅"
全书沿一条递进主线展开，每一层都对应一张概念卡：
- 基础：[[机器学习]] → [[深度学习]] → [[神经网络]] / [[卷积神经网络CNN]] / [[循环神经网络RNN]]（训练链：[[反向传播]] → [[损失函数]] → [[优化器]]）
- 矛盾：[[嵌入式深度神经网络]]（DNN 太贵，难用于 always-on）
- 解法：[[模型量化]] → [[二值神经网络]] → [[模型压缩与稀疏]] → [[分层级联处理]] → [[硬件算法协同优化]] → [[近似计算DVAFS]] → [[神经网络加速器]]

## 各章提纲

### 第1章 Embedded Deep Neural Networks（基础 + 挑战）
- 机器学习定义（监督/无监督）、深度学习三大网络（前馈 / CNN / RNN）。
- **核心矛盾**：DNN 计算与内存开销极大（数十 MB 系数、每输入数亿次运算），难用于电池 / 常开设备。
- → 见 [[嵌入式深度神经网络]]

### 第2章 Optimized Hierarchical Cascaded Processing
- 分层级联：简单样本用小模型早退，难样本才晋级大模型。
- 案例：CNN 人脸识别级联。
- → 见 [[分层级联处理]]

### 第3章 Hardware-Algorithm Co-optimizations
- 硬件-算法联合优化：同时优化网络拓扑与硬件架构。
- 量化：test-time 定点 vs train-time 量化；low-precision QNN；**int4 比 int8 同精度能效高 5–6×**。
- 聚类网络（clustered NN）。
- → 见 [[硬件算法协同优化]]、[[模型量化]]、[[模型压缩与稀疏]]

### 第4章 Circuit Techniques for Approximate Computing
- 近似计算范式：以可控精度损失换能效；DNN 对噪声有容忍度（精度未必下降）。
- DVAFS（动态电压-精度-频率缩放）：报道中最宽的能耗-精度权衡。
- → 见 [[近似计算DVAFS]]

### 第5章 ENVISION：稀疏 CNN 处理器
- 能量可伸缩的稀疏 CNN 加速器；V1 兼容 DVAS，V2 兼容 DVAFS。
- → 见 [[神经网络加速器]]

### 第6章 BINAREYE：二值网络处理器
- 二值神经网络：权重激活 ±1，乘法变 XNOR（`O = POPCOUNT(XNOR(I,W)) + B`）。
- BINAREYE：always-on 可穿戴唤醒任务；数字版 + 混合信号版 (MSBNN)。
- → 见 [[二值神经网络]]、[[神经网络加速器]]

### 第7章 Conclusions
- 总结全书贡献与未来方向（更高效的比特级表示、更优协同优化）。

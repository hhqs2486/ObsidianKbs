# 01-C语言
## 这条教程在解决什么
面向嵌入式自学者，系统建立 C 语言从"能写"到"懂为什么"的基础：从开发环境、数据类型、运算符，到数组、指针、函数、自定义类型、作用域/生存期，最后到预处理与多文件/库。PDF 是航哥嵌入式笔记，重"照着练 + 跑通结果"，本笔记补"工程师视角 + 为什么"。

## 关键内容（按 PDF 章节提纲）
- 第01章 C语言概述：发展史(C89/C99/C11/C17)、应用领域(OS/驱动/嵌入式/数据库/游戏)、VSCode+MinGW 环境配置、第一个 hello world、注释。
- 第02章 表达式：数据类型与字节数、整数进制(二/八/十/十六)、ASCII、语法符号(关键字32个/标识符/运算符)、常量与变量(auto/register/extern/static/const)、强制类型转换(显式/隐式/整数提升)、算术/关系/逻辑(短路)/位/赋值复合/逗号/三目/sizeof 运算符、运算符优先级。
- 第03章 输入输出：putchar/getchar、printf 格式符与修饰符、scanf 与"垃圾字符"处理(空格/%*c/getchar/%*[^\n])。
- 第04章 控制语句：顺序/分支/循环三结构；if-else、switch-case、for/while/do-while、goto、break/continue。
- 第05章 数组：一维/二维数组(行序优先)、冒泡排序、选择排序、斐波那契、字符数组与字符串、strcat/strcpy/strlen/strcmp/strncmp。
- 第06章 指针：地址与指针变量、&与*、指针运算、指针与一维/二维数组、字符指针、指针数组与多级指针、const/void 指针、函数指针/指针函数。
- 第07章 函数：定义/声明/调用、三种传参(复制/地址/全局)、函数指针与指针函数、函数指针数组、回调函数、递归、快速排序、封装思想。
- 第08章 自定义类型：结构体(成员/大小/数组/指针)、内存对齐、共用体(union)、枚举(enum)、typedef、位域。
- 第09章 作用域与生存期：作用域(函数原型/块/文件)、局部与全局、可见性、静态/动态生存期。
- 第10章 预处理：编译四步(预处理→编译→汇编→链接)、#include/#define(含宏函数)/#undef、条件编译(#if/#else/#elif/#ifdef/#ifndef)、防止头文件重复包含、多文件编译、静态库/动态库。

## 我卡住/没懂的地方
- 指针与数组的关系：a 是地址常量、p 是指针变量，a[i] / p[i] / *(a+i) / *(p+i) 四者等价的本质没吃透。
- 内存对齐为什么会让 sizeof(struct) > 成员之和，以及 #pragma pack 的影响。
- 递归的"递推+回归"两个阶段，尤其是快速排序里基准值归位那一刻。
- 联合体位域嵌套描述寄存器（APSR 例子）的字节重叠解读。

## 它背后的原理
- 程序入口是 main；编译链路是 预处理(文本替换/头展开)→编译(C→汇编)→汇编(→机器码 .o)→链接(合库成可执行)。
- 变量=带类型的内存块；类型决定"占多大、怎么解释位"。指针=存放地址的变量，&取地址、*取值，互为逆运算。
- 栈管理局部变量生命周期：调用压栈分配、返回弹栈释放；static 局部在静态区、只初始化一次。
- 计算机用补码表示负数，位运算直接操作二进制位，是嵌入式操控寄存器的基础。

## 我能复用/改编的点
- 把"置位/清位/取位"封装成宏：#define BIT(n) (1u<<(n))，x|=BIT(3) / x&=~BIT(3) / ((x>>3)&1)。
- 用 #ifndef _XXX_H 守卫头文件，驱动 .h 必加。
- 用 union+位域描述 MCU 外设寄存器，同时支持位访问和整字访问。
- 用函数指针数组做状态机/中断回调表。

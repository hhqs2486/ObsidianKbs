# 嵌入式Linux学习路线

> 路线图来自资料包 `学习路线思维导图`，已复制进库可直接预览。卡片知识见 [[嵌入式Linux地图]]。

## 一、总览：嵌入式 Linux = 四大块
bootloader（如 [[uboot与启动流程]]）→ 内核 → 驱动（[[Linux驱动与内核模块]]，配合 [[设备树DeviceTree]]）→ 根文件系统（[[交叉编译与根文件系统]]）。

## 二、三阶段学习路径（循序渐进，别跳）
1. **应用开发**：C 语言扎实 → 文件 IO（[[Linux文件IO与系统调用]]）→ 多进程/多线程 → 网络编程 → 可选 QT/Android。
2. **系统 / 移植**：uboot 移植、内核裁剪移植、根文件系统构建、[[交叉编译与根文件系统]]。
3. **驱动开发**：字符/块/网络驱动，从设备树到 `file_operations`。

## 三、两个常见误区
- 死磕桌面/服务器 Linux 使用（那只当开发工具，1~2 天会命令即可）。
- 零基础硬读内核源码（以卵击石，先有应用/驱动基础再带着目的读）。

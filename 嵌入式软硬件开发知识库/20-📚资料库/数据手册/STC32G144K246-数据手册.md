# STC32G144K246 数据手册笔记

> 抽取自《STC32G144K246-LQFP100 规格书》（深圳国芯人工智能有限公司，资料更新 2025-12-26，标注为「初稿框架，逐章校核」）。下文参数均按手册实抽，存在手册前后不一致处已标注页码供核对。

## 概要

STC32G144K246 是**车规 AEC-Q100 Grade1 级的 32 位 8051（Intel 80251 架构）MCU**，单时钟/机器周期（1T），内置 DSP32 与 TFPU 硬件加速、大容量 Flash/SRAM、丰富模拟外设（双 12 位 ADC/DAC、4 运放、4 比较器）及全速 USB / CAN-FD / LIN 等通信接口。典型用途：**平衡车 / 智能车核心板、电机控制、工业与车载电子、音频处理**。

## 关键参数

| 参数 | 数值（手册出处） |

| 内核 | 32 位 80251（兼容传统 8051 指令集，1T）；硬件 DSP32(74MHz) + TFPU(230MHz) 加速（封面 / 第 142 页） |

| EEPROM | 以 IAP 方式在 Flash 中模拟，地址固定 `FC:2800H`（第 114 页） |

| ADC | 2 组独立 12 位 ADC，每组 16 通道（共 32 通道）（第 142 页）；注意选型简介写「15+15 通道」（第 140 页），需核对手册第 140–142 页 |
| DAC | 2 组独立 12 位高速 DAC（第 142 页） |
| UART | 8 路（UART1~UART8，支持同步/异步、DMA、掉电唤醒）（第 140 页及外设章节） |
| SPI | 4 路（SPI1~SPI4）+ QSPI（第 140、142 页） |
| I2C | 2 路（I2C1~I2C2，支持 DMA、掉电唤醒）（第 140 页） |
| I2S | 2 路（音频总线，全双工录音+放音，掉电唤醒）（第 140 页） |
| CAN | 3 路 CAN-FD（CAN1~CAN3，汽车电子通讯，掉电唤醒）+ LIN 总线（第 140 页） |
| 比较器 | 4 路（CMP1~CMP4，6P6N 模式：6 正输入 + 6 负输入）（第 142 页） |
| 运算放大器 | 4 路（OPA1~OPA4，可作 PGA）（第 142 页） |
| PWM | 2 组 16 位高级 PWM 定时器（PWMA/PWMB，互补/对称/死区，时钟可达 230 MHz）+ 定时器 PWM 输出（第 142 页） |
| 定时器/计数器 | 14 个：T0~T11、T17、T18（外部管脚可掉电唤醒）+ 掉电唤醒专用定时器（第 142 页） |
| USB | 全速 USB 2.0/1.1，16 个双向端点，支持 USB-CDC / USB-HID（第 140、196 页） |
| RTC | 有（年/月/日/星期/时/分/秒/次秒 1/128 s，闹钟，复位不丢计数）（第 140、196 页） |
| DMA | 多路 DMA 覆盖 USART/SPI/I2C/I2S/ADC/PWM/TFT 等（第 140 页） |

| 看门狗 | 有（WDT_CONTR）（第 142、196 页） |

| 仿真/下载 | 硬件 USB 直接下载与仿真、SWD 硬件仿真（P3.0/P3.1，需 USB-Link1D）、串口下载（第 140、196 页） |

## 引脚与封装

- **封装**：LQFP100（100 引脚，引脚间距 0.5 mm，本体 16 mm × 16 mm，见手册第 4.17 节）。
- **电源类引脚**：`Vcc`（多组数字电源）、`Core_Vcc`（内核电源）、`AVcc`（ADC 模拟电源，复用 P1.2）、`VRef+` / `VRef-/AGnd`（ADC 参考电压）、`UCap`（内核稳压电容脚）、多组 `GND`。
- **地**：多组 `GND`（含 `AGnd` 模拟地）。
- **复位脚**：`P5.4`（标 `nRST`，低电平有效；出厂默认作 I/O，ISP 下载时可配置为复位脚）（第 196 页）。
- **晶振脚**：`P1.6` = XTALO（晶振输出）、`P1.7` = XTALI（晶振输入），支持外部 4~80 MHz 晶振及外部 32.768 kHz 晶振（第 196 页；注意第 141 页写 4~40 MHz，频率上限需核对手册）。
- **下载 / 通信脚**：`P3.0` = D-/RXD（USB D− 兼 UART 接收）、`P3.1` = D+/TXD（USB D+ 兼 UART 发送）；硬件 USB 直接下载、串口下载与 SWD 仿真均经此两脚（第 196、879–880 页）。

## 外设资源

- **ADC**：2 组独立 12 位 ADC，每组 16 通道（共 32 通道），支持 DMA（第 142 页）。详见 [[ADC]]。
- **DAC**：2 组独立 12 位高速 DAC（第 142 页）。
- **UART**：8 路（UART1~UART8），同步/异步、DMA、掉电唤醒（第 140 页）。详见 [[UART]]。
- **SPI**：4 路 SPI（SPI1~SPI4）+ QSPI，DMA、掉电唤醒（第 140 页）。详见 [[SPI]]。
- **I2C**：2 路（I2C1~I2C2），DMA、掉电唤醒（第 140 页）。详见 [[I²C]]。
- **I2S**：2 路，全双工音频（第 140 页）。
- **CAN / LIN**：3 路 CAN-FD（CAN1~CAN3）+ LIN（第 140 页）。
- **比较器 / 运放**：4 路比较器（CMP1~CMP4，6P6N）+ 4 路运放（OPA1~OPA4，可作 PGA）（第 142 页）。
- **PWM / 定时器**：2 组 16 位高级 PWM（PWMA/PWMB，互补/死区，230 MHz 时钟）+ 14 个定时器/计数器（T0~T11、T17、T18）及掉电唤醒定时器（第 142 页）。详见 [[定时器与PWM]]。
- **GPIO**：最多 90 个，所有 I/O 支持高/低电平、上升沿、下降沿中断并可掉电唤醒；传统外部中断 INT0~INT4（第 140、196 页）。详见 [[GPIO]]。
- **USB / RTC / DMA**：全速 USB（CDC/HID，16 端点）、RTC 实时时钟、多路 DMA（第 140 页）。
- 中断：I/O 均可中断（5 种模式），含 INT0~INT4 及大量外设中断源（中断向量表见第 100 页附近，编号至 120+）。

## 时钟与电源

- **时钟源**（系统时钟 SYSCLK 可选 6 源，第 240 页）：
  - 内部高速 IRC：多频段、最高 **74 MHz** 可调（满足串口通信，支持追频），精度随温度漂移（第 140 页）。
  - 内部低速 IRC：约 30 kHz（第 196 页）。
  - 内部 48 MHz IRC（IRC48MCR）。
  - 外部晶振 / 外部时钟：4~80 MHz（第 196 页，上限需核对）；外接 32.768 kHz 晶振可用于 IRC 校准降辐射（第 7 章）。
  - 两组独立 PLL：倍频后供 TFPU / PWM / I2S / SPI 等高速外设（手册第 141 页标 500 MHz、第 196 页标 96/144 MHz，频率值需核对）。
  - 系统时钟经 CLKDIV 分频得到 SYSCLK；i-Cache + WTST 等待控制使 CPU 不再受慢速 Flash（33~40 MHz）限制，可跑到 64~120 MHz（第 238 页）。
- **电源**：工作电压 1.9~5.5 V；内部 LDO 给内核供电（Core_Vcc + UCap 电容）；ADC 独立模拟电源 AVcc 与参考 VRef。电源与去耦设计见 [[线性电源LDO]] / [[开关电源DCDC]] / [[去耦电容]]；多电源域分割见 [[电源分割]]。
- **复位**：上电复位 1.7~1.9 V、P5.4 复位脚（低有效）、看门狗溢出、低压检测（4 级 2.0/2.4/2.7/3.0 V）、软件复位；内置专业级复位，省去传统阻容上电延时（第 196、230 页）。详见 [[复位电路]]。
- **看门狗**：硬件看门狗（WDT_CONTR），见 [[看门狗]]。
- **时钟电路**设计要点见 [[晶振与时钟电路]]。

## 典型应用

- **平衡车 / 智能车核心板**：双 12 位 ADC 采集陀螺仪/编码器，高级 PWM 驱动电机，CAN-FD/LIN 做车载通信，TFPU 跑浮点控制算法（参考核心板见 [[板级实战-STC32G144K246核心板]]）。
- 工业控制 / 电机驱动（PWM + 比较器 + 运放构成电流环）。
- 车载电子（车规 Grade1、CAN-FD/LIN）。
- 音频处理（I2S + 双 DAC + TFPU）。
- USB 设备（全速 USB，免外部晶振/复位即可下载仿真）。

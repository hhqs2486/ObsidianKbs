# 2026-07-23 AI 工具笔记

## ego lite
https://github.com/citrolabs/ego-lite

将 AI 浏览器自动化的 Token 消耗降低至原来的四分之一。

## Chrome Agent

基于 Chromium 内核开发的免费 Mac 端浏览器，主打与 AI Agent 协作，可导入 Chrome 的登录状态、插件等本地离线存储数据，解决传统工具重复登录的痛点。

**架构优势：** 采用 Space 多独立工作空间架构，支持多任务并行且不干扰用户正常浏览，相比传统方案可降低几十倍内存与进程开销；通过单次交互完成多步操作的逻辑，减少模型与浏览器的交互次数，提升执行速度、降低 Token 消耗。

**功能复用与拓展：** 可将 AI 操作流程固化为可复用 Skill，还能编写成独立脚本实现 0Token 全自动执行；支持接入 Workbody 等 AI Agent，完成竞品评论采集、行程规划、岗位筛选等复杂办公任务。目前 Chrome Agent 仅上线 Mac 版本，可直接从官网下载使用。

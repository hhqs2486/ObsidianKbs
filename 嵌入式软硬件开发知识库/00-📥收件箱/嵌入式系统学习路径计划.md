### 自测题（5 分钟完成，确定起点）

回答以下问题，根据得分选择起点：

**C 语言部分（每题 1 分）**
1. `int a[5] = {1,2,3,4,5}; int *p = a;` 那么 `*(p+2)` 的值是多少？`p+2` 指向哪里？
2. `0x0F & 0x33` 的结果是什么？`0x0F | 0x30` 呢？`~0x0F` 在 8 位下等于多少？
3. 写一个宏，把变量 x 的第 n 位置 1：`#define SET_BIT(x, n) (?)`
4. `struct { char a; int b; char c; }` 在 32 位系统下 sizeof 是多少？为什么不是 6？
5. `#ifndef _XXX_H ... #endif` 的作用是什么？

**硬件部分（每题 1 分）**
6. 电阻分压：5V 经 10kΩ 和 20kΩ 分压，输出多少？
7. 上拉电阻的作用是什么？什么时候需要外接上拉？
8. RC 滤波器的截止频率公式是什么？

**MCU 部分（每题 2 分）**
9. GPIO 的推挽输出和开漏输出有什么区别？
10. 什么是中断？中断服务函数和普通函数有什么不同？

### 评分标准

| 得分 | 建议起点 | 说明 |
|------|----------|------|
| 0-3 分 | Phase 1 | 从 C 语言基础开始，稳扎稳打 |
| 4-6 分 | Phase 1（快速过） | C 语言查漏补缺，重点啃指针和位运算 |
| 7-8 分 | Phase 2 | 跳过 C 语言，从电路硬件基础开始 |
| 9-10 分 | Phase 3 | 直接进入 STM32 裸机开发 |

> **默认建议**：即使自测分数较高，也建议至少快速浏览 Phase 1 的教程笔记 `[[01-C语言]]`，因为嵌入式 C 有很多课堂不讲的细节（位域操作寄存器、函数指针回调表、volatile 关键字等）。

## 阶段一：C 语言与编程基础

> **耗时估计**：2-3 周（有基础可压缩到 1 周）
> **难度**：入门
> **目标**：建立"嵌入式 C"思维，不只是"能写"，而是"懂为什么"

### 学习目标
- 理解指针本质（地址变量），能自如使用指针操作数组和结构体
- 掌握位运算，能直接用 C 操控寄存器位
- 理解编译链路（预处理→编译→汇编→链接），会用多文件工程
- 掌握结构体+位域+联合体描述硬件寄存器的方法

### 教程阅读
- `[[01-C语言]]` — 航哥嵌入式笔记，10 章全覆盖
  - 重点章节：第06章（指针）、第08章（自定义类型）、第10章（预处理）
  - 可略读：第01-05章（如果课堂学过）

### 概念卡精读（按顺序）
1. `[[C语言]]` — 总览
2. `[[指针与内存]]` — 核心中的核心
3. `[[位运算]]` — 嵌入式操控寄存器的基础
4. `[[结构体与位域]]` — 寄存器描述的标准写法
5. `[[预处理与宏]]` — 驱动头文件必知
6. `[[函数与栈]]` — 理解函数调用机制
7. `[[联合体]]` — 与位域配合描述寄存器

### 拓展阅读
- `[[C语言编码规范]]` — 养成好习惯
- `[[C语言高效编程技巧]]` — 嵌入式性能优化
- `[[volatile与const关键字]]` — 面试高频，嵌入式必知

### 实践练习
1. **位操作宏库**：编写一组宏，实现置位、清位、取位、翻转位
   ```c
   #define BIT(n)         (1U << (n))
   #define SET_BIT(x, n)  ((x) |= BIT(n))
   #define CLR_BIT(x, n)  ((x) &= ~BIT(n))
   #define GET_BIT(x, n)  (((x) >> (n)) & 1)
   #define TOG_BIT(x, n)  ((x) ^= BIT(n))
   ```
2. **寄存器映射**：用 `typedef struct` + 位域描述一个虚拟 MCU 的 GPIO 端口寄存器
3. **多文件工程**：把位操作宏库拆成 `bitops.h` + `bitops.c`，配好头文件守卫

### 并行 track（可选）
- `[[02-数据结构]]` + `[[25-算法刷题与数据结构实践]]`
- 重点概念卡：`[[线性表]]` `[[链表]]` `[[栈与队列]]` `[[排序与查找]]`
- 数据结构不是嵌入式主线，但链表和队列在 FreeRTOS 和驱动开发中会频繁出现

### 完成检查点
- [ ] 能解释 `a[i]` / `*(a+i)` / `*(p+i)` / `p[i]` 四者等价的本质
- [ ] 能用位域+联合体描述一个 32 位寄存器，同时支持位访问和整字访问
- [ ] 能写出带头文件守卫的多文件工程
- [ ] 理解 volatile 修饰指针的作用（防止编译器优化掉对寄存器的读写）

3. **示波器实操**（如有条件）：测量一个 PWM 波形的频率和占空比

## 阶段六：FreeRTOS 实时操作系统

## 学习方法建议

### 1. 教程笔记怎么读
知识库里的教程笔记（如 `[[01-C语言]]`）不是简单的目录翻译，而是按以下结构组织：
- **这条教程在解决什么** — 先看这个，建立全局认知
- **关键内容** — 按 PDF 章节的提纲，知道每一章在讲什么
- **我卡住/没懂的地方** — 前人踩过的坑，重点关注
- **它背后的原理** — 工程师视角的"为什么"
- **我能复用/改编的点** — 可以直接抄到项目里的代码模板
- **关联** — 通过 Obsidian 双链跳转到相关概念卡

### 2. 概念卡怎么用
概念卡（如 `[[GPIO]]`）是知识库的最小单元，每张卡讲透一个概念：
- 先读概念卡建立认知
- 再读教程笔记看实战应用
- 做项目时回来查细节
- 卡住时把问题贴给我，我基于概念卡内容给你解答

### 3. 遇到问题怎么办
- 在 Obsidian 中搜索关键词（Ctrl+Shift+F 全局搜索）
- 查 `[[40-🐞问题排查]]` 看有没有记录过类似问题
- 把问题描述清楚发给我，我会：
  1. 在知识库中搜索相关概念卡和教程
  2. 定位可能的原因
  3. 给出修复方案
  4. 如果是共性问题，记录到 `[[40-🐞问题排查]]`

### 4. 每阶段完成后
告诉我：
- 你完成了哪些内容
- 哪些概念还不清楚
- 做了什么练习/项目

我会：
- 基于知识库内容检查你的掌握程度
- 针对薄弱点推荐补充阅读
- 给出下一阶段的详细建议
- 如果需要，调整后续路径

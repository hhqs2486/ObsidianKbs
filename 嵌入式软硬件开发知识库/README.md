# 嵌入式软硬件开发知识库

> 用 Obsidian 搭建的**本地**第二大学习系统。
> 目标：从「照教程画」进阶到「从需求反推设计」的**工程师思维**，而不是只囤成品图。

---

## 怎么用（建议工作流）

1. 用 Obsidian 打开本文件夹：`File → Open vault → 选择 "嵌入式软硬件开发知识库"`。
2. 看到新资料（教程/网页/数据手册/自己的草稿）→ 先丢进 `00-📥收件箱`。
3. 打开 `99-📒提示词库`，挑一条提示词，把 `<占位>` 换成你的内容，发给 AI 助手，让它帮你整理成笔记。
4. 按 `90-⚙️模板` 的规范，把整理好的内容落到 `10-🧠核心概念` 或 `20-📚资料库`。
5. 做项目进 `30-🛠️项目实战`，踩坑进 `40-🐞问题排查`。
6. 从 `50-🗺️索引MOC/开始这里` 导航全局，别忘了用 `[[双链]]` 把笔记连起来。

---

## 推荐插件（设置 → 社区插件 → 浏览）

| 插件 | 干嘛用 |
|------|--------|
| **Templater** | 模板里用更灵活的变量和脚本（比原生模板强） |
| **Dataview** | 用查询自动汇总笔记，如「列出所有状态=种子且 7 天没复习的概念」 |
| **QuickAdd** | 一键把灵感捕获进收件箱 |
| **Obsidian Git** | 自动备份到本地/私有仓库，防丢 |
| **Graph Analysis** | 分析知识连接，找出「孤岛笔记」 |

> 原生「Templates」插件也够用，模板文件放 `90-⚙️模板`，在设置里把模板文件夹指到它即可。

---

## 命名约定

- 概念笔记：直接用名词，如 `I²C 总线`、`上拉电阻`
- 数据手册：`型号-器件名`，如 `STM32F103C8T6-数据手册`
- 项目：`YYYYMMDD-项目名`，如 `20260720-温湿度记录仪`
- 双链：用 `[[笔记名]]` 互相连接，关系图谱才长得好看

---

## 文件夹速览

- `00-📥收件箱`：临时堆放，定期清空
- `10-🧠核心概念`：你真正「懂了」的知识（硬件/软件/工具链）
- `20-📚资料库`：原始资料的结构化摘录（数据手册/教程/文章）
- `30-🛠️项目实战`：完整项目从需求到打样的记录
- `40-🐞问题排查`：踩过的坑 + 根因 + 修复
- `50-🗺️索引MOC`：地图索引（Maps of Content），从这儿出发
- `90-⚙️模板`：所有笔记模板
- `99-📒提示词库`：给 AI 用的优化提示词

---

## 提示词库怎么用

打开 `99-📒提示词库/AI提示词库.md`，复制任意一条提示词，把 `<占位>` 替换成你的内容，粘贴给 AI 助手即可。每条都标了「何时用 / 怎么填」。

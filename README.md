## 统一目录结构

每个知识库采用同构的 Obsidian Vault 结构，便于跨库导航和图谱分组：

```
知识库/
├── 00-📥收件箱/          # 新笔记暂存区，待整理归类
├── 10-🧠核心概念/        # 概念卡：每个文件讲透一个技术概念
├── 20-📚资料库/          # 教程笔记 + 板级实战 + 数据手册
├── 30-🛠️项目实战/        # 完整项目拆解（需求→架构→选型→实现）
├── 40-🐞问题排查/        # 踩坑记录与解决方案
├── 50-🗺️索引MOC/         # Maps of Content，每库的导航入口
├── 90-⚙️模板/            # 笔记模板（概念卡/教程/项目）
└── 99-📒提示词库/        # AI 辅助提示词
```

每篇笔记带有 `tags`（库名 + 子主题/类型），便于 Obsidian 图谱分组和检索。

## 各库简介

### 嵌入式软硬件开发知识库

嵌入式系统从零基础到工程实战的完整学习资料。以 STM32F103 为主线，覆盖裸机开发、FreeRTOS、Bootloader/OTA、嵌入式 Linux、PCB 设计全链路。

- **教程**：C 语言 → 数据结构 → 电路设计 → STM32 HAL 库 → FreeRTOS → Bootloader → 嵌入式 Linux（27 篇）
- **项目**：尚硅谷 6 大实战（智能车/平衡车/无人机/心电监测/宠物定位/水质监测）+ STM32 项目合集 22 个 + OTA 企业级项目
- **PCB 设计**：嘉立创 EDA 全流程 + 6 块板级实战（STM32 最小系统板/电机驱动板/PID 控制板/平衡车控制板等）
- **特色**：每篇项目笔记按「需求拆解→功能框图→器件选型→原理图推导→检查清单」结构组织，培养从需求反推原理图的工程师思维

### Python 知识库

从 Python 基础到现代生态的系统性笔记，含 13 个子主题。

- **基础**：数据类型、控制流、函数、面向对象、异常处理
- **进阶**：装饰器、生成器、上下文管理器、元类、并发编程
- **现代生态**：Python 3.10-3.13 新特性、pydantic、typer、rich、polars、httpx、FastAPI、SQLModel、uv、ruff、loguru
- **数据结构**：线性表、链表、栈与队列、树、图、排序与查找（配套严蔚敏教材）

### 云计算知识库

云计算与云原生技术笔记，覆盖容器、编排、服务网格等核心领域。

- **容器**：Docker 容器化、镜像构建与优化
- **编排**：Kubernetes 核心概念与实战
- **服务网格**：Istio 流量管理、可观测性
- **云服务**：主流云平台服务对比与实践

### 信号与系统知识库

基于吴大正《信号与线性系统分析》第 5 版整理的信号与系统学习笔记。

- **6 大模块**：信号基础 / 时域分析 / 傅里叶变换 / 拉普拉斯变换 / Z 变换 / 系统稳定性
- **内容**：66 概念卡 + 6 模块教程 + 23 典型例题 + 8 MOC
- **特色**：主教材为图片扫描版无文字层，所有笔记由题库文字版重新整理而成

### AI 智能体知识库

人工智能与智能体技术笔记，覆盖机器学习、深度学习到智能体应用的全栈知识。

- **深度学习**：神经网络、CNN、RNN、Transformer、反向传播、损失函数
- **模型优化**：量化感知训练、知识蒸馏、模型压缩与稀疏
- **边缘部署**：TinyML、CMSIS-NN、边缘 AI 加速器与推理引擎
- **智能体**：Agent 运行时、RAG、嵌入模型

## 笔记组织方式

### 概念卡（10-🧠核心概念/）

知识库的最小单元，每张卡讲透一个技术概念。以嵌入式知识库的 `GPIO` 为例：

- **是什么**：GPIO 的 8 种工作模式及电气特性
- **为什么**：推挽 vs 开漏的电路原理与适用场景
- **怎么用**：HAL 库配置方法与代码模板
- **关联**：通过 Obsidian 双链跳转到相关概念（上拉电阻、时钟树、中断等）

### 教程笔记（20-📚资料库/教程/）

对原始教材/PDF 的结构化提炼，不是简单目录翻译。每篇包含：

- **这条教程在解决什么** — 建立全局认知
- **关键内容** — 按章节的提纲与要点
- **卡住/没懂的地方** — 前人踩过的坑
- **背后的原理** — 工程师视角的"为什么"
- **能复用/改编的点** — 可直接抄到项目里的代码模板
- **关联** — 双链跳转到相关概念卡

### 项目笔记（30-🛠️项目实战/）

完整项目的深度拆解，培养工程思维：

1. **需求拆解** — 必须实现 / 可选实现 / 硬约束
2. **功能框图** — 模块间的数据流与控制流
3. **器件选型** — 型号、选型理由、替代方案
4. **原理图推导** — 逐个模块讲清为何需要每个元件
5. **关键算法** — PID、姿态解算、滤波等核心算法实现

## 使用方式

### 环境要求

- [Obsidian](https://obsidian.md/) — 本地 Markdown 笔记应用
- [Git](https://git-scm.com/) — 版本管理与同步

### 克隆与使用

```bash
# 克隆仓库
git clone https://github.com/hhqs2486/ObsidianKbs.git

# 用 Obsidian 打开任意知识库文件夹
# 例如打开嵌入式知识库：ObsidianKbs/嵌入式软硬件开发知识库/
```

每个知识库文件夹是一个独立的 Obsidian Vault，各自打开、图谱分离。建议安装以下 Obsidian 社区插件以获得完整体验：

- **Dataview** — 动态查询与表格生成
- **Excalidraw** — 手绘图表与功能框图
- **Templater** — 笔记模板自动化

### 日常同步

```bash
# 推送本地修改
cd ObsidianKbs
git add .
git commit -m "更新笔记"
git push

# 在另一台电脑拉取最新
git pull
```

## 知识库构建方法

本知识库使用一套可复用的批量建库方法论构建，核心流程：

1. **PDF 抽取切章** — 从原始教材 PDF 提取文本并按章节切分
2. **概念卡生成** — 逐个概念写成独立笔记，带 tags 和双链
3. **教程笔记整理** — 按统一模板结构化每篇教程
4. **MOC 生成** — 自动生成 Maps of Content 作为导航入口
5. **断链检测** — 检查所有双链是否有对应目标文件
6. **联网更新** — 补充最新技术前沿知识

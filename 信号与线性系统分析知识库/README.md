# 信号与线性系统分析 · 知识库

> 基于吴大正《信号与线性系统分析》（第 5 版）教材、配套笔记与考研真题题库整理的系统化学习知识库。
> 面向「从照书看到能自己反推」的工程师思维训练：结构清晰、重点标注、知识成网、例题驱动、便于速回。

## 这个库是怎么来的
- **主教材**（477 页）为**扫描件（无文字层）**，公式以图片形式存在，无法自动抽取，因此本库**不依赖**它的原文，而是以它的章节结构为骨架。
- **配套笔记 PDF**（185 页，有文字层）提供全部 8 章的「复习笔记 + 名校考研真题详解」——本库的**核心文本来源**（定义、分类、例题均取自此处）。
- **配套题库 PDF**（253 页，有文字层）覆盖第 5–8 章（s 域 / z 域 / 系统函数 / 状态变量）的「考研真题精选 + 章节题库」，作为**进阶例题库**。
- 所有公式由整理者按标准教材内容人工补全（源 PDF 公式均为图片），确保准确。

## 标签规范（便于图谱分组）
- `信号与系统/教程` —— 模块教程笔记
- `信号与系统/<子主题>` —— 核心概念卡片（如 `信号与系统/傅里叶变换与频域`）
- `信号与系统/MOC` —— 索引地图
- `信号与系统/易错点` —— 问题排查笔记

## 每个教程笔记包含的 5 要素
1. 📌 一句话定位　2. 🎯 核心概念　3. ⭐ 重点公式与定理（含标注）
4. 📝 典型例题（含思路 / 解答）　5. 🧭 复习要点（速记）　+ 🔗 前置依赖与关联

## 怎么用
1. 用 Obsidian 打开本文件夹（它自带 `.obsidian`，是一个**独立 vault**，不会和你其他库混图）。
2. 从 `50-🗺️索引MOC/开始这里.md` 进入。
3. 想建立全局认知先看 `知识依赖关系.md`；想刷题看各章教程里的「典型例题」与 `40-🐞问题排查`。
4. 开启 Obsidian 的「关系图谱」，按 `信号与系统/...` 标签筛选，即可看到知识网络。

> 建议打开 Obsidian 设置 → 编辑器，确认「数学公式（MathJax）」已启用，本库公式用 `$...$` / `$$...$$` 书写。

# 数据可视化（Visualizing Data, Ben Fry）

## 定位 / 适合谁
- 一本「可视化方法论 + Processing 实现」的经典：提出数据可视化的七阶段框架，并用大量案例演示。
- 重要：本书用 **Processing（Java 系）** 而非 Python 实现，是方法论与设计参考书，不是 Python 教程。
- 适合：想理解「如何把数据变成图」的设计者、分析师；Python 侧可配合 [[数据可视化]] 概念卡与 Matplotlib/Seaborn 实践。

## 章节脉络（按真实 TOC，TEXT 版）
- 第1章 数据可视化的七个阶段（Acquire→Parse→Filter→Mine→Represent→Refine→Interact）
- 第2章 上手 Processing（sketch、函数、导出分发）
- 第3章 地图映射（Map）
- 第4章 时间序列（Time Series）
- 第5章 关联与相关（Connections and Correlations）
- 第6章 散点地图（Scatterplot Maps）
- 第7章 树、层次与递归（Trees, Hierarchies, Recursion）
- 第8章 网络与图（Networks and Graphs）
- 第9章 获取数据（Acquiring Data）
- 第10章 解析数据（Parsing Data）
- 第11章 Processing 与 Java 集成

## 关键知识点（双链）
- 方法论（数据科学与AI 子类，已验证存在）：[[数据可视化]]、[[数据科学]]、[[数据分析]]、[[数据清洗]]（对应 Acquire/Parse/Filter 阶段）
- 与 Python 衔接：案例思路可迁移到 [[数据可视化]] 的 Matplotlib/Seaborn 实践；[[数据清洗]] 与 Python 数据管道互补
- 本书实现语言 Processing 在库中无对应卡，故用纯文本

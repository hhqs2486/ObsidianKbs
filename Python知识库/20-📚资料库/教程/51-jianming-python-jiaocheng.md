# 简明 Python 教程（A Byte of Python）

## 这条教程在解决什么
- 为完全零基础或只有少量编程经验的人，提供一条最短路径把 Python 用起来：从安装、解释器到写出第一个脚本。

## 定位 / 适合谁
- 定位：极简入门书，英文原版 A Byte of Python，以「最小必要知识」串联起 Python 主流程。
- 适合：没接触过编程的初学者；想把零散语法串成体系的自学者。
- 不适合：想深入并发、Web、数据分析的读者（本书不覆盖这些方向）。

## 关键内容（按 PDF 章节提纲）
1. 介绍：Python 的特色（简洁、面向对象、动态类型、跨平台）。→ [[Python]]
2. 安装 Python：Linux/BSD/Windows 安装。
3. 最初的步骤：解释器、编辑器、源文件、输出输入。
4. 基本概念：字面量、常量、变量、数据类型（主要为字符串）。→ [[变量与名字绑定]] [[数据类型]] [[字符串]]
5. 运算符与表达式。
6. 控制流：if / while / for / break / continue。→ [[控制流]]
7. 函数：def、形参、局部与全局变量、默认参数、关键参数。→ [[函数基础]] [[函数(参数与返回值)]]
8. 模块：sys 模块、`__name__`、自建模块、dir()。→ [[模块与包]] [[导入系统]] [[标准库]]
9. 数据结构：列表、元组、字典、序列、引用、字符串方法。→ [[列表]] [[元组]] [[字典]] [[字符串]] [[数据类型]]
10. 解决问题——编写一个 Python 脚本（综合案例）。
11. 面向对象的编程：self、类、对象、方法、`__init__`、继承。→ [[类与对象]] [[继承]] [[魔术方法]]
12. 输入/输出：文件读写、pickle 序列化。→ [[文件IO]] [[序列化(json与pickle)]]
13. 异常：try…except、引发异常。→ [[异常处理]]
14. Python 标准库：sys、os 模块。→ [[标准库]]
15. 更多 Python 的内容：lambda、列表推导、用 *args/**kwargs 接收参数、repr。→ [[推导式]] [[函数式编程]] [[函数(参数与返回值)]]
16. 接下来学习什么？

## 我卡住/没懂的地方
- 关键参数（keyword arguments）与 *args/**kwargs 的区别需结合 [[函数(参数与返回值)]] 理解。
- pickle 与 json 的取舍见 [[序列化(json与pickle)]]。

## 它背后的原理（别只记操作）
- Python 以缩进来划分代码块（而非大括号），这决定了可读性与「代码即文档」的设计哲学（见 [[Python]]）。
- 列表/字典是可变对象、字符串/元组不可变，理解「可变 vs 不可变」能解释很多赋值与函数传参的坑（见 [[数据类型]]）。

## 我能复用/改编的点
- 第 10 章的「写脚本解决问题」套路（明确输入→处理→输出）可直接套用到日常小工具。
- 模块 `__name__ == '__main__'` 约定是几乎所有 Python 项目的入口范式（见 [[导入系统]]）。

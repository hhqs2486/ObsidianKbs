# 117 · Python源码剖析（CPython 源码导览）

## 这条教程在解决什么
这是「源码与系统」集群的**主 anchor 书**：它带读者逐行钻进 CPython 解释器的 C 代码，把「对象怎么存、字节码怎么跑、import 怎么发生、线程怎么调度、内存怎么回收」讲透。本笔记作为**阅读地图**，把全书的脉络对应到本集群已建好的概念卡上（只链接、不重建）。

## 关键内容（按全书三大板块提纲）
- **第1部分 Python内建对象（对象模型与内置类型）**
  - 一切皆对象：统一头部 `PyObject` → [[对象内存布局]]；引用计数 `ob_refcnt` → [[引用计数]]。
  - 整数/字符串/列表/字典/元组等内置对象如何在 C 层实现（对象内存布局的具体化）。
- **第2部分 Python虚拟机（执行引擎与类机制）**
  - 编译结果：源码 → `PyCodeObject`/`co_code` → [[CPython字节码]]。
  - 执行环境：每调一个函数建一帧 → [[帧栈frame]]；`yield`/`await` 挂起帧 → [[协程底层实现]]。
  - 类与对象机制：属性查找顺序与描述符优先级 → [[属性查找MRO]]；`@property`/方法/staticmethod 的本质 → [[描述符协议底层]]。
  - 模块系统：字节码 `IMPORT_NAME` → C 层 `import_module_level`/`import_submodule`/`sys.modules` → [[import机制深入]]；解释器拉起过程 → [[解释器启动流程]]。
- **第3部分 Python高级话题（内存与并发）**
  - 循环引用回收：标记-清除 + 三代分代 → [[垃圾回收GC]]。
  - 多线程：GIL 保护字节码解释与引用计数 → [[GIL深入]]。

## 我卡住/没懂的地方
- 本书基于 Python 2.5（C 代码），部分结构与现代 CPython（3.x）有差异：如 `[[协程底层实现]]` 中 `async/await` 的 `PyCoroObject` 是现代补充；`[[GIL深入]]` 的 per-interpreter GIL 是 3.12+ 演进。读时需把「原理」与「具体版本实现」分开。
- 扫描版 `full.txt` 接近 0KB，本章节提纲依据真实目录结构与各概念卡的「来源」字段反向核对而成。

## 它背后的原理（别只记操作）
- 一条主线：**对象（布局+计数）→ 编译（字节码）→ 执行（帧栈）→ 机制（属性/描述符/import）→ 兜底（GC/GIL）**。理解了这条链，就理解了「Python 代码从 .py 到真正跑起来」的全景。
- 这些概念彼此咬合：`[[引用计数]]` 是 `[[对象内存布局]]` 头部的字段；`[[垃圾回收GC]]` 补引用计数的循环引用短板；`[[GIL深入]]` 保护引用计数与字节码解释；`[[帧栈frame]]` 是 `[[CPython字节码]]` 的执行现场；`[[import机制深入]]` 依赖 `[[解释器启动流程]]` 设好的 `sys.path`/`sys.modules`。

## 我能复用/改编的点
> 排查疑难时按图索骥：import 找不到包 → 看 `[[解释器启动流程]]`/`[[import机制深入]]`；内存涨 → `[[引用计数]]`/`[[垃圾回收GC]]`（小心 `__del__`）；多线程跑不满多核 → `[[GIL深入]]`；`self.x` 取到意料之外的值 → `[[属性查找MRO]]`/`[[描述符协议底层]]`；想读懂 `dis` 输出 → `[[CPython字节码]]`/`[[帧栈frame]]`。

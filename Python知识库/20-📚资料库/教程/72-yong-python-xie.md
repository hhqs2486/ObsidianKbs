# 用Python写网络爬虫（讲义文本）

## 本书定位 / 适合谁看
- 定位：一份面向「为什么用 Python 写爬虫、怎么写一个最小爬虫」的入门讲义/幻灯片。从概念、用途、语言选型，到一个 BeautifulSoup 实战案例，再到几个进阶主题，偏科普与快速上手。
- 适合：完全没接触过爬虫、想先建立直觉的读者；也适合作为《从零开始学Python网络爬虫》（教程 71）之前的热身。
- 不适合：想系统学 Scrapy / 分布式 / 工程化的人（看 71、68/69、118）。

## 核心章节脉络（据缓存真实讲义文本整理）
> 说明：缓存 `full.txt`（约 6.7KB）是可提取的**幻灯片讲义文本**（中国科技大学 王澎），并非原书正文 OCR，但内容真实可用；据此整理，未编造代码。

- **什么是网络爬虫**：自动提取网页的程序，为搜索引擎从万维网下载网页，对应 [[网络爬虫]] [[爬虫基础]]。
- **爬虫有什么用**：通用/垂直搜索引擎、科研数据收集（人类行为、复杂网络、数据挖掘）等，对应 [[爬虫实战]]。
- **用什么语言写爬虫**：C/C++ 快但慢开发；脚本语言（Perl/Python/Java/Ruby）易学、文本处理好，适合聚焦抓取，对应 [[Python]]。
- **一个简单的 Python 爬虫**：用 BeautifulSoup 的 `findAll()` 解析瀚海星云 BBS 页面；提到广度优先 / 深度优先遍历策略、中文乱码需编码转换，对应 [[BeautifulSoup]] [[正则表达式爬虫]] [[URL去重]]（遍历去重）。
- **用 MySQL 存储数据**：连库建表、写入抓取结果，对应 [[爬虫数据存储]]。
- **统计和做图**：用 networkx / matplotlib / scipy 对抓取数据做网络与统计可视化，对应 [[数据可视化]]（matplotlib 等）。
- **高级主题（一）更健壮的爬虫**：伪装成浏览器（改 UA/请求头）、容错，对应 [[爬虫伪装]] [[User-Agent池]] [[反爬虫进阶]]。
- **高级主题（二）动态网页爬取**：内容不在 HTML 里、由内嵌脚本产生，对应 [[动态网页爬取]] [[Selenium爬虫]]。
- **高级主题（三）SQLAlchemy**：ORM 把对象映射成关系表，对应 [[爬虫数据存储]]。
- **高级主题（四）统计利器 R 语言**：R / Rpy 做统计，作为数据后处理补充。

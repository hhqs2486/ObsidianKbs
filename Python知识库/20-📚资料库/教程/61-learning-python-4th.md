## 定位
Mark Lutz 的《Learning Python》第 4 版，是公认的「最厚、最系统」的 Python 自学教程。它从零讲起，循序渐进覆盖语言全貌，最后深入高级主题。偏向**教学 + 原理**，而非速查。

## 适合谁
- 想系统、扎实学完 Python 语言全貌的读者（含零基础到进阶）；
- 愿意花时间啃大书、理解「为什么」的人；
- 需要查语言细节时，配合 [[标准库]] 文档与精要参考（069）使用。

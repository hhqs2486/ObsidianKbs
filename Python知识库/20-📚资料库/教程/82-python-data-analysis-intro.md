# Python 数据分析入门：从数据获取到可视化

## 这条教程在解决什么
按真实工作流串起一整条数据分析链路：准备环境 → 获取数据 → 存取与清洗 → 分析并可视化 → 落地到生活场景。是[[数据分析]]这张卡最贴近「初学者全流程」的配套教程。

## 定位 / 适合谁
- 定位：零基础友好的数据分析入门书，强调「先跑通再理解」。
- 适合谁：非科班/第一次做数据分析的人；想看 pandas + 可视化怎么落地的读者。已系统的可对照[[数据科学]]总览查漏。

## 关键内容（按章节脉络）
1. **准备**：环境（Python/库安装）、基础语法热身——可回看[[Python]]与[[数据分析]]前置。
2. **数据的获取**：从文件、数据库、网络等渠道拿到原始数据。
3. **数据的存取与清洗**：读写、缺失/异常值处理、规整——对应[[数据清洗]]，细分见[[缺失值处理]]、[[异常值处理]]，清洗后常用[[分组GroupBy]]/[[数据聚合]]/[[透视表]]。
4. **数据的分析及可视化**：描述统计与绘图——对应[[探索性数据分析EDA]]、[[描述性统计]]、[[相关性分析]]与[[数据可视化]]（用[[Matplotlib]]/[[Pandas]]绘图）。
5. **Python 与生活**：把前面的技能用到日常小项目。

## 它背后的原理（别只记操作）
- 分析的本质是「提问 → 取数 → 清洗 → 描述/建模 → 呈现」的循环；清洗占大部分时间，因为脏数据会让结论失真（见[[数据清洗]]）。
- 可视化不是装饰，而是用图快速发现分布、异常与相关性（见[[数据可视化]]）。

## 我能复用/改编的点
> 拿到任意数据集：先第 3 章清洗（去缺失/异常），再用第 4 章做 EDA（describe + 相关矩阵 + 图），最后选合适的图呈现结论。需要更强清洗可叠加[[特征工程]]思路。

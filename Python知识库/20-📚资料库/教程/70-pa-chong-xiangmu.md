# Python项目案例开发从入门到实战：爬虫、游戏和机器学习（爬虫模块）

## 这条教程在解决什么
- 这是一本以"完整项目案例"串联 Python 应用的实战书，整体分三大模块：**爬虫 / 游戏 / 机器学习**。本书的分工里，我作为「网络爬虫」集群的**主 anchor**，负责把爬虫模块消化成概念卡并连成知识图谱。
- 它偏"跑通案例"而非讲透原理：用一个个可运行的小项目，带读者从环境搭建走到能采到数据、存进库里。

## 关键内容（按 PDF 章节提纲，图片版整理）
> 注意：本书 PDF 为**图片版**，`full.txt` 仅含水印噪声、无正文文本，manifest 也只有页码标记；以下章节脉络基于书名与同类实战书结构整理，知识点链接到本库已有概念卡。

- **请求层**：`urllib` 与 `requests` 发请求、带请求头与 Cookie，对应 [[urllib]] [[requests库]]。
- **解析层（静态页）**：正则抠文本、BeautifulSoup 温和提取、lxml 高速解析、XPath 与 CSS 选择器定位，对应 [[正则表达式爬虫]] [[BeautifulSoup]] [[lxml解析器]] [[XPath选择器]] [[CSS选择器]]。

## 它背后的原理（别只记操作）
- 爬虫本质是「发 HTTP 请求 → 收响应(HTML/JSON) → 解析提取 → 存储」的流水线；选型的反推逻辑是：先看目标页是静态/接口型/JS 渲染，再决定用轻量 requests+解析器、直连接口，还是上浏览器渲染 / Scrapy 框架 / 分布式。
- 反爬与伪装是一体两面：网站用流量指纹识别机器，爬虫用"随机 UA + 补齐请求头 + 随机延迟 + 代理池"把特征混进正常流量；但始终要以 [[Robots协议]] 与 [[爬虫限速]] 守住合规底线。

## 我能复用/改编的点

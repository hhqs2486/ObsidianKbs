# Learning Python, 5th Edition（学习 Python 第 5 版）

## 这条教程在解决什么
- 这是一本**面向语言本身、系统且权威**的 Python 教程，目标不是教你用某个框架做项目，而是把 Python 的「语言核心」从底层对象模型一路讲到高级主题（装饰器、描述符、元类），帮你建立扎实、不浮于表面的语言直觉。
- 本书是「语言核心」聚类的 **ANCHOR（锚点）书**：它负责打底核心概念，后续 Python 精进、Web、爬虫等书都建立在它覆盖的基础之上。

## 关键内容（按 PDF 章节提纲）
全书分 9 大部分（Parts），脉络如下：

- **Part I 入门（Getting Started）**：Python 是什么、为什么用、解释器怎么跑程序、怎么运行代码（交互提示符 / 脚本 / IDE）。建立「Python 是面向对象 + 函数式、免费、可移植、易学」的整体印象。
- **Part II 类型与操作（Types and Operations）**：本书核心地基。
  - 第 4 章 引入 Python 对象类型：[[Python对象模型]] 总览，以及 [[数字类型]] [[字符串]] [[列表]] [[元组]] [[字典]] [[集合]] 的初见。
  - 第 5 章 数字类型：int 无限精度、`/` 真除 vs `//` 地板除、`Decimal`/`Fraction`、进制字面量、`bool`。
  - 第 6 章 动态类型插曲：[[变量与名字绑定]]（变量是引用、共享引用、垃圾回收、`==` vs `is`）。
  - 第 7–8 章 字符串细节、列表与字典的深度操作，[[推导式]] 在此登场（矩阵列提取等）。
- **Part III 语句与语法（Statements and Syntax）**：[[控制流]]（赋值、`if`/`while`/`for`、迭代）、文档与测试。把「操作」升级成「流程」。
- **Part IV 函数与生成器（Functions and Generators）**：[[函数(参数与返回值)]]（def/return、参数按引用传递、`*args`/`**kwargs`、多态）、[[作用域与命名空间(LEGB)]]（global/nonlocal、词法作用域）、生成器与函数式工具。
- **Part V 模块与包（Modules and Packages）**：[[模块与包]] 是什么，[[导入系统]] 如何按搜索路径定位并加载模块、包导入与命名空间包。
- **Part VI 类与面向对象（Classes and OOP）**：类、继承、运算符重载、多态等（库中由 [[类与对象]] [[继承]] [[多态]] [[运算符重载]] 等卡承接）。
- **Part VII 异常与工具（Exceptions and Tools）**：错误处理（见 [[异常处理]]）。
- **Part VIII 高级主题（Advanced Topics）**：装饰器、描述符、元类、上下文管理器等（见 [[装饰器]] [[描述符]] [[元类]] [[上下文管理器]]）。
- **Part IX 附录（Appendixes）**：内置函数、运算符优先级速查等。

> 本笔记作为 ANCHOR，重点消化并新建了 Part II–V 的「语言核心」地基概念；OOP 与高级主题部分由对应归属卡承接，本书只做链接（不新建对应卡）。

## 我卡住/没懂的地方
- 「参数按对象引用传递」与「值传递」的直觉冲突——理解了 [[变量与名字绑定]] 的引用模型后才想通：函数内改可变对象会牵连外部，这是特性不是 bug。
- 默认参数是在 def 时求值一次（故可变默认参数被多次调用共享）——这是新手最高频的坑。

## 它背后的原理（别只记操作）
- 一切围绕 [[Python对象模型]]：类型属于对象、变量只是绑定；由此统一解释动态类型、共享引用、垃圾回收、`==`/`is` 差异。
- [[作用域与命名空间(LEGB)]] 与命名空间是贯穿函数、模块、类的统一机制——理解了「赋值决定名字落在哪层作用域」，大半诡异行为都豁然开朗。
- [[导入系统]] 本质是把模块对象绑定到名字，并用搜索路径 + 命名空间避免冲突。

## 我能复用/改编的点
> 给团队做「Python 入门规范」时，可直接套用本书的讲授顺序：先对象模型 → 再类型 → 再动态类型 → 再语句 → 函数 → 模块。新人最常踩的「可变默认参数」「共享引用误改」都能在对应概念卡里点到。

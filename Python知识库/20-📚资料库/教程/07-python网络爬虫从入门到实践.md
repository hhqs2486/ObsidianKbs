# python网络爬虫从入门到实践

## 这条教程在解决什么
- 面向零基础，用「从需求反推」的方式把爬虫拆成「请求 → 解析 → 存储」的流水线。
- 覆盖从静态页到动态页、从正则到 XPath/CSS、从单页到浏览器渲染的完整入门路径，让读者拿到任意采集需求都能反推出该用什么工具链。

## 关键内容（按 PDF 章节提纲）
> 原书为图片版扫描，章节文本提取为空，以下按真实章节结构（认识爬虫→原理→urllib 实践→正则→CSS→XPath→存储→动态 Selenium→模拟登录→中文乱码→并发提速→反爬→实战）结合领域知识整理；本笔记只建"入门实践"归属的 7 个概念，其余用 双链 指向别的书。

- **基础与原理**：什么是爬虫、爬虫的工作流程（请求→响应→解析→存储）、静态页 vs 动态页的根本差异、robots.txt 与合法性。→ 见 [[爬虫基础]] [[网络爬虫]]
- **请求层（入门）**：用标准库 urllib 发 GET/POST、加请求头、处理编码与异常。→ 见 [[urllib]]；更简洁的第三方方案见 [[requests库]]
- **解析层 · 正则**：用 re 按模式从文本抠字段，适合简单/固定前后缀的页。→ 见 [[正则表达式爬虫]]
- **解析层 · 选择器**：用 CSS 选择器（类/id/层级）与 XPath（路径表达式）在 DOM 树上精确定位；两者二选一。→ 见 [[CSS选择器]] [[XPath选择器]]；解析库见 [[BeautifulSoup]]
- **动态层**：JS 渲染页先让页面跑完再解析，或直连数据接口拿 JSON；浏览器自动化方案。→ 见 [[动态网页爬取]] [[Selenium爬虫]]
- **效率与对抗（他人所有，仅链接）**：提速用 [[并发编程]]、过防护用 [[反爬虫进阶]]；实战案例如 [[爬虫实战]]（由进阶书统管）。
- **工程细节**：模拟登录维持会话、解决中文乱码、数据落库（存储章节）。

## 它背后的原理（别只记操作）
- 爬虫本质 = 请求(HTTP) + 解析(DOM/正则) + 存储；三件事彼此独立，可分别替换工具。
- "静态 vs 动态"的根本差异在**数据在哪**：HTML 源码里（直接解析）、JS 渲染后（需浏览器/等渲染）、还是独立 JSON 接口（直接调接口）。先判位置，再选工具。

## 我能复用/改编的点
> 拿到任何采集需求，先问三句：数据在 HTML 里（用 XPath选择器 / CSS选择器）、在 JS 里（Selenium爬虫 渲染）、还是独立接口（直接 requests库 / urllib 调 JSON）？据此反推工具链，再决定要不要上并发与反爬。

# 133 · Python 极客项目编程

## 这条教程在解决什么
14 个「边做边学」的趣味项目，覆盖**文本 / 图像 / 声音 / 3D / 硬件**五大领域，用真实项目把 Python 各模块串起来（标准库、`collections`、`NumPy`、`PIL`、[[pygame]]、`turtle`、`matplotlib`、`serial`、Bottle）。定位：有 Python 基础、想「做点酷东西」练手的人——每章一个完整可跑的项目，从原理到全部代码。

> 提示：本书是可读 TEXT 版，内容以 `.cache` 全文为准。部分项目依赖外部硬件（Arduino / 树莓派 / 激光）和特定库（PyOpenGL、pygame、pyserial），需自行装环境；OpenGL/着色器章节门槛较高，可先跑通再深究。

## 关键内容（按 PDF 章节提纲）
全书五部分 14 章 + 3 附录：

**第一部分 热身运动**
- 第 1 章 解析 iTunes 播放列表：读 XML/plist（`plistlib`）、`collections.Counter` 统计、`matplotlib` 绘图。
- 第 2 章 万花尺：参数方程 + `turtle` 海龟画图 + 动画。

**第二部分 模拟生命**
- 第 3 章 Conway 生命游戏：网格 + 邻域规则迭代的元胞自动机——见 [[Conway生命游戏]]。
- 第 4 章 Karplus-Strong 算法：`collections.deque` 环形缓冲合成拨弦音、[[pygame]] 播放——见 [[Karplus-Strong算法]]、[[游戏音效]]。
- 第 5 章 类鸟群 Boids：分离/对齐/聚合三条规则涌现群体运动——见 [[类鸟群Boids]]。

**第三部分 图片之乐**
- 第 6 章 ASCII 文本图形：图像灰度映射成字符画（用 `PIL` / 自写像素处理）。
- 第 7 章 照片马赛克：按平均颜色匹配小块拼出大图。
- 第 8 章 三维立体画：深度图 + 平铺图案生成 autostereogram。

**第四部分 走进三维**
- 第 9 章 理解 OpenGL：老式 vs 现代（着色器）管线、几何图元、三维变换、顶点缓冲区、纹理——见 [[OpenGL]]。
- 第 10 章 粒子系统：粒子 + 着色器 + 公告板 + 混合做火/烟——见 [[粒子系统]]。
- 第 11 章 体渲染：三维纹理 + 光线投射渲染 CT/科学体数据——见 [[体渲染]]。

**第五部分 玩转硬件**
- 第 12 章 Arduino 简介：搭感光电路、串口读数据、实时图表（`serial` + `matplotlib`）。
- 第 13 章 激光音乐秀：音频 FFT 分析 → 控制电机画激光图案（Arduino + Python）。
- 第 14 章 基于树莓派的天气监控器：DHT11 传感器 + **Bottle** Web 框架 + flot 绘图做实时看板——见 [[树莓派]]、[[Web开发]]。

附录：软件安装、基础实用电子学、树莓派建议与技巧。

## 我卡住/没懂的地方
- 硬件章节（Arduino/树莓派/激光）需要真实设备才能跑，没有硬件时只能读代码学思路。
- 第 9–11 章 OpenGL/着色器（GLSL）对没图形基础的人门槛高，建议先理解「顶点→着色→光栅化」管线（见 [[OpenGL]]）再啃代码。
- FFT（第 13 章）是信号处理的通用数学工具，本书只给用法，原理可另补。

## 它背后的原理（别只记操作）
- 每个项目都是「**领域知识 + Python 实现**」：
  - 仿真类（生命游戏、Boids）靠「循环 + 向量更新」，思想和 [[游戏循环]]、[[NumPy]] 一脉相承；Boids 的分离规则本质也是 [[碰撞检测]] 式避碰。
  - 图像类（马赛克、ASCII）靠「像素/平均颜色」比较，思路与 [[OpenCV]] 的图像运算相通（本书多直接用 `PIL` 自写）。
  - 3D 类（粒子、体渲染）靠 [[OpenGL]] 的图形管线 + GPU 渲染。
  - 音频类（K-S）靠环形缓冲延迟反馈；激光秀靠 FFT 把时域转频域。
  - 硬件类靠串口通信 + Web 看板把物理世界接进 Python。

## 我能复用/改编的点
> 换个需求，这套做法还能怎么用？
- 照片马赛克 → **头像墙 / 海报生成器**；ASCII 图形 → 终端艺术 / 日志装饰。
- Boids → **游戏里鱼群/敌群 AI**、人群疏散仿真；生命游戏 → 生成艺术 / 屏保。
- 粒子系统 → 游戏爆炸/雨雪特效；体渲染 → 医学/科学三维可视化。
- 天气监控器 → 任意「传感器 + Bottle Web 看板」（温湿度、PM2.5、电量）的通用模板。
- K-S → 程序化音效 / 简易合成器。

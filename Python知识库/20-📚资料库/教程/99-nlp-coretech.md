# python自然语言处理实战：核心技术与算法

## 这条教程在解决什么
一本**面向中文 NLP** 的实战书：从分词、词性标注、NER，到关键词提取、句法分析、文本向量化、情感分析，最后用机器学习/深度学习做 NLP。侧重"中文场景下的具体技术与算法实现"。

## 本书定位 / 适合谁
- 想系统补齐**中文 NLP 技术栈**的 Python 开发者；适合已懂 [[Python]] 与基础 [[机器学习]] 的读者。
- 与纯英文语料书（[[自然语言处理]]/NLTK）互补：本书重点在中文分词、NER、关键词提取等"中文特有问题"。

## 关键知识点（指向概念卡）
- 中文 NLP 的"分词"是英文不具备的前置步骤，直接决定后续 [[特征工程]] 质量。
- 词性标注、NER、关键词提取都属于对文本的"结构化标注"，是 [[自然语言处理]] 的基石。
- 文本向量化把离散文本变成连续向量，是连接 NLP 与 [[机器学习]]/[[深度学习]] 的桥梁。
- 情感分析本质是一个 [[分类]]（正/负）或 [[回归]]（打分）问题。

## 互补关系
- 与 [[自然语言处理]]（NLTK 书）：NLTK 偏英文语料与语言学，本书偏中文工程实战。
- 与 [[深度学习]]（八）：第10章是深度模型在 NLP 的应用入口。
- 与 [[特征工程]]/[[数据清洗]]：文本预处理质量决定模型上限。

## 我能复用/改编的点
> 做中文评论分析时，先分词+去停用词+关键词提取，再做向量化与情感分类，是一条可复用流水线。

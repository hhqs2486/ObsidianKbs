# Python 文本分析

## 这条教程在解决什么
一本聚焦"文本→可分析数据"的实战书，系统讲解如何对中文/英文文本做清洗、结构化、向量化，并接入分类、情感、主题等分析任务。

> ⚠️ **PDF 为图片版**：本库缓存 `full.txt` 接近 0KB、manifest 无章节目录，无法提取原文。以下章节脉络基于本书主题领域知识整理，**未编造任何命令或代码**，仅作结构索引；正文细节请以原书为准。

## 定位 / 适合谁
- 定位：面向文本数据的分析入门到实战，偏"工程做法"而非纯 NLP 理论。
- 适合谁：需要用 Python 处理评论、文章、日志等文本，做情感/分类/挖掘的人；建议先有 [[Pandas]] / [[NumPy]] 基础。

## 关键内容（按主题脉络，知识整理）
- **文本获取与预处理**：编码处理、正则提取、去噪——对应 [[数据清洗]]
- **分词与词性标注 / 命名实体识别**：把句子拆成可计算单元（中文常借助分词工具）
- **句法分析**：短语结构、依存关系
- **文本向量化**：词袋(BoW)、TF-IDF、词嵌入(Word2Vec 等)——是 [[特征工程]] 在文本上的具体形式
- **文本分类**：训练监督模型判断类别，见 [[分类]] [[监督学习]]
- **情感分析**：正负面极性判断（典型二分类应用）
- **主题建模**：LDA 等从无标注文本中挖主题，见 [[聚类]] / 无监督思路
- **文本聚类**：相似文档归组，见 [[聚类]] [[无监督学习]]
- **可视化与词云**：分布与高频词展示，见 [[数据可视化]]

## 它背后的原理（别只记操作）
文本是"非结构化"数据，核心难点是 **把它变成数值特征**（向量化）才能交给 [[机器学习]]。向量化前的清洗质量直接决定模型上限——所以 [[数据清洗]] 与 [[特征工程]] 是文本分析里最值钱的两步。

## 我能复用/改编的点
> 做用户评论分析时：先清洗+分词 → TF-IDF 向量化 → 接分类/情感模型；做无标注语料探索时：LDA 主题建模 + 词云快速看大致话题。

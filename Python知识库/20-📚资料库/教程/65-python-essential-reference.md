# Python 精要参考（第二版，翻译 / David Beazley）· 教程笔记

> 角色：LINK（标准库与工程集群）｜缓存质量：TEXT（10 章正文齐全，中文翻译版）

## 定位
David Beazley《Python Essential Reference》第 2 版的**中文翻译**，是一本「语言 + 少量库」的精炼案头参考。相比纯标准库读本，它更偏向**语言核心的快速查阅**——用很短的篇幅把语法、类型、函数、类、模块、IO、执行环境讲清楚，是介于教程与字典之间的「精要手册」。

## 适合谁
- 已入门、需要一个能快速翻查语法与内置机制的工程师；
- 作为日常编码的「速查卡」，而非系统教材。

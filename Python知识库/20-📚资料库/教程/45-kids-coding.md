# 与孩子一起学编程（Python 版）

## 定位 / 适合谁
- 面向青少年 / 零基础读者的趣味入门：用游戏和图形把编程概念讲活，分 25 章循序渐进。
- 适合：中小学生、亲子共学、绝对零基础；不适合寻找工程深度的人。

## 章节脉络（按 manifest TOC，PDF 为图片版）
- 起步：出发吧、内存和变量、基本数学运算、数据的类型、输入
- GUI 与判断：图形用户界面、判断再判断、转圈圈（循环）、注释、游戏时间
- 深入：嵌套与可变循环、列表、函数、对象、模块
- 图形与交互：图形、动画精灵和碰撞检测、事件、声音、更多 GUI
- 收尾：打印格式化与字符串、文件输入与输出、随机性、计算机仿真、接下来呢
- 附录：变量命名规则、自测题答案

## 关键知识点（双链到 语言核心）
- 基础：[[变量与名字绑定]]、[[数字类型]]、[[数据类型]]、[[字符串]]、[[控制流]]
- 数据结构：[[列表]]、[[字典]]（对象章涉及）
- 抽象：[[函数基础]]、[[类与对象]]、[[模块与包]]、[[文件IO]]、[[迭代器与生成器]]
- 趣味项目相关（库中暂无专门卡，故用纯文本）：Pygame 图形/游戏、动画精灵、事件循环

## 互补关系
- 与《零基础入门学习Python（小甲鱼）》《跟老齐学Python 轻松入门》同为零基础入门，本书最「游戏化」。

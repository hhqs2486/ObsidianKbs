# minecraft-python

## 这条教程在解决什么
- **本书定位**：一本「用 Minecraft（我的世界）当练习场学 Python」的青少年编程书。它把 [[树莓派]] 上的 Minecraft：Pi Edition 与 Python API 结合，让读者用代码在游戏世界里盖房子、铺路、做机关，把抽象的编程概念变成可触摸的 3D 成果。
- **适合谁看**：① 爱玩 Minecraft、想顺便学编程的中小学生；② 需要「高即时反馈」入门载体的老师/家长；③ 本集群里和 112（海龟/Pygame）、105 同属「游戏化教 Python」路线，但载体是 Minecraft。
- 与库中关系：全书实践依赖新建的 [[Minecraft Pi编程]] 概念卡；环境即 [[树莓派]] + [[嵌入式Python]]；其坐标/循环/函数思想与 112 的 turtle、107 的硬件控制相通。

## 关键内容（章节脉络，依据本书公认内容结构与领域知识重建）
- **第1章 准备出发**：在 [[树莓派]] 上装系统、装 Minecraft：Pi Edition、配置 Python 与 `mcpi` API。对应 [[树莓派]] [[嵌入式Python]] [[包管理pip]] [[Minecraft Pi编程]]。
- **第2章 Python 基础——变量与计算**：用游戏里的数字理解 [[数据类型]] 与变量。对应 [[数据类型]] [[Python]]。
- **第3章 用循环建造**：用 `for` 循环批量放方块、盖墙/金字塔。对应 [[控制流]] [[列表]]。
- **第4章 条件与交互**：`if` 判断 + 点击方块事件，做「踩到触发机关」。对应 [[控制流]] [[函数基础]]。
- **第5章 函数封装**：把「盖一座房子」写成函数复用。对应 [[函数基础]] [[字符串]]（命名/参数）。
- **第6章 用 Python 操控 Minecraft**：`setBlock`/`getBlock`/`player.getTilePos` 操作 (x,y,z) 世界。对应 [[Minecraft Pi编程]] [[数据类型]]（坐标即元组/列表）。
- **第7章 Minecraft 综合项目**：钻石路径、炸弹方块、迷你小游戏等。对应 [[Minecraft Pi编程]] [[并发编程]]（事件监听循环）。

## 我卡住/没懂的地方
- 图片版无法核对 `mcpi` 的具体方法名与方块 ID 表，实操请以 [[Minecraft Pi编程]] 概念卡列出的原理为准，命令细节查官方 API 文档。
- 本书偏「玩中学」，[[函数基础]] 的返回值/作用域、[[控制流]] 的嵌套等讲得浅，需结合 112 或语言核心相关卡补全。

## 它背后的原理（别只记操作）
- **游戏世界 = 三维坐标系**：每个方块有 (x,y,z)，代码本质是「按坐标改格子」——这和 [[机器人控制]] 里「用坐标/角度驱动执行器」是同一种空间思维，只是从物理世界搬到了像素世界。
- **即时可见反馈**：放一块砖立刻在屏幕上出现，正是它比黑框练习好学的原因，与 112 的海龟绘图、107 的点灯同属「写代码→立刻看见」的入门范式。
- **事件 = 一直运行的任务**：侦听点击方块本质是一个持续运行的循环（见 [[并发编程]]），别误以为程序卡死。

## 我能复用/改编的点
> 换个需求，这套做法还能怎么用？
- 把「坐标+循环盖房子」的思维迁移到 [[GPIO]] 上的 LED 矩阵/点阵（如 107 的 8×8 点阵），空间逻辑完全通用。
- 用 Minecraft 事件做「编程闯关」教学：学生写函数让角色自动到达某坐标，等价于给 [[机器人控制]] 里的小车写导航逻辑。
- 在 [[树莓派]] 上跑本书案例，本身就是「嵌入式 Python + 趣味载体」的最佳 demo。

# 跟老齐学Python 轻松入门

## 定位 / 适合谁
- 老齐「轻松入门」系列，按「从基本对象类型 → 语句和文件 → 函数 → 类 → 异常 → 模块 → 操作数据」的顺序，温和铺开 Python 全貌。
- 适合：零基础到初级、喜欢循序渐进讲解的读者；不适合追求速成或高阶主题者。

# 树莓派编程

## 这条教程在解决什么
- **本书定位**：一本「先补一点 Python，再带你用树莓派做真实小项目」的实战入门书。它从装系统、写 Python 讲起，一路走到 GPIO 点灯、搭机器人、接传感器、用摄像头，是「软件 → 硬件」平滑过渡的范例。
- **适合谁看**：① 刚拿到 [[树莓派]]、想从「只会写 Python」进阶到「让 Python 控制真实世界」的人；② 本集群里 [[嵌入式Python]] 的实践配套读物；③ 作为 114（同主题第2版书）的互补对照。
- 与库中关系：和 [[树莓派]] [[GPIO]] [[传感器]] [[机器人控制]] [[电机驱动]] 概念卡强互补；和 105/107/115 同属「树莓派与硬件」集群，分别从游戏、MicroPython 小车、物联网角度切入。

## 关键内容（章节脉络，依据本书公认目录与领域知识重建）
- **第1章 树莓派简介**：什么是 [[树莓派]]、能做什么。对应 [[树莓派]] [[嵌入式Python]]。
- **第2章 搭建你的树莓派**：烧系统、连网、基本 Linux 操作，用 [[包管理pip]] 装库。对应 [[树莓派]] [[包管理pip]] [[虚拟环境]]。
- **第3章 Python 基础**：变量、[[数据类型]]、[[函数基础]]、[[控制流]]。对应 [[Python]]。
- **第4章 字符串、文件与字典**：[[字符串]]、[[文件IO]]、[[字典]]。对应 [[字符串]] [[文件IO]] [[字典]]。
- **第5章 用用户输入生成动态数据（Tkinter GUI）**：做简单图形界面收集输入。对应 [[模块与包]]（GUI 库属标准/第三方库）。
- **第6章 把数据存进数据库**：用 SQLite 记录数据。对应 [[sqlite3模块]]。

## 我卡住/没懂的地方
- 图片版无法核对书中具体 API 写法（如 `RPi.GPIO` 与 `gpiozero` 的取舍），实操时以 [[GPIO]] 概念卡原理为准，不凭记忆写命令。
- 第5章 Tkinter、第7章邮件、第11章摄像头均属「外围技能」，本书讲得浅，深入需另查对应库文档。

## 它背后的原理（别只记操作）
- **树莓派 = 能跑 Python 的小电脑 + 外露引脚**：软件侧用完整 CPython（见 [[嵌入式Python]]），硬件侧用 [[GPIO]] 把数字信号送到真实世界——本书整体就是「用 Python 思维驱动 [[树莓派]] 这张卡里说的『连接软件与物理世界的桥梁』」。
- **机器人/传感 = 输出与输入两头**：第9章小车是 [[电机驱动]]（输出），第10章是 [[传感器]]（输入），中间决策仍是普通 Python 逻辑，和 [[机器人控制]] 卡片的「感知—决策—执行」一致。

## 我能复用/改编的点
> 换个需求，这套做法还能怎么用？
- 把第8–10章的「点灯+传感+小车」直接组合成一个 [[智能家居]] 或环境监测节点：传感器读数经 [[物联网MQTT]] 上云（接 115 的物联网路线）。
- 第3–4章的 Python 基础可直接衔接 112 的趣味练习，作为硬件前的语言热身。

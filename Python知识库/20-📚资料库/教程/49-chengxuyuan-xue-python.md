# 程序员学Python（裘宗燕）

## 定位 / 适合谁
- 面向「已有编程经验」的读者系统讲解 Python 语言本身：从基础语法到数据组织、再到面向对象与进阶主题。
- 适合：有其他语言背景、希望把 Python 学扎实（而非仅会脚本）的程序员；不适合纯零基础。

## 章节脉络（按 manifest TOC，PDF 为图片版）
- 第1章 Python 基础（词法、语句、基本执行模型）
- 第2章 数据的构造和组织（组合类型与描述式）
- 第3章 深入理解 Python（对象模型、名字绑定、作用域）
- 第4章 面向对象编程（类、继承、多态）
- 第5章 Python 编程进阶（装饰器、函数式、迭代器等）
- 附录A Python 语言简明手册；附录B 标准函数；附录C IDLE 环境；附录D 本书使用标准库包

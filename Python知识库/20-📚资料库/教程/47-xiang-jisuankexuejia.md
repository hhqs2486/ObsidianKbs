# 像计算机科学家一样思考Python（第2版）

## 定位
经典教材《Think Python》第2版的中译。不以「速成」为目的，而是训练「像计算机科学家一样分解问题、设计算法」的思维方式。逻辑清晰、习题扎实，是公认的「最像教材的 Python 书」。

## 适合谁看
- 想要「学透」而非「学过」的自学者；
- 零基础但愿意跟着习题一步步推导的人；
- 教师 / 学生用作课程主教材。

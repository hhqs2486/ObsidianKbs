# Django 中文教程（The Django Book 中文版）

## 这条教程在解决什么
用"不用框架怎么写都会很痛苦"的对照方式，把 Django 这套全栈 Web 框架讲透：从 CGI 裸写到 MVC 分层，帮你建立"模型—视图—模板"的完整心智模型，最终能独立搭出一个数据库驱动的网站。是 Django 入门最经典的教材之一（对应 1.x 时代 API）。

## 关键内容（按 PDF 章节提纲）
- **第1章 介绍 Django**：用一段 16 行 CGI 脚本对比，点出"重复连接数据库、关注 Content-Type、页面逻辑与业务耦合"三大痛点 → 引出 [[Web开发]] 框架的价值；给出 MVC 四件套雏形 `models.py / views.py / urls.py / *.html`。
- **第2章 入门**：安装、建项目、跑起 `runserver`。
- **第3章 视图和 URL 配置**：[[路由(Web)]]——`urls.py` 的正则映射到视图函数，是 Django 请求入口。
- **第4章 模板** / **第9章 模板高级进阶**：[[模板引擎Jinja2]] 的 `{% for %}` `{{ var }}` 语法、模板继承、自定义标签/过滤器。
- **第5章 模型** / **第10章 模型高级进阶**：[[ORM对象关系映射]]——用 Python 类描述数据表，避免手写 SQL；关联、聚合等进阶。
- **第6章 Admin**：自带后台，定义 Model 即自动生成管理界面（Django 内容站基因）。
- **第7章 表单** / 第8章 高级视图与 URL：[[Web表单]]、通用视图前身、URL 命名与反向解析。
- **第11章 通用视图**：把"列表/详情"这类套路抽象成可复用视图。
- **第12章 部署 Django**：[[Web部署]]（Nginx + WSGI 服务器）。
- **第13章 输出非 HTML 内容**：返回 JSON/XML、文件下载（接口雏形）。
- **第14章 会话、用户和注册**：[[会话Session与Cookie]] 与 [[用户认证Web]]（登录、注册、权限）。
- **第15章 缓存机制**：站点/视图/模板片段多级缓存。
- **第16章 django.contrib**：内置组件（auth、sessions、admin、sitemaps…）。
- **第17章 中间件**：[[中间件]] 链的钩子（请求/响应前后处理）。
- **第18章 集成已有数据库和应用**：连遗产库、复用第三方 app。
- **第19章 国际化** / **第20章 安全**：i18n 与 CSRF、XSS 等防护。

## 我卡住/没懂的地方
- 1.x 时代的 `patterns('', ...)` 路由写法与今日的 `path()`/`re_path()` 差异较大，照书抄需注意版本。
- "MVC 在 Django 里叫 MVT（Template 替 Controller）"的概念易混，实际 Controller 由框架（URLconf + View 调度）承担。

## 它背后的原理（别只记操作）
一次请求的生命周期：浏览器 → Web 服务器 → [[WSGI]] 网关 → Django [[中间件]] 链 → [[路由(Web)]] 匹配 `urls.py` → 调用 View → View 经 [[ORM对象关系映射]] 查库、把数据交给 [[模板引擎Jinja2]] 渲染 → 响应原路返回。框架把"连接数据库、拼响应头、释放资源"这些脏活标准化了，开发者只写业务四件套。

## 我能复用/改编的点
> 做"内容发布 + 后台管理"类站点（博客、CMS、内部系统）时，直接套用本书的 MTV 分层：数据建模 → 写视图 → 配 URL → 写模板，再用 admin 快速获得管理界面，比从零拼 Flask 省力得多。

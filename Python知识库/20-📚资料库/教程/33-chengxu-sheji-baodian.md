## 它背后的原理（别只记操作）
- 这些“工程基本功”本质是同一主题的不同侧面：**让程序稳（异常/调试）、能持久（文件/序列化）、好维护（单测/虚拟环境/包管理）、处理真实文本与时间（正则/日期时间）**。
- 它们彼此咬合：[[异常处理]] `try/finally` 与 `with` 共同保证 [[文件IO]] 资源关闭；[[序列化(json与pickle)]] 落地依赖 [[文件IO]]；[[调试(pdb)]] 与 [[单元测试(unittest)]] 是排查失败的两把刀。

## 我能复用/改编的点
> 换个需求，这套做法还能怎么用？
- 做任何“要长期运行/会出错/要交付”的 Python 项目，都先搭好：`venv` 隔离 + `pip` 锁依赖 + 核心函数配 `unittest` + 出错走 `异常处理`/`自定义异常` + 数据用 `json` 持久化。这套骨架可套到爬虫、Web、数据分析任意项目。
- 教学/入门路线：把本篇“进阶核心”当作新手的「Python 工程能力 checklist」，逐个概念卡过一遍即可具备可交付能力。

# Python核心编程（第3版）·应用编程卷（高清晰完整中文版）

## 这条教程在解决什么（定位 / 适合谁）
- Wesley Chun《Core Python Applications Programming, 3rd Ed》的中文译本（应用编程卷）。
- 适合**已掌握 Python 基础语法**、想系统学习"用 Python 做实际工程"的读者：正则、网络、多线程、GUI、数据库、Web 等。
- 与 tut 30 是**同一英文原版的另一个中文扫描版本**（内容一致，扫描清晰度不同），二选一即可。

第1部分 通用应用主题
- 第1章 正则表达式 → [[正则表达式]]
- 第2章 网络编程（socket 客户端/服务器、Twisted）→ 套接字 API（无专门卡，属网络编程子类，由锚点书负责）

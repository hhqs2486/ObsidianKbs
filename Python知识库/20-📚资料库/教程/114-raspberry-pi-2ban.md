# raspberry-pi-2ban

## 这条教程在解决什么
- **本书定位**：树莓派 Python 入门的经典薄册（Simon Monk 第2版）。它从装系统、Python 语法一路讲到 [[GPIO]]、数字输入、电机输出、扩展板与摄像头，是「最省时间把树莓派用起来」的路线图；也是本集群的**第二 anchor 书**，但以链接已有概念卡为主、不复建。
- **适合谁看**：① 想要一本「短小精悍、 tomorrow 就能动手」的树莓派 Python 手册的人；② 作为 [[109-树莓派编程]]（109）的互补——109 偏项目综合、本书偏系统化速成；③ [[嵌入式Python]] 的实践速查。
- 与库中关系：几乎覆盖本集群全部核心概念卡（[[树莓派]] [[GPIO]] [[传感器]] [[电机驱动]] [[串口UART]]），并衔接语言核心与网络/Web 相关卡。

## 关键内容（章节脉络，依据本书公认目录与领域知识重建）
- **第1章 简介 / 第2章 开始上手**：烧录系统、首启、基本设置。对应 [[树莓派]] [[虚拟环境]] [[包管理pip]]。
- **第3章 Python 基础**：[[Python]] [[数据类型]] [[控制流]] [[函数基础]]。
- **第4章 字符串、列表与字典**：[[字符串]] [[列表]] [[字典]]。对应 [[数据类型]]。
- **第5章 模块**：`import` 与 [[模块与包]]、第三方库安装。对应 [[包管理pip]]。
- **第6章 文件 I/O**：读写文件。对应 [[文件IO]]。
- **第7章 网络**：用 Python 做网络请求/通信。对应 [[socket编程]] [[socket编程]]。
- **第8章 图形界面（Tkinter）**：做桌面小窗体。对应 [[模块与包]]（GUI 库）。
- **第9章 GPIO**：核心章，输出/输入引脚操作。对应 [[GPIO]] [[嵌入式Python]]。
- **第10章 数字输入**：按钮、[[传感器]]（数字量）。对应 [[传感器]] [[GPIO]]。
- **第11章 输出**：LED、PWM、[[电机驱动]]（小电机/舵机）。对应 [[电机驱动]] [[GPIO]]。
- **第12章 扩展板**：RaspiRobot 等板卡，封装 [[电机驱动]]/[[GPIO]]。对应 [[机器人控制]]。
- **第13章 树莓派摄像头**：拍照与简单视觉。对应 [[树莓派]] 多媒体接口。

## 我卡住/没懂的地方
- 图片版无法逐页核对书中示例命令（如 `RPi.GPIO` 具体调用），实操以 [[GPIO]]、[[电机驱动]] 概念卡原理为准，不凭记忆写代码。
- 第7章网络、第8章Tkinter、第13章摄像头偏概览，深入请查 [[socket编程]]、对应 GUI/视觉库文档。

## 它背后的原理（别只记操作）
- **一条主线：软件 Python → 引脚 GPIO → 物理世界**：第3–6章打语言底子，第9–12章把代码接到 [[GPIO]]（输出灯/电机、输入按钮/传感器），正是 [[嵌入式Python]] 卡片说的「用高级语言直接读写引脚」。
- **扩展板 = 把常用电路做成模块**：第12章的 RaspiRobot 板把 [[电机驱动]] 的 H 桥/供电封装好，让你只发方向+PWM 信号——和 [[机器人控制]] 里「底层交给驱动板、树莓派跑决策」一致。

## 我能复用/改编的点
> 换个需求，这套做法还能怎么用？
- 第9–11章可直接组合成 [[智能家居]] 节点：按钮/传感器输入 + 继电器输出控制灯，状态经 [[物联网MQTT]] 上报（接 115）。
- 第13章摄像头 + 第9章GPIO，可作为 [[机器人控制]] 里视觉小车的感知端雏形。

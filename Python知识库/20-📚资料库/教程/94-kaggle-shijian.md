# Python机器学习及实践——从零开始通往Kaggle竞赛之路

## 这条教程在解决什么
一本"从零搭环境到打 Kaggle"的中文实战书：先讲 Python 科学计算栈与语言基础，再用大量可运行实例逐个演示经典监督/无监督模型，最后落到泰坦尼克、图像识别等真实竞赛案例，强调"跑通一个完整流程"而非推导公式。

> ⚠️ **PDF 为图片版**：本库缓存 `full.txt` 仅约 197 字符、manifest 无可用章节标题（189 个章节页均为扫描页），无法提取原文。以下章节脉络基于本书主题领域知识整理，**未编造任何命令或代码**，仅作结构索引；正文细节请以原书为准。

## 定位 / 适合谁
- 定位：面向中文读者的机器学习"做中学"入门，弱化数学、强化代码流程与竞赛套路。
- 适合谁：想用 Python 真正跑通一个 ML 项目、准备参加 Kaggle 的新手；建议先有 [[NumPy]] / [[Pandas]] 基础。

## 关键内容（按主题脉络，知识整理）
- **环境与基础**：Python 科学计算生态（NumPy / SciPy / scikit-learn 安装与简介）、Python 语言基础——对应 [[NumPy]] [[Pandas]]
- **经典监督模型逐个实战**：K 近邻、决策树、朴素贝叶斯、支持向量机（见 [[支持向量机SVM]]）、逻辑回归、神经网络（见 [[神经网络]]）——统一归属 [[监督学习]] 与 [[分类]]/[[回归]]
- **无监督与降维**：K-Means 聚类（见 [[聚类]]）、PCA（见 [[降维PCA]]）——归属 [[无监督学习]]
- **特征与评估工程**：数据预处理、[[特征工程]]、[[交叉验证]]、模型评估（准确率/F1 等）、[[损失函数]] 与 [[梯度下降]] 直觉
- **模型集成**：随机森林（见 [[随机森林]]）、梯度提升、XGBoost 等——归属 [[集成学习]]，是竞赛提分关键
- **实战案例**：泰坦尼克生存预测、手写数字/图像识别（见 [[深度学习]] 基础）、新闻文本分类等，串起"EDA → 特征 → 建模 → 提交"的 [[数据科学]] 全流程
- **Kaggle 竞赛流程**：报名、提交、榜单、特征迭代——工程化套路

## 它背后的原理（别只记操作）
本书主线是 **"用统一 estimator 范式把每个模型跑通"**：无论 KNN 还是 SVM，都走 `fit → predict → score`，差异只在数据预处理与特征。竞赛提分的核心往往不是换算法，而是 [[特征工程]] + [[交叉验证]] 防过拟合 + [[集成学习]] 融合多模型。这与 [[神经网络]] / [[深度学习]]（图像案例）是同一目标的不同工具。

## 我能复用/改编的点
> 参加表格类竞赛时：EDA → 缺失值/编码处理（[[数据清洗]]）→ 树模型（[[决策树]]/[[随机森林]]）→ 交叉验证选特征 → 集成提交。图像类则切到 [[深度学习]] 管线。

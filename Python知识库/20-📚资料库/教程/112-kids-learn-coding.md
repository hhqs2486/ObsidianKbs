# 教孩子学编程 Python语言版

## 这条教程在解决什么
- **本书定位**：一本面向「零基础青少年（及任何编程小白）」的 Python 入门书。它不堆语法，而是用 **海龟绘图（turtle）** 和 **Pygame 小游戏** 把变量、循环、条件、函数变成看得见、玩得起来的东西。
- **适合谁看**：① 想带孩子/学生入门编程的老师家长；② 被「黑框 print」劝退、需要即时反馈的纯新手；③ 本库里 [[树莓派]] 玩家想找一套能直接在 Pi 上跑的趣味 Python 教材（书里案例在树莓派上同样适用，见 [[嵌入式Python]]）。
- 它和本集群其他书的关系：105 用 Minecraft 当沙盒、107/109/114 偏向树莓派硬件，而本书是「纯软件、先打 Python 底子」的那一本，是后面操控硬件前的语言热身。

## 关键内容（按 PDF 章节提纲）
- **第1章 Python基础——认识环境**：装 Python、写第一个程序、运行方式。对应概念 [[Python]] [[模块与包]]。
- **第2章 海龟作图——用Python绘图**：`turtle` 画线和圆、加颜色、用「一个变量搞定一切」。引出 [[变量与名字绑定]] 与 [[数据类型]]。
- **第3章 数字和变量——用Python做数学运算**：数字/操作符、[[字符串]]、[[列表]]、语法错误。对应 [[数据类型]] [[字符串]] [[列表]]。
- **第4章 循环很有趣（你可以再说一遍）**：`for`/`while`、用户输入、家庭成员螺旋线。对应 [[控制流]]。
- **第5章 条件（如果是这样该怎么办？）**：`if/else/elif`、布尔值、比较运算符、加密/解密小程序。对应 [[控制流]] [[异常处理]]（语法错误那一节）。
- **第6章 随机的乐趣和游戏**：猜数字、石头剪刀布、发牌、掷骰子、万花筒。用到 [[random模块]] 与 [[列表]]。
- **第7章 函数（那些东西有了一个名字）**：定义/调用、参数、返回值、事件处理（键盘/鼠标）。对应 [[函数基础]] [[数据类型]]。
- **第8章 定时器和动画**：引入 [[pygame]]、用 `Clock` 做移动和弹跳。对应 [[游戏循环]]。
- **第9章 用户交互——进入游戏**：点击/拖动、[[精灵Sprite]]、碰撞检测。对应 [[碰撞检测]] [[精灵Sprite]]。
- **第10章 游戏编程**：Smiley Pong / SmileyPop 完整游戏框架、计分、加音效。对应 [[pygame]] [[游戏循环]]。
- **附录**：Windows/Mac/Linux 装 Python 与 Pygame、构建自己的模块（[[模块与包]]）。

## 我卡住/没懂的地方
- 本书偏趣味、不深讲「为什么」：比如 [[函数基础]] 的返回值和作用域、[[列表]] 的引用语义，书里点到为止，需要配合语言核心相关卡补全。
- turtle/Pygame 的「事件循环」本质就是 [[并发编程]] 里持续运行的任务，书里没上升到这个抽象，建议学完后回看 [[并发编程]]。

## 它背后的原理（别只记操作）
- **即时反馈闭环**：绘图/游戏把「代码 → 画面」的延迟压到毫秒级，新手大脑能直接建立「我写的这行 = 屏幕上的那个」的因果映射，这是它比传统教材好学十倍的根本原因。
- **循环即重复劳动**：第4章的玫瑰花瓣本质是用 [[控制流]] 把「画一个圆」重复 N 次并旋转角度——这就是所有图形/动画的底层思维。
- **游戏 = 状态 + 循环 + 事件**：[[游戏循环]] 每帧重绘，[[精灵Sprite]] 是带位置的对象，[[碰撞检测]] 是比较坐标——和 [[机器人控制]] 里「感知—决策—执行」闭环是同一套思想，只是场景从物理世界换到了屏幕。

## 我能复用/改编的点
> 换个需求，这套做法还能怎么用？
- 把第2–3章的彩色螺旋线改成「用 [[树莓派]] + [[GPIO]] 控制 LED 跑马灯」——循环和坐标思维直接迁移到硬件（见 [[电机驱动]] 里的 PWM 调速同理）。
- 第10章的游戏框架可改成「用键盘方向键遥控 [[机器人控制]] 里的小车」，把屏幕事件换成串口指令（见 [[串口UART]]）。
- 教孩子时，先 turtle 建立信心，再用 Pygame 引入「对象/事件」，顺序别反。

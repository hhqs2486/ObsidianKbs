# 看漫画学Python（关东升）

## 这条教程在解决什么
- 用全彩漫画把 Python 入门知识讲“轻”、讲“好玩”，降低初学者的心理门槛。

## 定位 / 适合谁
- 定位：图文漫画式入门书，趣味性强，知识点覆盖标准入门范围。
- 适合：零基础、喜欢图文形式、想轻松入门 Python 的读者。
- 备注：漫画书文本密度低、以讲解为主，本笔记依缓存中的真实目录与章节文本整理，未编造代码。

## 它背后的原理（别只记操作）
- 面向对象三特性：封装（隐藏内部细节只留接口）、继承（子类复用父类）、多态（鸭子类型：不看继承关系，只看是否有相同行为）。
- 多线程让程序“同时”做多件事 → [[并发编程]]。

# 机器学习Python实践（魏贞原）

## 这条教程在解决什么
一本**纯实践**的机器学习书：不推导公式，而是用 [[Python]] + scikit-learn 走完"预测模型项目六步法"。核心目标——让你能独立启动并复用一套机器学习项目流程。

## 本书定位 / 适合谁
- 想**快速上手 scikit-learn 做分类/回归**的 Python 程序员；假设读者已会编程、懂一点 ML 基础。
- 与 [[深度学习]]（八）互补：本书只覆盖浅层模型（scikit-learn 不支持 GPU/深度网络），是入门首选。

## 关键知识点（指向概念卡）
- 预测模型六步法：定义问题 → 数据理解 → 数据准备 → 评估算法 → 优化模型 → 结果部署。
- 数据预处理按算法假设不同选择：尺度统一利于距离类（KNN），标准化利于高斯假设（线性/逻辑回归）。
- 算法审查思维："用数据去审算法"，而非"为数据选算法"——多试几种再比 [[交叉验证]] 结果。
- 提准确度靠 [[集成学习]]（Bagging/Boosting/Voting）与调参，防 [[过拟合]]/[[欠拟合]]。

# 从零开始学 Python（第二版）

## 这条教程在解决什么（定位 / 适合谁）
- 老齐（齐伟）风格的中文入门书，强调"从基础到能做网站 / 科学计算"。
- 适合零基础读者；前 9 章打基础，第 10–11 章偏进阶（Tornado 网站、Pandas 科学计算）。

## 核心章节脉络（12 章）
- 第1章 预备（Python 故事、安装、IDE）→ [[Python]] [[虚拟环境]]
- 第2章 基本数据类型 → [[数字类型]] [[字符串]] [[数据类型]] [[浮点数精度]] [[列表]] [[元组]] [[字典]] [[集合]]
- 第3章 语句和文件 → [[控制流]] [[文件IO]] [[迭代器与生成器]]（迭代）、自省/反射 → [[Python对象模型]]
- 第4章 函数 → [[函数基础]] [[函数(参数与返回值)]] [[闭包]] [[装饰器]]
- 第5章 类 → [[类与对象]] [[继承]] [[多态]] [[魔术方法]] [[迭代器与生成器]]（迭代器/生成器）
- 第6章 错误和异常 → [[异常处理]] [[自定义异常]]
- 第7章 模块 → [[模块与包]] [[导入系统]] [[标准库]] [[包管理pip]]（第三方库）
- 第8章 保存数据 → [[文件IO]] [[序列化(json与pickle)]]、MySQL / MongoDB / SQLite（无通用数据库卡）
- 第9章 实战
- 第10章 用 Tornado 做网站 → [[Web开发]]（无 Tornado 专门卡）
- 第11章 科学计算（Pandas 股票数据）→ [[Pandas]] [[数据科学]]
- 第12章 结尾（如何成为 Python 高手）

## 关键知识点（指向概念卡）
- 基础部分系统覆盖 [[数据类型]]、[[函数(参数与返回值)]]、[[类与对象]]、[[异常处理]]。
- 第3章"自省"与 [[Python对象模型]] 关联；第11章衔接数据科学子类的 [[Pandas]]、[[数据科学]]。

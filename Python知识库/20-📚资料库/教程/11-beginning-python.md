# Beginning Python: Using Python 2.6 and Python 3.1（Magnus Lie Hetland）

## 这条教程在解决什么（定位 / 适合谁）
- 经典**应用导向**入门书（注意基于 Py2.6 / 3.1，部分语法偏旧，如 `print` 语句、旧式类）。
- 适合想从"编程基础"过渡到"能写小项目"的读者：每章带可运行示例，后面进入文本处理、GUI、DB、网络、Web 等实战主题。

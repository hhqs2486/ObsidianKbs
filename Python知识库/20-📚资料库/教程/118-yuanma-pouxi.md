# Python源码剖析：深度探索动态语言核心技术（陈儒）

## 这条教程在解决什么
它回答一个初学者从不会问、但进阶者迟早要问的问题：**「Python 到底是怎么跑起来的？」** 本书以 CPython（Python 2.5 源码）为标本，从 C 结构体层面把「对象、字节码、虚拟机、类机制、多线程、内存管理」一层层剖开，是理解动态语言底层机制最经典的一本中文书。

## 关键内容（按 PDF 章节提纲）
本书分三大部分（PDF 第0章先讲如何自己编译 Python）：
- **第1部分 Python 内建对象**（ch11）：一切皆对象如何在 C 里落地——`PyObject`/`PyVarObject` 头部、定长/变长对象、整数/字符串/列表/字典等对象池机制。→ 见 [[对象内存布局]] [[引用计数]]
- **第2部分 Python 虚拟机**（ch12）：
  - 第7章 代码对象与字节码：`PyCodeObject`、`co_code`、`.pyc`。→ 见 [[CPython字节码]]
  - 第8章 执行环境：`PyFrameObject`、名字/作用域/LEGB、虚拟机求值循环。→ 见 [[帧栈frame]]
  - 第9–11章 表达式、控制流、函数机制（含闭包 `co_cellvars`/`co_freevars`）
  - 第12章 类机制：`tp_dict`、descriptor、MRO、metaclass。→ 见 [[属性查找MRO]] [[描述符协议底层]] [[元类]]
- **第3部分 Python 高级话题**（ch13）：
  - 第13章 解释器启动：线程环境、系统 module（`__builtin__`/`sys`/`__main__`）、激活虚拟机。→ 见 [[解释器启动流程]]
  - 第14章 import 机制：`IMPORT_NAME`、`sys.modules`、嵌套/包导入。→ 见 [[import机制深入]]
  - 第15章 GIL 与线程调度：`interpreter_lock`、时间片释放。→ 见 [[GIL深入]]
  - 第16章 内存管理与垃圾收集：对象池、arena/pool/block、标记-清除 + 三代分代。→ 见 [[垃圾回收GC]]

（协程/生成器部分本书以「frame 挂起（yield）」机制铺垫，现代 `async/await` 为后续演进，见 [[协程底层实现]]。）

## 我卡住/没懂的地方
- C3 线性化算法如何保证 MRO 的单调性——书里给了结果，数学证明需另查。
- GIL 在「时间片到点释放」的精确 tick 机制与后续 Python 版本的 GIL 重写差异。
- 第16章 arena/pool/block 三层内存池的状态机细节较繁琐，需边画图边读。

## 它背后的原理（别只记操作）
- 统一对象头（`PyObject`）是「用 C 模拟面向对象 + 多态」的关键，所有对象都能用 `PyObject*` 引用，靠 `ob_type` 运行时分派。
- 内存管理是「引用计数（实时、即时） + 标记清除/分代（延迟、破环）」双支柱。
- 字节码 + frame 的「栈式虚拟机」模型，是整个语言运行时的引擎；函数、类、协程都建立在这套 frame 机制之上。

## 我能复用/改编的点
> 换个需求：写调试器/性能剖析器时，从 `dis` + `sys._getframe()` 入手；排查内存涨涨不停时，先想循环引用与 `__del__` 干扰 GC；做高并发 I/O 时，理解 GIL 后自然选 `asyncio` 而非堆线程。

# Python 核心笔记（基于《Python核心编程(第二版)》）

## 这条教程在解决什么
- 把《Python核心编程(第二版)》浓缩成一份「核心 + 高级主题」速查笔记，帮助有 C/C++/Java 基础的人快速过一遍 Python 全貌。

## 定位 / 适合谁
- 定位：读书笔记（非入门教材），按「语言核心 + 高级应用」两条线组织；基于 Python 2.5（部分语法与 3.x 有差异，如 print 语句、raw_input）。
- 适合：已有其他语言基础、想系统梳理 Python 并顺带了解网络/数据库/GUI 等应用场景的读者。
- 不适合：纯零基础（作者也说明直接读会有困难）。

## 我卡住/没懂的地方
- 多继承下「属性查找顺序」与「如何调用父类方法」是难点（见 [[继承]]、[[类与对象]]）。
- GIL 为什么让「多线程」在 CPU 密集型任务里并不真正并行（见 [[并发编程]]）。

## 它背后的原理（别只记操作）
- 「可变 vs 不可变」贯穿对象模型：字典的键必须是可哈希的不可变对象（见 [[Python对象模型]] [[数据类型]]）。
- GIL 是 CPython 解释器的全局锁，保证同一时刻只有一个线程执行字节码，因此多线程更适合 I/O 密集型而非 CPU 密集型（见 [[并发编程]]）。

## 我能复用/改编的点
- import 顺序约定（标准库→第三方→自定义）可作为项目代码规范（见 [[模块与包]]）。
- 用 re 做「搜索 vs 匹配」、用非贪心 `?` 控制匹配长度（见 [[正则表达式]]）。

# TensorFlow技术解析与实战（李嘉璇）

## 这条教程在解决什么
一本围绕 **TensorFlow 1.x** 的"框架使用 + 实战"书：从系统架构、编程模型（图/会话/[[张量]]）讲起，再到 CNN/RNN/[[自然语言处理]]/GAN 等实战，最后覆盖分布式、移动端部署与评测体系。

## 本书定位 / 适合谁
- 想**系统学 TF 框架本身**（而不只是调库）的读者；适合已懂 [[Python]] 与基础 [[机器学习]] 的人。
- 注意：基于 TF 1.x（图与 Session 模式），与如今的 TF 2.x（Eager/Keras）差异较大，应作为"原理与生态"参考而非新项目模板。

## 核心章节脉络（按 TOC）
- **基础篇**：人工智能/[[深度学习]] 概述；环境准备（pip/conda）；[[数据可视化|TensorBoard]] 可视化；TF 基础知识（系统架构、图/操作/[[张量]]、变量作用域、神经元函数/[[激活函数]]/卷积/池化/分类、[[优化算法深度学习]]、批标准化、模型存取、队列线程、数据加载）；源代码解析。
- **第6章 神经网络发展及 TF 实现**：[[卷积神经网络]]（LeNet→AlexNet→VGG→GoogLeNet→ResNet）、[[循环神经网络]]（RNN→GRU→[[LSTM]]→双向/多层）。
- **实战篇**：第一个 TF 程序；MNIST（全连接/CNN/RNN/自编码）；人脸识别；[[自然语言处理]]（语音识别、聊天机器人）；图像+语音结合（看图说话）；**生成对抗网络**（GAN，本书独有视角，库无对应卡）。
- **提高篇**：分布式 TF（数据并行/模型并行）；XLA；TF Debugger；Kubernetes/Spark 结合；移动端（量化、iOS/Android/树莓派）；TF Serving；评测体系（BLEU、ROC/[[交叉验证|AUC]]、mAP）。

## 关键知识点（指向概念卡）
- 符号式编程：先建数据流图，再在 Session 中喂数据运行——与命令式（如 PyTorch）相对。
- 计算图里的反向传播即 [[反向传播]]，用 [[梯度下降]] 更新权重，配合 [[损失函数]]（如交叉熵）做 [[优化算法深度学习]]。
- 实战各章都是 [[深度学习]] 子结构的工程落地：CNN 用于视觉、RNN/[[LSTM]] 用于序列、GAN 用于生成。
- 批标准化对应库中 [[批量归一化]]；防止过拟合可参考 [[正则化深度学习]]。

## 互补关系
- 与 [[深度学习]]（八，动手学深度学习）：本书偏"TF 框架工程"，八偏"原理+通用实现"，可对照读。
- 与 [[卷积神经网络]]/[[循环神经网络]]/[[自然语言处理]] 概念卡互补：本书记更多"怎么在 TF 里搭出来"。
- 与量化/图像项目（OpenCV 等）可衔接做人脸识别、看图说话。

## 我能复用/改编的点
> 搭新网络前，先用 TensorBoard 的 GRAPHS/SCALARS/HISTOGRAMS 看结构与梯度分布，能提前发现梯度消失/爆炸。

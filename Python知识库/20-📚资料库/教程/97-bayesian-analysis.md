# Python贝叶斯分析（Bayesian Analysis with Python）

## 这条教程在解决什么
用**计算贝叶斯统计**的思路做数据分析：把模型写成概率模型，用 PyMC3 采样出后验分布，并量化参数的不确定性。重点不是推导公式，而是"用代码、图表、文字把贝叶斯概念讲清楚"。

## 本书定位 / 适合谁
- 面向**没有贝叶斯背景**、但会 Python（最好熟悉 [[NumPy]]、[[Matplotlib]]、[[Pandas]]）的本科生、研究生、数据科学家。
- 不要求统计学基础，刻意减少数学公式，借助 PyMC3 在有限数学水平下也能上手。
- 与 [[机器学习]] 互补：贝叶斯视角给线性/逻辑回归同时给出"最优参数 + 不确定性"，而传统最优化只给一个点估计。

## 核心章节脉络（按 TOC）
- **第1章 概率思维——贝叶斯推断指南**：概率与不确定性、贝叶斯定理与统计推断、单参数推断（抛硬币）、先验选择、如何报告结果。
- **第2章 概率编程——PyMC3 编程指南**：推断引擎、用 PyMC3 构建模型、对后验采样、模型检查与诊断（PDF 为图片版书里这部分是重点，本书是 TEXT 可正常引用代码）。
- **第3章 多参和分层模型**：冗余参数/边缘分布、高斯推断、鲁棒推断（异常值）、组间比较、分层模型与收缩（shrinkage）。
- **第4章 线性回归理解并预测数据**：一元/多元/多项式/多层 [[回归]]、与 [[机器学习]] 术语的桥接（回归=监督学习）。
- **第5章 逻辑回归做分类**（多输入/多输出 [[分类]]）。
- **第6章 模型比较**：信息准则、贝叶斯因子。
- **第7章 混合模型**：聚类、计数数据。
- **第8章 高斯过程**（非参数回归、核函数）。

## 关键知识点（指向概念卡）
- 贝叶斯推断本质是"在概率框架里描述不确定性"，与 [[机器学习]] 中 [[回归]]/[[分类]] 同宗不同表述。
- 线性回归的贝叶斯写法：y ~ Normal(α+βx, ε)，对 α/β/ε 设先验 → 同时得到点估计与置信区间。
- 分层模型用"收缩"在组间共享信息，是 [[数据科学]] 中处理小样本分组的有力工具。
- 异常值用"鲁棒推断"（厚尾分布）处理，对应 [[数据清洗]] 中的 [[异常值处理]] 思路。

## 互补关系
- 与 [[数据科学]]/[[数据分析]]（六）互补：本书提供"不确定性量化"这一它们较少强调的视角。
- 与 [[深度学习]]（八）互补：神经网络也可用贝叶斯视角解释，但本书停在经典统计模型。
- 量化/金融场景（[[回测]]、[[因子模型]]）常用贝叶斯方法做参数不确定性估计。

## 我能复用/改编的点
> 做 A/B 实验或策略评估时，与其只报一个点估计，可用 PyMC3 给出后验分布，用 HPD 区间判断"差异是否真实"。

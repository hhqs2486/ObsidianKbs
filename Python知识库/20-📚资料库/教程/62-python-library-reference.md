# Python 库参考手册（Python Library Reference 2.3.3）· 教程笔记

> 角色：LINK（标准库与工程集群）｜缓存质量：TEXT（官方参考手册中文翻译，正文齐全）

## 定位
官方 **Python Library Reference**（Release 2.3.3）的权威中文翻译，是与语言参考手册配套的「标准库 API 字典」。它不教编程，而是把每个标准库模块按主题分类、逐 API 说明，是查「某个函数签名/参数是什么」的终极去处。

## 适合谁
- 已懂 [[Python]]，需要精确查阅标准库模块接口与行为的工程师；
- 作为其他教程书的「备查手册」配合使用；
- 不适合系统学习（编排是字典式而非教学式）。

## 章节脉络（按服务类别分章）
- 第一章 内建对象 Built-In Objects：内建异常、函数、常量、内建类型（关联 [[数据类型]] [[标准库]]）
- 第二章 Python 运行时服务：顶层脚本环境（`__main__`）、`site`、`gc` 等
- 第三章 其他各类服务：所有版本通用的杂项模块
- 第四章 普遍的操作系统服务：文件/时钟等跨平台 OS 接口 —— 关联 [[os模块]] [[文件IO]]
- 第五章 可选配的操作系统服务：仅特定平台有的 OS 接口
- 第六章 互联网通讯协议及其支援：`socket`、`urllib`、邮件协议等（详见 网络编程 集群；`[[urllib模块]]`）
- 第七章 互联网资料处理：`base64`、`xml.dom`（DOM/SAX）、`htmlparser` 等 —— 关联 [[序列化(json与pickle)]] [[正则表达式]]
- 第八章 多媒体服务
- 第九章 加密服务：`md5`/`sha`/`hmac` 等
- 第十章 Python 语言服务：`tokenize`、`parser`、`py_compile`、`dis`、`compileall` —— 关联 [[模块与包]] [[调试(pdb)]]
- 第十一/十二/十三章 平台特定服务：SGI IRIX、SunOS、MS Windows

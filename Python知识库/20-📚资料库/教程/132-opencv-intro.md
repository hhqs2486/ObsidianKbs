# 132 · OpenCV 轻松入门：面向 Python

## 这条教程在解决什么
一本**面向 Python 的 OpenCV 系统入门书**，从「读图、显示、保存」一路讲到「人脸识别」，覆盖「图像处理 → 计算机视觉特征 → 机器学习识别」全链路。定位是「字典式工具书 + 实战示例」：每一章讲清一个主题的原理和 API，配可直接抄的代码，适合想系统学 OpenCV 的人当手册。

> 提示：本书是可读 TEXT 版，内容以 `.cache` 全文为准。注意它基于 **OpenCV 旧版接口**（如 `cv2.cv` 等已在新版移除/改名），学原理、按新版文档改函数名即可；BGR 顺序、`waitKey` 等细节务必留意。

全书 23 章 + 附录，分四大块：

**一、基础（第 1–5 章）**

- 第 5 章 几何变换：缩放/翻转/仿射/透视/重映射——见 [[图像处理基础]]。

**二、预处理（第 6–8 章）**

## 我卡住/没懂的地方
- 旧版 API（`cv2.cv`、`cv2.cv.CV_*` 常量）新版已移除，常量改为 `cv2.CV_64F` 风格、函数名常去 `cv` 前缀，抄代码要先查新版文档。
- `findContours` 返回值个数在 OpenCV 3/4 不同，旧书示例可能报错。
- 傅里叶/ML 章节数学味重，建议配合 [[机器学习]] 概念一起看。

## 它背后的原理（别只记操作）
- 一切基于「**图像 = [[NumPy]] 数组**」（见 [[OpenCV]]）：彩色图是 (H,W,3) 的 BGR 数组，所有函数本质是对数组做运算。
- 典型 CV 流水线：`读图` → `预处理(阈值/滤波/形态学)` → `特征(边缘/轮廓/分割)` → `识别(ML)`；每一步都可独立取用。
- 视频 = 连续帧，把单图算法套进逐帧循环即得实时能力（见 [[视频处理]]）。

## 我能复用/改编的点
> 换个需求，这套做法还能怎么用？
- **文档扫描**：透视变换拉正 + 阈值/形态学提字。
- **工业缺陷检测**：滤波降噪 → 边缘/轮廓量尺寸 → 阈值判良率。
- **摄像头实时识别**：VideoCapture 逐帧跑上述流水线 + 第 20–23 章分类器。
- 把这些基础卡（[[阈值处理]] [[边缘检测]] [[图像轮廓]] 等）当「积木」，拼任意视觉任务。

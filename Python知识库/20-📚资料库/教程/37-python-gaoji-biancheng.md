# Python高级编程

## 定位
面向已掌握 Python 基础、希望理解「语言内部机制与工程级写法」的进阶读物。主题聚焦：高级对象模型、装饰器 / 描述符 / 元类、并发与性能、扩展（C 扩展 / ctypes）、测试与调试等。

## 适合谁看
- 写过一段时间 Python，想从「会用」走向「懂原理」的开发者；
- 需要写可复用框架 / 库、或做性能优化的工程师；
- 与 [[12-effective-python]]、tut 27《Python 核心编程》（anchor）搭配作为「高级篇」。

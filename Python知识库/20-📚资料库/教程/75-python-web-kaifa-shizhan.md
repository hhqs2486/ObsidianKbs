# Python Web 开发实战

## 这条教程在解决什么
从一个能跑的 Flask 小站出发，逐步把"生产级 Web 服务"该有的部件补齐：REST/Ajax、网站架构、系统管理、测试与 CI、消息队列、服务化、数据处理。定位是**实战工程书**——不是讲框架原理，而是带你把书上Demo变成能上线、能运维的真实系统。

## 它背后的原理（别只记操作）
Web 服务 = 接收请求（[[WSGI]]/Nginx）→ 业务处理 → 可能触发异步任务（消息队列）→ 返回响应。随着流量与复杂度上升，单体 Flask 应用会沿"接口化 → 异步化 → 服务化"演进，每一步都是为解耦与可运维性买单。

## 我能复用/改编的点
> 做"要上线的中型 Python Web 服务"时，照本书的演进顺序补课：先 Flask 跑通核心，再用 REST 切开前后端，用 Celery 卸载耗时任务，用 CI + 日志把质量与可观测性托住。

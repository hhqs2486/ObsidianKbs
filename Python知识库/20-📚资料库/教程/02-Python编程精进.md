# Python编程精进(第1辑)(套装共3册)

## 这条教程在解决什么
- 这是一套 **3 卷本进阶书**，面向「已会 Python 基础、想进一步掌握工程级能力」的读者，目标是写出**高性能、可靠、可维护**的 Python 软件。
- 三卷各攻一个方向：
  - ①《Python高级编程（第2版）》：语言核心精进（装饰器/描述符/元类/并发/优化/工程化）。
  - ②《精通Python爬虫框架Scrapy》：用 [[Scrapy]] 框架做网络爬虫（属于 [[网络爬虫]] 主题，本书只链接不建卡）。
  - ③《精通Python自然语言处理》：用 NLTK 实现 NLP 任务（见 [[自然语言处理]]）。

## 关键内容（按 PDF 章节提纲）
### 第①卷 Python高级编程（第2版）
- 第1章 Python现状：[[虚拟环境]]（virtualenv/venv）、[[包管理pip]]、增强 shell。
- 第2章 语法最佳实践（类级别以下）：[[高级迭代器]]（迭代器/生成器）、[[装饰器]]、[[上下文管理器]]（with/contextlib）、函数注解（→ [[类型标注]]）。
- 第3章 语法最佳实践（类级别以上）：[[描述符]]、property、[[元类]]、类装饰器、__new__。
- 第4章 命名（PEP 8）；第5章 写包/发布 PyPI；第6章 部署（Fabric、隔离、进程管理）。
- 第7章 C 扩展/Cython；第8章 代码管理（Git/CI）；第9章 文档化；第10章 测试驱动开发。
- 第11章 优化原则与分析（cProfile/timeit/内存）；第12章 优化技术（复杂度/数据结构/架构权衡/缓存）。
- 第13章 [[并发编程]]（多线程/多进程/asyncio）；第14章 设计模式。

### 第②卷 精通Python爬虫框架Scrapy
- 专注 [[Scrapy]] 框架使用：Spider、Item、Pipeline、中间件、并发抓取等（本卷归「网络爬虫」主题，由《Python 3网络爬虫开发实战》拥有 [[Scrapy]] 卡，本书**只链接不建卡**）。
- 相关概念见 [[网络爬虫]]、[[BeautifulSoup]]、[[requests库]]（均归爬虫书，不在此建卡）。

### 第③卷 精通Python自然语言处理
- 字符串操作→统计语言建模→形态学→词性标注→语法解析→语义分析（NER/WordNet）→情感分析→信息检索→语篇分析→系统评估。
- 全基于 NLTK；核心概念见 [[自然语言处理]]。

## 我卡住/没懂的地方

- GIL 下「多线程 vs 多进程」的取舍，需结合自己机器的负载测试才敢下结论（书里也强调要测）。
- 第③卷偏「传统/统计」NLP，与当下 [[深度学习]]（CNN/RNN）做法差异大，需对照《动手学深度学习》互补。

## 它背后的原理（别只记操作）
- 「高级语法」本质是协议：迭代器协议、描述符协议、上下文管理器协议、元类协议——都是「特殊方法 + 固定查找顺序」。
- 性能优化不是技巧堆砌，而是「测量→定位瓶颈→针对性改」的迭代过程；并发是其中一种手段，但受 GIL 制约。
- NLP 是把模糊语言逐层「结构化」：字符→词→词性→句法→语义→语篇。

## 我能复用/改编的点
> 换个需求，这套做法还能怎么用？
- 把第①卷的「装饰器/上下文管理器/缓存」直接套到任何 Python 服务（Web、脚本、ETL）。
- 并发三件套（线程池/进程池/asyncio）几乎适用于所有「I/O 多或计算重」的场景，先看瓶颈再选。
- NLP 的预处理管道可复用到日志分析、工单分类等文本任务。

# Python 编程基础 教程笔记

## 这条教程在解决什么
- 教材式 Python 入门：从环境准备一路讲到文件操作，结构清晰、例题充足，适合课堂或自学打基础。
- 定位：高校/培训常用「编程基础」教材，偏教学节奏，每一章都配练习。

## 关键内容（按章节提纲）
- 第1章 准备工作：安装 Python、配置编辑器与运行环境
- 第2章 Python 基础知识：[[Python]]、[[变量与名字绑定]]、[[数据类型]]、[[字符串]]、运算符
- 第3章 Python 数据结构：[[列表]] [[元组]] [[字典]] [[集合]]、[[推导式]]
- 第4章 程序流程控制语句：[[控制流]]（if / for / while）
- 第5章 函数：[[函数基础]]、参数、返回值、作用域（见 [[作用域与命名空间(LEGB)]]）
- 第6章 面向对象编程：[[类与对象]] [[继承]] [[多态]]、属性和方法
- 第7章 文件基础：[[文件IO]]、[[序列化(json与pickle)]]、文本与二进制读写

## 它背后的原理（别只记操作）
- 教学主线是「数据（第2/3章）→ 控制（第4章）→ 抽象（第5章函数）→ 建模（第6章OOP）→ 持久化（第7章文件）」，符合从「处理东西」到「组织东西」的认知顺序。
- 名字绑定 + 对象模型（见 [[Python对象模型]]）是贯穿全书的隐性主线。

## 我能复用/改编的点
- 第3/4章的「数据结构 + 流程控制」练习可直接作为新人编码训练题。
- 第7章文件读写模板（读→处理→写）是任何脚本的通用骨架。

# iot-dev-practice

## 这条教程在解决什么
- **本书定位**：一本把 [[树莓派]] 当作「物联网边缘节点」、用 Python 串起「采集 → 传输 → 存储 → 可视化 → 上云」全链路的实战书。它把本集群零散的硬件能力（[[GPIO]] [[传感器]]）和「联网上云」拧成一条可落地的物联网开发线。
- **适合谁看**：① 想做真实物联网项目（环境监测、农业、家居）的人；② 已读过 [[109-树莓派编程]]/[[114-raspberry-pi-2ban]]、需要「如何联网」那一半的人；③ [[智能家居]] 项目的系统级参考。
- 与库中关系：强补 [[物联网MQTT]] 概念卡（传输层），并与 [[树莓派]] [[传感器]] [[嵌入式Python]] [[Flask]] [[数据分析]] 互补；和 107 的本地小车、105 的沙盒形成「单机/联网」对照。

## 关键内容（章节脉络，依据本书公认内容结构与领域知识重建）
- **第1章 物联网与 Python 概述**：什么是物联网、为什么用 Python。对应 [[树莓派]] [[嵌入式Python]] [[物联网MQTT]]。
- **第2章 开发环境搭建**：在 [[树莓派]]/Ubuntu 上装 Python、[[包管理pip]]、[[虚拟环境]]。对应 [[树莓派]] [[包管理pip]]。
- **第3章 传感器数据采集**：用 [[GPIO]]/[[I2C总线]]/[[SPI总线]]/[[串口UART]] 读 [[传感器]]。对应 [[传感器]] [[GPIO]]。
- **第4章 数据传输（MQTT/HTTP）**：设备经 [[物联网MQTT]] 上报、云端下发。对应 [[物联网MQTT]] [[socket编程]] [[socket编程]]。
- **第5章 数据存储**：把数据写入数据库。对应 [[sqlite3模块]] [[文件IO]]。
- **第6章 Web 可视化**：用 [[Flask]] 做 dashboard 展示。对应 [[Flask]] [[Web开发]] [[数据库集成Flask]] [[数据可视化]]。
- **第7章 云端部署**：把服务部署到云、长期运行。对应 [[Web开发]] [[并发编程]]（常驻服务）。
- **第8章 综合项目**：环境监测/智能家居类完整案例。对应 [[智能家居]] [[传感器]] [[物联网MQTT]] [[机器人控制]]（联动）。

- 第6–7章的 Web 与部署属于 Web 与框架集群范畴，本书讲得偏应用，深入见对应集群卡片。

## 它背后的原理（别只记操作）
- **端—边—云三段式**：[[传感器]]（端）在 [[树莓派]]（边）采集，经 [[物联网MQTT]]（传输）到云端/手机，再经 [[Flask]] 可视化——这正是 [[物联网MQTT]] 卡片讲的「发布/订阅解耦」，也是 [[智能家居]] 的「感知—连接—应用」三层。
- **为什么 Python 合适**：采集用 [[嵌入式Python]]，传输/存储/Web 都用同一门语言，避免切换，和本集群其他书「全程 Python」的理念一致。

## 我能复用/改编的点
> 换个需求，这套做法还能怎么用？
- 把第3–4章单独抽出来，做一个「[[树莓派]] + [[传感器]] + [[物联网MQTT]]」的温湿度上云节点，接 [[智能家居]] 看板。
- 第6章的 Flask 看板可直接展示 107 小车的遥测数据，或 105/112 的教学演示数据。
- 用 [[并发编程]] 把采集与上报拆成独立任务，避免阻塞（呼应 [[串口UART]] 卡里的超时/异步提醒）。

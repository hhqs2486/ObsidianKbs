# Python数据抓取技术与实战（简体版）

## 本书定位 / 适合谁看
- 定位：把「数据抓取」当作工程问题来讲——从单机抓取到分布式抓取、匿名、监控、对接大数据，偏技术实战与工程化。
- 适合：需要稳定、规模化地获取数据的工程技术人员；理工科做数据获取环节的本科生、大数据从业者。
- 不适合：零基础想先学 Python 语法的读者（本书第 1 章虽带 Python 基础，但节奏偏快）。

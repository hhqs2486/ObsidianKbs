# Python灰帽子：黑客与逆向工程师的Python编程之道

## 这条教程在解决什么
- 它教你用 **Python 把逆向工程 / 漏洞研究的“重活”自动化**：自己写调试器、挂钩子、注入代码、跑模糊测试、用 IDAPython 批量分析二进制。不是讲“怎么黑”，而是讲“怎么用 Python 造安全研究工具”。
- 适合：已经会 Python、想进入二进制安全 / 逆向 / 漏洞挖掘的人；也是 安全与逆向 集群里“工具化”那一层的教材。

## 关键内容（按 PDF 章节提纲）
> 来源说明：本书 PDF 为图片版，缓存 `full.txt` 接近 0KB，章节正文为水印无实质内容；以下章节结构取自缓存 `manifest.json` 的真实 TOC + 领域知识整理，**未编造命令/代码**。

- 第 1 章 搭建开发环境：PyDbg / Immunity Debugger / IDAPython 等工具链的安装与 Python 绑定（核心是让 Python 能驱动这些原生工具，见 [[标准库]] 的 ctypes）。
- 第 2 章 调试器原理和设计：调试器如何借操作系统接口挂住进程、设断点、捕获异常（见 [[调试器]] [[逆向工程]]）。
- 第 3 章 构建自己的 Windows 调试器：用 Python 实现断点 / 单步 / 异常处理，把黑盒变成可控实验台（[[漏洞利用]] [[缓冲区溢出]] 找偏移常用）。
- 第 4 章 PyDbg——Windows 下的纯 Python 调试器：现成库，写脚本批量监控进程。
- 第 5 章 Immunity Debugger：带 Python 接口的 GUI 调试器，可写插件做自动化分析（[[恶意代码分析]] 常用）。
- 第 6 章 钩子的艺术：在关键 API 上挂 [[钩子]]，不改源码也能截获参数 / 行为（配合 [[恶意代码分析]] [[网络安全]] 做行为记录）。
- 第 7 章 DLL 注入与代码注入技术：把探针代码塞进目标进程（[[代码注入]]），是调试器 / 钩子的“投递方式”。
- 第 8 章 Fuzzing：用畸形输入狂轰被测程序找崩溃（[[模糊测试]] [[缓冲区溢出]]）。
- 第 9 章 Sulley：Python 模糊测试框架，结构化生成变异样本、自动归类崩溃。
- 第 10 章 面向 Windows 驱动的 Fuzzing 测试技术：把 fuzzing 用到内核驱动这类高危目标。
- 第 11 章 IDAPython——IDA Pro 环境下的 Python 脚本编程：用 Python 驱动 [[逆向工程]] 主力工具 IDA，批量标注 / 提取信息（与 [[反编译]] 互补）。
- 第 12 章 PyEmu——脚本驱动式仿真器：不跑真实程序也能模拟执行片段，用于绕过反调试、分析关键函数。

## 我卡住/没懂的地方
- 图片版 PDF 无法提取具体代码与 API 参数，各章的 ctypes 调用细节、Sulley 的会话定义、IDAPython 的 API 名需将来对照实体书 / 官方文档补全。
- 32/64 位与 Windows 版本差异导致脚本不通用，需要实操验证。

## 它背后的原理（别只记操作）
- 整本书的主线：原生安全工具（调试器 / IDA / 驱动）大多用 C / 汇编写，但“胶水逻辑”（批量处理、模式匹配、自动化流程）用 Python 最省力——Python 通过 ctypes / 官方 Python 接口去驱动它们。
- 调试器、钩子、注入、fuzzing 是一条递进链：先看（调试）→ 拦（钩子 / 注入）→ 轰（fuzzing）→ 用 IDA / PyEmu 静态 + 仿真收尾，对应 [[逆向工程]] [[漏洞利用]] 的完整工作流。

## 我能复用/改编的点
> 换个需求，这套做法还能怎么用？

- 把“自己写调试器 / 挂钩子”的思路搬来做 **崩溃复现与回归测试**：给解析外部输入的模块喂畸形数据 + 调试器监控，保证“畸形输入只报错不崩溃”（见 [[模糊测试]]）。
- IDAPython 批量脚本可用于**自家闭源组件的安全审计**；行为日志思路用于**沙箱 / EDR 探针**（注意 [[认证授权]] 边界，只对自己拥有的进程做）。

# Python 数据可视化之 matplotlib 实践

> ⚠️ **PDF 为图片版，结合章节结构整理**：源文件 `.cache/041_Python数据可视化之matplotlib实践.pdf/` 经 OCR 后全文约为 0KB（各章 `.txt` 均为空），无可用正文文本。以下内容基于 matplotlib 通用实践结构与领域知识整理，**未编造任何命令或代码**，仅作章节脉络与学习路线参考。

## 这条教程在解决什么
一本以「画出来」为主线的 matplotlib 实战书：从库的安装与绘图对象（Figure / Axes）讲起，逐个击破常见统计图表，再进阶到高级绘图（箱线图、小提琴图、等高线、3D、地图、词云等），目标是能独立产出可用于报告/出版的可视化。

## 定位 / 适合谁
- 定位：matplotlib 上手指引 + 图表「菜谱」，偏操作、配图多。
- 适合谁：需要画柱状图/折线图/散点图/饼图等基础图，以及想进阶统计图与特殊图的人；理论向请回[[数据可视化]]。

## 关键内容（按 matplotlib 常规实践结构整理，非逐页原文）
1. **matplotlib 入门**：安装、两种接口（`pyplot` 与面向对象 `Figure/Axes`）、绘图六步（准备数据 → 建画布 → 绘图 → 自定义 → 保存 → 显示）。
2. **绘图基础**：坐标系、标题/轴标签、图例、刻度与网格、颜色与线型/标记。
3. **基础统计图表**：折线图、柱状图/条形图、散点图、饼图、直方图、面积图。
4. **高级统计图**：箱线图、小提琴图、误差棒、等高线图、热力图/伪彩图。
5. **多维与特殊可视化**：3D 绘图、地图可视化、词云、图像与动画（按书常见章节，图片版无法逐条确认）。
6. **版面与输出**：子图布局（`subplot`/`subplots`/`gridspec`）、tight_layout、导出 PNG/PDF/SVG。

## 它背后的原理（别只记操作）
- matplotlib 的核心是**「画布 Figure + 坐标系 Axes」**：大多数时候用子图（axes）即可，精确控制才用 Figure。这正是[[Matplotlib]]卡强调的面向对象模型。
- 选图先看数据形态：类别对比用柱状、趋势用折线、分布用直方图/箱线、相关用散点——对应[[数据可视化]]的选图原则。

## 我能复用/改编的点
> 任何分析收尾都要「出图」：先用[[Pandas]]/`NumPy` 备好数据，再按「选图类型 → Axes 绘图 → 设标签/图例 → savefig」的固定套路产出。更系统的绘图 API 可对照速查表类书 `87-cheatsheet-matplotlib.md`。

# Learning From Data（2nd Ed, Wiley 2007）— Abu-Mostafa 等

## 这条教程在解决什么（定位 / 适合谁）
- **机器学习理论奠基教材**（不是 Python 书，几乎无代码）。讲"学习问题"的形式化、泛化边界、线性模型、过拟合。
- 适合想搞懂 ML **数学原理 / 为什么能学**的读者；与库里"机器学习实战"类书形成理论↔实践互补。

## 核心章节脉络（典型结构）
- 第1章 The Learning Problem（感知机、学习模型）→ [[感知机]] [[机器学习]]
- 第2章 Training versus Testing（VC 维、泛化）→ [[机器学习]]
- 第3章 The Linear Model（线性回归、逻辑回归、线性判别）→ [[梯度下降]] [[损失函数]] [[机器学习]]
- 第4章 Overfitting（过拟合、正则化）→ [[机器学习]]（正则化思想另见数据科学子类的「正则化深度学习」）
- 第5章 Three Learning Principles（Occam、采样、数据窥探）→ [[机器学习]]
- 本书神经网络概念衔接 [[神经网络]]；其梯度 / 损失思想贯穿 [[深度学习]]。

## 关键知识点（指向概念卡）
- 理论无 Python 实现；核心概念 [[机器学习]]、[[感知机]]、[[梯度下降]]、[[损失函数]]、[[神经网络]] 均已在数据科学子类建卡，可直接跳转。
- 是理解 tut 96 / 101 / 102 等"机器学习 / 数据分析"书背后的**理论根**（本卷讲 why，那些讲 how）。

## 与其他书的互补关系
- 与 tut 96（Python 机器学习）、tut 101（机器学习 Python 实践）、tut 102（利用 Python 进行数据分析）互补：理论 ↔ 实战。
- 与 tut 44 第19章"机器学习"、tut 26 第19章"机器学习"互为理论 ↔ 入门对照。

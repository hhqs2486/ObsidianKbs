# Think Python（2nd Edition，英文原版）

## 定位
《像计算机科学家一样思考Python（第2版）》（tut [[47-xiang-jisuankexuejia]]）的英文原版。内容、章节结构与原书完全一致，只是语言为英文。适合想读一手原文、顺带练技术英语的读者。

## 适合谁看
- 偏好英文技术原版书、或想同步提升英语的学习者；
- 与中文译本 [[47-xiang-jisuankexuejia]] 对照阅读的人；
- 零基础、愿意跟习题推导的自学者。

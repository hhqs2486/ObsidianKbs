# Effective Python（59个有效方法）

## 定位
「写出地道 Python（Pythonic）代码」的条目式最佳实践书。59 条按主题分 8 章，每条一个具体建议 + 反例对比。适合已会基础、想提升代码质量的开发者常备案头。

## 适合谁看
- 写过 Python、希望代码更简洁 / 更健壮 / 更符合社区惯例的工程师；
- 做 code review、定团队规范的 tech lead；
- 作为 tut 36 / tut 47 之后的「进阶必读」。

## 章节脉络（依据 manifest 真实 59 条标题整理）
- 第1章 用 Pythonic 方式来思考：第1–14条 — 版本确认、`[[字符串]]` 与 bytes、切片、`[[推导式]]`、`[[迭代器与生成器]]`（生成器表达式）、`enumerate`/`zip`、`[[异常处理]]` 结构、`[[控制流]]`（for/while 后不写 else）
- 第2章 函数：第15–21条 — `[[闭包]]`、`[[迭代器与生成器]]` 改写、`[[函数(参数与返回值)]]`（可变位置参数、关键字参数、动态默认值、仅关键字参数）
- 第3章 类与继承：第22–29条 — `[[类与对象]]`、`[[继承]]`、`[[多态]]`、`[[抽象基类]]`、`[[描述符]]`、`[[属性管理]]`、`[[元类]]`、`[[魔术方法]]`、Mix-in、public/private
- 第4章 元类及属性：第30–35条 — `[[装饰器]]`、`[[描述符]]`、`[[属性管理]]`、`[[元类]]`、`__getattr__`/`__getattribute__`/`__setattr__`
- 第5章 并发及并行：第36–41条 — `subprocess`、`[[并发编程]]`、`Lock`/`Queue`、`[[协程]]`、`concurrent.futures`（GIL 无对应卡，plain）
- 第6章 内置模块：第42–48条 — `[[装饰器]]`（functools.wraps）、`[[上下文管理器]]`、`[[序列化(json与pickle)]]`、`[[日期时间]]`、`[[正则表达式]]`、内置算法与数据结构、`[[浮点数精度]]`、`[[标准库]]`
- 第7章 协作开发：第49–53条 — 文档字符串、`[[模块与包]]`、`[[包管理pip]]`、`[[异常处理]]`/`[[自定义异常]]`、`[[虚拟环境]]`、循环依赖
- 第8章 部署：第54–59条 — 模块级配置、`repr` 调试、`[[单元测试(unittest)]]`、`[[调试(pdb)]]`、`[[性能优化]]`、`tracemalloc`

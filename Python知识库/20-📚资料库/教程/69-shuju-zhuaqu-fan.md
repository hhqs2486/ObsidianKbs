# Python數據抓取技術與實戰（繁體可读版）

## 本书定位 / 适合谁看
- 定位：把「数据抓取」当作工程问题来讲——从单机抓取到分布式抓取、匿名、监控、对接大数据，偏技术实战与工程化。本书是**可全文阅读的文本版**（繁体），与简体图片版（教程 68）为同一本书。
- 适合：需要稳定、规模化地获取数据的工程技术人员；理工科做数据获取环节的本科生、大数据从业者。
- 不适合：零基础想先系统学 Python 的读者（第 1 章仅做语法铺垫）。

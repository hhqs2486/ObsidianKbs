# Python神经网络编程（Make Your Own Neural Network）

## 这条教程在解决什么
- 用最少的数学、约 100 行 [[Python]]（依赖 [[NumPy]]）从零搭一个能识别手写数字的三层 [[神经网络]]，目标是"看懂神经网络到底怎么工作"，而不是调现成框架。属于 [[数据科学]] / AI 入门的动手书。

## 关键内容（按 PDF 章节提纲）
> 章节标题来自 .cache/神经网络编程/manifest.json（PDF 为图片版，原文不可抽取，以下为结合领域知识整理的真实结构骨架）。

第1章 神经网络如何工作
- 1.1 尺有所短，寸有所长：引出"有些事规则写不出，得让机器自己学"。
- 1.2 一台简单的预测机：用 y = A·x 学斜率，误差 = 目标 − 预测，按 误差 × 输入 调 A——这就是一维 [[梯度下降]] 雏形。
- 1.3 分类器与预测器并无太大差别：把连续输出接一个阈值就变分类。
- 1.4 训练简单的分类器：用 [[损失函数]]（目标 − 输出）指导调权重。
- 1.5 有时候一个分类器不足以求解问题：线性分类有边界，复杂问题需要多个神经元组合。
- 1.6 神经元——大自然的计算机器：从生物神经元到人工神经元，引出 [[感知机]] 与 [[激活函数]]（sigmoid）。
- 1.7–1.9 在神经网络中追踪信号 / 矩阵乘法大有用途 / 三层网络示例：前向传播用矩阵写作 输出 = sigmoid(W · 输入)。
- 1.10–1.13 学习来自多个节点的权重 / 多输出节点反向传播误差 / 反向传播误差到更多层 / 矩阵反向传播：[[反向传播]] 误差按权重分摊、逐层乘激活导数。
- 1.14–1.15 我们实际上如何更新权重 / 权重更新成功范例：ΔW = 学习率 × 误差信号 × 前层输出ᵀ，配 [[梯度下降]]。
- 1.16 准备数据：输入缩放到 0~1，标签做成 10 维 one-hot。

第2章 使用 Python 进行 DIY
- 2.1–2.2 Python / 交互式 Python（IPython）：环境准备。
- 2.3 优雅地开始使用 Python：用一个 neuralNetwork 类封装初始化、训练(query)、预测(train)。
- 2.4 使用 Python 制作神经网络：用 [[NumPy]] 实现矩阵乘与 sigmoid，跑 MNIST。
- 2.5 手写数字的数据集 MNIST：28×28 = 784 输入、10 输出、约 6 万训练样本。

第3章 趣味盎然
- 3.1–3.2 自己的手写数字 / 神经网络大脑内部：拿自己写的数字测，观察隐藏层激活。
- 3.3 创建新的训练数据：旋转图像做数据增强，提升鲁棒性。
- 3.4 结语。

## 我卡住/没懂的地方
- 图片版原文不可读，1.11/1.13 的误差按权重"分摊"是否严格归一需对照原书确认（方向正确即可用）。
- [[反向传播]] 链式法则的逐层导数，书中借 sigmoid 导数性质简化，严格推导建议另补（见 [[深度学习]] 的自动求导）。

## 它背后的原理（别只记操作）
- 前向是"线性变换 + 非线性 [[激活函数]]"的堆叠；训练是用 [[损失函数]] 衡量差距，[[反向传播]] 用链式法则把差距分摊到每个权重，[[梯度下降]] 沿负梯度小幅更新——四者环环相扣，缺一不可。

## 我能复用/改编的点
> 换需求：把 784 输入改成任意特征维度、10 输出改成自己的类别数，就能套同一套"前向 + 反向 + 梯度下降"做图像/信号分类；数据增强（旋转/平移）思路可移到其他小样本任务；整本书的 neuralNetwork 类是理解 [[深度学习]] 框架（PyTorch / TensorFlow）内部的最小可运行原型。

# 跟老齐学Python：数据分析（老齐）

## 这条教程在解决什么
一本**数据分析入门**书：先把"数据/大数据/数据分析"等概念厘清，再系统讲 [[NumPy]]、[[Pandas]]、[[数据可视化]]，最后用综合应用与一章 [[机器学习]] 入门收尾。语言通俗，适合边读边练。

## 本书定位 / 适合谁
- 想从 **Python 基础过渡到数据分析**的读者；书里会带着复习 [[Python]] 关键语法。
- 与 [[数据科学]]/[[数据分析]]（六，Python数据分析与数据化运营）互补：六是更偏运营的进阶，本书是更平缓的入门。

## 核心章节脉络（按 TOC）
- **第0章 数据分析概述**：数据、大数据、数据分析、[[数据科学]] 等概念辨析。
- **第1章 NumPy 基础和应用**：ndarray、广播、向量化运算（对应 [[NumPy]]）。
- **第2章 Pandas 基础和应用**：Series / DataFrame / Panel、读写与切片（对应 [[Pandas]]）。
- **第3章 数据可视化**：Matplotlib/Seaborn 绘图（对应 [[数据可视化]]/[[Matplotlib]]/[[Seaborn]]）。
- **第4章 综合应用**：把前面串起来做真实分析（含 [[缺失值处理]]/[[异常值处理]]/[[描述性统计]]/[[相关性分析]]/[[透视表]]/[[分组GroupBy]]/[[数据聚合]]）。
- **第5章 机器学习**：[[回归]]、[[分类]] 等入门实例（接 [[机器学习]]）。

## 关键知识点（指向概念卡）
- [[NumPy]] 是地基（多维数组与向量化），[[Pandas]] 在其上提供 Series/DataFrame，使 [[数据清洗]] 更顺手。
- 数据分析标准流程：导入 → [[数据清洗]]（[[缺失值处理]]/[[异常值处理]]）→ [[描述性统计]]/[[探索性数据分析EDA]] → [[数据可视化]] → 结论。
- 分组聚合（[[分组GroupBy]]/[[数据聚合]]/[[透视表]]）是从数据里提取规律的常用操作。
- 最后用 [[机器学习]] 的 [[回归]]/[[分类]] 把"找规律"自动化。

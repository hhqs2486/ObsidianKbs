# Python游戏编程快速上手（Invent Your Own Computer Games with Python）

## 这条教程在解决什么
- 带零基础读者**用 Python 从零做出能玩的游戏**：前半部分用纯 Python 写文字/逻辑小游戏练语法，后半部分用 [[pygame]] 写带画面、声音、操作的 2D 游戏。
- 定位是"项目驱动学编程"：不是先讲完语法再写程序，而是边做游戏边补语法点。

## 关键内容（按 PDF 章节提纲）
> 注：原书为图片版（OCR 不可用），以下按真实目录结构 + 领域知识整理，未编造具体代码/命令。

### 第一部分：用 Python 写文字游戏（不依赖 pygame，练基础）
- 安装 Python 与 IDLE；字符串、变量、`print()` / `input()` —— 见 [[Python]] [[数据类型]]
- 函数、`if`、比较与布尔 —— 见 [[函数基础]] [[控制流]]
- 猜数字游戏（Bagels）：循环与字符串方法
- 骰子游戏、笛卡尔坐标
- 龙穴游戏（Dragon）、猜单词（Hangman）
- 井字棋 Tic-Tac-Toe 与简单 AI：用 [[类与对象]] 组织棋盘状态
- 坐标系统与 NIM 等小游戏

### 第二部分：pygame 图形游戏
- 安装 [[pygame]]、创建窗口与画布
- 绘制图形、颜色、像素
- [[游戏循环]] 与帧率控制（`Clock.tick`）、简单动画
- 事件处理：键盘与鼠标输入
- 字体与文本显示
- [[游戏音效]]：`mixer.music` 与 `Sound` —— 见 [[模块与包]] [[异常处理]]
- [[精灵Sprite]] 与 `Group` 批量管理角色
- [[碰撞检测]]：矩形/圆形/精灵间相交判断
- 综合项目：如 Dodger（躲避游戏）、打砖块、平台跳跃等

## 我卡住/没懂的地方
- 图片版无法核对书中 pygame 具体 API 写法（如 `Surface`、`Rect` 的方法名），以官方文档为准。
- 前后两部分跨度大：文字游戏偏语法，pygame 偏实时系统思想，需要把"循环/对象/事件"串起来理解。

## 它背后的原理（别只记操作）
- 文字游戏练的是**状态 + 分支 + 循环**：游戏本质是一个不断根据输入改变状态的状态机。
- 图形游戏的核心是 [[游戏循环]]：把"读输入→算逻辑→画画面"固化成每帧节奏，再用 [[精灵Sprite]] 把对象封装、用 [[碰撞检测]] 触发交互、用 [[游戏音效]] 给反馈。
- 这整套思想（循环 + 对象 + 事件）不只用于游戏，也适用于仿真、可视化、嵌入式人机界面。

## 我能复用/改编的点
> 换个需求，这套做法还能怎么用？
- 把"游戏循环 + 精灵"搬到**算法/物理可视化**（排序动画、质点运动、信号波形实时刷新）。
- 把碰撞检测思路用到**几何/UI 命中测试**、机器人避障（AABB 粗筛）。
- 文字游戏框架可直接改成**命令行小工具/答题系统**。

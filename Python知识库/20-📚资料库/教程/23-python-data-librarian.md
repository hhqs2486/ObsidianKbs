# 数据馆员的 Python 简明手册 教程笔记

## 这条教程在解决什么
- 面向**初级数据馆员 / 图书情报人员**的 Python 简明入门，目标是让读者在「没有编程经验」的前提下，也能用 Python 完成信息处理、数据分析与可视化任务。
- 定位：工具型入门手册，不追求语法完备，强调「能操作、能直观理解」；后半段直接通向数据工作流。

## 关键内容（按章节提纲）
- 第1章 关于 Python：发展历史、版本、基本语法（缩进、[[控制流]]）
- 第2章 流程控制：条件/循环、[[迭代器与生成器|迭代工具]]（并行迭代、enumerate）、[[推导式]]、range/array
- 第3章 函数及数据结构：[[函数基础]]、[[列表]] [[元组]] [[字典]]、全局/局部变量
- 第4章 异常处理：[[异常处理]]、try-except/finally、raise、[[自定义异常]]、traceback/sys
- 第5章 数据处理与计算：常用库概览、NumPy（[[NumPy]] 数组创建与算术/统计）
- 第6章 数据描述与分析：Pandas（[[Pandas]] 的 Series / DataFrame、加载保存、缺失值）、数据库基础
- 第7章 绘图与可视化：matplotlib、Seaborn、描述性统计图形（频数/关系/探索分析）→ 见 [[数据可视化]]
- 第8章 数据挖掘：线性回归、梯度下降、参数估计与假设检验
- 第9章 Django 与 Twisted：两个工程框架的极简上手（正文用英文名，库无独立概念卡，此处 Plain Text）
- 附录：环境安装与初步练习

## 它背后的原理（别只记操作）
- 数据馆员的核心痛点是「批量处理文献/书目/统计数据」：把重复的人工操作抽象成「读入→清洗→分析→出图」的管道（见 [[数据分析]] [[数据清洗]]）。
- [[NumPy]] 的向量化运算让「对整列数据做运算」不用写循环，是后续 [[Pandas]] 的底层基础。

## 我能复用/改编的点
- 第6章「用 Pandas 加载 CSV/Excel + 缺失值处理」可直接套到馆员常遇到的书目/读者数据统计。
- 第7章描述性统计图形清单（频数/关系/探索）是做任何数据汇报前的「先画图看分布」 Checklist。

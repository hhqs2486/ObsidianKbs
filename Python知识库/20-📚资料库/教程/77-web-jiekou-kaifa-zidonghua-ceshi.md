# WEB 接口开发与自动化测试（基于 Python 语言）

## 这条教程在解决什么
面向对象/接口测试工程师：用 Python 既"开发 Web 接口"又"对接口做自动化测试"，形成从造接口到测接口的闭环。重点不是框架原理，而是**如何用代码保证接口质量**（用例组织、断言、持续运行）。

## 它背后的原理（别只记操作）
接口测试 = 用程序模拟客户端发 HTTP 请求 → 拿到 [[请求与响应]] → 对状态码/结构/字段值做断言。核心是"可重复、可断言、可集成"，把人工点页面的验证变成代码资产。

## 我能复用/改编的点

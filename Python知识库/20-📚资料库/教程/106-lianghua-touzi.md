# 量化投资以Python为工具

## 定位
用 Python 把「量化投资」的全流程跑通：从金融数据获取、收益/风险指标计算，到选股、择时、套利策略的编写与回测评估。不是纯编程书，而是面向有金融常识、想把策略用代码落地的读者。

## 适合谁看
- 有基本金融/投资常识，想用 Python 验证想法、搭建策略的人。
- 想理解「回测、因子、夏普比率」这些词到底怎么算出来的入门者。
- 不适合：想深入学 Python 语言本身或深度学习的人（前者看基础教程，后者看深度学习/神经网络书）。

## 核心章节脉络（按公开章节结构整理）
> 说明：本书 PDF 为图片版（full.txt ≈ 0KB，manifest 无章节文本），以下基于公开目录结构与领域知识整理，**未逐页核对正文、不引用具体代码**。

1. **Python 量化基础**：变量/控制流快速过，重点 NumPy、Pandas、matplotlib 在金融数据上的用法。
2. **金融数据与收益率**：行情获取与清洗、日/对数收益率、收益与波动的度量。
3. **投资组合理论**：均值-方差、马科维茨有效前沿、CAPM 与 alpha/beta。
4. **统计指标与因子**：动量/反转、单因子检验、alpha 与 beta 拆解。
5. **选股策略——多因子模型**：因子构造、打分、组合构建。
6. **择时策略**：均线交叉、动量类择时信号。
7. **套利策略**：配对/统计套利、价差与协整思路。
8. **回测与绩效评估**：策略回测、夏普比率、最大回撤、止损与风险管理。

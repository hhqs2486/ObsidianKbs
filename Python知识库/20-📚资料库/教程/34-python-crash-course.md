# Python编程 从入门到实践（Python Crash Course）

## 这条教程在解决什么
- 前半本讲语法、后半本做三个完整项目，强调“学完就能动手”，是最受欢迎的 Python 入门书之一。

## 定位 / 适合谁
- 定位：零基础到初级，项目驱动；语法讲得干净，且特意强调代码风格与重构。
- 适合：想“学完就做项目”的读者（游戏 / 数据可视化 / Web 应用）。

## 关键内容（PDF 章节提纲，已核对目录正文）
第一部分 基础知识：
- 1 起步 / 2 变量和简单数据类型 / 3 列表简介 / 4 操作列表 / 5 if语句 / 6 字典 / 7 用户输入和while循环 / 8 函数 / 9 类 / 10 文件和异常 / 11 测试代码
第二部分 项目：
- 项目1 外星人入侵（Pygame, ch12–14）
- 项目2 数据可视化（matplotlib / pygal, ch15–17） → [[数据可视化]]
- 项目3 Web 应用程序（Django, ch18–20）

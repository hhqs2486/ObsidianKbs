# Python与量化投资：从基础到实战（王小川）

## 这条教程在解决什么
一本"**Python + 量化投资**"的实战书：从环境搭建、Python 基础/进阶，到金融数据获取整理、回测平台使用，再到常见量化策略的代码实现。把 [[Python]] 当工具，落到"能跑的策略"。

## 本书定位 / 适合谁
- 想用 Python 做**股票/基金/期货量化**的读者；金融背景或编程背景任一方面即可入门。
- 与 [[数据科学]] 互补：量化是数据科学在金融领域的垂直应用，强调实盘可行的策略与风控。

## 核心章节脉络（按 TOC）
- **第1章 准备工作**：Anaconda/conda、[[虚拟环境]]、包管理（对应 [[包管理pip]]）。
- **第2章 Python 基础介绍** + **第3章 Python 进阶**：语法、[[NumPy]]、[[Pandas]]、[[文件IO]] 等（对应 [[Python]] 语言核心）。
- **第4章 常用数据的获取与整理**：行情/财务/基金/期货/指数等金融数据（接 [[数据清洗]]）。
- **第5章 通联数据回测平台介绍**：在平台上写策略并 [[回测]]。
- **第6章 常用的量化策略及其实现**：股票/基金/指数等策略，含 [[因子模型]]、[[多因子]]、[[动量策略]]、[[均线策略]]、[[择时策略]]、[[套利]] 等。
- **第7章 量化投资十问十答**：经验与误区。

## 关键知识点（指向概念卡）
- 量化策略 = 金融数据（[[数据清洗]]）+ 数学模型（[[机器学习]]/统计/[[深度学习]]）+ 计算机技术。
- 策略写好后必须在 [[回测]] 中验证，并用 [[夏普比率]]、[[最大回撤]]、[[止损]] 等指标评估风险收益。
- [[因子模型]]/[[多因子]] 是选股核心；[[动量策略]]/[[均线策略]]/[[择时策略]] 是择时常用套路；[[套利]] 利用定价偏差。
- 实盘通过 [[量化交易API]] 下单，用 [[组合管理]]/[[风险管理]] 控制整体暴露。

## 互补关系
- 与 [[数据科学]]/[[数据分析]]（六）：量化是其在金融的落地，共用 [[NumPy]]/[[Pandas]]/[[数据可视化]]。
- 与 [[机器学习]]（八、098）：第6章模型含机器学习/深度学习方法。
- 与《Python贝叶斯分析》（97）：参数不确定性估计可用于策略置信度。

## 我能复用/改编的点
> 新策略上线前，先用 [[回测]] + [[交叉验证]] 思路切分样本内外数据，再用 [[夏普比率]]/[[最大回撤]] 做风控闸口。

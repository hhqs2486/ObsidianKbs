# Python机器学习实践指南

## 这条教程在解决什么
一本"用项目驱动"的机器学习书：第 1 章先铺好 Python 机器学习生态，随后 9 个递进式真实项目（房价、机票、IPO、新闻、股价、图像、聊天机器人、推荐……）每个都走"问题→数据→建模→评估"的完整闭环，强调工程落地。

> 注：本书 `quality=MIXED`（本库缓存 `full.txt` 约 178KB，含可提取正文），下列章节脉络取自原书目录，结构可靠。

## 定位 / 适合谁
- 定位：项目制 ML 实战，覆盖表格、文本、图像、推荐多类问题；比纯理论更"能用"。
- 适合谁：想通过真实项目积累端到端经验的人；建议先有 [[NumPy]] / [[Pandas]] 与基础 [[机器学习]] 认知。

## 关键内容（按原书章节脉络）
- **第1章 机器学习生态系统**：Python 工具链（[[NumPy]]/[[Pandas]]/scikit-learn/可视化）——对应 [[数据科学]] 基础栈
- **第2章 用决策树预测低价公寓/房价**：回归树、特征重要性——见 [[决策树]]、[[回归]]
- **第3章 机票价格预测**：回归建模与特征构造——见 [[回归]] [[特征工程]]
- **第4章 用逻辑回归预测 IPO**：二分类实战——见 [[分类]]（逻辑回归为细分算法，本库暂无独立卡）
- **第5章 新闻源/文章分类**：文本特征 + 分类——见 [[自然语言处理]] [[分类]] [[数据清洗]]
- **第6章 内容传播/病毒式预测**：传播建模、特征工程——见 [[特征工程]] [[监督学习]]
- **第7章 股票价格预测**：时间序列式回归——见 [[回归]] [[时间序列分析]]
- **第8章 图像相似度/图像识别**：卷积神经网络入门——见 [[神经网络]] [[深度学习]]
- **第9章 聊天机器人**：NLP + 序列模型——见 [[自然语言处理]] [[神经网络]]
- **第10章 推荐引擎**：协同过滤/矩阵分解思路——见 [[无监督学习]] 与 [[聚类]] 思想

## 它背后的原理（别只记操作）
本书核心价值是 **"不同问题→对应模型范式"的映射能力**：表格数值→树/线性模型（[[决策树]]/[[回归]]），文本→向量化后分类（[[自然语言处理]]），图像→[[深度学习]]，推荐→相似度/聚类（[[聚类]]）。掌握这种映射，比背单个算法更通用。

## 我能复用/改编的点
> 接新需求时先归类：是回归/分类/聚类/生成？再选栈。表格用树模型+[[交叉验证]]，文本走 TF-IDF+分类，图像直接上 [[深度学习]]。可视化用 [[Seaborn]]/[[Matplotlib]] 看效果。

# 零起点Python大数据与量化交易（量化交易入门）

## 这条教程在解决什么
- 面向**零基础**（只需会 Excel）读者，用纯 Python + zwQuant 开源框架，从故事案例讲清「量化交易」到底怎么落地：数据从哪来、策略怎么写、如何用 [[回测]] 验证、实盘怎么跑。
- 配套 zwPython 集成平台、zwQuant 量化系统、zwDat 数据包，书里近百套 Python 程序均可直接运行。

## 关键内容（按 PDF 章节提纲）
- **第1章 从故事开始学量化**：复利「神奇公式」、股市「一月效应」——用生活例子引出策略与算法；点明 Pandas 就是「Python 版 Excel」。
- **第2章 常用量化技术指标与框架**：均线、动量、布林带等技术指标基础（对应 [[均线策略]][[动量策略]]）。
- **第3章 金融数据采集整理**：tushare、zwDat、down_stk 多数据源下载与清洗（对应 [[量化交易API]][[数据清洗]]）。
- **第4章 PAT 案例汇编**：与 PAT 量化软件对标测试，统一回报率/夏普/回撤口径。
- **第5章 zwQuant 整体架构**：纯 Python、基于 [[Pandas]] 矩阵模式，全部代码 <1000 行；`zwBacktest`/`zwStrategy`/`zwQTBox` 等模块；性能指标 `sharpe_rate`、`downKMax` 的实现。
- **第6章 模块详解与实盘数据**：模块函数手册、实盘数据生成与第三方下单导入。
- **第7章 量化策略库**：内置 SMA/CMA/BBANDS/VWAP 等「1+1」策略函数组（对应 [[择时策略]]）。
- **第8章 海龟策略与自定义扩展**：从零写 tur10 海龟策略，完整演示数据预处理→策略分析→图表输出→参数优化→入库，落地 [[止损]] 与资金管理（[[组合管理]]）。
- **第9章 TA-Lib 函数库与策略开发**：几十个技术指标封装（MA/EMA/MACD/RSI/MOM/ROC…），是 [[因子模型]][[多因子]] 的因子原料。
- **第10章 扩展与未来** + 附录（zwPython 手册、量化学习路线图）。

## 它背后的原理（别只记操作）
- **工程内核 = 数据预处理 + 策略分析 + 回测引擎**：zwQuant 把「每根 bar 喂数据→策略算信号→记录交易→算指标」固化为标准流水线，策略只是流水线上的一个函数。
- **前视偏差防控**：成交价一律取次日开盘价（kprice），而非信号当日的收盘价，这是回测可信的关键。
- **风控贯穿全程**：仓位上限、[[止损]]、[[最大回撤]] 监控、[[夏普比率]] 评估，构成「活下去再赚钱」的闭环。

## 我能复用/改编的点
> 换个需求，这套做法还能怎么用？
- 用 zwQuant 的「1+1 策略函数组」模板，可把任意技术指标想法快速改写成可回测策略（均线、动量、布林带、海龟突破…）。
- `zwQTBox` 的 `sharpe_rate` / `downKMax` / `cross_Mod` 等工具函数可直接复用到自己的回测脚本里做绩效评估。
- TA-Lib / zw_talib 的指标库可当作 [[多因子]] 选股的因子池，配合 [[数据分析]] 做打分。

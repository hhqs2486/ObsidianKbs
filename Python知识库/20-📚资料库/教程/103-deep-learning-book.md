# 深入浅出深度学习：原理剖析与Python实践（黄安埠）

## 这条教程在解决什么
一本**偏理论剖析**的深度学习书：先补数学（线性代数/概率/概率图模型/最优化），再讲前馈网络、反向传播、自编码器、玻尔兹曼机、RNN、CNN 的原理，并用 Theano 实现。适合"想搞懂为什么"的读者。

## 本书定位 / 适合谁
- 想**理解深度学习数学与原理**、而不只是调框架的读者；需一定 [[Python]] 与数学基础。
- 与《TensorFlow技术解析与实战》（98）互补：98 偏工程框架，本书偏原理推导。

- **第1部分 概要**：绪论（AI/[[机器学习]]/[[深度学习]] 关系）、Theano 基础（符号变量、计算图、函数）。
- **第2部分 数学与ML基础**：线性代数（[[张量]]/矩阵/特征值/SVD/PCA）、概率统计、概率图模型（贝叶斯/马尔可夫网络、MCMC/Gibbs，本书独有，库无对应卡）、数值计算与最优化（[[梯度下降]]/动量/自适应/牛顿/拟牛顿）。

## 关键知识点（指向概念卡）
- 深度学习是 [[机器学习]] 中"深"的神经网络的特例；[[张量]] 是其基本数据容器。
- 训练=前向传播算 [[损失函数]]，[[反向传播]] 算梯度，[[梯度下降]]（含动量/自适应）更新权重。
- 防 [[过拟合]] 用 [[正则化深度学习]]；深层训练难点是梯度消失/爆炸。
- CNN 用于空间特征、RNN/[[LSTM]] 用于序列；[[降维PCA]] 是线性降维基础。

# Python语言程序设计基础（第2版）

## 定位
北理工「Python 语言程序设计」MOOC 配套教材，国内高校广泛采用的中文入门教材。以「计算生态」视角组织内容：先打语言地基，再快速过渡到标准库 / 第三方库与若干趣味实例（爬虫、数据分析、词云、手绘、小游戏、AI 入门）。

## 适合谁看
- 零基础、把 Python 当作第一门编程语言的本科生 / 自学者；
- 需要体系化、按教学大纲稳步推进的学习者；
- 想借一本书同时摸到「语法 + 计算生态 + 小项目」的人。

## 章节脉络（依据真实章节结构整理）
1. 程序设计基本方法 — 什么是程序、计算机如何执行、Python 生态概览
2. Python 程序实例 — 程序元素、turtle 海龟作图、温度转换案例
3. 基本数据类型 — `[[数字类型]]`、`[[字符串]]`、math 库、`[[浮点数精度]]`
4. 程序的控制结构 — `[[控制流]]`（分支 / 循环）、异常处理初步
5. 函数和代码复用 — `[[函数基础]]`、`[[函数(参数与返回值)]]`、递归、`lambda`
6. 组合数据类型 — `[[列表]]`、`[[元组]]`、`[[字典]]`、`[[集合]]`、`[[推导式]]`
7. 文件和数据格式化 — `[[文件IO]]`、CSV / JSON 格式化
8. Python 计算生态 — `[[标准库]]`、`[[包管理pip]]`、第三方库安装
9. Python 标准库概览 — turtle、random、time、datetime、collections 等
10. Python 第三方库概览 — numpy、matplotlib、pillow、wordcloud、jieba、requests
11. 程序设计方法学 — 枚举、递归、`[[异常处理]]`、测试思路
12. 面向对象编程 — `[[类与对象]]`、`[[继承]]`、tkinter GUI（GUI 无对应卡，plain）
13. 网络爬虫 — requests / BeautifulSoup（无对应卡，plain）
14–18. 实例专题 — 数据分析（numpy/matplotlib）、文本词云（jieba/wordcloud）、图像手绘（pillow）、交互媒体（pygame）、人工智能（sklearn/tensorflow）

- 语言地基几乎覆盖全部入门概念：`[[变量与名字绑定]]`、`[[数据类型]]`、`[[控制流]]`、`[[函数基础]]`、`[[函数(参数与返回值)]]`、`[[列表]]`、`[[元组]]`、`[[字典]]`、`[[集合]]`、`[[推导式]]`、`[[字符串]]`、`[[文件IO]]`、`[[异常处理]]`、`[[类与对象]]`、`[[继承]]`、`[[模块与包]]`、`[[包管理pip]]`、`[[标准库]]`。
- 计算生态章节强调「会用库」而非「造轮子」，可联动 `[[包管理pip]]`、`[[虚拟环境]]`。

# 笨办法学 Python（第三版）教程笔记

## 这条教程在解决什么
- 用「**看代码、敲代码、改代码**」的硬核方式学 Python：52 个习题，几乎不讲解法，逼你通过大量重复练习把语法变成肌肉记忆。
- 定位：强调「打字练习 + 刻意重复」的入门书；适合愿意下笨功夫、靠动手而非靠读懂的人。
- 注：第三版基于 Python 2/3 过渡期，个别写法（如 print）需对照 [[Python]] 版本说明。

## 关键内容（按习题脉络）
- 习题 0–26（基础）：环境准备、第一个程序、注释、数字/数学、[[变量与名字绑定]]、[[字符串]]、输入、参数解包、读/写 [[文件IO]]、函数与变量、返回值
- 习题 27–39（逻辑与结构）：布尔表达式、if/else、while/for、[[列表]]、访问元素、[[字典]]、[[推导式]]、列表操作
- 习题 40–49（面向对象与工程）：模块/类/对象、[[类与对象]]、[[继承]] vs 合成、项目骨架、[[单元测试(unittest)]]（自动化测试）、用户输入解析、造句游戏
- 习题 50–52（综合）：第一个网站、从浏览器取输入、web 游戏（用到 Flask 类思路，正文 Plain Text）

## 它背后的原理（别只记操作）
- 「硬办法」的本质是**刻意练习**：语法通过反复键入进入长期记忆，比只读不写扎实。
- 习题 47 把 [[单元测试(unittest)]] 当成「考试通过条件」，提前植入工程化意识。

## 我能复用/改编的点
- 把习题 0–26 当「每日打卡」给零基础学员练手感。
- 习题 46「项目骨架」是可复用的 Python 工程目录模板。

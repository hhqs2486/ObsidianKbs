# 集体智慧编程（python算法应用）

## 定位
用 Python **从零手写**实现机器学习/集体智能算法（不依赖 scikit-learn 等库），通过一组真实有趣的案例讲清算法原理：推荐、聚类、搜索排名、优化、分类、特征分解等。是经典的「动手实现算法」派入门书。

## 适合谁看
- 想真正理解算法底层、愿意自己写矩阵与距离度量的读者。
- 已学过 [[Python]] 基础，想从应用反推 [[机器学习]] 概念的人。
- 不适合：只想调库跑模型（看 机器学习Python实践 / Python机器学习）、或想学深度学习（看 [[深度学习]] / [[神经网络]]）的人。

## 核心章节脉络（按公开章节结构整理）
> 说明：本书 PDF 为图片版（full.txt ≈ 0KB，manifest 无章节文本），以下基于公开目录结构与领域知识整理，**未逐页核对正文、不引用具体代码**。

1. **协作过滤（推荐）**：基于用户/物品的推荐，皮尔逊相关、欧氏距离相似度。（「推荐系统」概念本库暂无独立卡片，用普通文本标注）
2. **发现群组**：层次聚类、K-means 聚类。
3. **搜索与排名**：简单爬虫、 inverted index、PageRank。
4. **优化**：随机爬山、模拟退火、遗传算法。
5. **文档过滤**：朴素贝叶斯、垃圾邮件分类。
6. **决策树建模**：信息增益、递归划分。
7. **价格模型**：线性回归、加权回归。
8. **高级分类**：核方法、支持向量机（SVM）。
9. **寻找独立特征**：非负矩阵分解（NMF）、主成分分析（PCA）。
10. **进化智能**：遗传编程。
11. **算法总结**：各方法适用场景对比。

# Python 入门指南（官方教程 Python 3 版）教程笔记

## 这条教程在解决什么
- 这是官方 **The Python Tutorial** 的 **Python 3** 中文版，按「解释器 → 流程控制 → 数据结构 → 模块 → 输入输出 → 异常 → 类 → 标准库」系统讲解语言本身。
- 定位：官方「标准入门文档」，权威、严谨，是系统建立 Python 语言全景的最佳起点之一。
- 与 tut21《Python 2.7 Tutorial 中文版》是同一份官方教程的不同版本，本笔记对应主流 Python 3。

## 关键内容（按章节提纲）
- Whetting Your Appetite：Python 能做什么
- Using the Python Interpreter：[[Python]] 解释器、交互模式
- More Control Flow Tools：[[控制流]]、[[推导式]]
- Data Structures：[[列表]] [[元组]] [[字典]] [[集合]]
- Modules：[[模块与包]]、[[导入系统]]
- Input and Output：[[文件IO]]、格式化
- Errors and Exceptions：[[异常处理]] [[自定义异常]]
- Classes：[[类与对象]] [[继承]]、特殊方法
- Brief Tour of the Standard Library (I/II)：[[标准库]] 概览
- Floating Point Arithmetic：[[浮点数精度]] 专章（为何 0.1+0.2≠0.3）
- What Now?：后续学习路径建议

## 它背后的原理（别只记操作）
- REPL（解释器循环）是最快的反馈回路；标准库「开箱即用」是 Python 生产力的核心（见 [[标准库]]）。
- [[浮点数精度]]：二进制浮点无法精确表示多数十进制小数，比较要用容差。

## 我能复用/改编的点
- 作为「官方语法字典」查漏补缺；Standard Library 两章可直接当 [[标准库]] 的索引清单。
- 教学时按此顺序（解释器→控制流→数据结构→类→标准库）带新人最稳。

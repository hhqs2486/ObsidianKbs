# 从芯片到云端：Python 物联网全栈开发实践（刘凯）

## 这条教程在解决什么
- 把「最底层的芯片/传感/执行器」一路连到「云端的服务与数据分析」，用 Python 贯穿全栈，讲清一个物联网系统是怎么从一块开发板长成可联网、可管控、可分析的产品的。
- 定位是**全栈实战型**：不只教某个库怎么用，而是把嵌入式侧（树莓派/Python 控制硬件）与云端侧（服务器、通信协议、数据分析）串成一条完整链路。

## 它背后的原理（别只记操作）
- 「从芯片到云端」的本质是**分层解耦**：感知（传感器）→ 控制（GPIO/总线/电机）→ 通信（MQTT/串口）→ 云端（服务/存储/分析）各层用清晰接口拼接，Python 贯穿其中降低全栈门槛。
- 边缘侧（树莓派）负责就近采集与控制，云端负责汇聚、持久化与跨设备协同；二者经 [[物联网MQTT]] 这类轻量发布/订阅协议松耦合连接。

## 我能复用/改编的点
> 换一套需求（比如从「家庭环境监测」改成「工厂设备预测性维护」），同一套架构可直接复用：边缘用 [[树莓派]]+[[传感器]] 采数，经 [[物联网MQTT]] 上报，云端做存储与告警/分析，反向指令再下发到 [[电机驱动]]/执行器。

# 教程笔记：Python机器学习（原书第2版）

> 对应缓存 KEY：`057_Python机器学习（原书第2版） (数据科学与工程技术丛书) by 塞巴斯蒂安·拉施卡`
> 本库教程编号：96 · 集群：数据科学与AI · 角色：anchor（ML/DL 核心概念卡归属书）

## 本书定位 / 适合谁看
- 作者 Sebastian Raschka（瓦希德·米尔贾利利合著），被誉为"用 scikit-learn 把机器学习讲透"的入门到进阶经典。
- 适合：已会 Python 基础、想系统建立机器学习直觉的读者（大二电子信息类学生尤其合适）；强调"先懂原理再调库"，每章配可运行代码。
- 不适合：只想读Transformer/BERT 等 2017 年后的前沿架构（本书出版于 2017，未覆盖注意力/Transformer/迁移学习范式，本笔记已作为核心概念补充）。

## 核心章节脉络（按 TOC）
1. 赋予计算机从数据中学习的能力——三类机器学习、术语、工作流
2. 训练简单的机器学习分类算法——感知器、Adaline、[[梯度下降]]
3. scikit-learn 分类器一览——逻辑回归、[[支持向量机SVM]]、[[决策树]]、KNN、[[随机森林]]
4. 构建良好的训练集——预处理、[[特征工程]]、标准化
5. 通过降维压缩数据——[[降维PCA]]、LDA、核 PCA
6. 模型评估和超参数调优——[[交叉验证]]、学习/验证曲线、[[过拟合]]/[[欠拟合]]、网格搜索
7. 组合学习——[[集成学习]]（多数票、Bagging、AdaBoost）
8. 情感分析应用
9. 模型嵌入网络应用
10. 回归分析预测连续目标——[[回归]]（线性、岭/LASSO/弹性网络、多项式、随机森林回归）
11. 聚类分析——[[聚类]]（k-均值、层次、DBSCAN）
12. 从零实现多层神经网络——[[神经网络]]、[[多层感知机]]、正向传播、[[反向传播]]、[[激活函数]]、[[损失函数]]
13–14. 用 TensorFlow 训练神经网络（张量、变量、优化器）
15. 深度卷积神经网络图像识别——[[卷积神经网络]]、卷积/池化、[[Dropout]]
16. 用递归神经网络为序列建模——[[循环神经网络]]、[[LSTM]]

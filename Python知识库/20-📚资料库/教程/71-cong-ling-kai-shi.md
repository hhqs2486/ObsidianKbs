# 从零开始学Python网络爬虫

## 本书定位 / 适合谁看
- 定位：体系化的「零基础 → Scrapy」入门路线：先讲网络与网页原理，再逐个技术点（正则 / XPath / API / 多进程 / 异步 / 登录 / Selenium / Scrapy）铺开，最后落到框架。
- 适合：完全零基础、想从原理一路学到 Scrapy 框架的读者；也适合作为爬虫技术的「总目录」式参考书。
- 不适合：只想快速抄一段代码抓某个网站的读者（本书铺垫较厚）；也非分布式引擎向（看《自己动手写网络爬虫》）。

# quantsp 研究计划书（中文金融新闻文本挖掘 + 量化投资）

## 这条教程在解决什么
- 一份研究计划书：设想搭建一个类 AZFinText 的中文财经新闻文本挖掘系统，实时挖掘新闻情绪并据此做量化策略模拟交易。

## 定位 / 适合谁
- 定位：研究计划 / 开题文档（非编程教材），描述「技术路线」而非给出完整代码。
- 适合：对 量化投资 + NLP 交叉方向感兴趣、想了解「新闻→情绪→交易信号」整体 pipeline 的研究者/学生。
- 不适合：想学具体 Python 实现的人（本书几乎不含代码）。

## 关键内容（按 PDF 章节提纲）
一、研究方向
1.1 研究问题：中文财经新闻文本挖掘 + 股价预测 + 量化策略模拟交易（对标 AZFinText）。
1.2 研究现状：国外 Schumaker 等将文本挖掘与量化结合；国内尚处起步。
1.3 研究意义：实时扫描新闻、抢在预期实现前交易的优势。

二、研究方案
2.1 新闻来源与提取：编写 网络爬虫 实时抓取证监会/上市公司/门户/自媒体新闻。→ [[网络爬虫]]
2.2 新闻文本挖掘：
  - 文本预处理：中文分词（正向最大匹配）、停用词。→ [[自然语言处理]]
  - 文本特征表示：TF-IDF 加权，得到特征向量。→ [[自然语言处理]] [[机器学习]]
  - 文本特征选择：DF / 信息增益 / 互信息 / CHI。
  - 文本分类与聚类：KNN、朴素贝叶斯、SVM（监督）/ K均值（无监督），用准确率、召回率、F-Measure 评价。
2.3 文本挖掘云计算平台：租用云服务器或自建 Hadoop 平台应对实时计算量。→ [[数据科学]]
2.4 文本挖掘结合量化投资：情绪打分（正面1/中性0/负面-1）+ 权重（可用机器学习调权）→ 交易信号。

## 我卡住/没懂的地方
- 计划书只给路线，TF-IDF 公式、分词实现、Hadoop 搭建都需另查资料与代码。
- 「机器学习调权重」（预测准的分析师权重翻倍）是示意，缺具体模型。

## 它背后的原理（别只记操作）
- 核心假设：新闻情绪短期（分钟级）对股价影响最大，故「实时性」是关键，从而引出对并发/云计算的需求。
- TF-IDF 直觉：词在当前文档越频繁越重要，但在全库越普遍越不重要（见 [[机器学习]] 中特征加权思想，[[数据科学]] 文本挖掘范式）。

## 我能复用/改编的点
- 「新闻→分词→TF-IDF→分类→情绪打分→策略」的 pipeline 可直接套到任何「文本情绪驱动决策」场景。
- 爬虫抓取 + 文本挖掘的组合是 [[网络爬虫]] 与 [[自然语言处理]] 的典型联合应用。

# 趣学Python编程（中文版）

## 定位
面向青少年 / 绝对初学者的趣味入门书。用海龟作图、弹球游戏、火柴人逃生游戏等小项目把语法「裹」在好玩的例子里，强调「边玩边学」。

## 适合谁看
- 零基础、怕枯燥的学习者（中小学生 / 编程小白）；
- 喜欢通过做小游戏来理解概念的人；
- 亲子共学或作为第一本「不吓人」的 Python 书。

## 章节脉络（依据 manifest TOC）
- 第1部分 学习编程：第1章 Python 不是大蟒蛇 / 第2章 计算与变量 / 第3章 字符串、列表、元组和字典
- 第4章 用海龟画图（turtle，plain）/ 第5章 用 if 和 else 来提问（`[[控制流]]`）/ 第6章 循环
- 第7章 使用函数和模块来重用代码（`[[函数基础]]`、`[[模块与包]]`）/ 第8章 如何使用类和对象（`[[类与对象]]`）
- 第9章 Python 的内建函数 / 第10章 常用的 Python 模块（`[[标准库]]`）
- 第11章 高级海龟作图 / 第12章 用 tkinter 画高级图形（GUI，plain）
- 第2部分 弹球实例：第13–14章 你的第一个游戏：弹球
- 第3部分 火柴人实例：第15–18章 火柴小人游戏的图形 / 开发火柴人游戏 / 创建火柴人 / 完成火柴人逃生游戏
- 附录：Python 的关键字 / 术语表

## 关键知识点（双链）
- 用游戏串起基础概念：`[[变量与名字绑定]]`、`[[字符串]]`、`[[列表]]`、`[[元组]]`、`[[字典]]`、`[[控制流]]`、`[[函数基础]]`、`[[类与对象]]`、`[[模块与包]]`、`[[标准库]]`。
- 项目驱动：弹球 / 火柴人游戏是 `[[类与对象]]` 与 `[[控制流]]` 的天然练习场。

# Building Machine Learning Systems with Python

## 定位
以「搭系统」为主线、而非讲算法理论的机器学习实战书。用 scikit-learn 等库，带读者从数据预处理一路走到聚类、分类、回归、主题模型、降维、计算机视觉，并讨论「更大规模数据」的工程问题。

## 适合谁看
- 已会 Python 基础、想上手机器学习项目的人；
- 更关心「怎么把模型跑通并工程化」而非推导公式的工程师；
- 与 `数据科学与AI` 集群的 tut 96《Python 机器学习》（anchor）、tut 102《利用Python进行数据分析》（anchor）搭配。

## 章节脉络（依据 cache 真实章节文件名）
1. Getting Started with Python Machine Learning — 环境、NumPy 数组、`[[模块与包]]`
2. Learning How to Classify with Real-world Examples — 第一个分类器（scikit-learn）
3. Clustering – Finding Related Posts — KMeans 聚类（plain）
4. Topic Modeling — LDA 主题模型（plain）
5. Classification – Detecting Poor Answers — 文本分类 / 特征工程
6. Classification II – Sentiment Analysis — 情感分析（plain）
7. Regression – Recommendations — 线性回归 / 推荐（plain）
8. Regression – Recommendations Improved — 正则化改进
9. Classification III – Music Genre Classification — 音乐流派分类
10. Computer Vision – Pattern Recognition — 图像模式识别（plain）
11. Dimensionality Reduction — PCA / 降维（plain）
12. Big(ger) Data — 规模化数据与流水线（`[[迭代器与生成器]]`、`[[推导式]]` 在处理大数据时有用）

## 关键知识点（双链）
- 工程基础全靠 Python 语言特性支撑：`[[模块与包]]`、`[[类与对象]]`、`[[迭代器与生成器]]`、`[[推导式]]`、`[[函数基础]]`、`[[异常处理]]`。

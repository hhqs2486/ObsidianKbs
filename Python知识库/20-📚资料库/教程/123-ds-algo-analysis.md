# Python数据结构与算法分析

## 这条教程在解决什么
- 用 Python 把「数据结构 + 算法」从数学定义落到可运行的代码：先讲清楚**为什么要分析算法复杂度**，再逐个实现线性结构（栈/队列/链表）、递归、搜索排序、树、图，最后用附加专题把前面知识串起来（RSA、跳表、图像量化、字符串匹配）。
- 它回答一个工程师天天碰到的问题：**同一个功能，不同写法为什么有的快、有的慢、有的吃内存？** 给你一套衡量与选择的尺子。

## 关键内容（按 PDF 章节提纲）
- **第1章 导论**：什么是计算机科学 / 编程 / 抽象数据类型（ADT）；Python 基础回顾（数据、控制流、函数、[[类与对象]]）。把「数据 + 操作」打包成 ADT 是全书的方法论起点。
- **第2章 算法分析**：核心就是 [[时间复杂度大O]] 与 [[空间复杂度]]。用「异序词检测」4 种解法对比性能；再给出 Python 内置 [[栈|列表]] 与 [[哈希表|字典]] 的实测复杂度表——告诉你「选对内置结构」比「手写优化」更重要。
- **第3章 基本数据结构（线性结构）**：[[栈]]（括号匹配、进制转换、表达式求值）、[[队列]]（打印任务模拟）、双端队列（回文检测）、[[链表]]（无序/有序列表的底层实现）。这一章把「列表为什么是 O(n) 插入」讲透了。
- **第4章 递归**：[[递归]] 三原则、栈帧如何实现递归、迷宫问题；并引出 [[动态规划]]（用缓存消除重复子问题）。
- **第5章 搜索和排序**：[[查找算法]]（顺序 / 二分）、[[哈希表|散列]]（散列函数、冲突、映射 ADT）；[[排序算法]] 全家桶——冒泡 / 选择 / 插入 / 希尔 / 归并 / 快速，其中归并与快排是 [[分治算法]] 的典型。
- **第6章 树**：[[二叉树]]（解析树、三种遍历）、用 [[堆|二叉堆]] 实现优先级队列、[[二叉树|二叉搜索树]]、[[二叉树|AVL 平衡树]]（自平衡保证 O(log n)）。
- **第7章 图及其算法**：[[图]] 的两种表示（邻接矩阵 / 邻接表）；[[图|宽度优先搜索]]（词梯问题）、[[图|深度优先搜索]]（骑士周游）、拓扑排序、强连通分量；最短路径用 [[贪心算法]] 的 Dijkstra / Prim。
- **第8章 附加内容**：复习列表 / 递归 / 字典 / 树 / 图，落地到真实问题——[[递归]]+同余定理实现 [[字符串算法|RSA 加密]]、用跳表优化字典、用八叉树量化图片、用 DFA/KMP 做 [[字符串算法|字符串模式匹配]]。

## 我卡住/没懂的地方
- 第7章「骑士周游」用 DFS + 启发式（Warnsdorff 规则）剪枝，为什么比裸 DFS 快几个数量级——需要动手跑一遍才直观。
- 第8章 RSA 里「逆元」与「最大公因数」的推导，数论部分需要补一点 modular arithmetic 才能完全吃透。

## 它背后的原理（别只记操作）
- 所有「快慢」的讨论都回归到 [[时间复杂度大O]]：嵌套循环一般是 O(n²)，分治一般是 O(n log n)，哈希是 O(1)。看代码先数「操作随输入怎么放大」。
- 「结构决定算法」：为什么 [[栈]] 适合括号匹配（后进先出天然对应嵌套）？为什么 [[队列]] 适合模拟排队？选结构就是在选「操作顺序的约束」。
- [[递归]] 与 [[栈]] 同源：每次调用压栈帧，所以递归的深度 = 栈的深度（这也是爆栈原因）。

## 我能复用/改编的点
> 做「一个任务调度 / 表达式计算器 / 社交关系推荐」系统时，我会先画 ADT（需要什么操作、什么顺序），再据此选 [[栈]]/[[队列]]/[[哈希表]]/[[图]]，最后用 [[时间复杂度大O]] 估一下最坏情况——而不是上来就 for 循环硬写。

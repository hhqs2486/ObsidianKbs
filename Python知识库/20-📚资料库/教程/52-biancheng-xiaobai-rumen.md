# 编程小白的第一本 Python 入门书 教程笔记

## 这条教程在解决什么
- 真正面向**「编程小白」**的零门槛入门：用生活化比喻（如「类与可口可乐」）讲清抽象概念，弱化术语，强调「先跑起来、再理解」。
- 定位：最友好的大众向入门书，适合完全没碰过代码、怕被术语劝退的读者。

## 关键内容（按章节提纲）
- 第1章 为什么选择 Python：Python 的特点与适用场景
- 第2章 现在就开始：安装、写出并运行第一个程序
- 第3章 变量与字符串：[[变量与名字绑定]]、[[字符串]] 拼接与格式化
- 第4章 函数：[[函数基础]]、参数与返回值
- 第5章 循环与判断：[[控制流]]（if / for / while）
- 第6章 数据结构：[[列表]] [[元组]] [[字典]]、增删改查
- 第7章 类与可口可乐：[[类与对象]]、属性与方法（用「可口可乐」比喻类与实例）
- 第8章 开始使用第三方库：安装与导入第三方包（见 [[包管理pip]]）
- 第9章 必读：给编程小白的学习资源清单

## 它背后的原理（别只记操作）
- 用「可口可乐 = 类，手里这瓶 = 实例」类比 [[类与对象]]，把抽象 OOP 落到日常直觉。
- 第三方库（第8章）让新手意识到：多数需求已有现成轮子，关键是用 [[包管理pip]] 装、用 [[模块与包]] 导入。

## 我能复用/改编的点
- 第7章的类比可直接借来给非技术同事做 OOP 科普。
- 第9章学习资源清单适合作为新人「下一步去哪」的导航。

# 机器人Python极客编程入门与实战

## 这条教程在解决什么
- **本书定位**：一本「从 Python 语法 → MicroPython 开发板（PyBox/TPYBoard）→ 机器人」的实战手册。它最大特色是**硬件不是树莓派，而是基于 MicroPython 的 PyBox 开发板**（STM32F405 单片机，通过 USB 当U盘拖入 `main.py` 即运行），但编程思维与树莓派一脉相承，是本集群里「嵌入式 Python 落到一个更小、更便宜的板子」的代表。
- **适合谁看**：① 想做教育机器人/创客小车的玩家；② 已懂一点 Python、想立刻上手点灯/测温/避障的人；③ 作为 [[树莓派]] 之外「更省电、更便宜的嵌入式 Python 入口」对照阅读（见 [[嵌入式Python]] 的 MicroPython 形态）。
- 与库中关系：和 [[机器人控制]] [[电机驱动]] [[传感器]] 概念卡强互补；和 109/114 的树莓派路线形成「树莓派 vs MicroPython 板」双视角。

## 我卡住/没懂的地方
- 本书用自带的 PyBox 固件 + `main.py` 拖拽运行，和树莓派上「终端跑 CPython 脚本」的开发流程不同，初期容易混淆（见 [[嵌入式Python]] 两种形态对比）。
- 视觉部分（OpenCV、人脸、CUDA）在正文与宣传里被反复提到，但核心实战章节以 GPIO/传感器/小车为主，CV 属于「扩展生态」，本书未系统展开，需另查 [[数据科学]] 相关卡。

## 它背后的原理（别只记操作）
- **MicroPython = 把 Python 解释器烧进单片机**：你写 `machine.Pin(2, Pin.OUT)` 点灯，和树莓派 `RPi.GPIO` 思路一致，只是没有 Linux、没有硬盘，靠「拖文件进 U 盘即刷入」——这就是 [[嵌入式Python]] 卡片里说的 MCU 形态。
- **灯/风扇/小车 = 同一套「输出」思维**：LED 是数字输出，风扇/舵机是 [[GPIO]] 的 PWM 调占空比，小车差速是左右 [[电机驱动]] 配合，全都能从 [[GPIO]] 这张卡推出来。
- **避障/寻迹 = 传感器喂决策**：超声波/红外读到距离 → Python 判断 → 给 [[电机驱动]] 发指令，闭合了 [[机器人控制]] 卡片讲的「感知—决策—执行」环。

## 我能复用/改编的点
> 换个需求，这套做法还能怎么用？
- 把第18–21章的小车案例直接映射到期末项目：把 PyBox 换成 [[树莓派]] + [[串口UART]] 通信的下位机，上层仍用 Python 跑决策（见 [[机器人控制]]）。
- 第8–9章的测温/PM2.5 采集，可改为 [[物联网MQTT]] 上报，接 [[智能家居]] 看板（把单机测量升级为联网监测）。
- 第16章舵机控制是 [[电机驱动]] 里「舵机=脉冲宽度定角度」的活例子，做机械臂云台时直接复用。

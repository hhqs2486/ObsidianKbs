# 零基础入门学习Python（小甲鱼）

## 这条教程在解决什么
- 给完全零基础的人一个轻松、幽默、配视频的 Python 第一本书；用大量小游戏和可视化例子把语法“讲明白”而不是“列语法”。

## 定位 / 适合谁
- 定位：趣味入门书，鱼C工作室出品，口语化强，重“先跑起来再讲原理”。
- 适合：零基础、喜欢轻松风格、愿意配合视频教程学习的读者。

## 我卡住/没懂的地方
- 第14章涉及 urllib/BeautifulSoup/Scrapy，环境配置（尤其 Python2 与 Scrapy）较旧，按现行 Python3 需自行迁移。

## 它背后的原理（别只记操作）
- 类与对象把“数据+行为”打包成对象，self 相当于每个实例的“门牌号”；继承让子类复用父类属性方法，super() 自动找基类。
- 爬虫本质：用 urllib 发 HTTP 请求拿 HTML → 用 [[正则表达式]] 或 [[BeautifulSoup]] 解析提取 → 用 [[Scrapy]] 做规模化框架。

## 我能复用/改编的点
> 换需求时：把“下载一只猫 / 有道翻译”的例子改写成“批量下载图片 / 调用任意 POST 接口”，核心套路（请求→解析→存储）完全通用。

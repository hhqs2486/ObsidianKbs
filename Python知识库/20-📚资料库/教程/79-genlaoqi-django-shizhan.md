# 跟老齐学 Python：Django 实战

## 这条教程在解决什么
以"做项目"为主线吃透 Django：从零搭一个多用户文章/博客系统，再扩展成带图片收集、在线学习应用的综合平台。与《Django 中文教程》（tut 74，偏原理）互补——本书**偏动手**，每章末都有"知识点"小结，强调"先忘记再重建"的扎实练法。

## 关键内容（按 PDF 章节提纲）
- **第1章 简单的博客系统**：Django 起步（安装、建项目/应用、网站配置）→ 用 [[ORM对象关系映射]] 写数据模型类 → 发布与显示文章（[[路由(Web)]] + 视图 + [[模板引擎Jinja2]]）。
- **第2章 用户管理**：自定义模板/[[静态文件]]位置；[[Web表单]]（表单类）→ 登录的视图与前端；用 Django 内置方法实现登录/退出、判断登录态；[[用户认证Web]]（注册、改密码、重置密码、第三方应用重置）；维护个人信息、上传裁剪头像。
- **第3章 文章管理和展示**：栏目 CRUD、发布/显示文章、用 Markdown 渲染、删除修改、分页；文章标题列表与展示。
- **第4章 拓展网站功能**：梳理已有功能；作者文章列表；文章点赞（改模型+视图+模板）；用 Redis 记录阅读次数、最"热"文章；评论功能；多样化展示（统计总数、最新、评论最多、自定义模板选择器）；文章标签的增删选显与相似推荐。
- **第5章 收集和展示图片**：爬取/管理网络图片；瀑布流展示与详情。
- **第6章 中场休整**：阶段性复盘。
- **第7章 创建在线学习应用**：基于类的视图（Class-Based Views）与 Mixin；课程标题管理、课程内容的数据模型/表单/视图、注册学习。
- **第8章 结束和开始**：收尾与进阶指引。

## 我卡住/没懂的地方
- 第2章起的 `TEMPLATES` 配置中 `APP_DIRS: False` 并把模板集中到项目根 `templates/`，与默认"每 app 自带 templates"约定不同，需注意查找顺序。
- 部分页面 OCR 噪声较大（如配置片段有乱码），关键代码以原书/官方示例为准。

## 它背后的原理（别只记操作）
贯穿一条主线：需求 → 改 [[ORM对象关系映射]] 模型类 → 写 [[Web表单]]/视图 → 配 [[路由(Web)]] → 改 [[模板引擎Jinja2]] 渲染 → 用 [[用户认证Web]] 管权限。每一次加功能都是"模型+视图+模板+URL"四件套的再组合，admin 与 auth 等内置 app 直接复用。

## 我能复用/改编的点
> 做"多用户内容平台"（博客/课程/社区）时，直接复用本书的功能模块清单：用户系统→内容 CRUD→互动（点赞/评论/标签）→热度统计→资源（图片）管理，按这个顺序迭代最稳。

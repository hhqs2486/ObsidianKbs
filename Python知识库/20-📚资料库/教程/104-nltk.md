# 用Python进行自然语言处理（NLTK 书）

## 这条教程在解决什么
NLP 经典教材（NLTK 官方配套）：用 NLTK 把语言学概念变成可运行代码——语料库、词链表、频率分布、分类标注、信息提取、句法/文法、语义、语言数据管理。边写程序边学语言学。

## 本书定位 / 适合谁
- 想系统学 **NLP 与共 NLTK 工具链**的读者；从零讲 Python 与语言学，适合入门。
- 与《python自然语言处理实战》（99，中文实战）互补：本书偏英文语料与语言学原理，99 偏中文工程。

## 核心章节脉络（按 TOC）
- **第1章 语言处理与 Python**：文本即词链表、NLTK 入门、搜索文本、计数词汇、[[字符串]] 与列表操作。
- **第2章 获得文本语料和词汇资源**：古腾堡/布朗等语料库。
- **第3章 加工原料文本**：分词、词形还原。
- **第4章 编写结构化程序**：[[函数基础]]/[[控制流]] 在 NLP 中的运用。
- **第5章 分类和标注词汇**：词性标注（接 [[自然语言处理]]）。
- **第6章 学习分类文本**：用 [[机器学习]] 做 [[分类]]（ spam/主题等）。
- **第7章 从文本提取信息**：命名实体、关系抽取。
- **第8–9章 分析句子结构 / 基于特征的文法**：句法树、特征文法。
- **第10章 分析句子意思**：语义、lambda 演算。
- **第11章 语言数据管理**：语料库建设。

## 关键知识点（指向概念卡）
- 文本在程序里就是"词组成的链表"，统计分析（词频、搭配）是 [[自然语言处理]] 的基础功。
- 词性标注、文本分类本质是 [[分类]] / [[监督学习]] 问题。
- NLP 流水线常接 [[数据科学]]：用 [[NumPy]]/[[Pandas]] 整理语料、用 [[数据可视化]] 看分布。

## 互补关系
- 与 [[自然语言处理]]（概念卡）：本书记 NLTK 的具体做法，概念卡给总览。
- 与《python自然语言处理实战》（99）：英文原理 vs 中文实战。
- 与 [[机器学习]]（八、101）：第6章是 ML 在文本分类的应用入口。

## 我能复用/改编的点
> 做语料探索时，先用 NLTK 的频率分布/搭配分析快速摸清文本特征，再决定是否上 [[分类]] 或 [[深度学习]]。

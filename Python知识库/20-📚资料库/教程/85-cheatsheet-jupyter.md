# 速查表：Jupyter Notebook（交互式开发环境）

## 这条教程在解决什么
一张 Jupyter Notebook 的界面与快捷键速查表（DataCamp / 呆鸟 译），覆盖笔记本的创建/保存、单元格编辑、命令模式与编辑模式快捷键、内核（kernel）操作、魔法命令与导出。

## 定位 / 适合谁
- 定位：随用随查的备忘录，不是教程。
- 适合谁：日常在 Notebook 里做[[数据分析]]/[[数据可视化]]/写文档，但总记不住快捷键的人。

## 关键内容（速查主题）
- **单元格类型**：代码（Code）、Markdown、Raw；用 Markdown 写说明、用 Code 跑分析。
- **文件与检测点**：新建/打开/重命名/另存为（ipynb、Python、HTML、PDF 等）、保存并创建检测点。
- **命令模式 vs 编辑模式**：单元格增删/移动/合并/分割/运行、查找替换等快捷键。
- **内核操作**：运行、中断、重启、清除输出、连接其它语言内核（IRkernel/IJulia 等）。
- **控件与导出**：Widgets 交互控件；NBConvert 把笔记本导出为多种格式。
- **帮助**：内置 NumPy / Pandas / Matplotlib / SciPy / SymPy / IPython 帮助入口。

## 与其他书的互补
- 是[[数据科学]]工作流的「操作台」：配合[[NumPy]]/[[Pandas]]/[[Matplotlib]]做探索性分析。
- 库 **Jupyter** 在库中暂无独立概念卡，需要时可在`数据科学与AI`或工程类下补充。
- 与 `83-matplotlib-practice.md`（Bokeh 的 `output_notebook`）联动使用。

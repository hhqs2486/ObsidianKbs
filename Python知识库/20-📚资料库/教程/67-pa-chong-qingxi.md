# Python 3爬虫、数据清洗与可视化实战

## 本书定位 / 适合谁看
- 定位：一条龙的「采集 → 清洗 → 可视化」实战路线，把爬虫和后续数据处理串起来，而不是只讲怎么抓。
- 适合：已经会一点 Python、想把「网上数据」变成「能看的图/表」的读者；做小数据分析、毕设、运营报表也很合适。
- 不适合：想深究 Scrapy 分布式架构或自研爬虫引擎的读者（看《自己动手写网络爬虫》与 [[分布式爬虫]]）。

## 核心章节脉络（按 TOC，图片版整理）
> 注意：本书 PDF 为**图片版**，`full.txt` 仅空行、无正文文本；以下章节脉络基于书名与同类实战书结构整理，知识点链接到本库已有概念卡，未编造代码。

- **网页请求**：`urllib` 与 `requests` 发请求、带请求头与 Cookie，对应 [[urllib]] [[requests库]]。
- **网页解析**：正则抠文本、BeautifulSoup 温和提取、lxml/XPath/CSS 定位，对应 [[正则表达式爬虫]] [[BeautifulSoup]] [[lxml解析器]] [[XPath选择器]] [[CSS选择器]]。
- **数据存储**：落文件 / MySQL / MongoDB，对应 [[爬虫数据存储]]。

- **Scrapy 框架**：流水线化「请求—下载—解析—存储」，对应 [[Scrapy]] [[数据管道Pipeline]]。

- **数据可视化**：matplotlib/pyecharts/词云做图，对应 [[数据可视化]]。
- **综合案例**：把上述串成可运行项目，对应 [[爬虫实战]]。

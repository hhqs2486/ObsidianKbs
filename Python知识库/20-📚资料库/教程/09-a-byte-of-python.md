# A Byte of Python（中文版）教程笔记

## 这条教程在解决什么
- 面向**零基础读者**的 Python 入门书，用最短篇幅讲清「能跑起来的 Python」：从安装、基础语法到面向对象、标准库，目标是让没有任何编程经验的人也能上手写脚本。
- 本书以「薄、精炼、直给」著称，是很多人的第一本 Python 书。

## 关键内容（按章节提纲）
- 安装与环境：在 Windows/macOS/Linux 安装 Python、配置编辑器
- First Steps / Basics：[[变量与名字绑定]]、[[数据类型]]（数字、[[字符串]]）
- Operators and Expressions：运算符与表达式求值
- Control Flow：[[控制流]]（if / while / for）
- Functions：[[函数基础]]、参数、局部/全局变量
- Modules：[[模块与包]]、[[导入系统]]、使用标准库模块
- Data Structures：[[列表]] [[元组]] [[字典]] [[集合]]、[[推导式]]、[[迭代器与生成器]]
- Problem Solving：综合小项目（地址簿 CLI）
- Object Oriented Programming：[[类与对象]] [[继承]] [[多态]]
- Input Output：[[文件IO]]、[[序列化(json与pickle)]]
- Exceptions：[[异常处理]] [[自定义异常]]
- Standard Library：[[标准库]]（sys / os 等常用模块）
- More：进阶补充（特殊方法、部分技巧）

## 它背后的原理（别只记操作）
- **一切皆对象**：名字绑定到对象，而非「变量有类型」（见 [[Python对象模型]]）。这解释了为什么 Python 里同一个名字可以先后指向不同类型。
- **缩进即语法**：用缩进来划分代码块，从语言层面强制写出可读代码。

## 我能复用/改编的点
- 书中的地址簿小项目可直接改造成个人通讯录 CLI 工具。
- 作为「第一本 Python」推荐给完全没有编程经验的同学，配合 [[Python]] 总览卡食用。

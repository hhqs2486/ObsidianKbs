# NLTK 基础教程：用 NLTK 和 Python 库构建机器学习应用

## 这条教程在解决什么
带你用 NLTK 跑通一条完整的自然语言处理（NLP）流水线：从原始文本 → 清洗与分词 → 词性标注/命名实体 → 句法解析 → 文本分类/聚类，再用 NLTK 串起 NumPy / SciPy / pandas / matplotlib，甚至接 Scrapy 与 PySpark 做规模化文本挖掘。

## 定位 / 适合谁
- 定位：面向「已经会一点 Python、想落地 NLP 项目」的入门实践书，重代码、轻理论。
- 适合谁：做文本分类、舆情/社交媒体挖掘、搜索引擎相关任务的学习者；不适合想深入语言学理论或 Transformer 大模型的人。

## 关键内容（按章节脉络）
1. **NLP 简介**：为什么学 NLP；先补齐 Python 基础；初识 NLTK 安装与语料库。
2. **文本的歧义及其清理**（本书最实用的一章）：分句（语句分离器）、分词（标识化处理）、词干提取、词形还原、停用词移除、罕见词移除、拼写纠错。对应[[数据清洗]]思路在文本上的变体。
3. **词性标注（POS）与命名实体识别（NER）**：规则/统计标注入门；NER 抽取人名地名机构名。
4. **文本结构解析**：浅解析 vs 深解析、不同解析器、依存解析、语块分解（chunking）、信息提取。
5. **NLP 应用**：动手搭第一个 NLP 小应用。
6. **文本分类与无监督**：引入[[机器学习]]，做[[分类]]与[[聚类]]，用到[[随机森林]]，并涉及主题建模（无监督，归入[[聚类]]/[[无监督学习]]思路）。
7. **Web 爬虫**：用 Scrapy 抓取语料（与网络爬虫集群相关，本书只做串联）。
8. **NLTK 与其他库搭配**：[[NumPy]]、SciPy、[[Pandas]]、[[Matplotlib]]（[[数据可视化]]）。
9. **社交媒体挖掘**：数据收集、提取、地理可视化（[[数据可视化]]）。
10. **大规模文本挖掘**：Hadoop / PySpark 上的 NLTK 与 Scikit-learn。

## 它背后的原理（别只记操作）
- 文本是「带噪声的符号序列」：分词/词形还原把变体归并，停用词/罕见词降噪，本质都是[[特征工程]]——把非结构文本变成可被[[机器学习]]消费的向量。
- 分类与聚类之所以有效，是因为「词频/共现」携带了语义信号（参考[[自然语言处理]]总览）。

## 我能复用/改编的点
> 要做自己的文本分类器：先清洗（分词→去停用词→词形还原），再用 NLTK 的 `nltk.classify` 或接 Scikit-learn，评估时回看[[交叉验证]]与[[描述性统计]]。

# 零基础入门学习Python（小甲鱼）

## 定位 / 适合谁
- 面向完全零基础、以轻松口吻教学的国民级入门书（配套鱼C 论坛视频），覆盖 Python 语法与一小部分进阶。
- 适合：纯新手、自学者；不适合寻找高级主题或严谨工程规范的人。

## 章节脉络（PDF 为图片版，依据书名与系列惯例）
- 基础语法：变量、数据类型、运算符、字符串、列表/元组/字典/集合
- 控制流：条件、循环、推导式
- 函数：定义、参数、作用域、lambda、装饰器
- 面向对象：类、继承、多态
- 文件与异常：[[文件IO]]、[[异常处理]]
- 标准库与模块：[[模块与包]]、[[标准库]]
- 进阶一点点：正则表达式、[[迭代器与生成器]]、[[并发编程]] 概念

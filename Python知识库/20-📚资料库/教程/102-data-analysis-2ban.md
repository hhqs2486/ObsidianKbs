# 利用Python进行数据分析（第二版）

> 本书英文原名 *Python for Data Analysis*（O'Reilly，第2版，2017），作者 Wes McKinney 即 pandas 库的创始人。这是数据分析领域最权威的「根教材」之一——书中的 API 设计与思想直接决定了 [[Pandas]] 今天的样子。本笔记是「数据科学与AI / 数据分析·可视化」子区的主锚点教程。

## 这条教程在解决什么
- 把「拿到一堆脏乱的原始数据 → 清洗 → 规整 → 聚合分组 → 可视化 → 得到结论」这条真实数据分析流水线，用 Python（以 [[NumPy]] 与 [[Pandas]] 为核心）完整跑通。
- 让你建立一套**以表格（DataFrame）为中心**的数据思维：不写 for 循环，用向量化/分组运算处理数据。
- 占分析师 80% 时间的其实是数据准备（加载、清洗、转换、重塑），本书把这部分讲得最透。

## 关键内容（按 PDF 章节提纲）
- **第1章 准备工作 / 第2章 Python 语法基础、IPython 和 Jupyter**：环境（Anaconda）、交互式工作流。工具链基础，[[数据科学]] 的实操入口。
- **第3章 Python 数据结构、函数和文件**：语言核心铺垫，为后续 pandas 操作打底。
- **第4章 [[NumPy]] 基础：数组和矢量计算**：`ndarray`、广播、向量化。理解为什么 pandas 建立在 NumPy 之上、为什么能「不用 for 循环」。
- **第5章 [[Pandas]] 入门**：两大核心结构 `Series`（带标签的一维）与 `DataFrame`（表格）。这是全书的地基。
- **第6章 数据加载、存储与文件格式**：`read_csv / read_excel / read_sql` 等，把外部数据读进 DataFrame。
- **第7章 [[数据清洗]] 和准备**：
  - [[缺失值处理]]：`NaN` 哨兵值、`dropna / fillna / interpolate`。
  - [[异常值处理]]：检测与处置思路（结合 [[描述性统计]] 与 [[探索性数据分析EDA]]）。
  - 重复值、字符串操作、数据类型转换。
- **第8章 数据规整：聚合、合并和重塑**：`concat / merge / join`、长表宽表互转（`melt / pivot`）。
- **第9章 [[数据可视化]]**：以 [[Matplotlib]] 为底层（`import matplotlib.pyplot as plt`），并介绍统计绘图库 [[Seaborn]]。用于 [[探索性数据分析EDA]] 找异常、找模式。
- **第10章 [[数据聚合]] 与 [[分组GroupBy]]**：`split-apply-combine`（拆分-应用-合并）范式；自定义聚合函数；生成 [[透视表]]（交叉表）。
- **第11章 [[时间序列分析]]**：`DatetimeIndex`、重采样（resampling，即按时间的 groupby）、移动窗口、时区。
- **第12章 pandas 高级应用**：`apply`、`cut/qcut`、日期偏移、性能技巧。
- **第13章 Python 建模库介绍**：scikit-learn 与 statsmodels 简明接入，承上启下到 [[机器学习]]。
- **第14章 数据分析案例**：真实端到端案例（如金融/统计数据集），综合上述全部技能。
- **附录A/B**：高阶 NumPy、更多 IPython 用法。

## 我卡住/没懂的地方
- 第2版代码基于 Python 3.6 与 2017 版 pandas；部分 API（如 `append`、`ix`）在新版 pandas 已弃用，实操时需对照当前版本。
- `groupby` 的「拆分-应用-合并」对初学者抽象，建议配合 [[透视表]] 一起理解。

## 它背后的原理（别只记操作）
- **向量化 > 循环**：pandas/NumPy 把运算压到 C 层批量执行，思维要从「逐行处理」切换为「对整个列/表下指令」。
- **split-apply-combine**：分组本质是把数据按键切成多块 → 每块跑同一个函数 → 结果拼回。SQL 的 `GROUP BY` 是它的特例，而 Python 允许传入任意函数。
- **表格即一等公民**：DataFrame 同时携带数据与索引/列标签，使切片、对齐、合并都有明确语义，这是它区别于裸 NumPy 数组的关键。

## 我能复用/改编的点
> 换个需求，这套做法还能怎么用？
- 任何「按某维度汇总指标」的需求（销售按地区、日志按小时、用户按渠道）都能映射成 [[分组GroupBy]] + 聚合。
- [[缺失值处理]] / [[异常值处理]] 的套路是通用的，先 EDA 再清洗再建模的顺序适用于几乎所有数据集。
- 时间序列的重采样/滑窗可直接用于 [[量化交易API]] 类场景的 K 线聚合。
- [[相关性分析]]（配合 [[描述性统计]]）是做 [[特征工程]]、[[因子模型]] 前的必经探索。

## 与库中其他书的互补关系
- **与《Python数据分析与数据化运营》（六）**：该书偏业务落地（用户画像、AB测试、指标体系），本书偏工具与底层原理（pandas/NumPy 本源）。二者互补——本教程负责「怎么用 pandas 把数据算出来」，六负责「算出来怎么用于运营决策」。
- **与《跟老齐学Python：数据分析》（121）**：入门向、中文通俗讲解；本书是同一主题更权威、更系统的原典。
- **与《Python数据分析入门：从数据获取到可视化》（040）**：入门实践路线；本书覆盖更深的聚合/分组/时间序列机制。
- **与《Python机器学习（原书第2版）》（057）/《动手学深度学习》（八）**：本书第13章已接入 scikit-learn，是通往 [[机器学习]]/[[深度学习]] 的数据预处理前置。
- **与《零起点Python大数据与量化交易》（127）/《Python与量化投资》（095）**：本书的时间序列与分组聚合是量化数据处理的基础能力。
- **与英文原版 O'Reilly Python for Data Analysis（017）**：同一本书的英文版，可作为查阅原始术语（如 `resample`、`pivot_table`）的对照。

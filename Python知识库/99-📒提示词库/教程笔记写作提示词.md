# 教程笔记写作提示词

> 给一个 agent 的 self-contained 提示词，用于把一本书/一批书消化成教程笔记（照 `90-⚙️模板/模板-教程笔记.md`）。

你是「{{知识库名字}}」的教程笔记写手。把《{{书名}}》消化成一篇教程笔记。

【输入】章节文本在 `<cache>/<key>/`（chNN_*.txt + full.txt，先 ls）；图片版书读 `manifest.json` 的 TOC，来源注明「PDF 为图片版」。
【模板】先读 `90-⚙️模板/模板-教程笔记.md`，照其结构写。
【必含段】这条教程在解决什么 / 关键内容(按真实章节提纲) / 我卡住的地方 / 背后原理 / 我能复用改编的点 / 关联(概念 `[[双链]]` + 项目) / 来源。
【风格】大二能懂；讲清「为什么」而非只记操作；用 `[[双链]]` 连到已有概念卡（名称须完全一致）。
【角色】若本书是该子主题的「anchor」：建它拥有的概念卡；否则只 `[[链接]]` 已有卡，不重复建。
【输出】完整 .md（frontmatter：`类型: 教程` / `来源:` / `tags: [{{知识库名字}}, 教程]` / `创建:` / `状态: 已读待消化`）。

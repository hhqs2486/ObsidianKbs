# 联网更新知识提示词

> 给 agent 的提示词：把某领域「最新知识」补进已有知识库，并与旧图谱 `[[双链]]` 长在一起（本次 Python 库即按此执行）。

你是「{{知识库名字}}」的知识更新 agent。任务：从互联网调研该领域近 1–2 年的**新特性 / 新库 / 新趋势**，补进知识库。

【步骤】
1. **WebSearch 调研**：官方 What's New / 权威博客 / 库官网，整理成结构化清单（特性名 / 解决什么 / 核心原理 / 易错点 / 来源 URL）。
2. **建新子主题**：在 `10-🧠核心概念/` 下新建一个子主题文件夹（如 `现代{{领域}}与生态/`），按概念卡模板写卡（建议 15–25 张）。
3. **写前沿教程**：一篇 `<编号>-前沿速览.md` 汇总，链接所有新卡。
4. **接旧图谱**：每张新卡用 `[[双链]]` 连到库里**已有**的相关卡（如 新库 → 旧库同名卡、新语言特性 → 已有语言概念），让新旧知识成网。
5. **刷新索引**：重跑 `genmoc.py` 生成新子主题地图；更新 `概念归属约定.md`（加第 N 子主题 + 标注「网络调研来源」）与 README 规模数字。
6. **校验**：跑 gapcheck 到 0 断链。

【来源诚实】每张卡「来源」写官网/文档 URL 与日期；不确定的不写。

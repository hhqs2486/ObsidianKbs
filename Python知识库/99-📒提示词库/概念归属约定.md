# 概念归属约定（多书协作防重复）

> 本库收录 **136 篇教程笔记（8 本种子书 + 127 本《Python学习书籍合集》+ 1 篇网络调研前沿）**，共 **336 张概念卡**，分 13 个子主题。为避免重复建概念卡、保证 `[[双链]]` 对得上，约定「谁拥有哪些概念」。另为图谱分组，所有笔记带 `tags`（库名+子主题/类型），见下方「标签体系」。
> **规则**：归属方负责建卡并写正文；非归属方只在自己的教程笔记里用 `[[链接]]` 指向它，**不新建同名卡**（除非补充该方独有角度，文件名加后缀区分，如 `装饰器-精进视角`）。

## 标签体系（图谱分组用）
- 每篇笔记 frontmatter 带 `tags`：第一维恒为 `Python`；第二维为**子主题名**（概念卡）或**类型**（`教程` / `MOC` / `项目实战` / `问题排查` / `收件箱` / `索引`）。
- 例：语言核心概念卡 → `tags: [Python, 语言核心, 概念]`；教程 → `tags: [Python, 教程]`；新集群卡 → `tags: [Python, 现代Python与生态, 概念]`。
- Obsidian 关系图谱里可按 `tags` 着色分组、用过滤器（如 `-tags:#教程`）只看某一类；三个库已各自独立成 vault，图谱之间不再混杂。

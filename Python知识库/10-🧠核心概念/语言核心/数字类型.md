# 数字类型

## 一句话定义
> Python 内置的数值对象家族：无限精度的 `int`、带小数点的 `float`、复数 `complex`，以及定点 `Decimal`、分数 `Fraction`、布尔 `bool`——外加一套运算符与多种进制字面量。

## 它解决什么问题 / 为什么存在
- 覆盖从「数数」到「高精度金融计算」的各种数值需求，省去自己造轮子。
- 整数不限长度（自动扩容），避免 C 语言那种溢出问题。

## 核心原理（大二能懂的水平）
- **int**：任意精度，写多大都行（`2**1000` 也能算）。
- **float**：双精度浮点，有精度上限（见 [[浮点数精度]]）。
- **除法 two 种**：`/` 是**真除法**（3.X 里 `3/2 == 1.5`，永远保留小数）；`//` 是**地板除**（向下取整，`3//2 == 1`）。
- **Decimal / Fraction**：`decimal.Decimal` 做定点财务计算，`fractions.Fraction` 表示精确分数，避免浮点误差。
- **bool 是 int 的子类**：`True == 1`、`False == 0`，只是显示不同。
- 进制字面量：`0o17`（八）、`0xFF`（十六）、`0b1010`（二）；`bin()/oct()/hex()` 互转。

## 关键参数 / 易错点
- **Python 3 中 `3/2 = 1.5`**，不是 `1`。想要整除用 `//`。
- 浮点别直接比相等（`0.1+0.2 != 0.3`），金额务必用 `Decimal`。
- `**` 是乘方；位运算 `& | ^ << >>` 作用在整数上。
- 比较可链式：`1 < x < 10` 合法且直观。

## 类比（帮助理解）
- `int` 像一支能无限接长的水笔，想写多长写多长；`float` 像带固定刻度的量杯，越大量程刻度越粗（精度越低）。

## 设计时怎么用（反推思维）
> 写下单/计价系统时，金额字段一律用 `Decimal` 并显式指定进位，别用 `float`，否则分币会被吃掉。做位掩码权限判断时，用 `& / | / <<` 而不是布尔列表。

## 典型应用 / 我在哪见过
- 计数器、索引、哈希种子（int）。
- 金额与税率（Decimal）、比例与概率（Fraction）。
- 掩码权限（位运算）。

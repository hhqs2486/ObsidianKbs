# 继承（单继承与多继承）

## 一句话定义
> 继承（派生 / 子类化）让一个**子类**自动获得**父类（基类）**的属性和方法，并能在之上「特化」出自己的差异——是 OOP 里「复用代码 + 表达 is-a 关系」的核心机制。

## 它解决什么问题 / 为什么存在
- 没有继承时，相似的对象要各自重写一遍相同逻辑（书里用全局变量存状态的 `OpenObject` 反例说明「复制粘贴」有多乱）。
- 继承把「公共行为」上提到父类，子类只写「不一样的地方」，既去重又清晰表达「子类是一个父类」的泛化/特化关系。

## 核心原理（大二能懂的水平）
- 语法：`class SubClassName(bases):`，`bases` 是一个（单继承）或多个（多重继承）父类。若没指定父类，新式类默认以 `object` 为母类（「所有类之母」）。
- 从 Python 2.2 起，不仅能从其他类派生，还能从内建类型（如 list、dict）派生子类。
- **泛化**：所有子类与父类/祖先类有相同特征，子类可视为祖先类的「是一个（is-a）」例子（技工「是一个」人）。**特化**：子类自定义「让它和祖先不同的属性」。
- **方法解释顺序（MRO，Method Resolution Order）**：多重继承时多个父类同名方法，新式类按 `__mro__` 属性确定的顺序查找——写在前面（左边）的父类优先。经典类与新式类的 MRO 行为不同（经典类深度优先，新式类按 C3 线性化）。
- 用 `super()`（Python 3 直接 `super()`）调用父类被重写的方法，避免重写构造函数时漏掉父类初始化。

## 关键参数 / 易错点
- **MRO 顺序**：多个父类同名方法，左边/前面的覆盖后面的；顺序不对会调到错的方法。新式类可用 `类.__mro__` 查看查找顺序。
- **`__init__` 重写必调 `super().__init__()`**：否则父类初始化没跑，访问父类属性报错。
- **菱形继承（钻石继承）**：新式类里若基类被多次出现，会在继承结构中形成「基类重复」，需要正确的 MRO 来解决（书里专门讲「继承的问题」）。
- 经典类已过时，强烈推荐新式类；但注意两者 MRO 差异。

## 类比（帮助理解）
- 像「电动自行车继承自行车」：多了电池和电机（特化），但「蹬」的方法直接沿用（泛化），不用重写一遍蹬车逻辑。
- 像生物族谱：技工「是一个」人，车「是一个」交通工具——从子类往祖先画一条「是一个」的线。
- 多重继承像「同时继承爸妈的技能」：但爸妈都会的技能（同名方法）得按约定顺序决定听谁的。

## 设计时怎么用（反推思维）
> 做「智能小车运动控制系统」时，我会反推「哪些行为相似、哪些不同」：把 `Motor`（属性 `speed`，方法 `set_speed/stop`）作为父类；`Forward(Motor)`、`Rotate(Motor)` 做子类，各自重写 `move()`，主循环写 `for m in modes: m.move()` 即利用多态与继承去重。一句话：**先找名词（候选类）与动词（候选方法），让相似类用继承去重，别用大字典硬扛所有状态**。

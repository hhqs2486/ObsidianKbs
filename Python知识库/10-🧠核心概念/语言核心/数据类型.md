# 数据类型

## 一句话定义
> 数据类型是“值的种类 + 能对这些值做的操作”的组合；Python 内置的核心数据类型是**数字、字符串、序列（列表/元组）、映射（字典）、集合**，它们构成了所有程序的原材料。

## 它解决什么问题 / 为什么存在
- 程序要处理数据，必须先把“原材料”分门别类：哪些能改、哪些不能改、用编号取还是用名字取。书的思路：先讲“数和表达式”（算术），再讲“序列”（列表/元组），再讲“字符串”，最后讲“映射”（字典，按名字而非编号取）。
- 不同场景要不同的容器：需要“可改的序列”用列表，需要“不可改的键”用元组，需要“按名字查值”用字典，需要“去重/集合运算”用 set。

## 核心原理（大二能懂的水平）
- **序列（列表、元组、字符串）**：元素带编号（索引从 0 开始，负数从末尾数）。通用操作：索引、切片 `a[1:5:2]`、相加、相乘、`in` 成员检查、`len/min/max`。
  - **列表 list**：可变的序列，Python 的“主力”。方法 `append/extend/insert/pop/remove/sort/reverse`（注意 `sort` 就地改、返回 None）。
  - **元组 tuple**：不可变序列，写 `42,` 才是单元素元组。用作字典键、集合成员；有些内置函数返回元组。
- **映射（字典 dict）**：Python 唯一内置映射，键→值。键必须是不可变类型（数、字符串、元组）。`d[k]=v` 自动建键，`k in d` 查的是键不是值。`get` 取不到返回 None 不报错；`items/keys/values` 返回“视图”（实时反映原字典）。
- **字符串 str**：字符组成的不可变序列。格式化 `format` / `format_map`（字典驱动模板，如 HTML）。
- **数字**：整数 `//` 整除（向下圆整）、`%` 求余、`**` 乘方、`0.5` 是 float。

## 关键参数 / 易错点
- **切片边界**：`a[1:5]` 含 1 不含 5；`a[-3:]` 取末尾三个；步长为负时第一个索引必须比第二个大，否则为空。
- **`sort` 返回 None**：`y = x.sort()` 会得到 `y is None`，正确做法是 `y = sorted(x)` 或先 `x.copy()` 再 sort。
- **`list` 复制 vs 关联**：`b = a` 只是多一个名字指向同一列表；`b = a.copy()` 或 `b = a[:]` 才是真副本。
- **字典 `get` vs `[]`**：`d['name']` 取不到键直接 `KeyError`；`d.get('name')` 安全返回 None。
- **浅拷贝陷阱**：`copy.copy` 只复制外层，内层可变对象仍共享（书里 `machines` 例子）；要完全独立用 `copy.deepcopy`。
- **集合不能含可变元素**，也不能直接作字典键；需要时用 `frozenset`。

## 类比（帮助理解）
- 序列像一排带编号的储物柜（0 号、1 号…），元组是“焊死的柜子”（不能改），列表是“可重新摆件的柜子”。
- 字典像真实世界的通讯录：你按“名字”（键）翻到“电话”（值），而不是数第几行。
- `deepcopy` vs `copy`：copy 像复印了一层文件夹，里面的子文件夹还是同一份；deepcopy 是把所有层都重新印了一份。

## 设计时怎么用（反推思维）
> 做 XX 系统时，我会用它能解决 YY：
> 做「学生考勤系统」时，我会反推数据形态来选类型——**每条记录用 dict**（键 `'学号'/'姓名'/'状态'` 让按名字查考勤 O(1) 而非遍历）；**全班记录用 list**（要增删、要排序）；**学号集合用 set**（去重、判断“哪些人既迟到又缺作业”用交集 `&`）；**固定配置如 `(波特率, 数据位)` 用 tuple**（不可改、还能当字典键）。一句话：先想“我怎么取数据”，再选容器，而不是上来就 list 一把梭。

## 典型应用 / 我在哪见过
- 书里电话簿用 dict；日期打印用列表+切片；垃圾邮件过滤用 `in` 成员检查字符串。
- `set` 求并集/交集（`|`、`&`）、`heapq` 优先队列、`deque` 双端队列（见[[标准库]]）。

# 标准库

## 一句话定义
> 标准库是「Python 安装包自带的、开箱即用的模块集合」——无需 `pip install`，`import` 就能用。它把操作系统接口、数据结构、文本/时间/随机/正则等常用能力都备好了，是“电池已 included”的那块电池。

## 它解决什么问题 / 为什么存在
- 书里 10 章：“安装 Python 后，你就免费获得了大量很有用的模块”。自己造轮子（解析命令行、读文件路径、生成随机数）既慢又易错，标准库提供经过检验的实现。
- 它让你专注业务逻辑：要时间用 `time`、要操作系统交互用 `os`、要命令行参数用 `sys`、要持久化用 `shelve/json`，不用从头写。

## 核心原理（大二能懂的水平）
- **`sys`**：和解释器最亲。`sys.argv` 是命令行参数列表（`argv[0]` 是脚本名）；`sys.path` 是模块搜索路径；`sys.exit()` 退出程序；`sys.stdin/stdout/stderr` 是三个标准流（见[[文件IO]]）；`sys.platform` 平台标识。
- **`os`**：操作系统接口。`os.environ` 环境变量映射；`os.system(命令)` 跑外部程序；`os.sep/os.linesep` 路径/行分隔符；`os.path` 提供跨平台路径拼接 `join`、拆分 `split`。Windows 启动程序用 `os.startfile`。
- **`fileinput`**：轻松迭代“多个文件中的所有行”，`for line in fileinput.input(['a.txt','b.txt'])`；`inplace=True` 可就地改文件（危险，先测好）。常与[[文件IO]]配合。
- **集合类数据结构**：
  - `set`（内置，不是模块）：去重、成员检查、`|` 并集 `&` 交集 `-` 差集 `^` 对称差；不能含可变元素，需要时用 `frozenset`。
  - `heapq`：堆/优先队列，`heappush/heappop` 取最小，`nlargest/nsmallest` 取前 N，比排序快。
  - `collections.deque`：双端队列，两端 `append/popleft` 都 O(1)，还能 `rotate` 旋转；`collections` 还有 `Counter` 等。
- **`time`**：获取/格式化时间。`time()` 当前秒数、`sleep(秒)` 休眠、`localtime/mktime/strptime/asctime`。还有 `datetime`（更直观的日期对象）、`timeit`（测代码耗时）。
- **`random`**：伪随机。`random()` 0~1、`randrange` 随机整数、`choice` 随机选、`shuffle` 打乱、`sample` 无放回抽样；加密级随机用 `os.urandom`。
- **`shelve` / `json`**：持久化。`shelve.open` 像字典一样存（键须字符串），底层是文件；`json` 存成别的语言也能读的文本格式。注意 `shelve` 的坑：改嵌套对象要先取副本再存回（或 `writeback=True`）。
- **`re`**：正则表达式。`.compile` 预编译、`search` 找子串、`match` 从头匹配、`findall` 列全部、`sub` 替换；`group()` 取编组；贪婪 vs 非贪婪（`+?`）。
- **其他值得一提**：`argparse`（命令行界面）、`csv`（表格）、`datetime`、`logging`（日志）、`itertools`（迭代器工具）、`statistics`（统计）、`functools`（含 `reduce`）。

## 关键参数 / 易错点
- **`sys.argv[0]` 是脚本名**：取用户参数要从 `argv[1:]` 开始。
- **`os.system` 跨平台坑**：Windows 路径反斜杠、空格要引号；优先 `os.startfile`（Win）或 `webbrowser.open`（开网址）。
- **`shelve` 改嵌套不生效**：`s['x'].append('d')` 不会自动存，要 `temp=s['x']; temp.append('d'); s['x']=temp`。
- **`re` 元字符要转义**：`.` 匹配任意字符，要字面点得 `\.` 或用原始串 `r'python\.org'`。
- **`heapq` 必须用它的函数建堆**：普通列表直接 `heappush` 才行，不能随便对普通 list 当堆用。
- **`random` 是伪随机**：加密用途用 `os.urandom` / `random.SystemRandom`。

## 类比（帮助理解）
- 标准库像「买电钻送的工具箱」：电钻本体是 Python 语法，箱子里的螺丝刀(os)、卷尺(time)、扳手(random)、万用表(sys) 不用另买，随取随用。
- `heapq` 像「自动排队机」：永远能最快拿出当前最小号，不用每次全队排序。
- `shelve` 像「带抽屉的文件柜」：你当字典用，关柜门（close）数据才真正存进磁盘。

## 设计时怎么用（反推思维）
> 做 XX 系统时，我会用它能解决 YY：
> 做「课程签到统计小工具」时，我会反推“现成能力别自己写”：读多个签到表用 `fileinput` 一行行过；用 `set` 算“全勤名单”（每天集合求交集 `&`）；用 `collections.Counter` 数每人签到次数；用 `random.sample` 抽幸运儿；用 `json` 把结果存成前端也能读的档案；时间显示用 `time.strftime`。一句话：**动手前先查标准库有没有现成的——`import` 一个模块往往比自己写 50 行更稳更快**（配合[[模块与包]]的导入机制）。

## 典型应用 / 我在哪见过

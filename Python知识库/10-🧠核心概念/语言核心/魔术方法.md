# 魔术方法

## 一句话定义
> 魔术方法（magic method / 特殊方法，special method）是名字以**双下划线开头和结尾**（如 `__init__`、`__str__`、`__len__`）的方法，Python 在背后「隐式」调用它们来支撑内建语法与行为。

## 它解决什么问题 / 为什么存在
- 没有魔术方法，你的类就无法用 `len()`、`print()`、`+`、`for` 这些「内建语法糖」直接操作，必须暴露一堆 `get_xxx()`。
- 魔术方法让你的自定义类「表现得像 Python 内建类型」，从而融入语言生态（书里称「定制类，模拟 Python 类型」）。

## 核心原理（大二能懂的水平）
- 所有「名字开始和结束都有两个下划线」的方法都是特殊方法。常见：`__init__`（实例创建后自动执行，类似构造器但不创建对象本身）、`__str__`（print/str 时调用）、`__repr__`（交互式回显）、`__len__`（len()）、`__add__`/`__sub__`/`__mul__`（运算符，见 [[运算符重载]]）、`__getitem__`/`__setitem__`（索引/切片，见 [[迭代器与生成器]]）。
- 默认情况下很多特殊方法有内建实现；定义/覆盖它们即可定制行为。例如覆盖 `__init__()` 可初始化实例状态。
- 注意 `__init__` 不是真正的构造器——它不「创建」对象，对象已由 `__new__` 造好，`__init__` 只做初始化。`__new__` 可定制对象创建（如让自定义类表现得像 float）。
- 用 `dir(对象)` 可查看对象拥有哪些特殊方法（如复数 `x.__class__`、`__add__`、`__getattribute__` 等），`__dict__` 在部分内建类型中不存在。

## 关键参数 / 易错点
- **`__init__` 不是构造器**：它只初始化，真正创建对象是 `__new__`；覆盖 `__init__` 不需手动调父类默认版本，但要保证父类初始化逻辑被执行（配合 `super()`）。
- 实现 `__setattr__` 要小心无限递归：`self.name = x` 内部会再次触发 `__setattr__`，需用 `object.__setattr__(self, ...)` 绕开。
- 一个类只要定义了 `__nonzero__`（Py2，Py3 为 `__bool__`）或 `__len__` 且值为 0，在布尔上下文里就是 False。
- 魔术方法「不该」被你直接调用（如不要写 `obj.__str__()`，而是 `str(obj)`）——让 Python 去隐式调。

## 类比（帮助理解）
- 像家电的「标准插口」：厂商按统一规格做好插座（魔术方法），你插上就能用（print/len/for），不用关心内部电路。
- 像餐厅的「后厨暗号」：你只说「来份牛排」（语法），后厨按暗号（`__xxx__`）自动出餐，你从不直接喊暗号。

## 设计时怎么用（反推思维）
> 做「向量 / 矩阵类」时，我会用 **魔术方法** 解决「希望 `v1 + v2`、`len(v)`、`print(v)`、`for x in v` 都能像内建类型一样直接用」的问题——实现 `__add__`/`__len__`/`__str__`/`__iter__`，让自定义类无缝融入 Python 语法，调用方写起来毫无违和感。

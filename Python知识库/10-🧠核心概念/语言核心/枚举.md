# 枚举 (enumerate)

## 一句话定义
> `enumerate(可迭代对象, start=0)` 是 Python 内置函数，把一个序列「包装」成能产生 `(下标, 元素)` 元组的迭代器，让你在 `for` 循环里同时拿到「位置」和「值」。

## 它解决什么问题 / 为什么存在
遍历列表时经常既要用元素、又要用它的序号（比如给 DNA 碱基标位置、给表格标行号）。老写法是手动维护一个 `i = 0` 计数器、每次循环 `i += 1`，既啰嗦又易错（漏加、加错位置）。`enumerate` 把「计数 + 取值」合成一步，代码更短、更安全。

## 核心原理（大二能懂的水平）
- `enumerate(seq)` 返回一个迭代器；每次 `next()` 吐出 `(index, value)`，其中 `index` 从 0 开始（可用 `start=` 改起点）。
- 底层等价于「边走边记序号」：`for i, item in enumerate(seq):` 就是自动帮你做 `i` 的自增。
- 它是惰性（lazy）的：不预先生成所有元组，随取随造，省内存。

## 关键参数 / 易错点
- 第二参数 `start` 设的是「起始序号」，不是「从哪个下标切」：`enumerate(seq, 1)` 让序号从 1 开始，但仍从第一个元素起取。
- `enumerate` 返回的是迭代器，只能消费一次；想多次使用要先 `list()` 转成列表。
- 需要同时拿「键和值」的字典遍历用 `d.items()`；`enumerate` 只给「序号和元素」，对 dict 遍历得到的是 0,1,2 而非键。

## 类比（帮助理解）
像图书馆给书架贴编号：你一本本拿书（元素），同时自动贴 0、1、2… 的标签（序号），不用自己拿纸笔数到第几本。

## 设计时怎么用（反推思维）
> 做「需要行号/位置标记」的批处理（读文件逐行带行号、统计序列中每个元素的位置、构建下标到值的映射）时，我会直接用 `for i, x in enumerate(seq):`，不手写计数器，减少越界和漏加错误。

## 典型应用 / 我在哪见过
- 原书第 6 章分析 DNA：用 `for index, base in enumerate(dna):` 同时拿到碱基和它在线段中的位置。
- 多项式类 `__call__` 里 `for i, c in enumerate(self.coeff):` 取系数及其幂次。
- 逐行读文件时 `for lineno, line in enumerate(f, 1):` 带 1 起始行号。

# 字符串

## 一句话定义
> 字符串是不可变的 Unicode 字符序列，是 Python 处理文本的核心对象——从一行日志到一份 JSON 都是它。

## 它解决什么问题 / 为什么存在
- 统一文本表示（默认就是 Unicode，天然支持中文等多语言）。
- 提供一套丰富的文本处理方法：切分、去空白、查找、格式化。

## 核心原理（大二能懂的水平）
- **不可变**：字符串一旦创建就不能改某个字符（`s[0] = 'x'` 会报错）。任何「修改」都返回一个新的字符串对象。
- 字面量写法：`'单引号'`、`"双引号"`、`'''三引号'''`（可跨行，常作文档字符串）。
- 序列操作：索引 `s[0]`、分片 `s[1:3]`、拼接 `s1 + s2`、重复 `s*3`、`len(s)`、`s in t`。
- 常用方法：`split()`、`strip()`、`upper()/lower()`、`replace()`、`find()`、`startswith()`。
- 格式化三件套：`%` 占位符、`str.format()`、以及最推荐的 **f-string**（`f"{name} = {val}"`）。
- 模式匹配：`re` 模块做正则。

## 关键参数 / 易错点
- **不可变**是最大坑：循环里用 `s = s + x` 反复拼接会不断生成新对象，效率低；大量拼接应收集到 [[列表]] 再 `"".join()`。
- 转义：`\n` `\t` `\\`；想原样就写原始串 `r"C:\new"`。
- 分片步长 `s[::-1]` 可反转。
- 3.X 里 `str` 就是 Unicode，`bytes` 才是原始字节，两者要 `encode/decode` 互转。

## 类比（帮助理解）
- 字符串像刻在石头上的字：要改一个字，只能另找一块石头重刻（生成新对象），原石不变。

## 设计时怎么用（反推思维）
> 解析日志/报文时，先用 `split/strip` 切出字段，再用 f-string 拼回输出。需要频繁修改的文本（如逐行累积）先放列表，最后 join，别在循环里 `+` 字符串。

## 典型应用 / 我在哪见过
- 日志、配置、URL、SQL 拼接（注意注入）、JSON（配合 [[字典]]）。
- 模板渲染（见 Web 的 Jinja2，底层也是字符串）。

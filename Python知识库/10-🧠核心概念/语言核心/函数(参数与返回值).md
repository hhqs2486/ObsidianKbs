# 函数(参数与返回值)

## 一句话定义
> 函数用 `def` 把一段可复用逻辑封装起来；调用时**参数按对象引用传递**（赋值绑定），`return` 把结果对象交回调用者。

## 它解决什么问题 / 为什么存在
- 把大问题拆成小函数，代码可复用、可测试、可读性高。
- 提供抽象：调用者只关心「喂什么、得什么」，不关心内部实现。

## 核心原理（大二能懂的水平）
- 定义：`def name(arg1, arg2, ...): ... return value`。`def` 本身是语句，运行后创建函数对象并绑定到名字。
- **参数传递 = 赋值（对象引用）**：形参名被绑定到传入的对象（见 [[变量与名字绑定]]）。所以可变对象在函数内被原地改，外部也看得到。
- 参数形态：位置参数、默认参数 `def f(a, b=1)`、关键字参数 `f(b=2, a=1)`、收集任意位置 `*args`（变元组）、收集任意关键字 `**kwargs`（变字典）。
- `return` 可返回任意对象，省略则返回 `None`；可返回多个值（本质是打包成 [[元组]]）。
- **多态**：Python 函数不限制参数类型，靠对象接口而非类型判断来工作，更灵活。

## 关键参数 / 易错点
- **可变默认参数陷阱**：`def f(x=[]): x.append(1); return x` —— 默认列表在多次调用间被**共享**，会越积越多。正确写法：`def f(x=None): x = x or []`。
- 传入可变对象（列表/字典）并在函数内原地修改，会**副作用**到外部——有时需要、有时是 bug，要清醒。
- `return` 省略或缺省 → 返回 `None`，别误以为有值。
- 参数顺序必须：位置 → 默认 → `*args` → 关键字 → `**kwargs`。

## 类比（帮助理解）
- 工厂：原料（参数）送进去，产品（return）出来。原料送的是「样品的引用」不是副本——工厂改了样品本身，你手里的同一个样品也变了。

## 设计时怎么用（反推思维）
> 写对外 API 时，默认参数用 `None` 作哨兵再在内部初始化，避免共享可变状态；函数应「对接口编程」而非「对类型判断」，保留多态优势。需要保留跨调用状态时，用 [[闭包]] 的 nonlocal 或类。

## 典型应用 / 我在哪见过
- `intersect`、`union` 等工具函数；`*args/**kwargs` 在装饰器和转发里极常用。
- 与 [[作用域与命名空间(LEGB)]] 紧密耦合：函数内赋值默认是局部名。

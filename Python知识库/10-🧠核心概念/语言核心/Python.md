# Python

## 一句话定义
> Python 是一种**面向对象、解释型、动态语义**的高级编程语言：它知道如何不妨碍你写程序，让你用清晰易懂的代码实现所需功能。

## 它解决什么问题 / 为什么存在
- 要让计算机做事，必须告诉它详尽的、它能听懂的步骤（算法）。C/C++ 这类编译型语言速度快，但写起来啰嗦、门槛高；Python 用简洁的语法让你专注“做什么”而非“怎么管内存/类型”，大幅节省编程时间。
- 书里原话：Python 是一种“知道如何不妨碍你编写程序的编程语言”。它适合系统管理、脚本、教学（NASA、Google、工业光魔都用），也适合从零入门。

## 核心原理（大二能懂的水平）
- **解释型**：代码不被直接编译成机器码，而是由「解释器」逐行翻译成机器能懂的指令并立即执行。所以你能打开交互式解释器 `>>>` 边写边跑（REPL）。
- **动态语义**：变量不需要预先声明类型，名字只是“指向值的标签”；同一个名字可以先后指向数字、字符串、列表。
- **面向对象**：一切皆对象，连函数、模块、数字都是对象，统一用“对象+方法”的模型思考。
- 运行方式两种：交互式解释器（练手）、把代码写进 `.py` 文件用 `python xxx.py` 运行（交付）。

## 关键参数 / 易错点
- **Python 3 与 Python 2 不兼容**：书上强调整除 `1/2` 在 Py3 得 `0.5`（float），Py2 得 `0`（int）。现在一律用 Py3。
- 解释器报 `SyntaxError: invalid syntax` 多半是中文标点、少了冒号、或把 `=` 当 `==` 用了。
- 速度不如 C/C++，但“编程时间”远少于 C/C++；性能热点可用 C 扩展（见[[标准库]]/扩展机制）补。
- 一行就是一条语句，行尾一般不用分号（加了也不报错，但社区不这么写）。

## 类比（帮助理解）
- C 程序像“拿着剃刀在刚打过蜡的地板上劲舞”（书上引言引用的吐槽）——步步惊心；Python 像开自动挡车，你只管说目的地，变速箱（解释器）帮你换挡。
- 解释器 `>>>` 是“进入黑客殿堂的大门”，是你控制计算机的第一步。

## 设计时怎么用（反推思维）
> 做 XX 系统时，我会用它能解决 YY：
> 做「课程实验采集系统」时，我会用 Python 作为**胶水语言 + 快速原型层**——先用它把“读传感器→滤波→画曲线→存 CSV”整条链路在脚本里跑通验证算法（反推：先用最少代码确认需求可行），再把实时性要求高的滤波内核用 C 重写、用 Python 调用。选 Python 不是因为它快，而是因为它让“从需求到可运行 demo”的链路最短。

## 典型应用 / 我在哪见过
- 系统管理脚本、文本/日志处理、爬虫、Web 后端、数据科学、教学入门。
- 书里 10 个后续项目：聊天服务器、P2P 文件共享、GUI 小游戏等，全用 Python 标准库拼出来。

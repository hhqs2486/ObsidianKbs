# 列表

## 一句话定义
> 列表（list）是有序、可变、可嵌套的序列容器，用方括号 `[]` 表示，是 Python 里最常用、最通用的「装东西的抽屉柜」。

## 它解决什么问题 / 为什么存在
- 需要保序、还能随时增删改一组元素时，列表是首选。
- 嵌套列表可表达矩阵、表格等二维数据。

## 核心原理（大二能懂的水平）
- 字面量：`[1, 2, 3]`；空列表 `[]` 或 `list()`。
- 序列操作齐全：索引、分片、拼接、`len()`、成员测试 `in`。
- 可变专属方法：`append()`、`extend()`、`insert()`、`pop()`（按索引删并返回）、`remove()`（按值删）、`sort()`、`reverse()`。
- 嵌套：`M = [[1,2,3],[4,5,6],[7,8,9]]` 可表示 3×3 矩阵。
- 常与 [[推导式]] 搭配生成新列表。

## 关键参数 / 易错点
- **共享引用**：`L2 = L1` 让两个名字指向同一个列表，改一个另一个也变。要独立副本用 `L2 = L1[:]` 或 `list(L1)` 或 `copy.deepcopy()`（含嵌套时）。
- **边界检查**：索引越界会 `IndexError`，不像 C 会静默越界。
- 排序：`sort()` 原地改、`sorted()` 返回新列表；可传 `key=` 自定义排序依据。
- 别把列表当函数默认参数（见 [[函数(参数与返回值)]] 的可变默认参数陷阱）。

## 类比（帮助理解）
- 一列带编号的抽屉：能往里塞、抽出来、调换位置，编号（索引）始终跟着位置走。

## 设计时怎么用（反推思维）
> 循环里收集结果时，先 `result = []` 再 `append`，或一步到位用 [[推导式]]。做矩阵/棋盘时，用嵌套列表；需要「改一处全同步」就放心共享，需要独立副本就显式拷贝。

## 典型应用 / 我在哪见过
- 批量数据累加、队列雏形、`*args` 展开。
- 与 [[元组]] [[字典]] 互相转换：`dict(zip(keys, vals))`、`list(d.items())`。

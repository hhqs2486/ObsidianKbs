# 文件IO

## 一句话定义
> 文件 IO 就是“程序用 `open` 打开磁盘上的文件，通过文件对象 `read/write` 读写内容，用完 `close` 关掉”的机制；它是 Python 程序**与外部世界（磁盘/管道/标准流）做持久化交换**的主通道。

## 它解决什么问题 / 为什么存在
- 前面程序的数据都在内存里，一关就没了。文件让数据**永久存储**，也能读取别的程序产出的数据（书里 11 章开头：让程序“与更大的外部世界交互”）。
- 除了普通文件，`sys.stdin/stdout/stderr` 也是“类文件对象”，支持 `read`/`write`，于是管道 `cat file | python script | sort` 才成立（书里 somescript.py 从 stdin 读、往 stdout 写）。

## 核心原理（大二能懂的水平）
- **`open(name, mode)`**：返回文件对象。模式 `'r'` 读（默认）、`'w'` 写（清空重建）、`'x'` 独占写（已存在报错）、`'a'` 追加、`'b'` 二进制、`'t'` 文本（默认）、`'+'` 读写。默认 `'rt'`：按 UTF-8 编解码、自动转换换行符。二进制 `'rb'` 关掉这些转换，用于图片/声音。
- **写**：`f.write(字符串)` 返回写入字符数；`writelines(列表)` 把一串字符串写进去（**不自动加换行**，得自己加）。
- **读**：`f.read(n)` 读 n 个字符（不传 n 读全部）；`f.readline()` 读一行；`f.readlines()` 读全部行返回列表。
- **`close()`**：务必关！写入的数据可能被 Python 缓冲，没关就崩溃会丢数据；读文件不关通常无害但关了更稳（释放句柄、避免锁定）。
- **`with` 语句（最佳实践）**：`with open('x') as f: ...` 离开代码块自动关文件，**哪怕出异常也关**。底层用“上下文管理器”（`__enter__`/`__exit__`）。比手写 `try/finally` 简洁。
- **迭代文件**：文件本身可迭代，`for line in f:` 逐行读（最常见）；大文件用 `fileinput` 做“延迟行迭代”省内存；`list(open('x'))` 等同 `readlines()`。
- **随机存取**（了解）：`seek(偏移, whence)` 跳到指定位置，`tell()` 返回当前位置；`'r+'` 不截断、`'w+'` 会截断。
- **管道/标准流**：`sys.stdin.read()` 读管道输入；`print(..., file=f)` 可写到文件。

## 关键参数 / 易错点
- **`'w'` 会清空原文件**：想保留原内容用 `'a'` 追加，别手滑用 `'w'` 把日志写没了。
- **忘了 `close`**：尤其写入文件，崩溃时数据可能没落盘。永远优先用 `with`。
- **`writelines` 不加换行**：要自己每行末尾带 `\n`。
- **文本 vs 二进制**：读图片/音频用 `'rb'`，否则自动转码会破坏数据。
- **编码不一致**：默认 UTF-8，跨平台/老文件可能乱码，必要时 `open(name, encoding='gbk', errors='ignore')`。
- **`read(n)` 到末尾返回空串 `''`**：这正是循环读字符/行的终止条件。

## 类比（帮助理解）
- 文件像「笔记本」：`open` 是翻开指定页，`write` 往当前位置写、`read` 从当前位置读，`seek` 是“直接翻到第几页”，`close` 是合上本子（不合并可能写的字还在肚子里没印上去）。
- `with` 像「借书登记」：借的时候登记，还的时候（离开块）系统自动帮你还，丢不了。

## 设计时怎么用（反推思维）
> 做 XX 系统时，我会用它能解决 YY：
> 做「实验数据记录仪」时，我会反推“数据从哪来、到哪去、崩了怎么办”：传感器采样结果用 `with open('log.csv','a',encoding='utf-8') as f:` 持续追加（用 `'a'` 不丢历史）；读取历史用 `for line in open(...)` 逐行过（大文件不爆内存）；处理多天日志用 `fileinput.input(['d1.csv','d2.csv'])` 当一个流遍历；整个采集循环外再套[[异常处理]]，异常时 `with` 仍保证文件关好。一句话：**先定“读还是写、追加还是覆盖、文本还是二进制”→ 选对 mode，再用 `with` 兜底关闭，别裸开裸写**。

## 典型应用 / 我在哪见过
- 书里：写/读 somefile.txt、管道单词计数 somescript.py、`fileinput` 给代码加行号、模板系统读多个文件。

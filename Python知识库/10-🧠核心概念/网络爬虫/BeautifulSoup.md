# BeautifulSoup

## 一句话定义
> 把 HTML/XML 文档解析成可遍历节点树的 Python 库，用于"温和地"按结构提取数据。

## 它解决什么问题 / 为什么存在
- 用正则表达式硬抠 HTML 容易因标签嵌套/换行变化而失效；BeautifulSoup 把文档建成 DOM 树，提供节点选择器、嵌套选择、关联选择，按结构稳稳取字段。

## 核心原理（大二能懂的水平）
- 解析器（推荐 `lxml`，快且容错好；也可用内置 `html.parser`）把字符串建成节点树。
- 用 tag 名或 CSS 选择器定位节点：`find` / `find_all` 或 `select`；`.string`/`.text` 取文本，`attrs` 取属性。

## 关键参数 / 易错点
- 解析器选择：用 `lxml` 需先安装，`BeautifulSoup(html, "lxml")`。
- `.string`（单节点文本）与 `.text`（所有后代文本拼接）含义不同。
- 多层嵌套提取可能返回 `None`，直接 `.strip()` 会崩，务必先判空。
- 编码：传入 `from_encoding` 或事后修正，避免乱码。

## 类比（帮助理解）
- 像在网页里用"查找 + 高亮"框选你要的那些格子，而不是用剪刀乱剪。

## 设计时怎么用（反推思维）
> 拿到 requests 返回的静态 HTML 后，若字段是按标签结构排布的，我就用 BeautifulSoup；规则简单用 CSS 选择器(`select`)，层级复杂用嵌套 `find`；若是 JS 动态渲染的页面，先渲染再交给它解析。

## 典型应用 / 我在哪见过
- 新闻正文/列表提取、商品价格抓取；常配合 requests 组成轻量爬虫。

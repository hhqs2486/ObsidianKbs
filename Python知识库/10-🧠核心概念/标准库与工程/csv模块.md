# csv 模块

## 一句话定义
> csv 模块读写「逗号分隔值」表格文件：`reader`/`writer` 处理行，`DictReader`/`DictWriter` 按列名访问。

## 它解决什么问题 / 为什么存在
- 手写 `split(',')` 处理 CSV 会被引号、逗号内嵌、换行搞崩。
- csv 模块按 RFC 正确解析各种边界情况。

## 核心原理（大二能懂的水平）
- **类比**：CSV 像「表格的纯文本照片」。csv 模块是「懂表格规则的翻译」，知道引号里的内容算一个格子，不会把里面的逗号切断。
- `csv.reader(f)` 逐行给列表；`csv.DictReader(f)` 给 `{列名:值}` 字典。

## 关键参数 / 易错点
- 用 `DictReader` 最舒服：行变字典，按 `row['name']` 取。
- `delimiter=','` 可改分隔符（如 `\t` 的 TSV）。
- 务必用 `newline='' ` 打开文件：`open('a.csv', newline='')`，否则 Windows 上会多出空行。
- 易错：忘记 `newline=''` 导致写出的 CSV 每行间有空行。

## 设计时怎么用（反推思维）
> 做「表格导入导出/数据清洗中间格式」时，我会用 csv.DictReader/Writer，正确处理引号与编码。

## 典型应用 / 我在哪见过
- 从 Excel 导出的数据做批处理。
- 爬虫结果存 CSV 供分析。

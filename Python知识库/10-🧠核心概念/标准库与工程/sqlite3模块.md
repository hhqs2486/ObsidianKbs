# sqlite3 模块

## 一句话定义
> sqlite3 是「内置的轻量数据库」：一个文件就是一个关系型数据库，支持 SQL，零配置、无需起服务。

## 它解决什么问题 / 为什么存在
- 小项目不想装 MySQL/PostgreSQL；又比纯文本/JSON 需要结构化查询、事务、索引。
- sqlite 单文件、进程内，开箱即用，适合本地应用/嵌入式/原型。

## 核心原理（大二能懂的水平）
- **类比**：JSON 文件像「一沓便签」，翻找麻烦；sqlite 像「带目录的账本」，用 SQL 一句话查到某行，还能保证「要么全记要么不记」（事务）。
- `conn = sqlite3.connect('app.db')`；`conn.execute('CREATE TABLE ...')`；`cur.fetchall()` 取结果。

## 关键参数 / 易错点
- 用参数化查询防注入：`cur.execute('SELECT * FROM t WHERE id=?', (uid,))`，别拼字符串。
- 写完要 `conn.commit()` 才真正落盘；建议 `with conn:` 自动提交/回滚。
- `row_factory = sqlite3.Row` 可用列名取值。
- 易错：忘记 commit 数据丢了；多线程共用同一连接会报错（每线程独立连接或用 `check_same_thread=False`）。

## 设计时怎么用（反推思维）
> 做「桌面工具/爬虫去重/本地缓存」时，我会用 sqlite3 存结构化数据，靠索引和事务保证可靠，省去外部数据库。

## 典型应用 / 我在哪见过
- 爬虫已抓取 URL 去重表。
- 单机记账/笔记应用存储。

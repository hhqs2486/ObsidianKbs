# itertools 模块

## 一句话定义
> itertools 提供「高效迭代器工具」：组合、排列、切片、分组、无限序列等，全部惰性（用完才算，省内存）。

## 它解决什么问题 / 为什么存在
- 手写嵌套循环做排列组合又慢又易错；大序列 `list` 全展开会爆内存。
- itertools 用 C 实现、返回迭代器，按需生成，既快又省。

## 核心原理（大二能懂的水平）
- **类比**：迭代器像「自来水龙头」，itertools 是各种「分流/混合/定量阀门」——`chain` 把几根管子接成一根，`islice` 只取前 N 滴，`combinations` 自动把所有搭配吐出来。不用先存满一缸水。
- `chain(a,b)` 拼接；`combinations('ABC',2)` → AB,AC,BC；`count()` 无限数数；`islice(it, 5)` 取前 5 个。

## 关键参数 / 易错点
- 常用：`chain`/`islice`/`takewhile`/`cycle`/`repeat`/`product`/`permutations`/`combinations`/`groupby`。
- `groupby` 要求**先按同一键排序**，否则分组会碎；易错点。
- 返回的是迭代器，只能遍历一次；要复用先 `list()`。
- 与 [[推导式]]、[[迭代器与生成器]] 互补：itertools 偏「组合/无限」，推导式偏「逐元素变换」。

## 设计时怎么用（反推思维）
> 做「全组合测试/分页切片/流式处理大文件」时，我会用 itertools 的惰性迭代器，避免把数据一次性装进内存。

## 典型应用 / 我在哪见过
- 参数网格搜索：`product(*param_lists)`。
- 大文件按块处理：`islice`。

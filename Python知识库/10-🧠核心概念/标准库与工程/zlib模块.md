# zlib 模块

## 一句话定义
> zlib 提供「zlib/gzip 兼容的数据压缩」：对字节流做压缩解压，是 gzip、PNG、ZIP 等格式的底层算法。

## 它解决什么问题 / 为什么存在
- 网络传输/存储想省空间，要对原始字节压缩。
- zlib 是 DEFLATE 算法的标准实现，跨语言跨平台通用。

## 核心原理（大二能懂的水平）
- **类比**：zlib 像「真空压缩袋」——把蓬松的衣服（数据）压扁省空间，需要时再吹开还原。压完还是「袋」（字节），要按 gzip 格式封口得靠 [[gzip模块]]。
- `zlib.compress(data)` / `zlib.decompress(cdata)` 对 bytes 操作；`compressobj` 支持流式。

## 关键参数 / 易错点
- 操作对象是 **bytes**，字符串要先 `encode()`。
- `compresslevel` 1–9 平衡速度与压缩率，默认 6。
- `decompress` 要求数据完整，损坏会抛异常。
- 易错：只产原始压缩字节，没有文件头；想要 `.gz` 文件用 gzip 模块。

## 设计时怎么用（反推思维）
> 做「网络协议体压缩/内存中大数据缓存」时，我会用 zlib 压 bytes 省带宽；落盘成 .gz 则用 [[gzip模块]]。

## 典型应用 / 我在哪见过
- HTTP body 的 deflate 压缩。
- 自定义二进制格式内嵌压缩块。

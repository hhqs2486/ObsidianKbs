# 碰撞检测

## 一句话定义
> 碰撞检测（Collision Detection）是判断游戏里两个物体（矩形 / 圆 / 像素）是否发生重叠或接触的计算，是触发"命中、拾取、受伤"等事件的前提。

## 它解决什么问题 / 为什么存在
- 玩家子弹打中敌人、角色踩到陷阱、吃到道具、撞到墙——这些"接触/相交"事件，都必须先知道"两个东西碰上了没有"，否则游戏逻辑无从触发。

## 核心原理（大二能懂的水平）
- 类比两个人是不是撞上了：最粗的办法看两人"外接矩形"有没有重叠；更精细的看具体身体（像素）或看圆心距离（圆形）。
- pygame 用 `Rect` 的 `colliderect()`（矩形相交）、`collidepoint()`（点是否在内），以及 `sprite.groupcollide()` / `spritecollide()` 做精灵间批量检测；圆形碰撞则比较两圆心距离是否小于半径之和。

## 关键参数 / 易错点
- **误用中心点距离代替包围盒**：只用中心距离容易"明明没挨着却判命中"或反之，矩形物体优先用 AABB（轴对齐包围盒）。
- **碰撞后没"收尾"**：命中后没标记删除/扣血，导致**同一帧内反复触发**（比如一颗子弹一帧扣光血条）。
- **圆形物体用矩形检测**：误差大，圆该用向量距离判定。
- 复杂场景先做粗略（大矩形）过滤，再做精细检测，省性能。

## 类比（帮助理解）
- 就像两个快递盒并排，先看外箱有没有叠在一起（AABB），要特别精准再看里面东西有没有碰到（像素级）。

## 设计时怎么用（反推思维）
> 做"命中 / 拾取 / 边界"判定时，先用 **AABB 矩形检测**（最简单最快）；手感不够再上升级到圆形或像素级。批量精灵碰撞直接用 `pygame.sprite` 提供的碰撞函数，别自己写双重循环。

## 典型应用 / 我在哪见过
- 飞机大战子弹打敌机、平台跳跃踩怪、球类游戏边界反弹、消除类游戏的方块相邻判断。

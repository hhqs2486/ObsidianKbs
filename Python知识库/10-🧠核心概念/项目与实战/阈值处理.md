# 阈值处理

## 一句话定义
阈值处理 = 按像素亮度设「门槛」，把图变成只有黑/白（或几级）的二值图，是分割前景背景最基础的手段。

## 它解决什么问题 / 为什么存在
彩色/灰度图信息太多，很多任务只需「是/否」两类（如把字从背景里抠出），阈值一步到位。

## 核心原理（大二能懂的水平）
`cv2.threshold(src, thresh, maxval, type)`：
- `THRESH_BINARY` 二值化、`THRESH_BINARY_INV` 反二值
- `THRESH_TRUNC` 截断（超阈值截到阈值）、`THRESH_TOZERO` / `TOZERO_INV` 低阈值归零
- **自适应阈值** `cv2.adaptiveThreshold`：不同区域用不同门槛，适合光照不均的图
- **Otsu** `cv2.THRESH_OTSU`：自动算最佳门槛（直方图双峰时好用，调用时 thresh 参数传 0）

## 关键参数 / 易错点
- 输入要先转**灰度**。
- Otsu 时把 thresh 参数设为 0 让其自动算。
- 自适应阈值只能用于单通道灰度，块大小须为奇数。

## 类比（帮助理解）
像「及格线」——高于线记满分、低于记零分，把连续成绩变成分及格/不及格两类。

## 设计时怎么用（反推思维）
> 文档扫描、车牌/文字提取、简单物体分割时先试阈值；光照不匀用自适应或 Otsu。

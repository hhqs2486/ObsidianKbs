# OpenGL

## 一句话定义
OpenGL 是跨平台的 2D/3D 图形渲染 API，用「图形管线」把顶点数据变成屏幕上的像素；本书用 PyOpenGL + 现代（着色器）管线做粒子、体渲染等实时 3D。

## 它解决什么问题 / 为什么存在
想要实时 3D（游戏、仿真、科学可视化）就得直接和 GPU 打交道；OpenGL 提供一套标准化的「喂顶点 → 着色 → 光栅化」流程，跨平台且贴近硬件。

## 核心原理（大二能懂的水平）
- **老式 vs 现代**：老式固定管线（`glBegin/glEnd`）已淘汰；现代用**着色器(Shader)** 管线。
- **现代管线**：顶点数据放**顶点缓冲区(VBO/VAO)**；**着色器**（GLSL 语言，顶点着色器 + 片段着色器）决定每个顶点/像素怎么变；**几何图元**（点/线/三角形）是基本绘制单位；**三维变换**（模型/视图/投影矩阵，MVP）把 3D 坐标投到 2D 屏；**纹理贴图**把图贴到表面。
- Python 用 PyOpenGL 调，配合 GLUT/GLFW 建窗口、处理回调。

## 关键参数 / 易错点
- 现代 OpenGL 必须写着色器，门槛比老式高。
- 坐标要乘 MVP 矩阵才能正确投影。
- 深度测试要开 `glEnable(GL_DEPTH_TEST)`，否则前后遮挡错乱。
- VBO/VAO 管理易漏（忘绑定/忘更新），导致黑屏或错位。

## 类比（帮助理解）
把 GPU 想成「超级工厂」，OpenGL 是「给工厂下指令的协议」：你提供顶点（原材料）和着色器（加工配方），工厂批量生产像素。

## 设计时怎么用（反推思维）
> 做任何实时 3D（游戏、仿真、科学可视化、数据三维呈现）时，OpenGL 是底层标准；高层引擎底层也是它。先用 [[NumPy]] 准备顶点数组，写顶点/片段着色器，放进 [[游戏循环]] 每帧渲染。

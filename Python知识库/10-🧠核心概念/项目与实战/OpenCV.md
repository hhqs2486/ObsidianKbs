# OpenCV

## 一句话定义
OpenCV（Open Source Computer Vision Library）是开源**计算机视觉库**，提供数千个图像/视频处理函数；Python 用 `cv2` 模块调用，底层是 C/C++，所以快。

## 它解决什么问题 / 为什么存在
- 图像处理、视频分析、识别这类事如果从头写（读解码、滤波、找边、匹配）极其繁琐且慢。
- OpenCV 把业界常用算法都实现好，一行 `cv2.xxx` 调用即可，覆盖采集→预处理→特征→识别→输出全链路。

## 核心原理（大二能懂的水平）
- **图像就是多维数组**：彩色图是形状为 (高, 宽, 3) 的 [[NumPy]] 数组 `ndarray`，每个元素是 0–255 的像素值；灰度图是 (高, 宽) 的单通道数组。OpenCV 几乎所有函数本质是对这个数组做运算。
- 读 `cv2.imread` → 数组；显示 `cv2.imshow`（内部起一个 HighGUI 窗口，要配合 `cv2.waitKey` + `cv2.destroyAllWindows`）；保存 `cv2.imwrite`。
- 视频 = 连续帧（见 [[视频处理]]），逐帧就是逐张图。
- 进阶算法（边缘、轮廓、分割、匹配等）建立在这之上（见 [[边缘检测]] [[图像轮廓]] [[图像分割]] [[模板匹配]]）。

## 关键参数 / 易错点
- **通道顺序是 BGR 不是 RGB**！`cv2.imread` 读进来是 BGR，和 matplotlib 的 RGB 相反，混用会颜色错乱（显示前 `cv2.cvtColor(img, cv2.COLOR_BGR2RGB)`）。
- `cv2.waitKey(0)` 必须跟在 `imshow` 后，否则窗口一闪而过；结束要 `destroyAllWindows`。
- 很多函数原地修改或返回新图，注意看文档（如 `cv2.flip` 返回新图，`cv2.drawContours` 可原地改）。
- 贡献库（SIFT/SURF 等）在 `opencv-contrib-python` 包里，要单独装（见 [[包管理pip]]）。

## 类比（帮助理解）
把图想成「装满数字的方格纸」，OpenCV 是「一大盒预写好的表格处理函数」——求和、滤波、找边框，直接调用，不用自己造轮子。

## 设计时怎么用（反推思维）
> 做「图像/视频相关的任何事」（相机预览、文档扫描、人脸识别、缺陷检测、AR）时，第一选择就是 OpenCV + [[NumPy]]；重活交给它，自己只写流程控制。

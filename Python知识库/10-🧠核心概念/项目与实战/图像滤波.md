# 图像滤波

## 一句话定义
图像滤波（平滑/模糊）= 用「核（小窗口）」在图上滑动做卷积，把噪点/细节磨平，是降噪和预处理标配。

## 它解决什么问题 / 为什么存在
拍照有噪点、边缘太毛糙，直接做边缘检测会被噪声带偏；先平滑能让后续算法更稳。

## 核心原理（大二能懂的水平）
- **均值滤波** `cv2.blur` / **方框滤波** `cv2.boxFilter`：邻域平均，简单但糊。
- **高斯滤波** `cv2.GaussianBlur`：按高斯权重平均，保边更好，最常用（边缘检测前首选）。
- **中值滤波** `cv2.medianBlur`：取邻域中值，去「椒盐噪点」极好且不糊边。
- **双边滤波** `cv2.bilateralFilter`：考虑空间 + 像素差，保边同时去噪，慢但效果好。
- `cv2.filter2D`：自定义 2D 卷积（自己给核）。

## 关键参数 / 易错点
- 中值滤波 `ksize` 必须是奇数；高斯核大小也是奇数。
- 双边滤波参数（d, sigmaColor, sigmaSpace）要调，慢。
- 核越大越糊、细节丢得越多，按需取小。

## 类比（帮助理解）
像「用湿毛笔把铅笔稿晕开」：均值是最笨的抹，高斯是按远近轻重抹，中值是「取中间值不被个别黑点带偏」，双边是「只晕开颜色相近处、保留轮廓」。

## 设计时怎么用（反推思维）
> 任何 [[边缘检测]] / [[图像分割]] 前先高斯或中值平滑；去椒盐噪点选中值；要保边去噪选双边。

# 视频处理

## 一句话定义
视频处理 = 用 [[OpenCV]] 从摄像头/视频文件「一帧帧」读图、处理、再写成新视频，把图像算法用到动态画面上。

## 它解决什么问题 / 为什么存在
图像算法只能看单张，视频是连续帧；用 VideoCapture / VideoWriter 把「逐帧循环」封装好，就能做实时检测/录制。

## 核心原理（大二能懂的水平）
- `cv2.VideoCapture(设备号 或 文件路径)`：`.read()` 返回 `(成功?, 帧)`；摄像头用设备号（0 默认）。
- `cv2.VideoWriter(文件名, fourcc, fps, 尺寸)`：用 `.write(帧)` 存；`fourcc` 决定编码（如 `cv2.VideoWriter_fourcc(*'XVID')`）。
- 主循环：`while cap.isOpened(): ret,frame=cap.read(); ...; cv2.imshow; if cv2.waitKey(1)&0xFF==27: break`，结束 `release()`。
- 每帧都是一张图，可直接套用 [[图像处理基础]] 里的所有算法。

## 关键参数 / 易错点
- `VideoWriter` 的尺寸必须和帧一致（用 `frame.shape[:2][::-1]` 取 宽,高）。
- fourcc 编码不支持会写不出文件。
- `waitKey(1)` 控制播放速度，没它窗口卡死；`&0xFF==27` 是 Esc 退出。

## 类比（帮助理解）
视频就是「一叠连续照片」：VideoCapture 是「自动翻页器」，每翻一页你把图像算法跑一遍再收进新相册（VideoWriter）。

## 设计时怎么用（反推思维）
> 实时人脸/物体检测、运动追踪、视频特效、监控录制；把单图算法升级成「实时流水线」的入口。

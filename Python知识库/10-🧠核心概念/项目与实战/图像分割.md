# 图像分割

## 一句话定义
图像分割 = 把图「切」成不同区域/物体，让每个像素属于「前景/背景/某物体」，是「从图到语义」的关键一步。

## 它解决什么问题 / 为什么存在
前面都是点/线/轮廓，分割要回答「哪些像素是一整块物体」，才能进一步识别、计数、测量。

## 核心原理（大二能懂的水平）
- **分水岭算法** `cv2.watershed`：把灰度图当「地形」，从种子点「淹水」漫延分水岭；常用于粘连物体（如一堆硬币）分离。步骤：[[阈值处理]] → 开运算去噪 → 确定前景/背景 → 距离变换找种子 → `connectedComponents` → `watershed`。
- **交互式前景提取** `cv2.grabCut`：标出「确定前景/背景」矩形，迭代建模把前景抠出（抠图/去背景）。

## 关键参数 / 易错点
- 分水岭对噪声和初始标记敏感，标记错会过分割；通常配合 [[形态学操作]] 与距离变换。
- grabCut 矩形要包住目标，迭代次数影响质量。

## 类比（帮助理解）
分水岭像「往有山有谷的地图灌水，水从各山谷涨起、在山脊相遇处画出分水岭 = 物体边界」；grabCut 像「你框出主体，算法帮你把背景擦掉」。

## 设计时怎么用（反推思维）
> 医疗影像器官分割、产品缺陷区域、抠图换背景、计数前把粘连物体切开。

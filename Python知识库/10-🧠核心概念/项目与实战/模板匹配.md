# 模板匹配

## 一句话定义
模板匹配 = 在一张大图里「滑动」一张小模板图，逐位置算相似度，找到最像的位置（如在一堆零件里找某个商标）。

## 它解决什么问题 / 为什么存在
已知「要找的东西长啥样（模板）」，要从大图里定位它，无需训练模型，直接比像素。

## 核心原理（大二能懂的水平）
- `cv2.matchTemplate(img, tmpl, method)`：method 有 `TM_SQDIFF`(越小越像)、`TM_CCORR`、`TM_CCOEFF`(越大越像) 等；返回结果图（每像素是相似度）。
- 用 `cv2.minMaxLoc` 取最值位置得到匹配点。
- **多模板匹配**：设阈值，把结果图里高于/低于阈值的都圈出来（避免只取一个峰值漏掉多个目标）。

## 关键参数 / 易错点
- 模板必须比原图小。
- 对尺度/旋转敏感：模板和原图里目标大小要一致，否则匹配差——尺度变化要用 [[图像金字塔]] 或多尺度。
- `TM_SQDIFF` 类取最小值，`TM_CCOEFF` 类取最大值，别取反。

## 类比（帮助理解）
像「在一张寻宝图里拿小碎片比对，看哪块最吻合」。

## 设计时怎么用（反推思维）
> 固定物体定位（Logo 检测、元件对齐、游戏 UI 元素识别）；不变尺度时用，变尺度配金字塔/特征匹配。

- 相关：[[图像轮廓]]（匹配到后可用轮廓量尺寸）

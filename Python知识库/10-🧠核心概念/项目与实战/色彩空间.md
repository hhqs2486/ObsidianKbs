# 色彩空间

## 一句话定义
色彩空间 = 用不同「坐标轴」表示同一个颜色；[[OpenCV]] 用 `cv2.cvtColor` 在它们之间转换，常用 GRAY / HSV / HLS，处理「某种颜色」时比 RGB 方便得多。

## 它解决什么问题 / 为什么存在
RGB 里「红色」的数值范围分散、难用一个阈值抓住；HSV 把「色相 / 饱和度 / 明度」分开，找某种颜色（肤色、交通灯、绿幕）只需限定 H 区间，稳定又直观。

## 核心原理（大二能懂的水平）
- **GRAY 灰度**：单通道 0–255，省计算，很多算法只需亮度。
- **HSV**：H(色相 0–179) S(饱和度) V(明度)；「标记红色」→ 限定 H 在红区范围，再用掩模抠出。
- **HLS / XYZ / YCrCb / CIELab / CIELuv / Bayer**：各有用途（YCrCb 常用于肤色，Lab 感知均匀适合色差）。
- **alpha 通道**：透明通道，图像合成时用。
- 配合 `cv2.inRange(lower, upper)` 生成二值掩模最常用。

## 关键参数 / 易错点
- **OpenCV 的 H 范围是 0–179**（不是 0–360）。
- 转完 HSV 再用 `inRange` 取掩模；`inRange` 的上下限是两个数组。
- 不同色彩空间互转要 `cv2.cvtColor`，不能直接当索引。

## 类比（帮助理解）
同一种「位置」可以用「经纬度」或「街区门牌」描述；HSV 就像「按颜色种类 + 浓淡 + 明暗」描述，比 RGB 三个混在一起好抓。

## 设计时怎么用（反推思维）
> 做「按颜色抠图/追踪」（绿幕、交通灯、肤色检测、颜色分类）时，先 `cvtColor` 到 HSV 再 `inRange` 生成掩模。

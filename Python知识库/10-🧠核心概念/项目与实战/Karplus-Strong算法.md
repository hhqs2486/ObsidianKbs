# Karplus-Strong算法

## 一句话定义
Karplus-Strong 算法 = 用「噪声脉冲 + 延迟反馈（环形缓冲区）+ 低通平均」物理地合成拨弦/钟等带泛音的乐音，极简却像真。

## 它解决什么问题 / 为什么存在
合成逼真的弦乐音色通常要复杂建模；K-S 用很短的代码（一个环形缓冲 + 平均反馈）就能出拨弦声。

## 核心原理（大二能懂的水平）
- 用 `collections.deque` 做**环形缓冲区**存最近 N 个样本（N = 采样率 / 频率，决定音高）。
- 每步：取缓冲头部样本，和下一个样本**平均（低通）** 后写回尾部，输出即弦音。
- 可接小调五声音阶奏旋律；用 [[标准库]] 的 `wave` 模块写 WAV，用 [[pygame]] 播放。

## 关键参数 / 易错点
- 缓冲区长度决定音高（N = 采样率 / f）。
- 只延迟不平均会尖锐刺耳，低通平均是关键。
- 采样率要对，否则音高/速度错。

## 类比（帮助理解）
像「弹一下琴弦后，弦的震动不断回荡并被一点点削弱变圆润」——环形缓冲就是那根不断回荡的弦。

## 设计时怎么用（反推思维）
> 程序化音效、简易合成器、游戏音效生成、音乐可视化输入时，用 K-S 几行代码出逼真拨弦声。

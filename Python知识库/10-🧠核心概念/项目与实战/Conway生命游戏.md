# Conway生命游戏

## 一句话定义
Conway 生命游戏 = 在网格上按两条极简规则迭代，涌现出滑翔机、振荡器等复杂生命现象，是元胞自动机(Cellular Automaton)的经典范例。

## 它解决什么问题 / 为什么存在
用极简确定性规则展示「简单规则如何产生复杂图案」，是离散动力学/涌现的入门模型，也是练 Python 网格/邻域运算的好题。

## 核心原理（大二能懂的水平）
网格每格「活/死」，下一代规则：
- 活细胞：邻居 <2（孤）或 >3（挤）则死；=2 或 3 则活。
- 死细胞：邻居恰 =3 则复活。
实现：用二维数组表示网格，算 8 邻域计数，处理边界条件（环面/固定），迭代更新。

## 关键参数 / 易错点
- 必须用「下一帧」**新数组**算，别原地覆盖导致规则错乱。
- 边界条件影响图案（环面边界图案能穿屏）。
- 用 [[NumPy]] 可向量化更新提速。

## 类比（帮助理解）
像「培养皿里的细菌」——每格只看周围 8 格的生死来定自己下一代，整体却长出会移动的花纹。

## 设计时怎么用（反推思维）
> 练网格/邻域算法、讲「涌现」概念、做屏保/生成艺术；思想可延伸到物理/生态/交通仿真。

# Qt控件

## 一句话定义
Qt 控件（Widget，Windows 里叫「控件 / 子窗口」）是界面上那些可见、可交互的屏幕元素——按钮、标签、输入框、滑块、表格、菜单等，在 Qt 里统统是 QWidget 及其子类的对象。

## 它解决什么问题 / 为什么存在
- 写 GUI 就是堆「用户能看、能点的零件」。Qt 把每种常见零件都做成现成的类，你拿来即用，不必从像素级自己画。
- 所有控件共享同一套基类 QWidget，因此有一致的显示、事件、布局、父子关系机制，能统一被 [[界面布局]] 管理、被 [[信号与槽]] 驱动、跑在 [[Qt事件循环]] 里。

## 核心原理（大二能懂的水平）
- **继承链**：所有控件最终继承自 `QWidget`，而 QWidget 继承自 `QObject`（所以控件天生支持信号槽）。
- **任何控件都能当顶级窗口**：哪怕是一个 QLabel、QPushButton，单独 `show()` 也会自动带标题栏变成窗口；不想带标题栏就改 window flags（如 splash 屏）。
- **父子关系**：创建控件时传 `parent`，父销毁子跟着销毁，且子控件显示在父内——这是 Qt 管理内存和层级的基石。
- 常用内置控件（本书出现的）：
  - `QLabel`：显示文本/图片，可接受 HTML（如红色大字）。
  - `QPushButton` / `QDialogButtonBox`：按钮。
  - `QLineEdit`：单行输入；`QTextBrowser`：只读多行富文本。
  - `QDial` / `QSpinBox` / `QSlider`：取值控件，都有 `valueChanged` 信号。
  - `QTabWidget`：选项卡分页容器；`QStackedWidget`：叠放只显一页。
  - 容器类：`QWidget`（普通容器）、`QMainWindow`（主窗口：菜单栏/工具栏/状态栏/中心部件）、`QDialog`（对话框）。
- 控件还能组合 / 子类化出「自定义控件」（本书第 11 章：用样式表美化、组合已有控件、子类化 QWidget 画分数滑块等）。

## 关键参数 / 易错点
- **不加到布局就不当布局管**：见 [[界面布局]]——控件要 `addWidget` 进布局并 `setLayout` 才会随窗口缩放。
- **改界面只能在主线程**：子线程直接操作控件会崩，必须经信号回主线程（见 [[并发编程]]、[[Qt事件循环]]）。
- 控件文本默认是 Unicode（QString），和 Python `str` 自动转换，但涉及编码读写时要注意（见本书第 1 章 Bytestrings/Unicode/QString 与第 8 章）。
- 父子关系搞错会导致控件不显示或内存泄漏；用布局时通常把控件 parent 设成承载它的窗口即可。
- 想深度定制外观用 Qt Style Sheets（类似 CSS），想改行为就子类化重写事件/方法。

## 类比（帮助理解）
控件像乐高积木：每块（按钮、标签、滑块）都是 QWidget 这一种「万能积木」的具体形状。它们能拼在一起（父子/布局），能互相发信号「打招呼」（信号槽），整盒积木由事件循环这个「手」不停摆弄。你想要独特形状，就把现成积木改一改或粘一粘（自定义控件）。

## 设计时怎么用（反推思维）
> 接到界面需求，我会先列出需要的「零件清单」（要输入用 QLineEdit、要选数用 QSpinBox、要展示用 QLabel/表格…），确认它们的信号，再决定用 QDialog 还是 QMainWindow 承载、用哪种布局摆放——先选对控件，再谈逻辑。

# 栈

## 一句话定义
> 栈是一种**后进先出（LIFO）**的线性结构，只允许在一端压入（push）和弹出（pop）。

## 它解决什么问题 / 为什么存在
- 需要「最新优先处理 / 可回溯」的场景：函数调用、撤销、括号匹配、深度优先搜索。

## 核心原理（大二能懂的水平）
- 操作：push（压栈）、pop（弹出栈顶）、peek（看栈顶不弹出）。
- Python 直接用 [[列表]] 的 `append()` 压、`pop()` 弹即可模拟。
- 函数调用本身就用「调用栈」；[[递归]] 靠栈保存每层现场。

## 关键参数 / 易错点
- 空栈 `pop()` 会 `IndexError`，操作前先判空。
- 别把栈和 [[队列]] 混用：栈是 LIFO、队列是 FIFO。
- 用 [[列表]] 模拟时 `pop()` 默认尾端 O(1)，但 `pop(0)` 是 O(n)，**切勿拿它当栈用**。

## 类比（帮助理解）
- 一摞盘子：只能从最上面放和取，最底下的最后才动。

## 设计时怎么用（反推思维）
> 括号匹配、撤销(undo)、DFS（见 [[图]]）、表达式求值都用栈；想要更语义化可用 [[类与对象]] 包一层封装。

## 典型应用 / 我在哪见过
- 调用栈、浏览器后退、编辑器撤销、DFS、中缀转后缀。

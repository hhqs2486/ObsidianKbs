# 哈希表

## 一句话定义
> 哈希表用「哈希函数」把键映射到数组下标，实现平均 O(1) 的增、删、查，是 [[字典]] 的底层实现。

## 它解决什么问题 / 为什么存在
- 极速地「按键查找」，是缓存、索引、计数、去重的基础。

## 核心原理（大二能懂的水平）
- 三件套：哈希函数 + 数组 + 冲突处理（链地址 / 开放寻址）。
- 理想情况查找 O(1)；冲突严重时退化到 O(n)。
- Python 的 [[字典]] 与 [[集合]] 本质就是哈希表；键必须是「可哈希」的不可变类型。

## 关键参数 / 易错点
- **键必须不可变**：[[列表]] 不能做键，[[元组]] 可以；自定义对象要正确实现 `__hash__`/`__eq__`。
- 冲突多会退化成 O(n)；哈希随机化使遍历顺序不稳定，别依赖顺序。
- 遍历 [[字典]] 时不能增删其大小，否则报错。

## 类比（帮助理解）
- 存物柜：给你名字算出一个柜号直接打开，不用挨个柜子找。

## 设计时怎么用（反推思维）
> 需要 O(1) 查找 / 去重 / 计数，直接用 [[字典]]/[[集合]]；做缓存、索引、频率统计首选；注意键的可哈希性。

## 典型应用 / 我在哪见过
- 缓存、索引、词频统计、集合运算、Rabin-Karp 滚动哈希（见 [[字符串算法]]）。

# 原型模式

## 一句话定义
> 原型模式通过「克隆一个已有实例」来创建新对象，而不是每次都从头 new——特别适合**构造成本高**或**需要以当前状态为模板**的场景。

## 它解决什么问题 / 为什么存在
- 有些对象构造很贵（要读配置、连数据库、初始化大量字段）。反复 new 很浪费；直接复制一个已初始化好的「原型」更快。
- 也用于「基于某个当前状态派生新对象」：复制后改几处即可。

## 核心原理（大二能懂的水平）
- Python 天然支持：`copy.copy`（浅拷贝）与 `copy.deepcopy`（深拷贝）。
- 也可让类实现 `clone()` 方法返回自身的副本，统一接口。
- 注意浅/深拷贝差异：浅拷贝共享嵌套对象，改一处会互相影响。

## 关键参数 / 易错点
- 默认 `copy.copy` 是浅拷贝，嵌套结构要用 `deepcopy`，否则「克隆体」和原体会意外共享内部数据。
- 含文件句柄、锁、线程等不可克隆资源时，原型模式要谨慎。

## 类比（帮助理解）
- 像用一份填好的模板（原型）复印后改几个空：比每次从空白表重新填快得多。

## 设计时怎么用（反推思维）
> 做「游戏里批量生成同款怪物，但每只初始属性略有差异」时，我会用 **原型模式**：先造好一只标准怪物当原型，`deepcopy` 后微调血量/位置，省去重复初始化开销。

## 典型应用 / 我在哪见过
- 配置对象的复制、GUI 组件的模板克隆、`copy` 模块本身。

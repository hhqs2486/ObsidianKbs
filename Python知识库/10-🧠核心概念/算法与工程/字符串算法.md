# 字符串算法

## 一句话定义
> 字符串算法是针对「文本串」的高效处理技术，包括模式匹配、前缀结构、相似度计算等。

## 它解决什么问题 / 为什么存在
- 文本搜索、生物序列比对、输入校验、敏感词过滤都需要比「逐字符硬扫」更快的方法。

## 核心原理（大二能懂的水平）
- 模式匹配：朴素 O(nm)、KMP（利用失配信息做到 O(n+m)）、Rabin-Karp（借 [[哈希表]]/滚动哈希）。
- 前缀结构：Trie（前缀树）、后缀数组，用于前缀查询、去重、后缀问题。
- 相似度：编辑距离（增删改最少步数）用 [[动态规划]]。
- Python 日常可用 `str` 方法与 [[正则表达式]] 解决大部分简单需求。

## 关键参数 / 易错点
- 朴素匹配在坏情况下 O(nm) 太慢，大文本要换算法或预建索引。
- KMP 的「失配/next 数组」易写错，是常见坑。
- 大文本反复用 `in` 扫描效率低，应考虑 [[哈希表]]/预处理。
- 注意 Unicode 与编码细节，不要假设「一个字符 = 一个字节」。

## 类比（帮助理解）
- 在长篇小说里找一句台词：一页页翻（朴素）很慢；先看目录/索引（预处理）就快很多。

## 设计时怎么用（反推思维）
> 单次小匹配直接用 `in`/内置方法；海量或高频匹配用 KMP 或预建索引；前缀查询用 Trie；相似度/对齐用 [[动态规划]]。

## 典型应用 / 我在哪见过
- 搜索引擎、 plagiarism 检测、基因比对、敏感词过滤、文件差异(diff)。

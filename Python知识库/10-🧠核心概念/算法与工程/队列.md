# 队列

## 一句话定义
> 队列是一种**先进先出（FIFO）**的线性结构，一端进（enqueue）、另一端出（dequeue）。

## 它解决什么问题 / 为什么存在
- 需要「按到达顺序公平处理」的场景：任务调度、缓冲、广度优先搜索。

## 核心原理（大二能懂的水平）
- 操作：enqueue（入队）、dequeue（出队）、front（看队首）。
- 用 [[列表]] + `pop(0)` 是 O(n)，高频场景应用 `collections.deque`（双端队列）做到 O(1)。
- BFS（见 [[图]]）天然用队列；带优先级的叫优先队列（见 [[堆]]）。

## 关键参数 / 易错点
- 用 [[列表]] 的 `pop(0)` 当队列会 O(n) 拖慢，应改用 `deque`。
- 空队列取元素会报错，操作前判空。
- 优先级队列不是普通 FIFO 队列——它按「优先级」而不是「到达顺序」出队。

## 类比（帮助理解）
- 食堂排队：先来的人先打饭，后来的排到队尾。

## 设计时怎么用（反推思维）
> 广度优先搜索、消息/任务调度、缓冲池都用队列；高频两端操作用 `deque`；需要「按重要程度」而非「先来后到」出队，用 [[堆]] 实现的优先队列。

## 典型应用 / 我在哪见过
- BFS、打印队列、线程池任务队列、层序遍历（见 [[二叉树]]）。

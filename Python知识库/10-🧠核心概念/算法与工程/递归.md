# 递归

## 一句话定义
> 递归是函数**直接或间接调用自身**来把大问题化为更小的同类问题，直到触达可直接解决的最小情形。

## 它解决什么问题 / 为什么存在
- 结构自相似的问题（树、分治、回溯、嵌套）用递归写最自然、最接近数学定义。

## 核心原理（大二能懂的水平）
- 三要素：**基准情形（base case）**、**递归情形**、**每步向基准收敛**。
- 每次调用都会把现场压进调用栈（与 [[栈]] 同源）；递归能改写成循环/[[迭代器与生成器]]。
- 示意（通用阶乘，非本书代码）：
  ```python
  def fac(n):
      if n <= 1:        # base case
          return 1
      return n * fac(n - 1)   # 向基准收敛
  ```

## 关键参数 / 易错点
- **缺基准情形** → 无限递归 → 栈溢出。
- **重复子问题** → 指数爆炸（如朴素斐波那契）；用 [[动态规划]]/记忆化（缓存）消除。
- **递归过深** → Python 默认约 1000 层就 `RecursionError`；尾递归 Python 不优化。
- 以为递归「不占内存」——其实每层栈帧都吃 [[空间复杂度]]。

## 类比（帮助理解）
- 俄罗斯套娃：打开一层，里面还有更小的同款，直到最小的那个（base case）停下。

## 设计时怎么用（反推思维）
> 写递归先定 base case 再写递推；子问题大量重叠就加 [[动态规划]]/记忆化；深度可能很大就改迭代或临时调高递归限制。

## 典型应用 / 我在哪见过
- 树/图遍历、[[分治算法]]、回溯、目录递归、表达式求值。

# 堆

## 一句话定义
> 堆是一种「父节点恒比子节点大/小」的**完全二叉树**，通常用数组（[[列表]]）实现，支持 O(log n) 取最值，是优先队列的底层。

## 它解决什么问题 / 为什么存在
- 需要频繁取最大/最小元素，或维护一个「随时能拿到最值」的集合。

## 核心原理（大二能懂的水平）
- 大顶堆 / 小顶堆：根分别是最大 / 最小。
- 插入、删除堆顶都 O(log n)；[[排序算法|堆排序]] 也是 O(n log n) 原地。
- Python `heapq` 模块实现的是**小顶堆**；`heapify` 能把列表原地调成合法堆。

## 关键参数 / 易错点
- `heapq` 默认小顶堆，要「最大」得取负或自定义包装。
- 必须先 `heapify` 才是合法堆，别直接当有序序列用。
- 堆只保证**堆顶**最值，不保证整体有序（区别于 [[二叉树]]/BST 的中序有序）。

## 类比（帮助理解）
- 公司里每个人只比直属上级弱，CEO 永远是最小的（小顶堆）；想找最小值直接看 CEO，不用翻全员名册。

## 设计时怎么用（反推思维）
> Top-K、定时任务调度、Dijkstra 最短路（见 [[图]]）都用堆；要全序遍历别用堆，用 [[排序算法]]/[[二叉树]]；高频入出用 `heapq`。

## 典型应用 / 我在哪见过
- 优先队列、Top-K、中位数维护、Dijkstra、堆排序。

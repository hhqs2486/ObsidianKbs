# 网络安全

## 一句话定义
> 网络安全（Network Security）是**保护网络上传输和存储的数据不被窃听、篡改、伪造**，以及保证通信双方确实是“对的人”。

## 它解决什么问题 / 为什么存在
- 网络是公开的“公路”，数据裸奔就会被截获/篡改。网络安全提供“加密隧道 + 身份核验 + 完整性校验”三件套。
- 本书大量用 Python 抓包、嗅探、伪造包（第 4、5、6 章），理解这些才能既会攻也会防。

## 核心原理（大二能懂的水平）
- 分层防护：链路层（ARP 欺骗防护）、网络层（IP 伪造识别）、传输层（TLS 加密）、应用层（[[认证授权]]、[[SQL注入]] 防护）。
- 嗅探 = 把网卡设为混杂模式，抓经过的所有包（像在广播喇叭旁竖起耳朵）；Python 用 `scapy` 就能构造/解析任意包。
- 机密性靠 [[加密与哈希]]，完整性靠消息认证码（MAC），真实性靠证书/签名。

## 关键参数 / 易错点
- 易错点：以为“用了 HTTPS 就绝对安全”——TLS 配置错（旧协议、弱套件）照样可被降级攻击。
- 易错点：明文传输密码、token 是头号错误；应走加密通道 + 不存明文。
- 易错点：自己造加密协议几乎必错，用成熟库（标准库/openssl）。

## 类比（帮助理解）
- 像寄信：明文=明信片谁都能看；加密=上了锁的信封；签名=防伪印章；证书=权威机构背书“这印章是真的”。

## 设计时怎么用（反推思维）
> 做客户端/服务端通信时，我会默认链路不可信：全程 TLS、敏感字段再叠加 [[加密与哈希]]、用 [[并发编程]] 处理高并发连接，并在入口挡住 [[SQL注入]]/[[XSS跨站脚本]] 这类应用层攻击。

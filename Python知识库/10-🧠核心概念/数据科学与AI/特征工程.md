# 特征工程

## 一句话定义
把原始数据转换成更适合模型学习的新特征的过程，是机器学习最关键的一步。

## 解决什么问题
原始数据往往不能直接喂给算法（尺度不一、缺失、噪声、冗余），需要整理成"好特征"。

## 核心原理（类比）
像做菜前洗切配料——同样的食材，切配得当才好吃。好的特征让简单模型也能表现好（常言"特征比算法更重要"）。

## 易错点 / 常见坑
- 标准化 / 归一化要在**训练集上 fit 再 transform 到测试集**，不能整体 fit（数据泄露）。
- 高相关 / 冗余特征可 [[降维PCA]]；类别变量要编码（独热）。
- 不同距离度量的算法（如 SVM、KNN）对特征尺度极敏感，必须标准化。

## 设计时怎么用（从需求反推）
1. 探索性分析（相关矩阵、散点图）。
2. 缺失值 / 异常值处理（[[数据清洗]]）。
3. 标准化 / 编码。
4. 必要时降维（[[降维PCA]]）或构造新特征。
5. 再训练模型。

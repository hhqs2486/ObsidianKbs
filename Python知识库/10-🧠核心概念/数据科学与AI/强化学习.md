# 强化学习

## 一句话定义
智能体通过与环境交互、以"奖励"为反馈来学习最优行动策略的机器学习范式。

## 解决什么问题
没有现成标签、只有"做得好 / 不好"的奖励时，如何让代理学会一连串决策（下棋、游戏、机器人控制）。

## 核心原理（类比）
像训练小狗：做对了给零食（正奖励）、做错了不给（负奖励），它慢慢学会"哪些动作能换来更多零食"。国际象棋每一步的环境状态对应不同奖励，目标是最大化长期总奖励。

## 易错点 / 常见坑
- 奖励信号稀疏 / 延迟时学习极慢，需"信用分配"（哪一步导致了最终胜负）。
- **探索与利用**的权衡：既要试新动作，又要利用已知好动作。
- 与 [[监督学习]] 不同，没有"标准答案"标签。

## 设计时怎么用（从需求反推）
- 适合序列决策 / 控制问题。
- 先定义状态、动作、奖励函数。
- 本书主要聚焦分类 / 回归 / 聚类，RL 为延伸方向（见 [[机器学习]]）。

# 过拟合

## 一句话定义
模型在**训练集**上表现极好，但泛化到新数据能力差（高方差）。

## 解决什么问题
防止模型"死记硬背"训练样本中的噪声，而非学到可推广的规律。

## 核心原理（类比）
像学生把习题答案背下来，考试换道题就不会——模型记住了噪声而非规律。表现为训练准确率高、验证准确率低，两者差距大。

## 易错点 / 常见坑
- 反复用测试集调参会让测试集"泄题"；应保留独立测试集、用验证集 / [[交叉验证]] 调参。
- 模型越复杂越易过拟合（深层网络、高阶多项式、深 [[决策树]]）。
- 数据少、噪声大时更易发生。

## 设计时怎么用（从需求反推）
- 用学习曲线 / 验证曲线诊断偏差-方差。
- 加 [[正则化深度学习]]（L1 / L2）、[[Dropout]]、提前停止。
- 增加数据、降低模型复杂度、或做 [[特征工程]] 中的特征选择 / [[降维PCA]]。

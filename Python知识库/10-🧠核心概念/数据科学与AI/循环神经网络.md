# 循环神经网络

## 一句话定义
> 循环神经网络（RNN）是带"隐藏状态"的神经网络：它把上一步的隐藏状态与当前输入一起算当前输出，从而让信息沿时间步流动，专门处理序列数据。

## 它解决什么问题 / 为什么存在
- 文本、语音、时序信号都是"有先后顺序"的数据。普通网络（[[多层感知机]]/[[卷积神经网络]]）假设输入相互独立，处理不了"第 t 个词依赖前面所有词"的情况。
- n 元语法为了记住长依赖要存指数级多的统计量；RNN 用一个固定大小的隐藏状态 Hₜ 滚动存储历史，参数数量不随时间步增长。

## 核心原理（大二能懂的水平）
- 核心公式：Hₜ = ϕ(Xₜ·Wₓₕ + Hₜ₋₁·Wₕₕ + bₕ)，Oₜ = Hₜ·Wₕq + b_q。Hₜ₋₁ 是上一时刻的隐藏状态，把它"循环"回来参与本步计算——这就是"循环"二字的来源。
- 隐藏状态捕捉"截至当前时间步的历史信息"，像网络的记忆。
- 训练用"通过时间反向传播（BPTT）"：把网络按时间步展开后做 [[反向传播]]。
- 经典问题：时间步多了梯度易衰减或爆炸；应对办法是梯度裁剪（clip gradient），以及改用门控结构 [[LSTM]] / GRU。

## 关键参数 / 易错点
- 隐藏单元数、时间步数（num_steps）、批量大小是常用超参数。
- 易错：RNN 梯度经长时间步连乘，容易出现梯度消失/爆炸（见 [[训练技巧]] 数值稳定性），普通 RNN 难捕捉长距离依赖。
- 易错：时序数据采样有"随机采样/相邻采样"之分，影响隐藏状态要不要跨小批量传递；相邻采样时需用 `detach()` 切断计算图以免梯度累积爆炸。
- 评价语言模型常用"困惑度（perplexity）"。

## 类比（帮助理解）
- 像边读句子边在草稿纸上记要点：每读一个新词，都把"之前的要点"和"当前词"合并，更新草稿（隐藏状态）；预测下一个词时，依据这份不断更新的草稿。

## 设计时怎么用（反推思维）
> 做"文本生成 / 机器翻译 / 语音识别 / 股票序列预测"等有时序依赖的任务时，我会用 [[循环神经网络]] 作序列建模骨干：输入是 `(批量, 时间步, 特征)` 的张量；若序列长、依赖跨度大，直接用 [[LSTM]]（或 GRU）门控结构替代普通 RNN，并配合梯度裁剪来稳定训练。

## 典型应用 / 我在哪见过
- 字符级语言模型写歌词、机器翻译的编码器/解码器、语音识别。
- 深度 RNN（多层）、双向 RNN（同时看前后文）。

# 回归

## 一句话定义
[[监督学习]]的一个分支，预测**连续的数值型**目标变量。

## 解决什么问题
预测房价、销售额、温度、股价等连续量，而非离散类别。

## 核心原理（类比）
根据"房间数"画一条最能代表整体趋势的直线——直线上下样本点的竖直距离（残差）之和最小，这条线就能用来预测新房间的价格。本质是拟合 `y = w·x + b`。
- 简单 / 多元线性回归：特征与目标的线性关系。
- 岭回归 / LASSO / 弹性网络：在最小二乘上加 L2 / L1 惩罚，防过拟合。
- 随机森林回归、多项式回归：处理非线性关系。

## 易错点 / 常见坑
- 线性回归假设**线性关系**，非线性关系需多项式特征、对数变换或树模型。
- **离群值**会严重拉偏最小二乘拟合（可用 RANSAC 稳健回归）。
- 看测试集的 R² / MSE 判断过拟合，不能只看训练拟合好坏。

## 设计时怎么用（从需求反推）
1. 目标为连续值 → 选回归。
2. 先画相关图 / 相关矩阵选特征。
3. 用岭回归 / LASSO / 弹性网络做 [[正则化深度学习|正则化]] 防过拟合。
4. 非线性用 [[随机森林]] 或多项式特征。

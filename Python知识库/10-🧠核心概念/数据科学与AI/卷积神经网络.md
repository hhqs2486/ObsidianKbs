# 卷积神经网络

## 一句话定义
> 卷积神经网络（CNN）是含"卷积层"的神经网络，用滑动的小窗口（卷积核）在图像等空间数据上提取局部特征，是计算机视觉的基石。

## 它解决什么问题 / 为什么存在
- 全连接层（如 [[多层感知机]]）处理图像有两个毛病：① 把像素拉平后，原来相邻的像素变远了，局部模式难捕捉；② 参数爆炸——1000×1000 彩色图接一层 256 输出的全连接就有约 3×10⁶×256 个权重，存不下也训不动。
- 卷积层靠"局部连接 + 权值共享"同时解决这两点：保留空间结构，且参数只跟卷积核大小有关，与输入尺寸无关。

## 核心原理（大二能懂的水平）
- 二维互相关：卷积核（filter）在输入上从左到右、从上到下滑动，窗口内元素与核按元素相乘再求和，得到特征图（feature map）。核的权重是学出来的（如边缘检测核 [1,-1] 能找出横向亮度突变）。
- 关键超参数：填充（padding，往四周补 0，常用来让输出与输入同尺寸）、步幅（stride，窗口每次滑动几格，>1 会缩小输出）、输入/输出通道数（channel，彩色图 RGB 是 3 通道；多输出通道让网络学多种特征）。
- 池化层（pooling）：对窗口取最大/平均，缓解对位置的过度敏感、降低分辨率（如 2×2 最大池化）。
- 1×1 卷积：只在通道维做加权组合，可当作"保持尺寸的全连接"，用来调整通道数、控制复杂度。
- 现代 CNN 套路：卷积块（卷积+激活+池化）堆叠提取特征，末尾展平接全连接分类。

## 关键参数 / 易错点
- 输出尺寸公式：(输入高 − 核高 + 填充 + 步幅) // 步幅（宽同理）。
- 易错：卷积核多用奇数（3/5/7），便于以中心元素对称填充；通道数要逐层想清楚（输入通道数必须与上层的输出通道数匹配）。
- 代表结构：LeNet、AlexNet、VGG（重复小块）、NiN（用 1×1 卷积替全连接）、GoogLeNet（Inception 并行多尺度）、ResNet（残差连接）、DenseNet；还有 [[正则化深度学习|批量归一化]] 稳定训练。

## 类比（帮助理解）
- 像用"放大镜 + 模板"扫图：模板（卷积核）是提前练好的"边缘/纹理探测器"，在同一个图的不同位置复用同一套模板——所以参数量小，且不管目标出现在图的左上还是右下都能认出来。

## 设计时怎么用（反推思维）
> 做"图像分类 / 目标检测 / 人脸识别"时，我一定用 [[卷积神经网络]] 作骨干：输入组织成 `(批量, 通道, 高, 宽)` 的张量，先堆几组"卷积+ReLU+池化"提取由浅到深的特征，再全局平均池化或展平接分类头；需要更深时上 ResNet 残差块防退化。只要数据带"空间局部性"就该想到 CNN。

## 典型应用 / 我在哪见过
- Fashion-MNIST / ImageNet 分类、车牌识别、医学影像。
- 也用于语音、推荐系统的局部模式提取。

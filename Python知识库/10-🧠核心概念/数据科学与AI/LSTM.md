# LSTM（长短期记忆网络）

## 一句话定义
LSTM 是一种给 [[循环神经网络]] 加了「记忆细胞 + 三道门」的变体，让网络能用一条贯穿时间线的「传送带」把信息长期保留下来，从而缓解长序列训练时梯度衰减、忘性大的问题。

## 它解决什么问题
普通 [[循环神经网络]] 在长句子、长时序上会「健忘」：随时间步增多，反向传播时梯度要么趋零（梯度衰减）、要么爆炸，导致模型学不会相距很远的两个词之间的依赖关系。LSTM 就是为了解决「长期依赖」这个痛点而设计的——它要让重要的信息能跨过很多步直接传到后面，无关信息则被及时忘掉。

## 核心原理（大二能懂）
把 RNN 里那个简单的隐藏状态拆成两部分：
- **记忆细胞（Cell, C）**：一条横贯时间步的「传送带」，信息能几乎不损失地从上一步流到下一步。
- **三道门**：每道门都是用 sigmoid 算出的 0~1 权重，决定多少信息通过。
  - **遗忘门 F**：决定记忆细胞里哪些旧信息该丢掉（`Ft = sigmoid(...)`）。
  - **输入门 I**：决定当前候选记忆里哪些新信息该写进去。
  - **输出门 O**：决定记忆细胞里哪些内容该暴露成当前隐藏状态。

关键公式（D2L 版）：
```
候选记忆  C̃t = tanh(Wc·[Ht-1, Xt] + bc)
遗忘门    Ft = sigmoid(Wf·[Ht-1, Xt] + bf)
输入门    It = sigmoid(Wi·[Ht-1, Xt] + bi)
新细胞    Ct = Ft ⊙ Ct-1 + It ⊙ C̃t      （⊙ 是逐元素乘）
输出门    Ot = sigmoid(Wo·[Ht-1, Xt] + bo)
隐藏状态  Ht = Ot ⊙ tanh(Ct)
```
因为 `Ct` 是用「加法」把旧记忆和候选记忆拼起来的，梯度可以沿着这条加法通路顺利回传，所以比普通 RNN 的连乘更不容易衰减。

## 关键参数与易错点
- **三道门的激活**：门用 sigmoid（输出 0~1 当开关），记忆候选用 tanh。别把门也写成 tanh。
- **隐状态维度 h**：决定每条门的参数规模，是主要调参项。
- **易错点**：LSTM 参数比普通 RNN 多约 4 倍（四组权重），训练和显存都更贵；不是「门越多越好」，短序列上普通 RNN/GRU 就够。
- **初始遗忘门偏置**：实践里常把 `bf` 初始化得偏大，让网络默认「多记住、少遗忘」，训练更稳。

## 类比
把 LSTM 想成一条带「分拣员」的传送带：遗忘门是「该扔掉哪些旧包裹」的质检员，输入门是「哪些新包裹值得上架」的收货员，输出门是「今天对外展示哪些库存」的窗口管理员。传送带（记忆细胞）保证包裹不会走着走着就丢了。

## 设计时怎么用（反推思维）
- 做**机器翻译 / 长文本摘要 / 语音识别**这类「前后文相距很远才有关系」的任务时，我会直接用 LSTM（或它的简化版 GRU），而不是裸 [[循环神经网络]]——因为这类任务天然要求长期记忆。
- 做**时序预测（股价、传感器）**时，如果历史窗口超过几十步，我会优先 LSTM，并通过门控缓解梯度衰减，避免模型只盯住最近几步。
- 选型时若序列很短、想省算力，我会先用 GRU；只有当长依赖明显、且 LSTM 效果更好时才坚持用 LSTM。
- 它通常作为 [[深度学习]] 序列模型的一个「积木」，上游接词嵌入、下游接全连接或 [[多层感知机]] 做分类。

## 典型应用
- 机器翻译（编码器-解码器都用 LSTM）
- 语音识别与合成
- 手写体识别、视频时序建模
- 长时间序列预测（电量、流量、气象）

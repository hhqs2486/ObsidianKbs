# 降维PCA

## 一句话定义
主成分分析（PCA）——一种**无监督线性变换**，把高维数据投影到保留最大方差的低维子空间。

## 解决什么问题
高维数据难算、难可视化、易过拟合（维数诅咒）；PCA 压缩维度、去噪、便于二维 / 三维展示。

## 核心原理（类比）
像把立体的影子投到墙上——虽然变扁了，但保留了最能区分物体的"最大变化方向"；第一主成分就是数据波动最大的方向，第二主成分与之正交且次大，依此类推。
- 步骤：标准化 → 协方差矩阵 → 特征值分解 → 取前 k 个特征向量构成投影矩阵 → 变换。
- 核 PCA（KPCA）用核技巧处理非线性降维。

## 易错点 / 常见坑
- PCA 是**无监督**的，不看标签（与有监督的 LDA 不同）；降维后解释性变差。
- 对尺度极敏感，必须先标准化（均值 0、方差 1）。
- 主成分是正交方向，不一定对应有物理意义的特征。

## 设计时怎么用（从需求反推）
- 预处理 / 可视化常用；选前 k 个主成分使累计解释方差足够（如 > 95%）。
- 高维先降维再 [[聚类]] 或 [[分类]]。
- 非线性数据用核 PCA。

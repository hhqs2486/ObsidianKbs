# 感知机

## 一句话定义
> 最简单的"人工神经元"：把若干输入加权求和，再过一个阈值函数，输出 0 或 1；是神经网络最基本的组成单元。

## 它解决什么问题 / 为什么存在
- 想用机器模拟"生物神经元收到多个信号、够强就放电"的行为，得到一个能做二分类的最小计算单元。
- 它证明了"可调权重的简单单元"能学会线性可分的判断（如"满足几条条件就判定为正类"）。

## 核心原理（大二能懂的水平）
- 计算：输出 = 阈值函数( w1·x1 + w2·x2 + … + wn·xn + b )，其中 w 是权重、b 是偏置。
- 阈值函数（阶跃函数）：求和结果 > 0 输出 1，否则输出 0，相当于在输入空间画了一条"直线"当分界线。
- 学习：拿 (输入, 正确标签) 样本，预测错了就按"误差"微调权重：w += 学习率 × 误差 × 输入。这和本书 1.2 那台"简单预测机"调斜率是同一思路。
- 局限：阶跃函数不连续、不可导，没法用 [[梯度下降]] 平滑调参；只能处理线性可分问题。

## 关键参数 / 易错点
- 权重 w、偏置 b 是学习对象；学习率控制每步改多大。
- 易错：以为一个感知机能解决一切分类——它只能画一条直线，遇到"异或(XOR)"这类线性不可分问题彻底无解。
- 易错：把"阈值/阶跃"当成现代网络的激活函数——现代常用连续可导的 [[激活函数]]（如 sigmoid）替代它，才能做深层训练。

## 类比（帮助理解）
- 像投票：每个输入是一位评委，权重是评委话语权；总票数过门槛(b)就通过(输出1)，否则不通过(输出0)。

## 设计时怎么用（反推思维）
> 当我需要"几个条件加权表决、输出是与否"的极简二分类器，且数据线性可分时，会先用单层感知机快速验证；一旦需求出现非线性边界（如两类交错成环形），立刻升级到带 [[激活函数]] 的多层 [[神经网络]]，而不是硬调一个感知机。

## 典型应用 / 我在哪见过
- 最早用于逻辑门学习（与、或、非）；作为理解 [[神经网络]] 的入门台阶。
- 本书 1.6 神经元——大自然的计算机器，从生物神经元讲到人工神经元，再引出可叠加成网络。

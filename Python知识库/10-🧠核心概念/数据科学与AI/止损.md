# 止损

## 一句话定义
> 当亏损达到预设比例/价格时，自动砍仓离场，防止小亏变大亏。

## 它解决什么问题 / 为什么存在
- 人性厌恶止损（扛单），结果深套甚至归零；止损用规则代替情绪，保住本金，是 [[风险管理]] 的第一道防线。

## 核心原理（大二能懂的水平）
- 买入时定好「跌到 X 就卖」。形式：固定比例止损（如 −8%）、移动止损（从最高点回撤 −15%）、技术止损（跌破支撑/均线）。
- 海龟法则核心就是「设定收益点、止损点，严格按程序操作」；书中 tur10 用 `xlow`（N 日最低价）作为卖出触发。

## 关键参数 / 易错点
- 止损太窄被洗（震荡市误杀）。
- 太宽没保护作用。
- 更致命的是「该止损不止损」（扛单）。
- 幅度须由 [[最大回撤]] 目标反推，并用 [[回测]] 标定。

## 类比（帮助理解）
- 像火灾报警器——平时嫌它吵，真起火时它就是保命的；止损就是账户的「自动喷淋」。

## 设计时怎么用（反推思维）
> 策略函数里卖出分支写死止损条件（如 `dprice < xlow` 卖出），实盘挂条件单；幅度由 [[最大回撤]] 目标反推，配合 [[风险管理]]。

## 典型应用 / 我在哪见过
- 海龟策略 tur10：当收盘价 < N 日最低价 xlow 时卖出；案例累计回报 43% / 95%。

# 自然语言处理

## 一句话定义
> 自然语言处理（NLP，Natural Language Processing）是人工智能与计算语言学的交叉领域，研究「如何让计算机理解、生成和处理人类语言（文本）」——本书用 Python + NLTK 把各任务跑通。

## 它解决什么问题 / 为什么存在
- 人类语言充满歧义、省略、上下文依赖，机器不能直接「读懂」。NLP 把语言转成可计算的结构，支撑搜索、翻译、问答、情感分析等真实应用。
- 本书定位：给学生/研究者一份「用 Python 实现各种 NLP 任务、做出真实项目」的进阶指南。

## 核心原理（大二能懂的水平）
- **预处理（字符串操作）**：把原始文本切成句子/词（tokenization）、标准化（去标点、大小写、停止词 stopwords）、用编辑距离/Jaccard 做相似度。
- **统计语言建模**：算词频（MLE）、平滑（加法/Good-Turing/Kneser-Ney）、用复杂度（perplexity）评估模型；涉及隐马尔科夫、Gibbs 采样。
- **形态学**：词干提取（stemming）、词形还原（lemmatization）、形态分析与生成。
- **词性标注（POS）**：给每个词标名词/动词等；用 n-gram 统计建模、机器学习算法、分块（chunking）。
- **语法解析**：从 Treebank 抽取上下文无关文法（CFG），用 CYK / Earley 线图算法解析句子结构。
- **语义分析**：浅层语义如 NER（命名实体识别，识别人名/地名/机构），用 WordNet 做同义词集、词义消歧（WSD）。
- **情感分析**：判断文本情绪（正面/负面），可用 NER + 机器学习。
- **信息检索（IR）**：向量空间模型、隐性语义索引（LSI）、文本摘要、问答系统。
- **语篇分析**：中心理论、指代消解（谁指代谁）。
- **评估**：用黄金数据、精确率/召回率、错误识别等指标评测 NLP 系统。
- 主工具：**NLTK（Natural Language Toolkit）**——本书所有示例都基于它（需 Python 2.7/3.2+ 与 NLTK 3.0）。

## 关键参数 / 易错点
- 预处理决定上限：切分/停止词/词干这一步没做好，后面模型再强也白搭。
- 词干提取（粗暴砍尾）vs 词形还原（还原词典原形）——前者快但可能砍错，后者需词典/词性。
- 统计模型要平滑，否则遇到训练未见过的 n-gram 直接概率 0。
- 深度学习兴起后，很多传统任务（如 NER、情感）已被神经网络大幅超越——本书偏「传统/统计」方法（见 [[深度学习]] 的关系）。

## 类比（帮助理解）
- 像教外国人读中文：先分词、认词性、分析句子骨架、搞懂「他」「小明」是不是同一个人——一步步把模糊语言变成结构化信息。
- 像流水线工厂：原矿（文本）→ 清洗（预处理）→ 分类（POS/解析）→ 提炼意义（语义/情感）。

## 设计时怎么用（反推思维）
> 做「用户评论情感监控 / 客服工单分类」系统时，我会用 **自然语言处理** 解决「海量非结构化文本没法直接统计」的问题——先 NLTK 做分词+去停止词，再用情感分析/分类模型打标，配合 NER 抽出产品名与地点，输出「哪些产品差评多、集中在哪」，给产品/运营看板用。

# 深度学习

## 一句话定义
> 深度学习是[[机器学习]]的一个分支：它用"多层神经网络"这种特定形式的函数去拟合数据，让模型自动从原始输入逐级学到越来越抽象的特征，最终直接输出结果。

## 它解决什么问题 / 为什么存在
- 很多真实任务（看图认猫、语音识别、机器翻译）无法用"if-else + 手工特征"写出程序——特征组合太复杂，人类写不出来。
- 传统机器学习靠人手工设计特征（如 SIFT 边缘、词袋），深度学习改成"端到端"：把原始数据丢进多层网络，特征由模型自己从数据里学出来，省掉特征工程这一步。

## 核心原理（大二能懂的水平）
- 本质是"用数据编程"：不去写识别猫的规则，而是收集大量"有猫/无猫"的样本，让模型从数据里学出一个能推断的函数 f(图像)→有/无猫。
- 函数形式是多层神经网络：输入（如像素）→ 若干隐藏层（每层做"线性变换 + 非线性激活"）→ 输出。
- 两个关键特点：① 表征学习，逐级把原始数据变成越来越抽象的概念（像素→边缘→花纹→部件→物体）；② 端到端训练，整个系统一起训练，而不是分段调试再拼装。
- 训练靠 [[反向传播]] + [[梯度下降]] 最小化 [[损失函数]] 来迭代参数。

## 关键参数 / 易错点
- 超参数需人为设定：网络层数、每层神经元/通道数、学习率、批量大小、迭代周期、激活函数类型。
- 易错：把"降低训练误差"当成目标——深度学习的真正目标是降低泛化误差；过拟合是大坑（见 [[正则化深度学习]]）。
- 深度学习能容忍非凸、非全局最优解，不追求解析解。

## 类比（帮助理解）
- 像工厂流水线：原材料（像素）进第一道工序只挑出"边缘"，第二道拼成"花纹"，第三道认出"猫耳朵"，最后汇总判断是不是猫。每道工序的"操作手法"是从大量样品里练出来的，不是工程师拍脑袋定的。

## 设计时怎么用（反推思维）
> 做"图像分类 / 语音识别 / 文本生成"这类"规则写不出、但样本管够"的系统时，我会用深度学习（多层神经网络）来做端到端的特征学习；具体选哪种网络再反推：数据带空间结构（图片）→ 用 [[卷积神经网络]]；数据带时间顺序（语音、文本）→ 用 [[循环神经网络]] 或 [[LSTM]]；数据是普通表格特征 → 用 [[多层感知机]]。

## 典型应用 / 我在哪见过
- 手机：拼写纠正、语音识别、照片里认好友。
- ImageNet 图像分类、机器翻译、AlphaGo、自动驾驶的感知部分。

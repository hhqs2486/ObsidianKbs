# 数据可视化

## 一句话定义
> 数据可视化是用图形（散点、线、柱、热力图等）把数据关系与规律呈现出来，让人“一眼看懂”并辅助决策的表达方式。

## 它解决什么问题 / 为什么存在
- 人脑处理图像远快于处理表格数字；可视化把抽象数据变成可感知的模式（趋势、异常、构成）。
- 书中定位：图形展示是数据可视化的必要内容，Matplotlib 是 Python 实现 2D 绘图的主流库（Ch1 1.2.3）；Ch9 9.1.3 专门讲“漂亮的可视化图形”是出彩报告的必备。
- 既是分析手段（先用图看趋势再选模型，如 Ch1 散点图发现线性→选回归），也是成果交付（报告/大屏）。

## 核心原理（大二能懂的水平）
- 选图 = 选“要表达的关系”：
  - 趋势→折线图；构成→饼图/堆叠柱；分布→直方图/散点；排名→条形图；多维→雷达图；地理位置→地图。
- Ch9 建议的图形：树形图(层级/分割)、桑基图(流程演变)、关系图(关联)、象形图(贴近业务形态)、动态图(实时)、子弹图(完成率/进度)、热力图(位置集中度,如点击分布)、字符云(关键词量)、日历图(时间对比)。
- Ch9 不建议：玫瑰图、极坐标图——增加阅读成本。
- 实现：Matplotlib（plt.scatter/plot/bar...）、或 Pandas 直接 plot、或 BI 工具。
- 报告呈现讲究：配色(主色/相近色/互补色/无色系)、留白、对称、字体(<3种、投影≥18号)，并突出关键信息。

## 关键参数 / 易错点
- 易错点1：图很漂亮但读者看不懂（玫瑰图/极坐标图）——优先简单平面图。
- 易错点2：过度加阴影/立体/透视特效，抢了信息主体。
- 易错点3：一份图想表达所有事，反而无重点。先定“要突出的关键信息”再设计。
- 易错点4：维度 >2 时散点图失效，需降维或换多子图。
- 易错点5：给领导看要结论先行（摘要），图形只是佐证，不是推导过程。

## 类比（帮助理解）
- 可视化像“给数据拍照片”：原始数字是 raw 数据，图表是冲洗出来的照片，让人直接看到“长什么样”。
- 配色/留白像“排版海报”：内容再干货，排版乱也无人看。

## 设计时怎么用（反推思维）
> 做 **分析系统或大屏的前端展示层时**，我会用它能解决 **“让运营/老板秒懂数据结论”**——先按要表达的关系(趋势/构成/异常)反推选图：用 [[Pandas]] 算好的指标做 Matplotlib 图或 BI 组件，异常用热力图、流程用桑基图，并遵循配色/留白/突出关键的报告原则，把 [[数据分析]] 结果变成可行动的视觉信号。

## 典型应用 / 我在哪见过
- Ch1 散点图定线性趋势；Ch9 多种图形清单；会员活跃度、流量漏斗、转化路径都靠图呈现。
- 日常：周报图表、监控大屏、A/B 结果对比图。

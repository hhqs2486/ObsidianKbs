# 张量

## 一句话定义
> 张量是深度学习里存储和变换数据的多维数组（书中 MXNet 的 NDArray，对应 PyTorch 的 Tensor），是网络所有输入、权重、中间结果的统一容器。

## 它解决什么问题 / 为什么存在
- 深度学习的输入五花八门：一张图是 (通道, 高, 宽)、一段文本是一个序列、批量数据还要多一维"样本"。需要一个统一的数据结构来装下这些任意维度的数值，并支持 GPU 加速和自动求梯度。
- 张量 = 标量/向量/矩阵 的推广：0 维是数，1 维是向量，2 维是矩阵，3 维及以上就是"高阶张量"。

## 核心原理（大二能懂的水平）
- 张量就是带"形状(shape)"的多维数组。例如 `nd.arange(12).reshape((3,4))` 得到一个 3×4 矩阵；`nd.zeros((2,3,4))` 是一个"2 张 3×4 图"的三维张量。
- 支持按元素运算（加/乘/指数）、矩阵乘法（dot）、连结（concat）、广播（broadcasting，形状不同的两个数组合并时自动复制对齐）、索引切片。
- 与 [[NumPy]] 的 ndarray 很像，但张量额外支持 GPU 计算和 [[自动求导]]。

## 关键参数 / 易错点
- `.shape` 看形状、`.size` 看元素总数、`.reshape` 改形状（用 `-1` 让框架推断某一维）。
- 易错：按元素运算要求形状相同，否则触发广播；广播有时默默生效，结果却不是你以为的那样（如 `(3,1)+(1,2)→(3,2)`）。
- 易错：运算默认新开内存（如 `Y=Y+X` 会换新地址），高频训练循环里要注意原地操作（`Y[:]=...` 或 `+=`）以省内存。
- 张量可在 CPU/GPU 之间搬（`as_in_context`）。

## 类比（帮助理解）
- 像 Excel 表格的升级版：一维是一列、二维是一张表、三维是一摞表；深度学习批处理时再外加一层"同时处理很多张表"。

## 设计时怎么用（反推思维）
> 做模型时，我会用张量作为所有数据的标准容器：把一批图像组织成 `(批量, 通道, 高, 宽)` 四维张量喂给 [[卷积神经网络]]；训练时让框架对"参数张量"开启 `attach_grad()`，从而用 [[自动求导]] 自动算出梯度，无需手写导数公式。

## 典型应用 / 我在哪见过
- 图像 `(1,3,224,224)`、词嵌入批量 `(批量, 时间步, 词向量维)`、隐藏状态 `(批量, 隐藏单元数)`。
- 与 [[NumPy]] 互转（`array` / `asnumpy`）。

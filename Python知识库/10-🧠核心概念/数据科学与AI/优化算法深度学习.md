# 优化算法（深度学习）

## 一句话定义
深度学习里的「优化算法」是一族用来更新模型参数、最小化 [[损失函数]] 的迭代方法——从最朴素的随机梯度下降到带「动量」「自适应学习率」的 Adam，本质都是在回答「下一步参数往哪走、走多大」。

## 它解决什么问题
[[多层感知机]]/[[卷积神经网络]] 这类模型的损失面又高维又崎岖，没法直接求解析解。我们需要一种反复「看一小批数据 → 算梯度 → 挪动参数」的循环，既快又稳地逼近好解。朴素 [[梯度下降]] 在鞍点、狭窄山谷、稀疏特征上会慢或乱抖，于是才有了下面这一堆改进算法。

## 核心原理（大二能懂）
所有算法都基于同一条更新式：`参数 -= 学习率 × 某种「方向」`。区别在「方向」怎么算：
- **小批量 SGD**：每次随机抽一小批样本算梯度当方向。简单但震荡大。
- **动量法（Momentum）**：给更新量加「惯性」，把历史梯度指数加权累积，像小球下坡越滚越快，能冲过浅坑、减少横向抖动。
- **AdaGrad**：给每个参数维护一个梯度平方的累积，频繁更新的参数步长变小、稀疏参数步长变大——但因累积只增不减，后期步长会趋近于 0。
- **RMSProp**：在 AdaGrad 基础上加衰减系数，让历史梯度平方「忘记」旧的，解决步长过早归零。
- **AdaDelta**：进一步去掉对学习率的依赖，用参数更新的平方做自适应缩放。
- **Adam**：把「动量（一阶矩）」和「RMSProp（二阶矩）」合体，并对两者做偏差校正，是目前最常用、开箱即用的默认选择。

一句话记忆：**SGD 是走路，动量像滚球，Ada 系列各自管步长，Adam 是「既带惯性又自适应步长」的全能选手。**

## 关键参数与易错点
- **学习率 lr**：最重要的超参；太大发散、太小慢。常用 1e-3（Adam）或 1e-2（SGD）。
- **批量大小 batch_size**：太小噪声大、太大占显存且泛化略差；常用 32/64/128。
- **动量系数（0.9）、Adam 的 β1/β2（0.9/0.999）、ε（1e-8）**：一般别乱改。
- **易错点**：Adam 收敛快但泛化有时不如精心调过的 SGD；CV 任务常有「先用 Adam 探、再换 SGD 精调」的做法。
- **学习率调度**：常配合「余弦退火 / 阶梯衰减」，比固定 lr 更稳。

## 类比
把优化想象成在雾里下山找谷底：SGD 是闭眼只看脚边坡度一步步挪；动量法是你带了个往前冲的惯性，过小平地也停不下来；AdaGrad 是给常走的路铺了减速带；RMSProp 是减速带会随路况刷新；Adam 是你既记得之前冲的劲头、又随时根据各方向陡缓调整步幅。

## 设计时怎么用（反推思维）
- 搭一个新 [[深度学习]] 模型做快速验证时，我**默认上 Adam + 学习率 1e-3**，少调参就能跑通。
- 做**图像分类（CV）且要刷精度**时，我会先用 Adam 找大致可行区，再切到 **SGD + 动量 0.9 + 余弦退火学习率**，往往泛化更好。
- 遇到**训练 loss 震荡、不收敛**：先怀疑学习率太大或批量太小，而不是先换模型结构。
- 做**稀疏特征 / NLP 词嵌入**时，AdaGrad/RMSProp 这类自适应步长更友好。
- 无论选哪个，优化目标（[[损失函数]]）和 [[反向传播]] 算出的梯度是它们的上游输入。

## 典型应用
- 训练所有 [[卷积神经网络]]、[[循环神经网络]]、[[多层感知机]] 的参数
- 配合学习率调度用于大模型的预训练与微调
- Adam 是 Transformer/大语言模型的标配优化器

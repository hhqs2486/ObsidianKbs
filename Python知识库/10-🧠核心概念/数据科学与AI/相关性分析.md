# 相关性分析

## 一句话定义
> 相关性分析是用相关系数衡量两个变量之间线性关系"密切程度"的统计方法，系数越接近 ±1 关系越强，接近 0 则几乎无关。

## 它解决什么问题 / 为什么存在
- 建模/特征选择前要知道"哪些变量一起变"，相关性高可能共线（需取舍），也可能暗示预测信号。
- 本章（Ch10.3）用 `corrwith` 算股票日收益率与标普500的年相关系数；Ch9 用散点/回归线直观看相关；Ch11 用滚动相关看关系随时间变化。

## 核心原理（大二能懂的水平）
- `Series.corr(other)` 算两序列相关；`DataFrame.corr()` 给整张相关矩阵（默认 Pearson，也有 Spearman/Kendall）。
- `Series.corrwith(other_series)` 算一个序列与另一序列的相关；`DataFrame.corrwith(df['SPX'])` 算各列与某列的成对相关。
- **分组相关**：`by_year.apply(lambda g: g['AAPL'].corr(g['MSFT']))` 算逐年相关系数。
- **滚动相关**：`returns.AAPL.rolling(125).corr(spx_rets)` 看关系随时间漂移。
- 相关系数范围 `[-1, 1]`：正相关同涨同跌，负相关反向，0 无线性相关。
- 实际常用 `pct_change()` 把价格转成收益率再算相关，避免趋势主导。

## 关键参数 / 易错点
- 易错点1：相关系数只衡量**线性**关系，非线性（如抛物线）可能系数接近 0 却强相关。
- 易错点2：**相关 ≠ 因果**，A、B 同涨可能都是 C 驱动的。
- 易错点3：异常值会严重扭曲相关系数，先过 [[异常值处理]]。
- 易错点4：价格序列有趋势，直接 corr 会被趋势带偏，先算收益率。

## 类比（帮助理解）
- 像看"身高和体重"的同步程度：大多数人越高越重（正相关）；但身高和"鞋码随机抽签"就接近 0 相关。同步程度就是相关系数。

## 设计时怎么用（反推思维）
> 做 **特征工程 / 变量筛选**时，我会用它能解决 **"哪些变量有关联"**——先 `df.corr()` 看全矩阵，剔除高度共线特征；再在 [[探索性数据分析EDA]] 里用 [[Seaborn]] 的 `pairplot`/`regplot` 直观确认；时间序列场景用 `rolling().corr()` 看关系稳不稳定（[[时间序列分析]]）。

## 典型应用 / 我在哪见过
- Ch10.3 分组加权平均数和相关系数：`corrwith` 年相关系数、`AAPL` 与 `MSFT` 逐年相关；Ch9 `regplot`/`pairplot` 可视化；Ch11 滚动相关。
- 日常：特征选择、风险对冲（资产相关性）、用户行为关联。

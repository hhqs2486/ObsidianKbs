# 支持向量机SVM

## 一句话定义
寻找使两类**间隔最大化**的决策边界（最大间隔超平面）的分类器，可用核技巧处理非线性。

## 解决什么问题
小样本、高维下的强分类器；尤其擅长找到"最稳妥"的分隔面。

## 核心原理（类比）
像在两堆东西之间画一条最宽的"隔离带"——不只分开，还让边界离两边最近的点都尽量远，这样对新点更不容易分错。最近的那几个点就叫"支持向量"。
- 线性不可分时引入松弛变量做**软间隔**。
- 用**核技巧**（如 RBF 高斯核）把数据映射到高维再分，得到非线性边界。

## 易错点 / 常见坑
- 参数 **C** 权衡间隔与误分：C 大 → 间隔窄、易过拟合；C 小 → 间隔宽、偏置大。
- 核函数与 **γ** 很关键：RBF 核 γ 过大 → 边界过紧、过拟合。
- 对特征尺度极敏感，必须先标准化；大规模数据训练较慢。

## 设计时怎么用（从需求反推）
- 中小数据集、追求高准确用 SVM。
- 线性问题用线性核，非线性用 RBF 核 + 网格搜索调 C / γ。
- 多分类用一对多（OvR）。

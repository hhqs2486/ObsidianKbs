# 监督学习

## 一句话定义
从**带标签**的训练数据中学习一个映射函数，对新样本预测标签或数值的监督式机器学习范式。

## 解决什么问题
已知"正确答案"时，如何训练模型做预测：垃圾邮件过滤、疾病诊断、房价预估、图像分类等都属此类。

## 核心原理（类比）
像老师拿着标准答案批改作业——给模型看大量"题目 + 正确答案"，让它总结出规律；之后遇到新题就能作答。
- **分类**：输出离散标签（如"猫 / 狗"）。
- **回归**：输出连续数值（如"房价 42 万"）。
两者都属于监督学习，区别只在目标变量是离散还是连续。

## 易错点 / 常见坑
- 用测试集反复调参会导致"数据泄露"、泛化估计过于乐观，应保留**独立测试集**，只用训练/验证集调参。
- 标签含噪声、样本不平衡（如 90% 健康样本）会让模型学到假规律，准确率也会骗人。
- 训练集与测试集的**分布要保持一致**，否则训练出的规律不适用。

## 设计时怎么用（从需求反推）
1. 先明确"要预测什么"——标签是什么、是离散还是连续。
2. 选分类还是回归（见 [[分类]] / [[回归]]）。
3. 收集带标签数据 → 划分训练 / 验证 / 测试。
4. 用 [[交叉验证]] 评估泛化误差，必要时加 [[正则化深度学习]] 防过拟合。

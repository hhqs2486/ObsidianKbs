# 分类

## 一句话定义
[[监督学习]]的一个分支，为样本分配**离散的类别标签**。

## 解决什么问题
"属于哪一类"的问题：垃圾邮件识别、图像分类、疾病诊断、情感分析等。

## 核心原理（类比）
像分拣邮件——根据历史被打过标签的样本，模型学到一条"决策边界"把不同类分开；新邮件落在这条线的哪一侧就归为哪类。
- 线性模型（逻辑回归、[[支持向量机SVM]]）画直线 / 超平面边界。
- 非线性用核技巧或 [[神经网络]]。
- 多分类常用一对多（OvR）或独热编码。

## 易错点 / 常见坑
- **类别不平衡**时准确率会骗人（如 90% 健康样本全判健康也有 90% 准），要看精确率 / 召回率 / ROC AUC。
- 线性模型只能分线性可分数据；非线性问题需核方法或神经网络。
- "逻辑回归"名字带"回归"但其实是分类器，别混淆。

## 设计时怎么用（从需求反推）
- 目标为离散标签 → 选分类。
- 评估用混淆矩阵、F1、ROC AUC（而非只看准确率）。
- 小数据集优先逻辑回归 / SVM；追求可解释用 [[决策树]]；追求性能用 [[集成学习]] 或 [[神经网络]]。

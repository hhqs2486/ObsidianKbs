# 无监督学习

## 一句话定义
在**没有标签**的数据中发现内在结构、分组或分布的机器学习范式。

## 解决什么问题
数据没有标准答案时：发现自然分组（[[聚类]]）、压缩维度（[[降维PCA]]）、异常检测、去噪。

## 核心原理（类比）
像整理一堆没贴标签的杂物——你不知道每样东西叫什么，但能按"相似程度"把相近的归到一起（聚类），或把占地方的物品折叠压缩省空间（降维）。

## 易错点 / 常见坑
- 没有标签就无法用准确率直接评估，要靠**肘法、轮廓系数**等内在指标判断质量。
- **距离度量**（如欧氏距离）对尺度敏感，必须先把特征标准化。
- 高维下"维数诅咒"使聚类与距离计算变难，常需先降维。

## 设计时怎么用（从需求反推）
- 当目标是**探索 / 分组 / 降噪 / 预处理**时用无监督学习。
- 常作为监督学习前的 [[特征工程]]：先 PCA 降维再喂给分类器。
- 与 [[监督学习]] 互补：有标签用监督，无标签用无监督。

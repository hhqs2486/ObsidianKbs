# 机器学习

## 一句话定义
机器学习是「用数据自动找规律、让程序在不写显式规则的情况下完成任务」的学科——给定数据，算法从数据中学习一个映射（模型），用来对没见过的数据做预测。[[深度学习]] 是它的一个分支。

## 它解决什么问题
很多任务（识别猫、翻译句子、预测销量）没法靠人把「规则」一条条写清楚。机器学习换了个思路：**不写规则，改写「从数据里学规则」的算法**。你给例子，它自己归纳出输入输出之间的函数。它是 [[数据科学]] 里做预测建模的核心工具。

## 核心原理（大二能懂）
基本套路就三步：
1. **表示**：把现实问题转成「特征向量 + 标签」（如一张图→像素数组，房价→面积/地段）。
2. **学习（优化）**：定义一个 [[损失函数]] 衡量「预测和真实差多远」，再用 [[梯度下降]] 一类算法调模型参数，把损失压到最低。
3. **评估/泛化**：用没参与训练的数据检验模型，看它能不能推广到新样本。

三大范式：
- **监督学习**：有标签（分类、回归），最常见。
- **无监督学习**：只有数据没标签（聚类、降维）。
- **强化学习**：靠「试错 + 奖励」学策略。

[[神经网络]] 是一类可微的参数化模型，深度学习 = 把神经网络堆得很深 + 用 [[反向传播]] 训练。

## 关键参数与易错点
- **训练/验证/测试集划分**：测试集必须全程不碰，否则评估结果虚高（数据泄露）。
- **偏差-方差权衡**：高偏差=欠拟合（模型太简单），高方差=过拟合（模型太复杂），这是所有 ML 模型的永恒矛盾。
- **特征质量 >> 模型复杂度**：垃圾特征喂再深网络也救不了。
- **易错点**：把测试集当验证集调参；以为 acc 高就万事大吉（类别不平衡时看 F1/ROC）；忽略数据分布漂移。

## 类比
机器学习像「让徒弟看大量例题自己悟解法」：你不用把解题步骤写成手册，只要给他足够多「题+答案」，他通过反复比对（损失）和修正（梯度下降），慢慢长出解题直觉；最后用没见过的考题（测试集）看他真懂没。

## 设计时怎么用（反推思维）
- 接到一个新需求（如「判断邮件是不是垃圾」），我会先问：**有没有标签？数据量多大？** 有标签 → 监督学习；海量无标签 → 考虑自监督/预训练。
- 选模型时按「数据量 + 任务」反推：小数据用简单模型（树/线性）先基线；大数据 + 感知类任务（图/语音/文本）才上 [[深度学习]]。
- 永远先定**评估指标和验证方案**（见 [[训练技巧]] 的 K 折），再谈调模型——不然你不知道改进是真有效还是运气。
- 它是 [[深度学习]]、[[神经网络]] 的父框架；具体训练细节交给下游概念卡。

## 典型应用
- 垃圾邮件过滤、推荐系统、信用评分（传统 ML）
- 图像/语音/自然语言（深度学习主导）
- 工业质检、医疗影像、销量预测

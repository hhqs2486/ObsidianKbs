# 模板引擎Jinja2

## 一句话定义
> Jinja2 是 Flask 内置的模板引擎，让你用"HTML + 占位符/控制语句"的模板文件，把后台数据渲染成最终网页。

## 它解决什么问题 / 为什么存在
- 如果所有页面都靠 Python 字符串拼接 `'<h1>'+name+'</h1>'`，代码丑、易 XSS、难维护。Jinja2 把"页面长什么样"交给模板（前端友好），"数据从哪来"留给 Python，并自动转义防注入。

## 核心原理（大二能懂的水平）
- 模板里用定界符写逻辑：`{{ 变量 }}` 输出值（自动 HTML 转义）、`{% 语句 %}` 写 for/if 等控制流、`{# 注释 #}`。
- Flask 用 `render_template('xxx.html', 数据=...)` 把数据注入上下文并渲染成字符串返回。
- 模板可继承（`{% extends %}` + `{% block %}`）做统一布局，子模板只填自己的 block。

## 关键参数 / 易错点
- 输出变量默认转义 `{{ name|e }}` 防 XSS，需要原样输出 HTML 才用 `|safe`（慎用，易被注入）。
- 过滤器 `{{ name|length }}`、测试器 `{% if x is defined %}`、宏 `{% macro %}` 相当于模板里的函数。
- `url_for('static', filename=...)` 引静态文件；`{{ super() }}` 在继承时调用父块内容。
- 易错：把业务逻辑写进模板（应留在视图函数）。

## 类比（帮助理解）
- 像邮件合并：模板是"亲爱的 {{姓名}}，您的订单 {{单号}} 已发货"的信纸，Jinja2 负责把数据库里的真实姓名单号填进去，批量生成百份。

## 设计时怎么用（反推思维）
> 做需要统一导航栏/页脚的网站时，我会建 base.html 用 block 占位，每个页面 `extends` 它——改一处布局全站生效，不用复制粘贴。

## 典型应用 / 我在哪见过
- 博客文章列表/详情页、带循环的商品列表、错误页自定义、后台管理界面。
- 本书：自定义 404/500 错误页用 `@app.errorhandler(404)` + 模板。

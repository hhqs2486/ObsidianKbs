# 树莓派

## 一句话定义
> 树莓派（Raspberry Pi）是一块信用卡大小、能跑完整 Linux 的单板计算机，既具备通用计算能力，又保留可操控的 [[GPIO]] 引脚，是物联网/机器人原型开发里「连接软件世界与物理世界」的万能桥梁。

## 它解决什么问题 / 为什么存在
- 普通电脑没有外露引脚、碰不了真实硬件；单片机（如 Arduino）能控硬件但跑不动 Linux/数据库/视觉。树莓派两头通吃：既能 `apt` 装系统、跑 Python 服务、连 Wi-Fi 上云，又能直接读传感器、控电机——是「从芯片到云端」理念里最典型的边缘节点。

## 核心原理（大二能懂的水平）
- **片上系统(SoC)**：ARM 处理器 + GPU + 外设控制器集成在一颗芯片，外挂内存与 SD 卡（系统盘）。
- **跑 Linux**：插卡即一台 Debian 系小电脑，能用 [[包管理pip]] 装 Python 库、跑服务器、连网络。
- **引出硬件接口**：40-pin 排针提供 [[GPIO]]、I2C、SPI、UART、PWM，软件直接操作物理引脚（如 `RPi.GPIO` / `gpiozero`）。
- **联网与多媒体**：自带 Wi-Fi/蓝牙、USB、Camera/DSI 接口，可做边缘网关或轻量视觉。

## 关键参数 / 易错点
- **GPIO 是 3.3V**：误接 5V 或过大电流会永久损坏。
- **SD 卡脆弱**：频繁写日志/数据库易损卡，重要场景用读-only 根文件系统或外挂 SSD。
- **供电要足**：用 5V/≥2.5A 好电源，电压不足会随机重启、SD 卡损坏。
- **散热与降频**：高负载会 thermal throttle，长时间跑要加散热片/风扇。
- **不是硬实时**：跑 Python 直接控电机等实时任务有抖动，关键控制下沉到 MCU。

## 类比（帮助理解）
- 树莓派像「带手脚的迷你电脑」：它既能在屏幕上敲代码、上网上云（电脑的一面），又能伸出 GPIO「手指」去摸真实世界的开关与电机（硬件的一面）。

## 设计时怎么用（反推思维）
> 做「物联网边缘网关」时，我会以树莓派为中心：本地用 Python 收 [[传感器]] 数据、经 [[物联网MQTT]] 上云，必要控制走 [[GPIO]]/[[电机驱动]]；把重实时任务交给下位 MCU，树莓派专注通信、逻辑与云端协同。

# GPIO

## 一句话定义
> GPIO（General Purpose Input/Output，通用输入输出）是芯片上那些「出厂时没固定用途、可由软件自由配置成输入或输出」的引脚，是树莓派这类开发板和外部硬件对话的最基本接口。

## 它解决什么问题 / 为什么存在
- 计算机内部总线（内存、PCIe）速度太快、协议太复杂，没法直接接灯泡、按键、继电器。GPIO 提供了一组「慢但简单」的引脚，让软件能用最朴素的方式读一个开关、点亮一个 LED、或者给电机发一个高低电平信号。
- 没有 GPIO，嵌入式开发就得为每个外设单独做电路板；有了它，一块通用板卡就能通过软件适配成千上万种硬件。

## 核心原理（大二能懂的水平）
- 每个 GPIO 引脚可以配置成两种角色：
  - **输出（Output）**：CPU 写 1，引脚输出高电平（树莓派为 3.3V）；写 0，输出低电平（0V）。相当于你用代码控制一个「电子开关」的通断。
  - **输入（Input）**：CPU 读取引脚当前是高是低，从而知道外部世界的状态（按键按下=低电平，松开=高电平）。相当于把外部开关接到一颗「电压探针」上。
- 还能配置**上拉/下拉电阻**：输入引脚悬空时电平会乱跳，加上拉电阻后默认是高电平，外部按键接地把它拉低——这样读到的状态才稳定。
- **PWM（脉宽调制）** 是 GPIO 输出的进阶用法：快速翻转高低电平、控制「高电平占空比」，用来近似模拟「中间电压」或调节 LED 亮度、电机转速。

## 关键参数 / 易错点
- **电压电平**：树莓派 GPIO 是 **3.3V**，绝对不能接 5V 信号或直接驱动大电流负载，否则会烧芯片。
- **电流能力**：单个引脚通常只能输出 ~16mA，所有引脚合计有上限（约 50mA），接 LED 必须串限流电阻。
- **编号混乱**：有「物理引脚号（BOARD）」和「BCM 芯片内编号」两套，写代码时务必说清用的是哪套，否则接错脚。
- **输入悬空**：不配置上/下拉的输入脚读到的是随机噪声，必须先处理。

## 类比（帮助理解）
- GPIO 像房子墙上一排「备用接线孔」：你可以今天接个门铃（输入），明天接个灯泡（输出）。CPU 就是房主，通过程序决定每个孔是「听」还是「说」。

## 设计时怎么用（反推思维）
> 做「用树莓派监控并控制一个设备」系统时，我会先用 GPIO 当最底层的手和眼：输入脚读传感器/按键状态，输出脚通过继电器或晶体管去控灯/电机；需要调光调速时再用带 PWM 的引脚，而不是直接数字开关。

## 典型应用 / 我在哪见过
- 按键检测、LED 闪烁、继电器控制、蜂鸣器、用 PWM 调 LED 亮度或舵机角度。

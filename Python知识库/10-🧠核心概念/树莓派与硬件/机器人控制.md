# 机器人控制

## 一句话定义
> 机器人控制是用嵌入式计算机（如树莓派）协调感知、决策与执行，让机器人完成移动、抓取、避障等任务的系统工程；在 Python 物联网全栈里，它把 [[传感器]]、[[电机驱动]]、[[GPIO]] 与上层算法拧成一体。

## 它解决什么问题 / 为什么存在
- 机器人要在不确定环境里「感知→思考→动作」闭环运行。树莓派提供足够算力跑视觉/AI，同时经 GPIO/总线驱动物理执行器，是教学与原型机器人的常用「大脑」。

## 核心原理（大二能懂的水平）
- **感知**：摄像头、超声波、IMU（陀螺仪加速度计）通过 [[I2C总线]]/[[串口UART]]/USB 把环境数据喂给树莓派。
- **决策**：Python 里跑控制逻辑或简单算法（巡线、PID 调速、避障状态机），必要时调 [[数据科学]]/机器学习模型。
- **执行**：决策结果经 [[GPIO]]（PWM）或 [[电机驱动]] 板控制轮子/舵机/机械臂。
- **闭环控制**：用编码器/传感器反馈不断修正（如 PID），让机器人走直线而非越偏越远。
- 常用框架：ROS（Robot Operating System）节点可用 Python 编写；轻量项目直接用 GPIO 库。

## 关键参数 / 易错点
- **实时性**：Python 不是硬实时，关键控制循环要用合适周期 + 独立线程，必要时把底层 PWM/编码器交给单片机/实时协处理器。
- **电源**：电机启动电流大，要和树莓派分开稳压供电，否则电压跌落会重启板子。
- **接地共地**：驱动板与树莓派必须共地，控制信号才有效。
- **安全停**：程序异常时要能急停/失能电机，别让小车乱撞。

## 类比（帮助理解）
- 机器人像人：眼睛耳朵（传感器）收集信息，大脑（树莓派跑 Python）判断，手脚（电机驱动）行动，而且边走边看随时修正方向。

## 设计时怎么用（反推思维）
> 做「树莓派小车/机械臂」时，我会分层：底层用单片机或 GPIO 做精确 PWM 与编码器计数，树莓派跑上层感知与决策（Python），通过 [[串口UART]]/[[I2C总线]] 与底层通信，形成「感知—决策—执行」闭环。

# 传感器

## 一句话定义
> 传感器是把「物理量」（温度、光照、距离、加速度……）转换成「电信号」的器件，是物联网设备感知现实世界的「五官」，转换后的信号再由树莓派通过 GPIO / I2C / SPI / UART 等接口读进来。

## 它解决什么问题 / 为什么存在
- 计算机只认 0 和 1，而现实世界是连续的温度、压力、光线。传感器充当「翻译官」，把模拟/数字世界映射到计算机能处理的数字量。
- 没有传感器，物联网就只剩下「联网」，没有「物」可联——它是一切数据采集的源头。

## 核心原理（大二能懂的水平）
- **模拟传感器**：输出随被测物理量连续变化的电压（如热敏电阻分压）。树莓派没有原生 ADC，通常要外加 ADC 芯片或选数字传感器。
- **数字传感器**：内部已把模拟量转成数字，直接通过 I2C/SPI/UART 把数值「报」给主控，比如 DHT22 报温湿度、BME280 报温湿压。
- 常见种类：温度/湿度（DHT、BME）、光照（光敏电阻/数字光照计）、距离（超声波 HC-SR04、ToF）、运动（加速度计 MPU6050）、图像（摄像头）。
- 读取方式：简单开关量（有没有人）走 [[GPIO]] 输入；复杂数值走 [[I2C总线]]/[[SPI总线]]/[[串口UART]] 总线协议。

## 关键参数 / 易错点
- **量程与精度**：传感器只在标定范围内准，超量程会饱和或报错。
- **模拟量需要 ADC**：树莓派 GPIO 只能读数字高低，读连续电压必须加模数转换芯片。
- **供电与电平匹配**：3.3V 系统接 5V 传感器要注意分压/电平转换。
- **时序要求**：像 DHT 这类单总线传感器对采样时序很敏感，用 Python 轮询容易丢数据，常用 C 扩展或专用库。
- **噪声与抖动**：原始读数会跳，需软件滤波（滑动平均、去抖）。

## 类比（帮助理解）
- 传感器像人的感官：温度计是皮肤、麦克风是耳朵、摄像头是眼睛。树莓派是大脑，先靠感官把世界「数字化」，才能思考和决策。

## 设计时怎么用（反推思维）
> 做「环境监测/智能农业」类物联网系统时，我会先列清要感知哪些量，再选对应传感器：开关状态走 GPIO，温湿度等数值优先选 I2C 数字传感器（接线少、抗干扰），最后在 Python 里做滤波与单位换算，再上报。

## 典型应用 / 我在哪见过
- 温湿度监测、光照自动窗帘、超声波避障小车、加速度计姿态检测。
- 本书第 5 章「设备连接和编程接口」涉及各类传感设备的接入。

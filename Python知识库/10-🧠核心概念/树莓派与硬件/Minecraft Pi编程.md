# Minecraft Pi编程

## 一句话定义
> Minecraft Pi 编程是指在树莓派上运行「Minecraft：Pi Edition」（树莓派版我的世界），通过它内置的 Python API（`mcpi` / `minecraft` 模块）用代码在游戏世界里放置/读取方块、移动玩家、侦听事件，把「玩游戏」变成「用 Python 改造游戏」的入门编程方式。

## 它解决什么问题 / 为什么存在
- 对编程初学者（尤其青少年）来说，纯黑框 `print("hello")` 很枯燥。Minecraft 是他们熟悉的世界，Pi 版专门开放了一个编程接口：你写几行 Python，游戏里就凭空长出一座房子、一条钻石小路——**即时、可见的反馈**极大降低了学习门槛，并天然串联起坐标、循环、条件、函数等编程概念。
- 它是「树莓派即教学平台」理念的典型落地：既能跑 [[树莓派]] 的 Linux，又能用 [[嵌入式Python]] 思维控制一个 3D 沙盒。

## 核心原理（大二能懂的水平）
- **游戏内建 API 服务**：Minecraft：Pi Edition 启动后会监听本机一个端口；Python 端用 `from mcpi.minecraft import Minecraft` 连上，拿到一个 `mc` 对象。
- **用坐标操作世界**：游戏世界是三维网格，每个方块有 `(x, y, z)` 坐标。`mc.setBlock(x, y, z, block_id)` 放一个方块，`mc.getBlock(...)` 读回方块类型，`mc.player.getTilePos()` 拿到玩家位置——和数学里的坐标系一致。
- **批量建造靠循环**：用 [[控制流]] 的 `for` 循环 + 坐标变化，就能「一行代码盖一排墙、一个金字塔、一座迷宫」。
- **事件与交互**：`mc.events.pollBlockHits()` 能侦听玩家点击了哪个方块，从而做「点哪炸哪」「踩到方块触发机关」之类的交互，引出 [[函数基础]] 与事件处理思想。
- 运行环境就是树莓派上的 CPython（见 [[嵌入式Python]]），`pip` 装好 API 后即可在终端或 IDLE 里跑。

## 关键参数 / 易错点
- **只能在 Pi 版运行**：API 依赖 Minecraft：Pi Edition，桌面完整版 Java 版默认没有这个接口（需额外 mod），所以这本书的实践场景是 [[树莓派]] 而非普通电脑。
- **坐标搞错世界就乱**：`y` 是高度，初学者常把 x/y/z 顺序弄混，导致方块出现在脚底下或天上；先 `getTilePos()` 打印坐标再动手最稳。
- **方块 ID 记不住**：不同方块用数字 ID（如 1=石头、2=草、56=钻石块、0=空气）；用常量（书里常定义 `AIR=0, STONE=1...`）比裸数字可读。
- **连不上游戏**：必须先开游戏再跑 Python，且两者在同一台 Pi 上；连不上通常是游戏没启动或 API 端口被占。
- **阻塞思维**：侦听事件若用死循环 `while True`，要理解它和 [[并发编程]] 里「持续运行的任务」是一回事，避免以为程序「卡死」。

## 类比（帮助理解）
- Minecraft Pi 编程像给乐高世界装了一个「魔法遥控器」：你不用手动一块块摆，而是写一张「说明书（Python）」交给遥控器，它按坐标瞬间把积木摆好、还能在你踩到某块时自动反应。

## 设计时怎么用（反推思维）
> 做「青少年 Python 入门」或「可视化教循环/坐标」时，我会以 Minecraft Pi 为沙盒：用 `setBlock`+循环教坐标与迭代，用事件教交互与函数封装；它把抽象的 [[数据类型]]/[[函数基础]] 变成看得见摸得着的建筑，比纯文本练习更能留住初学者。

## 典型应用 / 我在哪见过
- 自动盖房子、钻石路径、炸弹方块、踩方块触发机关的迷你游戏。
- 本书（《我的 python 世界：玩<Minecraft 我的世界>学 python 编程》，程晨）全书即以 Minecraft Pi 为实践载体串讲 Python。

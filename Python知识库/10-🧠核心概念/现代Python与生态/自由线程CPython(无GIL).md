# 自由线程 CPython（3.14 正式支持，3.15 稳定 ABI）

## 一句话定义
> 3.14（PEP 779）将 free-threaded 构建正式化；3.15（PEP 803）提供 free-threaded 的稳定 ABI，多线程真正并行不再是实验。

## 它解决什么问题 / 为什么存在
- 传统 CPython 因 GIL，多线程 CPU 密集任务无法利用多核。

## 核心原理（大二能懂的水平）
- 3.13：实验性 free-threaded 构建
- 3.14（PEP 779）：正式支持，不再是实验特性
- 3.15（PEP 803/820/793）：free-threaded 稳定 ABI，C 扩展可在无 GIL 模式下编译和分发
- 线程可并行执行 Python 字节码；配合 JIT 效果更佳

## 关键参数 / 易错点
- 仍非默认构建；部分老 C 扩展需重新编译
- 3.15 起 C 扩展开发者可为 free-threaded 构建发布稳定 ABI 的 wheel
- 多线程数据竞争的责任在开发者（真正的并行 = 真正的竞态）

## 类比（帮助理解）
- 3.13 是试运营多车道，3.14 正式通车，3.15 修好所有匝道（C 扩展 ABI 稳定）。

## 设计时怎么用（反推思维）
> CPU 密集多线程需求可关注 free-threaded 构建 + 3.15 稳定 ABI，先在非生产环境验证依赖兼容。

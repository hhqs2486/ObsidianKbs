# rich（终端富文本）

## 一句话定义
> 终端输出加颜色、表格、进度条、语法高亮，几乎零成本。

## 它解决什么问题 / 为什么存在
- 黑白 print 难读；手动拼 ANSI 麻烦。

## 核心原理（大二能懂的水平）
- `from rich import print`；`Console()`、`Table`、`track()` 进度；异常也能美化。

## 关键参数 / 易错点
- 只影响显示不影响逻辑；CI/管道里颜色可能干扰解析(可关)。

## 类比（帮助理解）
- 像给终端装了排版软件。

## 设计时怎么用（反推思维）
> 调试输出 / CLI 工具用 rich 提升可读性。

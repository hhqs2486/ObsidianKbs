# pydantic（v2 数据校验）

## 一句话定义
> 用类型标注定义数据模型，运行时自动校验与转换（v2 基于 Rust，快 5–50×）。

## 它解决什么问题 / 为什么存在
- 手写 dict 校验又臭又长；API/配置数据来源不可信。

## 核心原理（大二能懂的水平）
- `class User(BaseModel): name: str; age: int = 0`；自动类型转换、报错清晰；v2 用 pydantic-core(Rust)。

## 关键参数 / 易错点
- v2 与 v1 不兼容（校验器改 `@field_validator`）；默认会强制转换类型("5"→5)，注意是否要 strict 模式。

## 类比（帮助理解）
- 像给数据入口配了个安检员，不合格不让进。

## 设计时怎么用（反推思维）
> 做 API/配置/数据解析时，用 pydantic 取代裸 dict。

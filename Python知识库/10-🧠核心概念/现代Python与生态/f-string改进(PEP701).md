# f-string 语法放开（PEP 701，3.12）

## 一句话定义
> 3.12 起 f-string 内可重用引号、可多行、可嵌套。

## 它解决什么问题 / 为什么存在
- 以前 f-string 里想用同引号会报错、换行麻烦。

## 核心原理（大二能懂的水平）
- `f"{f'{x}'}"` 嵌套；`f'''...多行...'''`；引号不再冲突。

## 关键参数 / 易错点
- 老版本(≤3.11)不支持嵌套/多行；可读性别过度嵌套。

## 类比（帮助理解）
- 像引号「套娃」终于被允许。

## 设计时怎么用（反推思维）
> 生成复杂字符串(如嵌套 JSON/SQL)时更顺手。

## 关联
- 前置知识：[[字符串]]

## 来源
- Python 3.12 (PEP 701)

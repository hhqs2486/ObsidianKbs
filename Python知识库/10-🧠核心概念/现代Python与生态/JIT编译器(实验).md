# JIT 编译器（3.13 实验 → 3.15 显著增强）

## 一句话定义
> CPython JIT 从 3.13 实验起步，3.14 进驻官方构建，3.15 实现 8–9% Linux + 12–13% macOS AArch64 几何平均性能提升。

## 它解决什么问题 / 为什么存在
- 纯解释执行有开销；JIT 把热点编译成本地码提速。

## 核心原理（大二能懂的水平）
- 3.13：实验性复制式 JIT，默认关闭
- 3.14：JIT 进入官方 macOS/Windows 构建
- 3.15：支持更多字节码、AArch64 架构、寄存器分配优化，几何均值 8–9%（x86-64 Linux）/ 12–13%（AArch64 macOS）
- 与 free-threaded 构建可叠加使用

## 关键参数 / 易错点
- 3.15 的提速已可感知（非实验玩具），但仍非全面优化
- 关注未来版本路线图

## 类比（帮助理解）
- 3.13 是「涡轮接口」，3.14 是「装好涡轮」，3.15 是「涡轮开始发力」。

## 设计时怎么用（反推思维）
> 3.15+ 版本可默认享受 JIT 提速，无需额外配置；CPU 密集型场景收益最明显。

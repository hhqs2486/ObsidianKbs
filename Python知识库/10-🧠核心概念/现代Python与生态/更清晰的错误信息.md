# 更清晰的错误信息（3.11+）

## 一句话定义
> 3.11 起 traceback 直接指出出错的表达式与位置，并给出「你也许想写 X」。

## 它解决什么问题 / 为什么存在
- 以前只给行号、定位难；现在高亮 `datas[0]` 这种子表达式。

## 核心原理（大二能懂的水平）
- PEP 657 细粒度位置；`e.add_note("...")`(PEP 678) 给异常附加说明文字。

## 关键参数 / 易错点
- 不是 3.11 前没有异常，只是信息更精确；add_note 需 3.11+。

## 类比（帮助理解）
- 像编译器从「第 3 行错了」精确到「第 3 行的 datas[0] 未定义」。

## 设计时怎么用（反推思维）
> 调试时先读彩色 traceback 的精确位置，再决定改哪。

# 结构模式匹配（match / case）

## 一句话定义
> 用 `match x:` + `case` 按数据的「结构/形状」做分支，比一串 if/elif 更清晰。

## 它解决什么问题 / 为什么存在
- 解析协议、处理带类型的返回值、写状态机时，if/elif 又长又易错。

## 核心原理（大二能懂的水平）
- case 可匹配字面量、类型(`case int()`)、序列(`case [a,b]`)、字典(`case {"k":v}`)、通配(`case _`)、守卫(`case x if x>0`)；自上而下、首个命中即停。

## 关键参数 / 易错点
- case 后是「模式」不是表达式；`_` 是通配不是变量；匹配类需 `__match_args__` 或 `case Point(x,y)`。

## 类比（帮助理解）
- 像路由表：按「形状」把请求分发到对应处理函数。

## 设计时怎么用（反推思维）
> 做协议解析 / 命令分发 / 状态机时，优先用 match 而非长 if/elif。

# typer（类型提示写 CLI）

## 一句话定义
> 用普通函数+类型提示写 CLI，自动生成 --help、参数解析、补全。

## 它解决什么问题 / 为什么存在
- argparse 样板多；typer 让 CLI 像写普通函数。

## 核心原理（大二能懂的水平）
- `@app.command()` + 类型提示参数；`python cli.py --help` 自动有文档；出自 FastAPI 作者。

## 关键参数 / 易错点
- 子命令都用 `@app.command()`；超复杂交互还是得上 Click。

## 类比（帮助理解）
- 像把函数签名直接变成命令行界面。

## 设计时怎么用（反推思维）
> 写小工具/自动化脚本的 CLI 时优先 typer。

# 解包推导式（PEP 798）

## 一句话定义
> Python 3.15 允许在列表/集合/字典推导式中使用 `*` 和 `**` 解包，`{**d for d in dicts}` 一行合并多个字典。

## 它解决什么问题 / 为什么存在
- 之前推导式中无法用解包：`{**d for d in dicts}` 是语法错误
- 合并多个字典得用 `dict(**d1, **d2)` 或 `{k: v for d in dicts for k, v in d.items()}`，后者 O(n²) 且难读
- 解包其他可迭代也受限：`[*t for t in tuples]` 也不允许

## 核心原理（大二能懂的水平）
- 推导式 `for` 子句前允许 `*expr`（可迭代解包）和 `**expr`（映射解包）
- 编译期展开为等效的嵌套循环

```python
# 合并多个字典
dicts = [{"a": 1}, {"b": 2}, {"a": 3}]
merged = {**d for d in dicts}  # {"a": 3, "b": 2}

# 展平嵌套列表
nested = [[1, 2], [3, 4], [5]]
flat = [*row for row in nested]  # [1, 2, 3, 4, 5]

# 集合同理
unique = {*s for s in [{1, 2}, {2, 3}]}  # {1, 2, 3}
```

## 关键参数 / 易错点
- 后出现的键覆盖前的（字典解包保持右优先）
- 仅 list/set/dict 推导式支持，生成器表达式不支持
- 不是 `{for d in dicts: **d}`，语法仍为推导式

## 类比（帮助理解）
- 像快递分拣中心：以前一个包裹一个包裹打开归类（内层循环），现在直接拆箱倒出来（**解包）。

## 设计时怎么用（反推思维）
> 合并配置、展平嵌套数据时，用解包推导式取代嵌套循环，代码更短更易读。

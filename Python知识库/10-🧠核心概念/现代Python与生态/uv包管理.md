# uv（全合一 Python/包管理）

## 一句话定义
> Rust 写的极速 Python 项目管理器，取代 pyenv+venv+pip：装版本、建虚拟环境、装依赖一条龙。

## 它解决什么问题 / 为什么存在
- 环境/版本/依赖管理分散且慢。

## 核心原理（大二能懂的水平）
- `uv venv` / `uv pip install` / `uv run`；`uv.lock` 锁依赖；比 pip 快 10–100×。

## 关键参数 / 易错点
- 新工具，团队需统一；CI 里用它加速安装。

## 类比（帮助理解）
- 像 pip+pyenv+poetry 的「超速合体」。

## 设计时怎么用（反推思维）
> 新建项目时用 uv 管理环境与依赖。

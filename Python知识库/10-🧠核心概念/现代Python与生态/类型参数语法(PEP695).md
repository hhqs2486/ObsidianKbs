# 类型参数语法（PEP 695，3.12）

## 一句话定义
> 3.12 可用 `type Alias = X` 定义类型别名、`class C[T]:` / `def f[T]()` 声明泛型参数，更直观。

## 它解决什么问题 / 为什么存在
- 以前泛型要 `TypeVar`+`Generic`，冗长且作用域混乱。

## 核心原理（大二能懂的水平）
- `type Point = tuple[float, float]`；`def first[T](x: list[T]) -> T:`；`class Box[T]: ...`；可设默认值 `T = str`。

## 关键参数 / 易错点
- 仅 3.12+；老代码仍可用 TypeVar，两者并存不冲突。

## 类比（帮助理解）
- 像给「盒子」贴泛型标签，以前要额外领一张 TypeVar 牌子。

## 设计时怎么用（反推思维）
> 写泛型容器/函数时，优先用新语法更清爽。

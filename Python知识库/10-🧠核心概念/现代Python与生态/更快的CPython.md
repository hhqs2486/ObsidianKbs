# 更快的 CPython（性能项目）

## 一句话定义
> 3.11 起「Faster CPython」项目让解释器持续提速：3.11 约快 25%，3.14 新增尾调用解释器，3.15 JIT 落地 8–13%。

## 它解决什么问题 / 为什么存在
- Python 一直被认为慢；专项优化解释器/启动/帧/JIT。

## 核心原理（大二能懂的水平）
- 3.11：自适应专门化解释器（PEP 659），帧更轻量，启动更快
- 3.14：新「尾调用解释器」（tail-calling interpreter），利用编译器尾调用优化减少调度开销
- 3.15：Windows 64位官方二进制默认使用尾调用解释器；JIT 几何均值性能提升 8–9%（x86-64）/ 12–13%（AArch64 macOS）

## 关键参数 / 易错点
- 提速是「整体基准」，单段代码不一定；别拿版本差异当唯一性能依据
- 尾调用解释器需较新编译器，源码构建时需注意

## 类比（帮助理解）
- 3.11 换了新引擎，3.14 优化了传动系统，3.15 加了涡轮——同一辆车，越来越快。

## 设计时怎么用（反推思维）
> 升级 Python 版本本身就能白嫖性能，优先考虑；3.15 的 JIT + 尾调用解释器让这更值得。

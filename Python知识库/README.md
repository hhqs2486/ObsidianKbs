## 命名与链接铁律
- `[[双链]]` 的链接名必须与目标笔记文件名**完全一致**（大小写、中英文、空格）。
- 文件名**不要含 `/`**（会被 Obsidian 当成路径）；多词概念用连字符，如 `包管理pip`。
- 组件/库用英文原名（`Flask`/`NumPy`/`Pandas`/`requests`），中文概念用中文名（`装饰器`/`爬虫`）。
- 概念卡防重复：谁拥有谁建卡，其他人只 `[[链接]]` —— 见 `99-📒提示词库/概念归属约定.md`。

## 图谱与标签（2026-07-21 优化）
- 每篇笔记带 `tags`：第一维 `Python`，第二维子主题名（概念卡）或类型（`教程`/`MOC`/`项目实战` 等）。关系图谱里按 `tags` 着色分组、用过滤器只看某一类，从此不再眼花缭乱。
- 三个 Python 子主题之外的库（云计算/嵌入式）已各自独立成 vault，互不在同一关系图。

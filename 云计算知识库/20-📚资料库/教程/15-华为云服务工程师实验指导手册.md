# 华为云服务工程师实验指导手册

## 这条教程在解决什么
- 带学员在真实的华为公有云上，从「账号 / IAM」一路做到「计算 / 网络 / 存储 / 运维 / 综合上云」，掌握华为云核心服务的实际用法，目标是能独立用云服务搭企业 IT 架构（对应 HCIA-Cloud Service 认证）。
- 一句话心智模型：**华为云 = 公有云全家桶**——ECS 算、VPC 网、OBS 存、CCE 跑 K8s、ELB 分流、AS 弹性。

## 关键内容（按 PDF 章节提纲）
- **实验一 华为云操作入门**：注册账号 → 实名认证 → 建 IAM 用户/用户组并授权（最小权限，不用主账号）→ 创 VPC 验证权限 → 释放资源。
- **实验二 计算类服务**：ECS 生命周期（建 Windows/Linux 两台、变更规格）、镜像服务 IMS（系统盘镜像、区域内复制、共享镜像、用镜像开新机）、弹性伸缩 AS（伸缩配置/伸缩组/周期+定时策略、带宽伸缩）。
- **实验三 网络类服务**：建多 VPC（上海一 2 个、北京四 1 个）；验证同 VPC 内 ECS 互通、安全组控流、绑 EIP 上公网；ELB 流量分发（监听器+后端组+健康检查）；对等连接打通同区域不同 VPC；VPN 打通跨 Region（上海一↔北京四）。
- **实验四 存储类服务**：云硬盘 EVS（买盘/挂载/初始化/卸载迁移/开机自动挂载/快照回滚）；对象存储 OBS（建桶/上传下载分享/多版本）；弹性文件服务 SFS（NFS 共享文件系统，Linux+Windows 挂载）。
- **实验五 运维类服务**：云审计（关键操作通知，搭配 SMN 消息）、云监控（CPU 告警规则，echo 算 π 拉高 CPU 验证）、云日志（日志组/流 + ICAgent 采集）。
- **实验六 综合实践·企业网站上云**：需求反推架构——业务/数据节点分离（ECS + RDS）、VPC 提供网络、AS 按 CPU 动态扩缩 Web 节点、ELB 分流、云监控看状态；实操 LAMP（httpd+PHP+WordPress）+ 镜像 + AS + ELB 高可用网站。

## 我卡住/没懂的地方
- 本书为图片混排版，大量控制台截图无对应文字，部分步骤（如 WordPress 数据库连接配置、ELB 监听器细项）只能靠图，文本信息有限。
- 全书未单独实验 [[云容器引擎CCE]] 与 [[裸金属服务器BMS]]，仅在与 SFS 相关的说明里点名「容器（CCE&CCI）」「BMS」；这两张概念卡据华为云体系补充，非本书实操。
- 安全组、对等连接、VPN 的「为什么不通」排查，需结合 VPC 网段规划理解（见 [[虚拟私有云VPC]]）。

## 它背后的原理（别只记操作）
- 华为云是 [[公有云]] 的一个实例；资源按「账号 → IAM → 项目/Region → 云服务」组织，隔离靠项目与 [[虚拟私有云VPC]]。
- 计算（[[弹性云服务器ECS]] / [[裸金属服务器BMS]]）→ 网络（[[虚拟私有云VPC]] / [[负载均衡ELB]]）→ 存储（[[对象存储OBS]] / EVS / SFS）→ 弹性（[[弹性伸缩AS]]）是一条完整的「从需求反推架构」主线。
- CCE 就是华为云托管的 [[Kubernetes]]，把 [[容器]] 编排当服务卖；理解它，就把华为云和 [[云原生]] 体系打通了。

## 我能复用/改编的点
> 综合实验六的架构（ECS 业务节点 + RDS 数据节点 + VPC 组网 + ELB 分流 + AS 弹性 + 云监控）就是一套「典型 Web 上云模板」。换个需求：把 ECS 换成 [[云容器引擎CCE]] 跑 [[容器]]、把 OBS 当静态资源仓、用 [[弹性伸缩AS]]+[[负载均衡ELB]] 做 [[高可用]]，就是云原生版上云方案。

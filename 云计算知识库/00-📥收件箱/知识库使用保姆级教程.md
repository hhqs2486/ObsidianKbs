# 知识库使用保姆级教程

> 适用库：Python知识库 / 云计算知识库 / 嵌入式软硬件开发知识库。
> 三个库结构相同、插件相同（dataview / infranodus / excalidraw / obsidian-git / templater），**本教程放哪个库都通用**。

## 〇、一句话心法
这套库不是"电子书仓库"，而是**你的外脑**：用它导航、检索、串联知识，把你脑子里零散的东西变成一张可生长的网。用它的核心就一句话——**从地图进、顺双链跳、用图谱串、靠收件箱收**。

## 一、先搞懂：库里有哪几种笔记（决定你怎么用）

| 目录 | 放什么 | 什么时候看 |
|------|--------|-----------|
| `00-📥收件箱` | 临时草稿、未整理笔记、随手记 | 随时，每周清空 |
| `10-🧠核心概念` | **概念卡**（一个概念一篇，如 Pod、GIL、链表） | 要弄懂某个名词/原理 |
| `20-📚资料库/教程` | **教程笔记**（一本资料一篇，按章提纲，双链到概念） | 系统学一本资料 |
| `30-🛠️项目实战` | 你亲手做的项目复盘 | 找实操经验 |
| `40-🐞问题排查` | 踩坑记录 | 下次遇到同类问题 |
| `50-🗺️索引MOC` | **地图**（本主题所有卡的索引） | 进入主题的入口 |
| `90-⚙️模板` | 新建笔记的模板 | 创建新笔记时 |
| `99-📒提示词库` | AI 提示词、概念归属约定 | 用 AI 写笔记时 |

**铁律**：`10-🧠核心概念` 是"字典"，`20-📚资料库/教程` 是"书"，`50-🗺️索引MOC` 是"目录页"——**别直接翻文件夹，先从 MOC 进**。

## 二、玩法① 导航：从「地图」进，别翻文件夹

> 新手最容易犯的错：在左侧文件树里一层层翻。**正确姿势是走地图。**

1. 打开 Obsidian → 左侧切到对应 vault（如 `Python知识库`）。
2. 打开 `50-🗺️索引MOC/开始这里.md`（这是**总入口**，像书的扉页）。
3. 按主题地图走：
   - Python：基础语法 / 数据结构 / Web 开发 / …（看它的子主题地图）
   - 云计算：`容器与K8s地图` / `监控与可观测性地图` / `OpenStack与虚拟化地图` / …
   - 嵌入式：主控时钟 / 通信接口 / 信号采集 / …
4. 点地图里的 `[[链接]]`，就跳到了具体概念卡。

**示意**：入口 → 主题地图 → 概念卡
```
开始这里 → 监控与可观测性地图 → Prometheus → PromQL / Alertmanager
```

## 三、玩法② 阅读：顺着「双链」跳，别线性读

> 这套库最大的价值是**笔记之间互相链接**，像维基百科一样。

1. 打开一张概念卡（如 `[[Prometheus]]`）。
2. 看卡片的结构：一句话定义 → 解决什么 → 核心原理 → 易错点 → 类比 → 关联。
3. 看到蓝色的 `[[链接]]` 就点，跳到相关概念（比如从 Prometheus 跳到 `[[Alertmanager]]`）。
4. 想回到上一级？看卡片底部的 `## 关联` 和 `## 来源`，或按 `Alt+←` 返回。
5. 想看它在哪本资料里出现？看 `## 来源`，通常链到 `20-📚资料库/教程/某本教程.md`。

**进阶**：按 `Ctrl+E` 在「编辑/预览」模式间切换；预览模式下双链更好看。

## 四、玩法③ 检索：找不到时，三招并用

### 招式1：全文搜索（最常用）
- `Ctrl+Shift+F` 打开全局搜索。
- 输入关键词（如 `PromQL`），回车，列出所有含该词的笔记。
- 点任意结果跳转。

### 招式2：按标签找（tags）
- 每篇笔记 frontmatter 都有 `tags`（如 `[概念]` `[教程]` `[组件参考]`）。
- 在左侧「标签」面板（默认在右侧栏）点标签，列出该标签下所有笔记。
- 例：点 `#概念` 看所有概念卡；点 `#教程` 看所有教程。

### 招式3：关系图谱（图谱视图）
- `Ctrl+G` 打开**关系图谱**。
- 中间的点是笔记，连线是双链。
- 鼠标悬停某点，高亮它的直接关联；双击进入该笔记。
- **找孤岛**：图谱里孤零零的点 = 没被任何笔记链接的笔记（可能需要补链接）。

## 五、玩法④ 新增：先丢收件箱，再整理（最养成习惯的一招）

> 想到一个知识点，**别纠结放哪、怎么写**——先丢进收件箱，再定期整理。

### 第一步：随手记（30 秒）
1. `Ctrl+N` 新建笔记，随便写个标题。
2. 在顶部加 frontmatter（至少写 `tags`）：
   ```
   ---
   tags: [收件箱]
   ---
   ```
3. 内容随便记，哪怕一句话。
4. 把它**拖进 `00-📥收件箱/`**（或直接保存在那里）。

### 第二步：每周清空收件箱（15 分钟）
1. 打开 `00-📥收件箱/`，逐条处理：
   - 是一个概念？→ 用 `90-⚙️模板/概念卡片模板` 整理成标准概念卡，移到 `10-🧠核心概念/<对应子目录>/`，并在相关 MOC 地图里加一条 `[[链接]]`。
   - 是一段教程/资料？→ 用 `教程笔记模板`，移到 `20-📚资料库/教程/NN-主题.md`。
   - 是踩坑？→ 移到 `40-🐞问题排查/`。
2. 收件箱清空后，才算"消化完"。

### 关键：记得加双链
新笔记一定要 `[[链接]]` 到已有笔记（比如在概念卡里 `## 关联` 链相关概念），否则它会成为"孤岛"，图谱里找不到。

## 六、玩法⑤ 复习：用「状态」追踪进度

> 概念卡的 frontmatter 里有个 `状态` 字段，用来标记你的掌握程度。

- `状态: 种子` —— 刚建的卡，还没细看。
- `状态: 待精读` —— 想重点学的。
- `状态: 已精读` —— 已掌握。

**用法**：
1. 左侧「大纲/属性」面板可看到当前笔记的状态。
2. 想找"还没精读的卡"？用全文搜索搜 `状态: 待精读`。
3. 学完一张卡，把 `待精读` 改成 `已精读`。

（可选进阶：你已装 `dataview` 插件，可以写查询自动列出所有"待精读"的卡，如：
````
```dataview
LIST WHERE 状态 = "待精读"
```
````
）

## 七、玩法⑥ 备份：Git 版本化，防丢

> 你已装 `obsidian-git` 插件，库里的笔记可以像代码一样版本化。

- 插件会定期自动 commit（看插件设置里的 auto backup interval）。
- 想手动提交：`Ctrl+P` → 输入 `Git: Commit all changes` → 回车。
- 想看历史：命令面板里有 `Git: View source control`。
- **建议**：把 vault 根目录（如 `C:\Users\liang\ObsidianKbs\Python知识库`）配成一个 git 仓库，推到 GitHub 私有仓库做云备份。

## 八、给你的「第一周上手清单」

按这个顺序做，一周后你就熟了：

1. **第 1 天**：打开 `开始这里.md`，把三个库的主题地图各点一遍，知道每个库里大概有什么。
2. **第 2 天**：挑一个你想懂的概念（如 `Prometheus` / `GIL` / `链表`），从地图进，顺着双链跳 5 张卡。
3. **第 3 天**：用 `Ctrl+Shift+F` 搜一个你最近遇到的问题关键词，看库里有没有现成笔记。
4. **第 4 天**：随手记一个知识点到 `00-📥收件箱`，体验"先丢收件箱"。
5. **第 5 天**：把收件箱那条整理成标准概念卡（用模板），移到 `10-🧠核心概念/`，并加 3 条双链。
6. **第 6 天**：打开关系图谱 `Ctrl+G`，找你刚建的卡在哪，看它跟谁连。
7. **第 7 天**：把"待精读"的卡挑 3 张学完，状态改成"已精读"；用 obsidian-git 提交一次。

## 九、常见问题（FAQ）

**Q1：概念卡和教程笔记有什么区别？**
A：概念卡是"字典"，一个概念一篇，讲清"是什么/为什么/怎么用"；教程笔记是"书"，一本资料一篇，按章提纲、链到概念卡。**概念卡是核心**，教程笔记是入口。

**Q2：我改了笔记，关系图谱没更新？**
A：图谱是实时的，改完保存就更新。如果没变，按 `Ctrl+R` 重开图谱。

**Q3：双链打不出来 `[[`？**
A：在预览模式下 `[[` 会被解析成链接；想写字面 `[[`，用反引号包起来：`[[字面]]`。

**Q4：三个库怎么切换？**
A：Obsidian 左下角或 `Ctrl+P` → "Open another vault"，选对应目录。三个库是**独立 vault**，图谱互不干扰（这是我们特意设计的）。

**Q5：收件箱会不会越堆越多？**
A：会，所以才有"每周清空"的铁律。把它当成"大脑的临时缓存"，清空了才算消化。

> **最后一句**：这套库的价值不在"建得多全"，而在"你天天用它"。每天 10 分钟，从地图进、顺双链跳、随手记收件箱，一个月后它就成了你的第二大脑。

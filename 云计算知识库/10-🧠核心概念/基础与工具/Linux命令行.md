# Linux命令行

## 一句话定义
> Linux 命令行（CLI）是通过 shell 输入文本命令来操作系统的交互界面，是管理 Linux 服务器最主要、最不可替代的方式。

## 它解决什么问题 / 为什么存在
- 服务器大多**没有图形界面**（云主机、容器、K8s 节点都是纯命令行），只能用 CLI 操作。
- 命令行比"点鼠标"更快、可复制、可脚本化、可远程——批量管理和自动化都建立在它之上。

## 核心原理（大二能懂的水平）
- 你敲的命令由 shell（默认 [[bash]]）解析：要么是**内置命令**（`cd`/`echo`/`export`/`read`，shell 自己干），要么是 **PATH 里的外部程序**（如 `/bin/ls`、`/usr/bin/grep`）。
- Linux 哲学"一切皆文件"：磁盘、键盘、网卡、管道都是 `/dev` 或 `/proc` 下的文件，命令本质是对这些文件做读写。
- 通用结构：`命令 -选项 参数`。`-a` 是单字母短选项，`--all` 是语义化长选项；多短选项可合并 `-la` = `-l -a`。

## 关键参数 / 易错点
- 查文档：`man cmd` 看手册、`cmd --help` 看用法、`cmd --version` 看版本——遇事不决先 `--help`。
- 效率键：`Tab` 补全路径/命令、`Ctrl-R` 反向搜索历史、`Ctrl-C` 中断、`Ctrl-A/E` 跳行首行尾。
- 权限：`sudo` 临时提权；文件分 `r/w/x` 三类、属主/属组/其他三类（`chmod`/`chown`）。
- `PATH` 决定哪些命令能"裸敲"；`which cmd` / `type cmd` 查命令到底来自哪个文件。
- 区分**相对路径**（相对于当前目录）和**绝对路径**（从 `/` 起），脚本里尽量用绝对路径避免"在哪跑都不对"。

## 类比（帮助理解）
- 命令行像和操作系统"发微信"：你发一句指令，系统回你一段结果；图形界面是"当面比划"，命令行是"远程指挥"——可记录、可群发（脚本）、可复盘（历史）。

## 设计时怎么用（反推思维）
> 搭任何 Linux 服务 / 容器 / K8s 节点之前，先把 [[Linux命令行]] 和 [[bash]] 练熟——否则排障寸步难行。命令行是上层一切（[[管道与重定向]]、[[文本处理]]、[[CI-CD]]）的地基。

## 典型应用 / 我在哪见过
- 文件：`ls`/`cp`/`mv`/`find`；进程：`ps`/`top`/`kill`；网络：`netstat`/`ss`/`curl`；
- 包管理：`yum`/`apt`；权限：`chmod`/`chown`；日志：`tail -f`/`grep`；
- 这些命令正是 15 本 Shell 书里所有脚本的"零件"。

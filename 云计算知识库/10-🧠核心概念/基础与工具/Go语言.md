# Go语言（Golang）

## 一句话定义
> Go（Golang）是 Google 设计的静态编译型语言，用「轻量并发 + 简洁语法 + 单二进制部署」解决大规模分布式系统的工程效率问题，是云原生（Kubernetes / Docker）的母语。

## 它解决什么问题 / 为什么存在
- C++ 编译慢、内存管理易出错；Java 运行时重、启动慢；Python 并发弱、GIL 受限。
- 云时代需要「编译快、并发好、部署简单、最适合写基础设施」的语言 → Go 应运而生，成为云原生生态的事实标准。

## 核心原理（大二能懂的水平）
- 静态类型、编译为**单一静态二进制**（无运行时依赖），`go build` 直接出可执行文件，拷贝即用。
- 原生并发：**Goroutine + Channel**（见 [[Goroutine]]）做并发，比 OS 线程轻几个数量级。
- 自动垃圾回收（GC）、接口（duck typing，隐式实现）、包管理（见 [[Go模块]]）。
- 标准库强大：`net/http`、`context`、`sync`、`encoding/json` 开箱即用，写服务少依赖。

## 关键参数 / 易错点
- 现代用 **Go Modules**（GO111MODULE=on），不再依赖 GOPATH（见 [[Go模块]]）。
- 零值可用；`nil` 切片/map 可直接 `range`；map 并发读写会 panic（需 `sync.Mutex` 或 `sync.Map`）。
- `defer` 后进先出；方法 Receiver 用指针还是值，会影响方法集与性能。
- 易错：**Goroutine 泄漏**（channel 没关闭、没退出条件）；Go 1.22 前的 `for i` 循环变量闭包捕获陷阱。

## 类比（帮助理解）
- Go 像「自带扳手和螺丝刀的乐高积木」：零件少而精，拼起来快，拼完是一个能直接跑的整体（单二进制），不像别的语言还要带一堆零件箱（运行时/依赖）。

## 设计时怎么用（反推思维）
> - 需求「写高并发微服务 / 中间件」→ 反推：用 Go，Goroutine 天然支持百万级并发连接，单二进制方便容器化部署到 [[Kubernetes]]。
> - 需求「云原生基础设施」→ 反推：Kubernetes、Docker、etcd、Prometheus 都是 Go 写的，生态一致、排错语言统一。

## 典型应用 / 我在哪见过
- Kubernetes、Docker、etcd、Prometheus、Terraform、Gin / gRPC 服务、各类云原生组件。
- 几乎所有「云原生大礼包」里的核心组件底层都是 Go。

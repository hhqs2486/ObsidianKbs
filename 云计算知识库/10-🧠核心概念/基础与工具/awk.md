# awk

## 一句话定义
> awk 是面向文本的数据处理语言，用 `pattern { action }` 模型，把"行=记录、空白/分隔符=字段"的文本当成表格，做按列提取、条件过滤、分组统计和报表生成。

## 它解决什么问题 / 为什么存在
- 大量数据是结构化/半结构化文本（日志、CSV、命令输出表），需要"取某几列、按条件算、分组汇总"。用 sed 硬拆列很痛苦，写 Python 又杀鸡用牛刀——awk 正好卡在中间：比 sed 懂字段，比通用语言轻。

## 核心原理（大二能懂的水平）
- 逐行读入，自动按 FS（字段分隔符，默认空白）切成 `$1 $2 ... $NF` 字段；`$0` 是整个当前行。
- 对每行测试 pattern（条件），命中就执行 `{action}`。
- `BEGIN{}` 在处理**前**跑一次（常放表头、初始化），`END{}` 在处理**后**跑一次（常做汇总打印合计）——这是 awk 出报表的"圣地"。

## 关键参数 / 易错点
- `awk '{print $1}'` 打印第一列；`awk '{print $1, $3}'` 打印第 1、3 列。
- `-F` 指定分隔符：`awk -F: '{print $1}' /etc/passwd`（取用户名）。
- pattern 写法灵活：`awk '$3>100'`（第 3 列 >100 的行）、`awk '/error/'`（含 error 的行）、`awk 'NR>1'`（跳过首行表头）。
- 内建变量：NR（已读行号）、NF（当前行字段数）、FS（输入分隔）、OFS（输出分隔）、ORS（输出行分隔）。
- 关联数组 `arr[key]`，key 可为字符串，是分组计数（如"每个 IP 访问几次"）的核心，`END` 里 `for(k in arr)` 遍历。
- 易错陷阱：**字符串比较与数字比较都写 `==`，但 `"10" < "9"` 是按字典序为真**——混用类型会坑；用 `+($3)` 把字段强制转数字。
- `printf` 不自带换行，记得手动加 `\n`；字符串拼接直接挨着写（不用 `+` 或逗号）。
- 命令行传参用 `-v var=value`，别把 Shell 变量硬拼进脚本。

## 类比（帮助理解）
- 像"自动分列的电子表格公式"：每行当成一条记录，awk 按你写的规则对每一列算一遍，最后还能在 `END` 出一张汇总表——只不过公式写在命令行里，一行搞定。

## 设计时怎么用（反推思维）
> 做监控报表 / 日志统计系统时，我会用 awk 把"按列聚合（求和、计数、分组）"做成短管道，而不是写一大段 Python 只为算个平均值——这正是 [[文本处理]] 的"列级"那一半活。

## 典型应用 / 我在哪见过
- 统计各 IP 访问次数：`awk '{c[$1]++} END{for(i in c) print i, c[i]}' access.log | sort -k2 -nr`
- 算平均响应时间：`awk '{s+=$10; n++} END{print "avg=", s/n}' access.log`
- 提取 CSV 某几列：`awk -F, '{print $2, $5}' data.csv`
- 报表生成：BEGIN 打表头、END 打合计，替代 Excel 透视表

# 云计算（Cloud Computing）

## 一句话定义
通过网络**按需**获取计算、存储、网络等资源的服务模式——像用水用电一样，用多少付多少，弹性伸缩。

## 它解决什么问题
- 自建机房：前期投入大、扩容慢、运维重
- 流量波动大时，固定资源要么浪费要么撑不住

## 核心原理（大二能懂）
把数据中心的计算能力「池化」，用户通过网络申请，提供商按量计费。三个交付层次：
- **IaaS（基础设施即服务）**：给你虚拟机/存储/网络，自己装系统装软件（如 AWS EC2、OpenStack）
- **PaaS（平台即服务）**：给你运行环境，只管写代码部署（如 Kubernetes 平台、Cloud Foundry）
- **SaaS（软件即服务）**：直接用现成软件（如邮箱、网盘）

部署形态：公有云 / 私有云 / 混合云 / 多云。

## 关键参数 / 易错点
- 弹性伸缩 ≠ 无限扩容，要设配额和上限
- 云原生（Cloud Native）是**构建**云上应用的方法论，不等于「跑在云上」
- 易错：把「上云」等同于「用云」——真正价值在弹性 + 托管服务，而不是把物理机搬到云上

## 一个生活类比
早先每家自己打井（自建机房）；后来接市政自来水（云计算），拧开水龙头就有水，按吨计费，旱季多开、雨季少开。

## 设计时怎么用（反推思维）
- 设计系统时先想：跑在哪层云？用哪些托管服务（数据库/消息队列/监控）？
- 要弹性 → 选托管 K8s；要可控 → 自建 OpenStack
- 云原生应用 = 微服务 + 容器 + DevOps + 不可变基础设施

## 典型应用
- 互联网业务弹性扩容
- 大数据/AI 训练（按需算力）
- 企业 IT 私有云

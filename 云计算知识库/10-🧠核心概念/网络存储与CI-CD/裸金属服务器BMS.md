# 裸金属服务器BMS

## 一句话定义
> 裸金属服务器（Bare Metal Server，BMS）是「没有虚拟化层、独占整台物理机」的云服务器——既有物理机性能，又有云的弹性交付。

## 它解决什么问题 / 为什么存在
- 某些场景虚拟机性能 / 隔离不够（高性能计算、大型数据库、安全合规要求物理隔离、需要特殊硬件如 GPU/FPGA），又不想自己买机器、上架、运维。BMS 给你独享物理机，分钟级交付、按需计费。

## 核心原理（大二能懂的水平）
- BMS 与 [[弹性云服务器ECS]]（虚拟机）共享同一套云网络 / 存储底座：它同样挂 [[虚拟私有云VPC]]、能用云硬盘 EVS、能挂弹性文件服务 SFS，但 CPU / 内存 / 网卡是整台物理机独享，没有 Hypervisor 开销，性能与隔离性最强。

## 关键参数 / 易错点
- 规格（鲲鹏 / Intel 大规格、本地盘、GPU / FPGA）、网络带宽、快速发放（可基于镜像秒级装好 OS）。
- 易错：BMS 不是 ECS，不能热迁移；规格选择看重本地盘 / 直通网卡；成本远高于 ECS；交付后仍要走 VPC 才能被其它云资源访问。

## 类比（帮助理解）
- ECS 是合租公寓，BMS 是整栋独栋别墅——独享、贵、性能顶，适合「对性能 / 隔离有硬要求」的住户。

## 设计时怎么用（反推思维）
> 做「数据库、HPC、AI 训练、或对性能 / 物理隔离有硬要求」的系统时，用 [[裸金属服务器BMS]] 当计算底座；网络仍走 [[虚拟私有云VPC]]，持久化可接 [[对象存储OBS]] / 云硬盘，必要时上面再跑 [[云容器引擎CCE]] 节点。

## 典型应用 / 我在哪见过
- 本书在云硬盘 EVS（为 ECS、BMS 提供块存储）、弹性文件服务 SFS（为 ECS、CCE&CCI、BMS 提供共享文件）的说明中提及 BMS，可见它是华为云计算家族里「性能天花板」那一档。

## 关联
- 前置知识：[[公有云]]、[[弹性云服务器ECS]]
- 相关：[[虚拟私有云VPC]]、[[对象存储OBS]]、[[云容器引擎CCE]]
- 反例/误区：普通 Web / 测试用 [[弹性云服务器ECS]] 足够，上 BMS 纯属浪费钱。

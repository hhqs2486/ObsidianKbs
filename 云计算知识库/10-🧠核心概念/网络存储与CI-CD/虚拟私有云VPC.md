# 虚拟私有云VPC

## 一句话定义
> 虚拟私有云（Virtual Private Cloud，VPC）是你在华为云上「圈出的一块私有网络空间」，云服务器 / 容器 / 数据库都住里面，互相隔离、自己配路由。

## 它解决什么问题 / 为什么存在
- 公有云多租户混跑，你需要一块「属于自己的、可控的」网络，定义网段、子网、路由、安全，才能像自建机房一样组网并与其他租户隔离。

## 核心原理（大二能懂的水平）
- VPC = 一个 Region 内的私有网段（如 192.168.0.0/16），下面划子网（subnet，如 192.168.0.0/24）。ECS 落到子网拿到内网 IP。
- 同 VPC 同子网 ECS 默认互通；不同 VPC 默认不通（需建对等连接）；跨 Region 用 VPN/云连接。
- 安全组是绑在 ECS 上的「虚拟防火墙」，控制入/出方向流量。弹性公网 IP（EIP）让 ECS 出公网。本书实验三实操。

## 关键参数 / 易错点
- 网段 CIDR、子网、路由表、安全组、对等连接、EIP。
- 易错：网段别和要对通的对端冲突（否则无法对等连接）；安全组默认拒绝（入方向要显式放行）；EIP 绑 ECS 才能上公网；同一 VPC 内不同子网默认也能互通。
- 本书实操：上海一建 VPC-SH01（192.168.0.0/16，两子网）、VPC-SH02（10.0.0.0/16）；北京四建 VPC-BJ01，用 VPN 跨 Region 打通。

## 类比（帮助理解）
- VPC 像「园区围墙」，子网是「楼内楼层」，安全组是「门禁」，EIP 是「园区对外大门号码」，对等连接是「两个园区间挖的专用地道」。

## 设计时怎么用（反推思维）
> 做「任何上云系统」时，第一件事就是划 [[虚拟私有云VPC]] 网段与子网，把 [[弹性云服务器ECS]]、[[云容器引擎CCE]] 节点、数据库放进去；用安全组做最小放行，跨 VPC 用对等连接，出公网用 EIP 或 [[负载均衡ELB]]。

## 典型应用 / 我在哪见过
- 本书实验三：同 VPC ECS 互通、安全组控流、EIP 上公网、对等连接、VPN 跨 Region。
- 综合实验六：VPC 为 ECS 与 RDS 提供网络底座。
- 网络实验：ELB / AS 都依赖 VPC 子网。

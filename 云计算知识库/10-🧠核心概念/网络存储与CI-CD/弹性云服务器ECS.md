# 弹性云服务器ECS

## 一句话定义
> 弹性云服务器（Elastic Cloud Server，ECS）是华为云上「租来的、可随时升降配的虚拟机」，相当于云上的电脑。

## 它解决什么问题 / 为什么存在
- 传统自建物理服务器：买硬件贵、上架慢、闲置浪费。ECS 让你分钟级拿到一台带网络的计算实例，用多少付多少，业务高峰加配、低谷降配。

## 核心原理（大二能懂的水平）
- ECS 本质是一台运行在华为云物理机上的虚拟机。你选 CPU 架构（x86/鲲鹏）、vCPU 数、内存、镜像（操作系统模板）、系统盘，云在后台从资源池切一块算力给你。
- 它必须挂在 [[虚拟私有云VPC]] 的一个子网里才有网络；可选绑弹性公网 IP（EIP）才能被公网访问。
- 镜像服务（IMS）提供「系统盘镜像」：把一台配置好的 ECS 做成模板，后续批量开一模一样的机器（本书实验二、综合实验六都用到）。

## 关键参数 / 易错点
- 计费模式：按需计费 / 包年包月 / 竞价计费。
- 规格：如 s6.large.2 = 2vCPUs/4GiB；分通用计算型、计算增强型等。
- 可用区（AZ）：同一 Region 内不同机房；跨 AZ 部署可容灾。
- 易错：系统盘随 ECS 创建，数据盘（云硬盘 EVS）可单独买/挂载/卸载；改规格需先关机；登录凭证有密钥对与密码两种方式（Linux 常用密钥对，需 Putty 转换）。
- 本书实操：s6.large.2（2vCPU/4G）跑 CentOS 7.6 / Windows Server 2012；用 `python -m SimpleHTTPServer` 起 http 服务配合 ELB 验证。

## 类比（帮助理解）
- 像「按小时租的租房」：不用买房（买服务器），随时换更大套间（变更规格），退租不亏（释放资源）。镜像是「精装样板间图纸」，照着能复制出一整栋一样的房。

## 设计时怎么用（反推思维）
> 做「需要跑一个网站 / 应用后端」的系统时，我会用 [[弹性云服务器ECS]] 作为计算节点；再配 [[虚拟私有云VPC]] 组网、[[对象存储OBS]] 存静态资源、[[弹性伸缩AS]] 按负载加减机器、[[负载均衡ELB]] 把流量分摊到多台 ECS。

## 典型应用 / 我在哪见过
- 本书实验二：创建 Windows/Linux 两台 ECS、变更规格、做系统盘镜像。
- 综合实验六：ECS 作业务节点跑 WordPress（LAMP），RDS 实例作数据节点。
- 网络实验三：VPC 内 ECS 互通验证、绑 EIP 上公网。

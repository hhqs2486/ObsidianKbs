# 华为云

## 基本信息
- 类别（编排/虚拟化/监控/网络/存储/CI）：公有云 / 云服务平台（IaaS + PaaS + SaaS 全家桶）
- 核心用途：华为公司运营的公共云计算平台，把「服务器、网络、存储、数据库、容器、AI」等能力做成按需取用的服务，企业不用自建机房就能上云。
- 官方文档链接：https://support.huaweicloud.com/

## 关键能力/参数（摘录）
| 维度 | 说明 | 备注 |
|------|------|------|
| 架构角色 | 公有云「总入口 / 资源池」：Region（区域）→ AZ（可用区）→ 各云服务 | 资源归属账号，按用量计费 |
| 数据模型 | 账号 → IAM 用户/用户组 → 项目/Region → 各类云资源（ECS/VPC/OBS…） | 资源隔离靠项目与 VPC |
| 扩展性 | 计算/网络/存储均可弹性伸缩；容器用 [[云容器引擎CCE]] 横向扩 | [[弹性伸缩AS]] / [[负载均衡ELB]] / CCE 负责弹性与分发 |
| 性能/规模 | 单 Region 多 AZ；全球多 Region；规格从 1vCPU 到裸金属/超算 | 见 [[弹性云服务器ECS]] [[裸金属服务器BMS]] |

## 与其它组件的关系
- 依赖：底层是 [[公有云]] 模式（多租户、按需计费）；资源的网络底座是 [[虚拟私有云VPC]]；身份与权限靠 IAM（本书实验一）。
- 被依赖：几乎所有上层服务都跑在华为云之上——[[弹性云服务器ECS]] 算、[[虚拟私有云VPC]] 网、[[对象存储OBS]] 存、[[云容器引擎CCE]] 跑 K8s、[[负载均衡ELB]] 分流、[[弹性伸缩AS]] 弹性。
- 替代/竞品：阿里云、腾讯云、AWS、Azure 等其它公有云。

## 设计时必看的点
- 部署前提：先有华为云账号 + 实名认证；按需付费需充值；多区域数据不互通（跨 Region 用 VPN/云连接）。
- 配置要点：用 IAM 用户而非主账号操作（最小权限）；选对 Region/AZ；用 VPC 隔离业务网络。
- 常见坑：Region 选错导致资源无法互通；主账号直接共享给他人（应建 IAM 子用户）；忘记释放按量资源会持续计费。

## 选型结论
> 适合「不想自建机房、要快速拿到计算/网络/存储/容器能力」的团队。华为云是国产公有云代表，HCIA-Cloud Service 就是讲怎么用它的核心服务搭企业 IT 架构。CCE 等于「华为云里托管的 [[Kubernetes]]」，把 [[容器]] 编排当服务卖。

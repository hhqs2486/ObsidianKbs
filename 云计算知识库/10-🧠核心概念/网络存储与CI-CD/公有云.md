# 公有云

## 一句话定义
> 公有云是「多家企业共享同一云厂商的物理资源、各自逻辑隔离」的交付模式——算力通过网络公开售卖、按需取用。

## 它解决什么问题 / 为什么存在
- 企业不必自建机房、买硬件、养运维，按需租用 IT 资源，把一次性资本支出（CAPEX）变成按量运营支出（OPEX），业务起步快、试错成本低。

## 核心原理（大二能懂的水平）
- 云厂商把大量服务器 / 网络 / 存储池化，用虚拟化 + 多租户隔离切分给不同客户；按用量（CPU 时长、流量、存储量）计费。
- 服务模型分三层：IaaS（租基础设施，如 [[弹性云服务器ECS]]）、PaaS（租平台，如 [[云容器引擎CCE]]）、SaaS（租软件）。
- [[华为云]] 就是一家公有云；它的资源分布在多个 Region（区域），每个 Region 内有多个 AZ（可用区）做容灾。

## 关键参数 / 易错点
- 部署模型（公有 / 私有 / 混合）；服务模型（IaaS / PaaS / SaaS）；Region / AZ；SLA / 可用性指标。
- 易错：公有云 ≠ 免费，忘删资源会持续计费；数据合规 / 出境要评估；多租户隔离靠厂商保障，敏感业务可考虑私有云或专属云。

## 类比（帮助理解）
- 像「市政水电」：你只管插线用水，不用自己建电厂水厂；用多少交多少。

## 设计时怎么用（反推思维）
> 做「新业务、要快上线、规模有弹性」的系统时，优先选 [[公有云]]（如 [[华为云]]），用 ECS 算、VPC 网、OBS 存、CCE 跑容器；稳定后再按合规 / 成本 fine-tune。

## 典型应用 / 我在哪见过
- 本书实验环境就是真实华为公有云（www.huaweicloud.com），全部 6 个实验在其上操作。
- 综合实验六的「企业网站上云」是典型的公有云 Web 架构模板。

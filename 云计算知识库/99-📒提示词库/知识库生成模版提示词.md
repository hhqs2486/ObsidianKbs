## 4. 第 2 步：提取文本与目录

把下面脚本保存为 `<仓库根>/.cache/extract_pdfs.py` 并运行（需 PyMuPDF：在隔离 venv 里 `pip install pymupdf`）。

```python
#!/usr/bin/env python3
"""extract_pdfs.py — 抽取 PDF 全文 + 目录(TOC)，按章切分为小文本文件。
用法: python extract_pdfs.py --cache <输出目录> "E:/books/A.pdf::akey" "E:/books/B.pdf::bkey"
每个源在 <cache>/<key>/ 下生成 full.txt / chNN_*.txt / manifest.json
"""
import fitz, os, re, sys, json, argparse

def safe(name):
    name = re.sub(r'[\\/:*?"<>|#]', '_', name)
    name = re.sub(r'\s+', ' ', name).strip()
    return name[:60]

def extract(path, key, out_dir):
    os.makedirs(out_dir, exist_ok=True)
    doc = fitz.open(path)
    n = doc.page_count
    print(f"[{key}] pages={n} size={os.path.getsize(path)//1024//1024}MB", flush=True)
    toc = [t for t in doc.get_toc() if t[0] <= 2]
    chapters = sorted({(lvl, title, max(0, page - 1)) for lvl, title, page in toc}, key=lambda x: x[2])
    full = [doc[i].get_text() for i in range(n)]
    full_text = "\n".join(full)
    with open(os.path.join(out_dir, "full.txt"), "w", encoding="utf-8") as f:
        f.write(full_text)
    print(f"[{key}] full.txt = {len(full_text)//1024}KB", flush=True)
    splits = [c for c in chapters if c[0] == 1] or [c for c in chapters if c[0] == 2]
    manifest = []
    if splits:
        bounds = [(title, start) for _, title, start in splits]
        for idx, (title, start) in enumerate(bounds):
            end = bounds[idx + 1][1] if idx + 1 < len(bounds) else n
            chunk = "\n".join(full[start:end])
            fname = f"ch{idx+1:02d}_{safe(title)}.txt"
            with open(os.path.join(out_dir, fname), "w", encoding="utf-8") as f:
                f.write(chunk)
            manifest.append({"file": fname, "title": title, "pages": f"{start+1}-{end}", "chars": len(chunk)})
        print(f"[{key}] split into {len(manifest)} chapters", flush=True)
    else:
        print(f"[{key}] NO TOC -> single full.txt", flush=True)
    doc.close()
    with open(os.path.join(out_dir, "manifest.json"), "w", encoding="utf-8") as f:
        json.dump({"pages": n, "chapters": manifest}, f, ensure_ascii=False, indent=2)

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--cache", required=True)
    ap.add_argument("books", nargs="+", help="格式: <pdf路径>::<key>")
    args = ap.parse_args()
    for spec in args.books:
        if "::" not in spec:
            print("跳过(缺 ::key):", spec); continue
        path, key = spec.split("::", 1)
        if not os.path.exists(path):
            print("MISSING", path); continue
        try:
            extract(path, key, os.path.join(args.cache, key))
        except Exception as e:
            print("ERR", key, repr(e), flush=True)
    print("DONE", flush=True)

if __name__ == "__main__":
    main()
```

运行要点：
- 递归扫描 `{{源文件夹路径}}`，把每个 PDF / docx 映射成一个 `key`（用「书名去标点」或「序号」都行，但要稳定且唯一）。
- 调用示例：`python extract_pdfs.py --cache <仓库根>/.cache "<路径>/A书.pdf::A书" "<路径>/B书.pdf::B书" ...`
- **幂等**：脚本已存在 `full.txt` 的 key 自动跳过；重复运行不会覆盖。
- **质量分级**（按 `manifest.json` 的 `chars` 或 `full.txt` 字节/页粗判）：
  - `TEXT`（每页 >700 字节真实文字）：正常抽取。
  - `MIXED`（150–700）：图文混合，能用文字部分。
  - `SCANNED`（<150，纯图片扫描）：文字极少，靠 TOC 章节标题 + 领域知识补全，来源注明「本书第 X 章（PDF 为图片版，结合章节结构整理）」，**绝不编造命令 / 字段**。
- docx 用 `python-docx` 读取（`doc = Document(path)`，`"\n".join(p.text for p in doc.paragraphs)`），同样按标题层级切章，复用同一输出结构。

## 5. 第 3 步：规划「概念归属约定」（防重复核心）

多本书覆盖同一概念（如 3 本 K8s 书都有 Pod / Service）时，**预先划分谁拥有哪个概念**：

- **归属方**：负责建卡并写正文。
- **非归属方**：只在自己教程笔记里用 `[[链接]]` 指向它，**不新建同名文件**；若需补充独有角度，文件名加后缀区分（如 `Pod-权威指南视角`）。

在 `概念归属约定.md` 里维护一张**分书表格**（随着书越来越多持续追加）：

```
## 一、<书名A>（<定位：基础入门/实践运维/权威大部头/另一主题/监控/...>）
归属（写在 <子主题> 下）：`概念1` `概念2` `概念3`
- 只 [[链接]]（不建）：`概念X`（已归属<书B>）`概念Y`（已归属<书C>）

## 二、<书名B> ...
```

**跨书枢纽概念**（每域挑几个，指定唯一 owner，避免竞态）：例如云域的 `云原生` `微服务` `容器编排` `声明式API` `高可用` `负载均衡` `可观测性` `CI/CD` `YAML` `RESTfulAPI` —— 第一本遇到它的 agent 负责建卡，其余只链接。把枢纽清单也写进 `概念归属约定.md` 顶部。

**链接一致性铁律**（写进约定文件，每个 agent 必读）：
- 笔记名与 `[[链接]]` 必须完全一致（含大小写、中英文、有无空格）。
- 组件统一用英文原名（`Pod` 不是 `POD`/`pod`；OpenStack `Nova`/`Neutron` 同理）。
- 中文概念用中文名（`容器` 不是 `Container`，但可在正文标注英文）。
- 文件名**不要含 `/`**（会被 Obsidian 当路径），多词概念用连字符：`CI-CD`、`CKA认证`。

## 7. 第 5 步：断链检测与补全

把下面脚本保存为 `<仓库根>/.cache/gapcheck.py` 并运行：

```python
#!/usr/bin/env python3
"""gapcheck.py — 检测 Obsidian 仓库的断链与孤岛笔记。
用法: python gapcheck.py --root <仓库根>
输出 gaps.json 并打印汇总（断链 = 被链接但无对应文件；孤岛 = 存在但从未被链接）。
"""
import os, re, argparse, json
LINK_RE = re.compile(r"\[\[([^\]]+)\]\]")

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--root", required=True)
    ap.add_argument("--scan", nargs="*",
                    default=["10-🧠核心概念", "20-📚资料库", "30-🛠️项目实战",
                             "40-🐞问题排查", "50-🗺️索引MOC"])
    args = ap.parse_args()
    existing = set()
    for d in args.scan:
        root = os.path.join(args.root, d)
        if not os.path.isdir(root):
            continue
        for dp, _, fns in os.walk(root):
            for fn in fns:
                if fn.endswith(".md"):
                    existing.add(fn[:-3])
    links = {}
    for d in args.scan:
        root = os.path.join(args.root, d)
        if not os.path.isdir(root):
            continue
        for dp, _, fns in os.walk(root):
            for fn in fns:
                if not fn.endswith(".md"):
                    continue
                try:
                    txt = open(os.path.join(dp, fn), encoding="utf-8").read()
                except Exception:
                    continue
                for m in LINK_RE.findall(txt):
                    t = m.split("|")[0].split("#")[0].strip()
                    if t:
                        links.setdefault(t, set()).add(fn)
    gaps = {t: sorted(v) for t, v in links.items() if t not in existing}
    referenced = set(links.keys())
    islands = sorted(existing - referenced - set(gaps.keys()))
    print("existing notes:", len(existing))
    print("distinct link targets:", len(links))
    print("BROKEN LINKS:", len(gaps))
    for t in sorted(gaps):
        print(f"  [[{t}]]  <- {len(gaps[t])} file(s): {gaps[t][:6]}")
    print("ISLANDS:", len(islands))
    for i in islands:
        print("  ", i)
    out = os.path.join(args.root, ".cache", "gaps.json")
    os.makedirs(os.path.dirname(out), exist_ok=True)
    json.dump({"gaps": {k: list(v) for k, v in gaps.items()}, "islands": islands,
               "existing": sorted(existing)}, open(out, "w", encoding="utf-8"),
              ensure_ascii=False, indent=2)
    print("saved", out)

if __name__ == "__main__":
    main()
```

修复动作（跑到 0 断链）：
- 任何文件名含 `/` → 改名（`CI/CD.md`→`CI-CD.md`）并重写 `[[CI/CD]]` 链接。
- 为每个**真实缺口**建卡：常见有顶层中枢（`Kubernetes`/`高可用` 一类跨书枢纽）、跨切概念（`脑裂`/`CGroup`/`CRI`）、被顺带提及但未建的组件。按所在子主题放入 `10-🧠核心概念/<子主题>/`。
- 代码块 / 格式示例里误触发的 `[[链接]]`、`[[:space:]]` 属误报，忽略。
- 复跑 gapcheck 直到 `BROKEN LINKS: 0`。

## 8. 第 6 步：生成 MOC 索引地图

- 生成 `50-🗺️索引MOC/开始这里.md`：指向各子主题地图 + 教程列表 + 项目实战列表，是仓库入口（允许它是孤岛）。
- 每个子主题一张地图（例 `容器与K8s地图.md`）：把该子主题下**所有**概念卡列成 `[[链接]]`（可写个小脚本遍历真实文件生成，保证不漏）。
- MOC 只用链接、不放细节。可用如下思路脚本自动生成（按真实文件保证完整）：

```python
#!/usr/bin/env python3
# genmoc.py — 按真实文件为每个子主题生成 MOC（保证 0 遗漏）
import os, re
ROOT = r"<仓库根>"   # 替换
base = os.path.join(ROOT, "10-🧠核心概念")
for sub in sorted(os.listdir(base)):
    sp = os.path.join(base, sub)
    if not os.path.isdir(sp):
        continue
    cards = sorted(f[:-3] for f in os.listdir(sp) if f.endswith(".md"))
    out = os.path.join(ROOT, "50-🗺️索引MOC", f"{sub}地图.md")
    lines = ["---", "类型: MOC", "tags: [MOC]", "---", "", f"# {sub}地图", "", "> 只放链接，不放细节。", ""]
    for c in cards:
        lines.append(f"- [[{c}]]")
    os.makedirs(os.path.dirname(out), exist_ok=True)
    open(out, "w", encoding="utf-8").write("\n".join(lines))
    print("wrote", out, len(cards), "cards")
```

## 11. 常见坑与铁律（速查）

- **图片版 PDF**：抽取文字稀薄是正常的，靠 TOC 章节标题 + 领域知识补全，诚实标注来源；OCR 是可选增强，不影响可用性。
- **`/` 进文件名**：必断链，一律用 `-` 或无分隔。
- **重复建卡**：概念归属约定是保持关系图干净的唯一手段，每个 agent 提示里都要强制。
- **链接名漂移**：`[[X]]` 与 `X.md` 必须大小写 / 中英文 / 空格完全一致。
- **递归去重**：源文件夹含子目录时递归扫；已存在的 `full.txt` key 跳过；同名书只加一次。
- **分批**：来源多时分批并行派 agent（每批 5–8 本），逐批跑 gapcheck，避免一次性巨量写入冲突。

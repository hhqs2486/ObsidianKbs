# 04-拉普拉斯变换（连续系统的 s 域分析）

## 本模块在解决什么
连续系统的时域分析（[[微分积分方程的s域求解|微分方程时域法]]）要解齐次+特解+定初值，过程繁琐。引入拉普拉斯变换后：
1. **把不稳定的信号也纳入分析**（[[傅里叶变换(FT)]] 做不到）；
2. **把微分/积分变成代数运算**，方程一秒变多项式；
3. **把系统压缩成一个基因 $H(s)$**，稳定、因果、滤波特性全刻在零极点里。

工程师思维主线：**碰到"要解微分方程 / 要看系统稳不稳 / 要知道滤什么波" → 先拉到 s 域 → 代数算完 → 反变换回时域**。

## 核心知识点（按逻辑递进）

### 1. 拉普拉斯变换定义（LT ↔ FT 的关系）
- 单边：$F(s)=\int_{0^-}^{\infty}f(t)e^{-st}dt,\;s=\sigma+j\omega$。记忆："先乘衰减 $e^{-\sigma t}$ 再傅里叶"。
- 双边：$\int_{-\infty}^{\infty}$。默认"拉氏变换"指单边。
- 与 FT 的关系：ROC 的收敛坐标 $\sigma_0$ 决定——$\sigma_0<0$ 时 $F(j\omega)=F(s)|_{s=j\omega}$；$\sigma_0>0$ 时 FT 不存在；$\sigma_0=0$ 时 FT 含冲激项。
- 详见 [[拉普拉斯变换(LT)]]、[[单边与双边LT]]。

### 2. 收敛域 ROC（变换不可分割的一半）
- ROC 是使 $f(t)e^{-\sigma t}$ 绝对可积的 $\sigma$ 范围；有理变换 ROC 内无极点、边界由极点定。
- 看 ROC 形状判信号类型：右半平面→右边/因果；左半平面→左边；竖条带→双边。
- ROC 含虚轴 ⇔ FT 存在 ⇔（因果系统）稳定。详见 [[收敛域(ROC)]]。

### 3. 常用变换对与 LT 性质（不求积分也能算）
- 必背变换对：
  $$\delta(t)\leftrightarrow1,\quad u(t)\leftrightarrow\frac1s,\quad e^{-at}u(t)\leftrightarrow\frac1{s+a},\quad t^n u(t)\leftrightarrow\frac{n!}{s^{n+1}},\quad \cos\beta t\,u(t)\leftrightarrow\frac{s}{s^2+\beta^2}$$
- 关键性质：时移 $f(t-t_0)u(t-t_0)\leftrightarrow e^{-st_0}F(s)$；频移 $e^{s_0t}f(t)\leftrightarrow F(s-s_0)$；尺度 $f(at)\leftrightarrow\frac1a F(s/a)$；时域微分 $f'\leftrightarrow sF-f(0^-)$；s 域微分 $-tf(t)\leftrightarrow F'(s)$；时域积分 $\int_0^tf\leftrightarrow F/s$；**卷积 $f_1*f_2\leftrightarrow F_1F_2$**。
- 详见 [[LT性质]]。

### 4. 初值定理与终值定理（不反变换看头尾）
- 初值：$f(0^+)=\lim_{s\to\infty}sF(s)$（含冲激需先拆分）。
- 终值：$f(\infty)=\lim_{s\to0}sF(s)$，**前提是 $sF(s)$ 极点全在左半平面或仅虚轴单极点**。
- 终值定理误用是全章最高频错误。详见 [[初值定理]]、[[终值定理]]。

### 5. 逆变换：部分分式展开法
- 真分式按极点类型展开：单极点 $k_i/(s-p_i)$；共轭单极点配 $e^{-\alpha t}(A\cos\beta t+B\sin\beta t)$；重极点用导数法求系数。
- 假分式先化为多项式+真分式，多项式对应 $\delta(t)$ 及其导数。

### 6. s 域电路模型（动态电路→电阻网络）
- $Z_R=R,\;Z_L=sL,\;Z_C=1/(sC)$；初值变附加电源：电感 $L i_L(0^-)$、电容 $u_C(0^-)/s$。
- 画 s 域图 → 节点/网孔法列方程 → 解像函数 → 反变换。详见 [[s域电路模型]]。

### 7. 微分/积分方程的 s 域求解（自动带初值）
- 步骤：两边取 LT → 代入 $y(0^-),y'(0^-)$ → 整理得 $Y=Y_{zi}+Y_{zs}$ → 部分分式 → 反变换。
- $Y_{zi}(s)$ 由初值项来，$Y_{zs}(s)=H(s)F(s)$。详见 [[微分积分方程的s域求解]]。

### 8. 系统函数 $H(s)$（系统总枢纽）
- $H(s)=Y_{zs}/F=\mathscr{L}\{h(t)\}$，只由结构参数定。
- 极点全左半平面→稳定；虚轴单极点→临界稳定；右半/虚轴重极点→不稳定。
- 滤波类型看分子阶次：$as/(bs^2+cs+d)$ 带通、$as^2/(...)$ 高通、常数分子低通。
- 稳定时 $H(j\omega)=H(s)|_{s=j\omega}$。详见 [[系统函数H(s)]]。

## 📌 复习要点（速记清单）
- [ ] 单边 LT 定义与 $0^-$ 含义：默认"拉氏变换"=单边
- [ ] LT = "先衰减再傅里叶"，$s=\sigma+j\omega$，$\sigma_0<0$ 时退化 FT
- [ ] ROC 形状判信号：右半平面→因果、左半→反因果、竖条→双边；含虚轴才有 FT
- [ ] 必背变换对：$\delta\!\leftrightarrow\!1,\ u(t)\!\leftrightarrow\!1/s,\ e^{-at}u(t)\!\leftrightarrow\!1/(s+a),\ t^n u(t)\!\leftrightarrow\!n!/s^{n+1}$
- [ ] 性质四件套：时移 $e^{-st_0}$、频移 $F(s-s_0)$、微分 $sF-f(0^-)$、卷积 $F_1F_2$
- [ ] 初值 $s\to\infty$、终值 $s\to0$，**终值先查 $sF(s)$ 极点是否在左半平面**
- [ ] s 域电路：电感 $sL$ 串 $L i(0^-)$、电容 $1/sC$ 串 $u_C(0^-)/s$，别忘了初值电源
- [ ] 方程 s 域解：初值项一项不漏；$Y=Y_{zi}+Y_{zs}$
- [ ] $H(s)=Y_{zs}/F=\mathscr{L}\{h\}$，极点定稳定、分子阶次定滤波类型
- [ ] 稳定才谈 $H(j\omega)$；全通=零极点虚轴镜像；零点不影响稳定性

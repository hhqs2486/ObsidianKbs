# 05-Z变换（离散系统的 z 域分析）

## 本模块在解决什么
连续系统用 [[拉普拉斯变换(LT)]] 把微分方程变代数方程；离散系统（由 [[线性常系数差分方程]] 描述）用 **Z 变换**做同样的事。它把「延时」变成 $z^{-1}$、把「卷积」变成「乘积」，让我们能像解代数题一样解离散系统：求响应、判稳定、设计滤波器。

> 工程师视角：先问「我想让系统干什么（给输入求输出 / 让它稳定 / 让它只放某频率）」，再反推「该用 ZT 的哪一步」——这正是本模块的思维主线。

## 核心知识点（按逻辑递进）

### 1. ZT 定义与 ROC
- 双边 $F(z)=\sum_{k=-\infty}^{\infty}f(k)z^{-k}$；单边 $F(z)=\sum_{k=0}^{\infty}f(k)z^{-k}$。
- $z$ 是复变量，**只在 [[收敛域(ROC)]] 内** $F(z)$ 才有意义。详见 [[Z变换(ZT)]]、[[单边与双边ZT]]。
- 四种序列的 ROC 形态：有限长（除 0、∞ 外全平面）、右边（圆外）、左边（圆内）、双边（环域）。

### 2. 常用变换对（工具箱，必须背）
- $\delta(k)\leftrightarrow 1$
- $\varepsilon(k)\leftrightarrow \dfrac{z}{z-1}$
- $a^k\varepsilon(k)\leftrightarrow \dfrac{z}{z-a}$（ROC 圆外）
- $-a^k\varepsilon(-k-1)\leftrightarrow \dfrac{z}{z-a}$（ROC 圆内，注意负号）
- $k a^{k-1}\varepsilon(k)\leftrightarrow \dfrac{z}{(z-a)^2}$

### 3. ZT 性质（翻译字典）
- 时移、z 域尺度、卷积 $f_1*f_2\leftrightarrow F_1F_2$、z 域微分 $kf(k)\leftrightarrow -zF'(z)$。
- 初值/终值定理（终值定理要求极点全在单位圆内）。详见 [[ZT性质]]。

### 4. 逆 Z 变换（回到时域）
- 部分分式展开法为主：先做 $F(z)/z$ 展开，再按 ROC 决定每项取 $\varepsilon(k)$ 还是 $\varepsilon(-k-1)$。
- **同一 $F(z)$ + 不同 ROC = 不同序列**。详见 [[逆Z变换]]。

### 5. 差分方程的 z 域求解
- 对方程取单边 ZT，时移性质自动带入初始条件，得 $Y(z)=Y_{zi}(z)+H(z)F(z)$。
- 逆变换得全响应 = 零输入 + 零状态。详见 [[差分方程的z域求解]]。

### 6. 系统函数 $H(z)$（系统身份证）
- $H(z)=Y_{zs}(z)/F(z)=\mathscr{Z}\{h(k)\}$。
- **因果** $\Leftrightarrow$ ROC 圆外；**稳定** $\Leftrightarrow$ 极点全在单位圆内（ROC 含单位圆）。
- 频率响应 $H(e^{j\omega})=H(z)|_{z=e^{j\omega}}$。详见 [[系统函数H(z)]]。

### 7. z 域与 s 域的关系（拓展）
- 复变量关系 $z=e^{sT}$，$s=\sigma+j\omega \leftrightarrow z=\rho e^{j\theta}$，故：$\sigma<0$（s 左半平面）$\to \rho<1$（单位圆内）；$\sigma>0\to\rho>1$。这是 [[拉普拉斯变换(LT)] 与 ZT 的桥梁。

## 📌 复习要点（速记清单）
- [ ] 单边 ZT 只从 $k=0$ 求和；因果序列单/双边相等，双边序列一般不等
- [ ] ROC 四种形态：有限长(除0、∞)、右边(圆外)、左边(圆内)、双边(环域)
- [ ] 背熟 8 个常用变换对，尤其左右序列 $z/(z-a)$ 的符号与 ROC 区别
- [ ] 时移：双边 $z^{\pm m}F(z)$；单边带初始条件项，解差分方程不能省
- [ ] 卷积定理 $f_1*f_2\leftrightarrow F_1F_2$ 是 $H(z)$ 的理论基础
- [ ] 终值定理前提：极点全在单位圆内（含 $z=1$ 一阶），否则无终值
- [ ] 逆 ZT：先 $F(z)/z$ 展开，ROC 圆外→右边序列，圆内→左边序列(带负号)，环域→双边(内外极点各取一侧)
- [ ] 差分方程 z 域解：$Y(z)=Y_{zi}(z)+H(z)F(z)$，全响应=零输入+零状态
- [ ] 因果 $\Leftrightarrow$ ROC 圆外；稳定 $\Leftrightarrow$ 极点全在单位圆内（ROC 含单位圆）
- [ ] $H(z)=\mathscr{Z}\{h(k)\}$，零极点图决定滤波特性与稳定性

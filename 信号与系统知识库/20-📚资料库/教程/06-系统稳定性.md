# 06-系统稳定性与系统函数

## 本模块在解决什么
第 7 章（系统函数）与第 8 章（状态变量分析）合起来回答一个大二工程师最该建立的直觉：
**「给我一个系统，我能不能不解方程，就看出它稳不稳、是低通还是高通、内部会不会偷偷发散？」**
核心武器是两张"地图"——**零极点图**（看稳定性和频响）和**状态空间**（看内部演化与可控可观测）。本模块覆盖：系统函数的零极点表达 → 稳定性/因果性判据 → 频率响应与零极点的几何关系 → 信号流图与梅森公式 → 状态方程与输出方程。

## 核心知识点（按逻辑递进）
### 1. 系统函数与零极点图
- 系统函数 $H(s)/H(z)$ 是零状态下输出/输入变换之比，是 $s/z$ 的有理式（定义见 [[系统函数H(s)]]、[[系统函数H(z)]]，本模块用其「零极点图」视角，见 [[系统函数]]）。
- 由微分方程/差分方程**系数比**直接写 $H$：响应各阶导数系数作分子、激励各阶导数系数作分母（零状态！）。
- 零点=分子根（"黑洞"），极点=分母根（"火山"）。极点决定冲激响应波形，零点只改幅度相位（见 [[零极点]]）。
- 实系数 ⇒ 复零/极共轭成对；画图标零点"〇"、极点"×"。

### 2. 稳定性判据（连续 + 离散）
- BIBO 稳定：有界输入 ⇒ 有界零状态响应。
- **连续**：极点全在左半 $s$ 平面；虚轴一阶极点=临界稳定；右半平面或虚轴二阶 ⇒ 不稳定（见 [[稳定性判据]]）。
- **离散**：极点全在单位圆内；单位圆上一阶=临界稳定；圆外或圆上二阶 ⇒ 不稳定。
- 含待定参数（如增益 $K$）时，用**罗斯判据**列首列同号不等式求稳定范围。
- 状态空间判稳：连续看 $|sI-A|=0$、离散看 $|zI-A|=0$ 的特征值位置，规则同上。

### 3. 因果性（与稳定并列，别混淆）
- [[因果性]]（由 01 模块定义）：连续 $h(t)=0(t<0)$、离散 $h(k)=0(k<0)$，ROC 含 $\infty$。
- 因果 + 稳定 ⇒ ROC 含虚轴/单位圆 ⇒ 极点必在左半平面/单位圆内且虚轴/单位圆上无极点。
- 因果 ≠ 稳定，稳定 ≠ 因果（例 $H(s)=1/(s-1)$ 因果但不稳定）。

### 4. 频率响应与零极点（滤波特性）
- 因果稳定系统令 $s=j\omega$（连续）或 $z=e^{j\theta}$（离散）得频率响应（见 [[频率响应]]、[[频率响应与零极点]]）。
- **矢量图解法**：$|H(j\omega)|=K\prod|j\omega-z_j|/\prod|j\omega-p_i|$。极点靠近虚轴 ⇒ 该频增益峰；零点靠近 ⇒ 该频陷波。
- 滤波类型速判：$\omega=0$ 大、$\infty$ 小 ⇒ 低通；反之高通；中间凸起 ⇒ 带通；中间凹陷 ⇒ 带阻。
- 不稳定系统 ROC 不含虚轴/单位圆 ⇒ **无频率响应**。

### 5. 全通系统与最小相位系统
- [[最小相位系统]]：零极点全在左半平面/单位圆内。同幅频中相移最小、逆系统稳定可实现。
- 全通：零极点关于虚轴/单位圆镜像，$|H|=1$ 只搬相位。注意：全通≠最小相位，稳定≠最小相位。

### 6. 信号流图与梅森公式
- 流图：结点+有向支路（增益），信号顺箭头、结点值=入支路和（见 [[信号流图与梅森公式]]）。
- **梅森公式**：$T=\dfrac{1}{\Delta}\sum_k P_k\Delta_k$，$\Delta=1-\sum L_a+\sum L_bL_c-\sum L_dL_eL_f+\cdots$。
  - $L_a$：单独回路增益；$\sum L_bL_c$：两两**互不接触**回路增益积；高阶类推。
  - $P_k$：第 $k$ 条前向通路增益；$\Delta_k$：与第 $k$ 条前向通路**不接触**子图的特征行列式。
- 用途：由框图/流图一步求 $H$；逆用可由 $H$ 反画流图做系统模拟（直接/级联/并联型）。

### 7. 状态变量分析（第 8 章）
- [[状态方程]]：$\dot{\mathbf{x}}=A\mathbf{x}+B\mathbf{f}$（连续）/$ \mathbf{x}(k+1)=A\mathbf{x}(k)+B\mathbf{f}(k)$（离散）。
- [[输出方程]]：$\mathbf{y}=C\mathbf{x}+D\mathbf{f}$（连续）/$ \mathbf{y}(k)=C\mathbf{x}(k)+D\mathbf{f}(k)$（离散）。
- 状态变量选法：连续选积分器输出（或独立 $u_C,i_L$）；离散选单位延时器输出。
- 建立路径：微分方程/差分方程 → 流图 → 选一阶子系统输出为状态 → 列状态方程 → 列输出方程；电路则直接对电容节点列 KCL、电感回路列 KVL。
- 系统函数矩阵：$H(s)=C(sI-A)^{-1}B+D$，极点一般为 $|sI-A|=0$ 根。
- **零极点相消的隐患**：分子约掉极点 ⇒ 该模态不可观测/不可控，输入输出 BIBO 稳定但**内部不稳定**。

## 📌 复习要点（速记清单）
- [ ] 由微分方程/差分方程写 $H$ 用**系数比**，且取**零状态**
- [ ] 极点定 $h(t)$ 波形与稳定性，零点只改幅度/相位
- [ ] 连续稳定 ⇔ 极点全在**左半 s 平面**；离散稳定 ⇔ 极点全在**单位圆内**
- [ ] 虚轴/单位圆**一阶**极点=临界稳定；二阶及以上=不稳定
- [ ] 因果：$h(t)=0(t<0)$，ROC 含 $\infty$；因果+稳定 ⇒ 极点限在允许区且轴上无极点
- [ ] 罗斯判据：分母排阵列，首列全同号 ⇔ 稳定，据此求 $K$ 范围
- [ ] 频率响应：连续代 $s=j\omega$、离散代 $z=e^{j\theta}$；不稳定系统无频率响应
- [ ] 矢量法：极点近虚轴/单位圆 ⇒ 幅频峰；零点近 ⇒ 幅频谷；据此判低/高/带通/带阻
- [ ] 梅森公式 $T=\frac{1}{\Delta}\sum_k P_k\Delta_k$，$\Delta_k$ 是与第 $k$ 条前向通路**不接触**子图的行列式
- [ ] 状态方程 $\dot{\mathbf{x}}=A\mathbf{x}+B\mathbf{f}$、输出方程 $\mathbf{y}=C\mathbf{x}+D\mathbf{f}$；判稳看 $|sI-A|=0$（$/|zI-A|=0$）特征值位置
- [ ] 零极点相消 ⇒ 内部模态被隐藏（不可观/不可控），BIBO 稳定 ≠ 内部稳定

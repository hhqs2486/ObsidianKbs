# 03 频域分析（傅里叶变换）

## 本模块在解决什么
- 时域看波形，频域看"成分"。本模块把信号从时域搬进频域：用一组正交"频率基底"把任意信号拆成不同频率的正弦/复指数分量，再用"频谱"把成分画出来。
- 工程师思维：先想清楚"我要保留/去掉哪些频率"，再去设计系统——频域分析正是把"滤波、调制、保真、抽样"这些需求翻译成频率上的操作。
- 主线：**正交基底 → 周期信号（FS）→ 非周期信号（FT）→ 频谱与性质 → 抽样 → 无失真/滤波器 → 频率响应 → 离散傅里叶分析（DTFT/DFS/DFT）**。

## 核心知识点（按逻辑递进）
### 1. 正交函数集（为什么信号能"拆"）
- 信号能被分解为正弦叠加，本质是投影到完备正交函数集（三角集 / 复指数集）上。系数是"投影"，帕塞瓦尔恒等式保证能量守恒。详见 [[正交函数集]]。

### 2. 周期信号的傅里叶级数 FS
- 三角型（单边谱）：$f(t)=\frac{a_0}{2}+\sum[a_n\cos n\Omega t+b_n\sin n\Omega t]$，系数由内积求得，波形对称性可大幅化简（偶/奇/半波对称）。见 [[傅里叶级数（三角型）]]。
- 指数型（双边谱）：$f(t)=\sum F_n e^{jn\Omega t}$，$F_n=\frac{1}{T}\int_T f(t)e^{-jn\Omega t}dt$，复数系数含幅度+相位，实信号满足 $F_{-n}=F_n^*$。见 [[傅里叶级数（指数型）]]。
- 由 FS 引出频谱与三大特点（离散/谐波/收敛）。见 [[频谱]]。

### 3. 非周期信号的傅里叶变换 FT
- 正变换 $F(j\omega)=\int f(t)e^{-j\omega t}dt$，反变换 $f(t)=\frac{1}{2\pi}\int F(j\omega)e^{j\omega t}d\omega$。把"周期→离散谱"推广为"非周期→连续谱"。见 [[傅里叶变换(FT)]]。
- 必须背熟的常用变换对：$\delta(t)\leftrightarrow1$、$e^{-at}\varepsilon(t)\leftrightarrow\frac{1}{a+j\omega}$、门函数 $\leftrightarrow \tau\mathrm{Sa}(\omega\tau/2)$、$\mathrm{Sa}\leftrightarrow$ 门、$\cos/\sin\leftrightarrow$ 冲激对等。

### 4. FT 性质（不积分求谱的工具箱）
- 时移只改相位、尺度时频互易、对称、微分、卷积定理（时域卷积=频域相乘）。这是后续一切频域分析的"语法"。见 [[FT性质]]。

### 5. 周期信号的傅里叶变换
- 周期信号 FT = 一串冲激：$\sum 2\pi F_n\delta(\omega-n\Omega)$，统一了 FS 与 FT 两套语言。见 [[周期信号的傅里叶变换]]。

### 6. 抽样定理（连续→离散的边界）
- 时域：限带信号采样率须 $f_s\ge 2f_m$（奈奎斯特），否则频谱混叠；频域对偶：时限信号频谱也须足够密采样。运算对最高频率的影响（乘积相加、卷积取小）是算抽样率的关键。见 [[抽样定理]]。

### 7. 无失真传输与理想滤波器
- 无失真充要条件：全频带 $|H|=K$、$\varphi=-\omega t_0$，即 $h(t)=K\delta(t-t_0)$。见 [[无失真传输]]。
- 理想低通在通带内就是无失真，但 $h(t)$ 非因果、物理不可实现，引出可实现性约束。见 [[理想滤波器]]。

### 8. 频率响应
- $H(j\omega)=\mathcal{F}[h(t)]=Y/F$，幅频+相频描述系统对不同频率的处理；与 [[系统函数]] 关系 $H(j\omega)=H(s)|_{s=j\omega}$。见 [[频率响应]]。
- 能量/功率谱：$E(\omega)=|F|^2$、$P=\sum|F_n|^2$，谱与自相关互为 FT。见 [[能量谱与功率谱]]。

### 9. 离散傅里叶分析（数字化的傅里叶）
- DTFT：非周期序列 → 连续周期谱（周期 $2\pi$）。见 [[DTFT]]。
- DFS：周期序列 ↔ 周期离散谱，公式含旋转因子 $W_N$。见 [[DFS]]。
- DFT：有限长序列的主值变换，与 DFS 同式，是 FFT/计算机谱分析的数学对象；注意"圆周"移位与卷积。见 [[DFT]]。

## 📌 复习要点（速记清单）
- [ ] **正交基底**：三角集 $\{1,\cos,\sin\}$ 与复指数集 $\{e^{jn\Omega t}\}$ 是两大完备正交集，FS 系数 = 投影。
- [ ] **FS 系数公式**：$a_n=\frac{2}{T}\!\int_T f\cos n\Omega t$，$b_n=\frac{2}{T}\!\int_T f\sin n\Omega t$；$F_n=\frac{1}{T}\!\int_T f e^{-jn\Omega t}$。
- [ ] **三角↔指数**：$F_n=\frac{a_n-jb_n}{2}$，$|F_n|=\frac{A_n}{2}$，实信号 $F_{-n}=F_n^*$。
- [ ] **频谱三大特点**：离散性、谐波性、收敛性（仅对周期/离散信号成立）。
- [ ] **FT 正/反变换**：$F(j\omega)=\int f e^{-j\omega t}dt$，$f=\frac{1}{2\pi}\int F e^{j\omega t}d\omega$；必背门↔Sa、$\delta\leftrightarrow1$、$e^{-at}\varepsilon(t)\leftrightarrow\frac{1}{a+j\omega}$。
- [ ] **性质四件套**：时移改相位（$e^{-j\omega t_0}$）、尺度互易（$\frac{1}{|a|}F(j\omega/a)$）、对称（$F(t)\leftrightarrow2\pi f(-\omega)$）、卷积定理（时域卷积=频域乘）。
- [ ] **周期信号 FT**：$\sum 2\pi F_n\delta(\omega-n\Omega)$，冲激强度带 $2\pi$。
- [ ] **抽样定理**：$f_s\ge2f_m$（奈奎斯特频率），$T_s\le1/(2f_m)$（间隔）；乘积使带宽相加、卷积使带宽取小。
- [ ] **无失真**：$|H|=K$、$\varphi=-\omega t_0$、$h(t)=K\delta(t-t_0)$；幅度平≠无失真，相位须线性过原点。
- [ ] **理想低通不可实现**（非因果）；离散三件套：DTFT 连续周期谱、DFS/DFT 离散周期谱，DFT 注意"圆周"效应。

# 连续信号与离散信号（01-信号基础）

## 本模块在解决什么
- 这一章是整门课的「地基」：先搞清楚**信号是什么、怎么分类**，再掌握**信号的基本变换（画图）**，最后建立**系统的四大性质**与 **LTI** 这一核心分析框架。
- 工程师思维：拿到问题先「分类 → 选工具」。本模块就是教你把信号/系统分好类，为后面时域、频域、s 域、z 域的分析铺路。

## 核心知识点（按逻辑递进）
### 1. 信号分类（先看清楚手里是什么）
- 按确定性、周期性、自变量连续性、实/复、能量/功率多维分类（见 [[信号分类]]）。
- 连续 vs 离散（[[连续时间信号]]、[[离散时间信号]]）决定用积分还是求和、微分方程还是差分方程。
- 能量 vs 功率（[[能量信号与功率信号]]）决定用能量谱还是功率谱。

### 2. 典型与奇异信号（积木块）
- 典型连续信号：正弦、指数、Sa、门；典型离散信号：序列、复指数。
- 奇异信号三件套（[[奇异信号]] 统领）：
  - [[单位阶跃]] $u(t)$：开关/截断/分段表示。
  - [[单位冲激]] $\delta(t)$：抽样、筛选、系统试金石。
  - [[冲激偶]] $\delta'(t)$：瞬时变化率、冲激的导数。

### 3. 信号基本运算（画图基本功）
- 加减、乘常数、反转、平移、尺度（见 [[信号基本运算]]）。
- 核心难点 $f(t)\to f(at-b)$：两种顺序（先平移后尺度 / 先尺度后平移 $b/a$）。

### 4. 系统四大特性（给系统「体检」）
- [[线性]]：齐次 + 可加（叠加性），无乘积/平方/常数项。
- [[时不变性]]：参数不随 $t$ 变，输入延迟输出也延迟。
- [[因果性]]：不依赖未来输入，物理可实现。
- [[稳定性(概念)]]：有界输入→有界输出（BIBO）。

### 5. LTI 系统（本课主角）
- 同时满足线性 + 时不变（见 [[LTI系统]]）。
- 由冲激响应 $h(t)$ 完全表征，零状态响应 = 卷积（[[卷积积分]]/[[卷积和]]，02 模块）。
- 具备微分性、积分性、级联可交换等重要性质。

### 6. 周期信号判断（分类的延伸）
- 两周期分量之和周期化的条件：$T_1/T_2$ 为有理数，周期 $T=mT_1=kT_2$（见 [[周期信号判断]]）。

## 📌 复习要点（速记清单）
- [ ] 信号五类分法：确定/随机、周期/非周期、连续/离散、实/复、能量/功率
- [ ] 能量信号 $E$ 有限 $P=0$；功率信号 $P$ 有限 $E=\infty$；周期信号必为功率信号
- [ ] 连续/离散区别只看「自变量」是否连续，不看幅值
- [ ] 离散信号一般不做尺度展缩（只整数点取值）
- [ ] $\delta(t)$ 抽样性质：$\int f(t)\delta(t-t_0)dt=f(t_0)$；筛选：$f(t)\delta(t-t_0)=f(t_0)\delta(t-t_0)$
- [ ] 尺度变换：$\delta(at)=\frac1{|a|}\delta(t)$；与阶跃互导：$\delta(t)=du/dt$
- [ ] 冲激偶：$\int f(t)\delta'(t)dt=-f'(0)$；乘积：$f(t)\delta'(t)=f(0)\delta'(t)-f'(0)\delta(t)$
- [ ] $f(t)\to f(at-b)$ 两种顺序，注意第二种平移量是 $b/a$ 不是 $b$
- [ ] 线性 = 齐次+可加，含 $f^2$、乘积、常数项即非线性
- [ ] LTI 身份证：零状态响应 = 输入 * 冲激响应（卷积）；因果看 $h(t)=0(t<0)$，稳定看 $\int|h|<\infty$

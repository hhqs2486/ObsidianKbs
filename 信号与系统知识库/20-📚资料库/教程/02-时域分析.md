# 时域分析（连续+离散）

## 本模块在解决什么
时域分析回答一个最朴素的问题：**给定一个系统（用微分方程或差分方程描述）和一个输入，输出是什么、怎么随着时间变化？**
本模块同时覆盖第 2 章（连续系统）与第 3 章（离散系统）的时域分析。两条线高度对称——连续用微分/积分，离散用差分/求和，核心思想完全一致，建议**对照着学**。

工程师思维主线（从需求反推原理）：
1. 系统长啥样？→ 用 [[线性常系数微分方程]] / [[线性常系数差分方程]] 建模。
2. 它的"标准反应"是什么？→ 求 [[冲激响应]] 与 [[阶跃响应]]。
3. 任意输入怎么办？→ 用 [[卷积积分]]（连续）/ [[卷积和]]（离散）一步到位得 [[零状态响应]]。
4. 还有初始储能怎么办？→ 单独算 [[零输入响应]]，再加起来得 [[全响应]]（或用 [[经典法求解]] 直接求全解）。

## 核心知识点（按逻辑递进）

### 1. LTI 系统是这一切的前提
只有 [[LTI系统]]（线性 + 时不变）才满足**叠加性 + 卷积表征**。没有线性就没有"分解-叠加"，没有时不变就没有"冲激响应平移加权"的卷积结构。本模块所有公式都建立在这个假设上。

### 2. 冲激响应与阶跃响应：系统的"时域身份证"
- [[冲激响应]] $h(t)$（连续）/ $h(k)$（离散）：系统对 $\delta$ 的零状态响应，完全刻画系统时域特性。
- [[阶跃响应]] $g(t)$/$g(k)$：对 $u$ 的零状态响应。
- 二者互推：
  - 连续：$h(t)=\dfrac{dg(t)}{dt},\; g(t)=\int_{-\infty}^{t}h(\tau)d\tau$
  - 离散：$h(k)=g(k)-g(k-1),\; g(k)=\sum_{i=-\infty}^{k}h(i)$
- 从 $h$ 可读出系统性质：因果 $\iff h(t)=0\;(t<0)$；稳定（BIBO）$\iff \int|h|<\infty$（连续）/ $\sum|h|<\infty$（离散）。
- 求法：令激励为 $\delta$、初态为 0，解齐次方程并用 $\delta$ 平衡最高阶导数定 $0_+$ 初始值。

### 3. 卷积：由冲激响应求零状态响应的引擎
- [[卷积积分]]（连续）：$y_{zs}(t)=f(t)*h(t)=\int_{-\infty}^{\infty}f(\tau)h(t-\tau)d\tau$
- [[卷积和]]（离散）：$y_{zs}(k)=f(k)*h(k)=\sum_{i=-\infty}^{\infty}f(i)h(k-i)$
- 图解法五步（连续/离散通用）：**换元 → 反转 → 平移 → 相乘 → 积分/求和**。
- 时限离散序列更推荐**不进位乘法（列表法）**，长度 $=L_1+L_2-1$。
- 常用性质：交换/结合/分配律，时移，微分/差分，与 $\delta$、$u$ 卷积。

### 4. 微分/差分方程的求解
两套等价路数：
- **一般解法（推荐，工程直觉强）**：先由特征根求 [[零输入响应]]（用 $0_-$ 初值），再由卷积求 [[零状态响应]]（用 $0_+$ 初值），相加得 [[全响应]]。
- **[[经典法求解]]（直接）**：全解 = 齐次解（自由响应）+ 特解（强迫响应），用 **$0_+$ 初值**定系数；难点在"由 $0_-$ 求 $0_+$ 的跳变分析"。
- 离散初始条件注意：零输入用 $y(-1),y(-2),\dots$；零状态用 $y_{zs}(0),y_{zs}(1),\dots$。

### 5. 响应分解：两种视角不要混
- 按起因：全响应 = [[零输入响应]] + [[零状态响应]]。
- 按形式：全响应 = 自由响应（齐次解）+ 强迫响应（特解）。
- 关键关系：**零输入响应 ⊆ 自由响应**；**零状态响应 = 部分自由响应 + 强迫响应**。所以"齐次解 ≠ 零输入响应"。
- 还可分暂态（衰减项）/稳态（最终项）。

## 📌 复习要点（速记清单）
- [ ] 连续卷积：$y=f*h=\int f(\tau)h(t-\tau)d\tau$；离散卷积和：$y=f*h=\sum f(i)h(k-i)$
- [ ] 零状态响应 = 输入卷积冲激响应（连续/离散同构）
- [ ] 冲激↔阶跃：连续 $h=dg/dt$；离散 $h(k)=g(k)-g(k-1)$
- [ ] 因果：$h(t)=0\;(t<0)$；稳定：$\int|h|<\infty$（连续）/$\sum|h|<\infty$（离散）
- [ ] 图解法五步：换元→反转→平移→相乘→积分/求和（反转的是第二个信号）
- [ ] 离散时限卷积长度 $=L_1+L_2-1$；用不进位乘法不易错
- [ ] 全响应 $=y_{zi}+y_{zs}$；且 $=$ 自由响应$+$强迫响应（两视角系数不同但结果同）
- [ ] 零输入用 $0_-$ 初值，零状态/经典法用 $0_+$ 初值
- [ ] 经典法：$y=y_h+y_p$，难点是 $0_-\to0_+$ 跳变分析（激励含 $\delta$ 或 $t=0$ 跳变时才需）
- [ ] 齐次解 ≠ 零输入响应；零状态响应里也含一部分自由响应（不是纯特解）

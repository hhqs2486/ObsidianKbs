# 常用变换对速查表（待核对）

> 把信号与系统最高频的变换对集中列出，便于考前速查。公式为**标准结果**，但主教材（吴大正《信号与线性系统分析》第5版）为图片扫描版未 OCR，本库公式由标准知识整理，**数值/边界建议对照教材原表核对**。核对完可在对应行打勾。

## 一、常用傅里叶变换对（连续）

| 信号 $f(t)$ | $F(j\omega)$ | 备注 |
|---|---|---|
| $\delta(t)$ | $1$ | 全频谱均匀 |
| $1$ | $2\pi\delta(\omega)$ | |
| $\varepsilon(t)$ | $\pi\delta(\omega)+\dfrac{1}{j\omega}$ | 含冲激项 |
| $e^{-at}\varepsilon(t),\ a>0$ | $\dfrac{1}{a+j\omega}$ | |
| $e^{-a\lvert t\rvert},\ a>0$ | $\dfrac{2a}{a^{2}+\omega^{2}}$ | 双边 |
| $e^{j\omega_{0}t}$ | $2\pi\delta(\omega-\omega_{0})$ | 频移 |
| $\cos(\omega_{0}t)$ | $\pi[\delta(\omega-\omega_{0})+\delta(\omega+\omega_{0})]$ | |
| $\sin(\omega_{0}t)$ | $-j\pi[\delta(\omega-\omega_{0})-\delta(\omega+\omega_{0})]$ | |
| 矩形脉冲 $g_{\tau}(t)$（宽 $\tau$） | $\tau\,\mathrm{Sa}\!\left(\dfrac{\omega\tau}{2}\right)$ | $\mathrm{Sa}(x)=\sin x/x$ |
| $\mathrm{Sa}(\omega_{c}t)$ | $\dfrac{\pi}{\omega_{c}}g_{2\omega_{c}}(\omega)$ | 时频对偶 |

## 二、常用单边拉普拉斯变换对

| $f(t)\ (t\ge 0)$ | $F(s)$ | ROC |
|---|---|---|
| $\delta(t)$ | $1$ | 全 $s$ |
| $\varepsilon(t)$ | $\dfrac{1}{s}$ | $\mathrm{Re}(s)>0$ |
| $t^{n}\varepsilon(t)$ | $\dfrac{n!}{s^{n+1}}$ | $\mathrm{Re}(s)>0$ |
| $e^{-at}\varepsilon(t)$ | $\dfrac{1}{s+a}$ | $\mathrm{Re}(s)>-a$ |
| $\sin(\omega_{0}t)\varepsilon(t)$ | $\dfrac{\omega_{0}}{s^{2}+\omega_{0}^{2}}$ | $\mathrm{Re}(s)>0$ |
| $\cos(\omega_{0}t)\varepsilon(t)$ | $\dfrac{s}{s^{2}+\omega_{0}^{2}}$ | $\mathrm{Re}(s)>0$ |
| $e^{-at}\sin(\omega_{0}t)\varepsilon(t)$ | $\dfrac{\omega_{0}}{(s+a)^{2}+\omega_{0}^{2}}$ | $\mathrm{Re}(s)>-a$ |
| $e^{-at}\cos(\omega_{0}t)\varepsilon(t)$ | $\dfrac{s+a}{(s+a)^{2}+\omega_{0}^{2}}$ | $\mathrm{Re}(s)>-a$ |
| $t\,e^{-at}\varepsilon(t)$ | $\dfrac{1}{(s+a)^{2}}$ | $\mathrm{Re}(s)>-a$ |

## 三、常用 Z 变换对（单边因果）

| $f(k),\ k\ge 0$ | $F(z)$ | ROC |
|---|---|---|
| $\delta(k)$ | $1$ | 全 $z$ |
| $\varepsilon(k)$ | $\dfrac{z}{z-1}$ | $\lvert z\rvert>1$ |
| $a^{k}\varepsilon(k)$ | $\dfrac{z}{z-a}$ | $\lvert z\rvert>\lvert a\rvert$ |
| $k\,\varepsilon(k)$ | $\dfrac{z}{(z-1)^{2}}$ | $\lvert z\rvert>1$ |
| $k\,a^{k}\varepsilon(k)$ | $\dfrac{az}{(z-a)^{2}}$ | $\lvert z\rvert>\lvert a\rvert$ |
| $k^{2}\varepsilon(k)$ | $\dfrac{z(z+1)}{(z-1)^{3}}$ | $\lvert z\rvert>1$ |
| $\cos(\omega_{0}k)\varepsilon(k)$ | $\dfrac{z(z-\cos\omega_{0})}{z^{2}-2z\cos\omega_{0}+1}$ | $\lvert z\rvert>1$ |
| $\sin(\omega_{0}k)\varepsilon(k)$ | $\dfrac{z\sin\omega_{0}}{z^{2}-2z\cos\omega_{0}+1}$ | $\lvert z\rvert>1$ |
| $a^{k}\cos(\omega_{0}k)\varepsilon(k)$ | $\dfrac{z^{2}-az\cos\omega_{0}}{z^{2}-2az\cos\omega_{0}+a^{2}}$ | $\lvert z\rvert>\lvert a\rvert$ |

## 四、s 域电路元件模型（复频域）

| 元件 | 复频域阻抗 | 初始值等效源（串联形式） |
|---|---|---|
| 电阻 $R$ | $R$ | 无 |
| 电感 $L$（初值 $i_L(0^-)$） | $sL$ | 附加电压源 $L\,i_L(0^-)$ |
| 电容 $C$（初值 $u_C(0^-)$） | $\dfrac{1}{sC}$ | 附加电压源 $\dfrac{u_C(0^-)}{s}$ |

> 等效源方向与初始电流/电压参考方向有关；电容亦有并联电流源形式。详见 [[s域电路模型]]，建议对照教材原表核对。

# 系统稳定性-例题2：由零极点分布判断滤波特性

## 题目
> 设系统的函数为
> $$H(s)=\frac{s+2}{s^2+2s+2}$$
> 求：（1）系统的零极点图；（2）系统的幅频特性曲线；（3）该系统的滤波器特性（带通、带阻、低通或高通）。

## 解题思路（先看这一步）
- 先因式分解分母找极点、分子找零点，画零极点图（见 [[零极点]]）。
- 令 $s=j\omega$ 得频率响应，用**矢量图解法**分析 $|H(j\omega)|$ 随 $\omega$ 从 0 到 $\infty$ 的变化（见 [[频率响应与零极点]]）。
- 根据"$\omega=0$ 与 $\omega\to\infty$ 处幅值大小对比 + 中间有无峰/谷"判定滤波类型。

## 详细解答
**（1）零极点**
$$H(s)=\frac{s+2}{(s+1)^2+1}=\frac{s+2}{(s+1-j)(s+1+j)}$$
- 零点：$z=-2$（实轴上"〇"）。
- 极点：$p_{1,2}=-1\pm j$（左半平面共轭对"×"）。

**（2）幅频特性（矢量法）**
令 $s=j\omega$：
$$H(j\omega)=\frac{j\omega+2}{(j\omega+1)^2+1}=\frac{j\omega+2}{-\omega^2+2j\omega+2}$$
$$|\,H(j\omega)\,|=\frac{\sqrt{\omega^2+4}}{\sqrt{(\,2-\omega^2)^2+4\omega^2}}=\frac{\sqrt{\omega^2+4}}{\sqrt{\omega^4+4}}$$
关键取样：
- $\omega=0$：$|H|=\sqrt{4}/\sqrt{4}=1$；
- $0<\omega<1$：分母增长慢于分子，幅值略升；
- $\omega=1$（极点虚部附近）：$|H|=\sqrt{5}/\sqrt{5}=1$，且附近出现轻微谐振峰；
- $\omega>1$：分母 $\sim\omega^2$ 主导，幅值单调下降；
- $\omega\to\infty$：$|H|\sim 1/\omega\to 0$。

**（3）滤波器特性**
$\omega=0$ 处幅值不为零、$\omega\to\infty$ 处趋于 0，且全频段无持续谷值，故该系统具有**低通滤波器**特性（极点靠近虚轴在 $\omega\approx1$ 处产生一个谐振峰，但整体仍属低通）。

## 考点 & 易错
- 考查知识点：[[零极点]]、[[频率响应与零极点]]、[[稳定性判据]]
- 易错点：
  1. 极点靠近虚轴会产生**谐振峰**，易被误判为"带通"。判低/高/带通要看 $\omega=0$ 与 $\omega\to\infty$ 两端幅值：两端一高一低=低通或高通；两端都低、中间高=带通；中间低、两端高=带阻。
  2. 忘记先判**稳定性**：本题极点全在左半平面 ⇒ 稳定 ⇒ 频率响应存在。若极点在右半平面则无频率响应。
  3. 离散域应代 $z=e^{j\theta}$ 并扫单位圆（$\theta\in[0,2\pi)$），别套用连续公式。

## 同类题 / 变式
- 若题目只给零极点图（如零点在虚轴、共轭极点在左半平面），用矢量法"沿 $j\omega$ 轴走一遍"：$\omega$ 从 0 起幅度由 0 升到峰再降到 0 ⇒ **带通**（华中科技大学 2012 类似题）。
- 离散低通例：$H(z)=\frac{z^2+1}{z^2-0.9z}$，极点 $0,0.9$ 均在单位圆内 ⇒ 频率响应存在，幅频呈低通（章节题库第 7 章分析计算题 3）。

# 知识网络总图（前置依赖 + 五大维度）

> 本库按你的 5 点要求构建。下面先讲清「知识点之间怎么连」，再说明「每张笔记含哪五维」。

## 一、前置依赖链（从基础到进阶）
信号与系统是一条递进链，前一个模块是后一个的「地基」：

```
[01 信号基础] ──LTI / 冲激 / 阶跃──▶ [02 时域分析] ──卷积 / 冲激响应──┐
                                                          │              │
              ┌───────────────────────────────────────────┘              │
              ▼                                                            ▼
   [03 傅里叶频域] ◀──FT 是 LT 在虚轴取极限──▶ [04 拉普拉斯变换] ──H(s)──┐
   (连续频域)                                          (s 域)            │
                                                                           ▼
   [05 Z变换] ◀──ZT 是 LT 在离散上的对应──▶ ────────────────────▶ [06 系统稳定性]
   (z 域, H(z))                                                       (零极点 / 状态方程)
```

- **信号与系统基础（01）** 是所有模块的入口：信号分类、奇异信号、系统四大特性、**LTI** 贯穿全书。
- **时域分析（02）** 在 LTI 前提下引入 **冲激响应** 与 **卷积**，是后续一切变换域方法的物理意义来源。
- **频域（03）/ s 域（04）/ z 域（05）** 是同一套思想的三种「坐标」：
  - FT（03）看频率成分；LT（04）= FT + 衰减因子，能处理不稳定信号；ZT（05）是离散版的 LT。
  - 三者通过 **系统函数** 统一：$H(j\omega)=\mathcal{F}\{h\}$、$H(s)=\mathcal{L}\{h\}$、$H(z)=\mathcal{Z}\{h\}$。
- **系统稳定性（06）** 是收口：用 **零极点位置** 判断稳定（连续：左半 s 平面；离散：单位圆内），并把前五个模块串成「系统函数 → 响应 → 稳定」的完整闭环。

## 二、每张笔记的五个维度（对应你的要求）
1. **知识结构化**：66 张概念卡按 6 大模块分目录；每模块一篇 教程笔记（逻辑递进组织）。
2. **⭐ 重点标注**：每张概念卡的「⭐ 重点标注」段单独拎出核心公式 / 定理 / 必记考点，便于快速定位记忆。
3. **知识关联**：每张卡「关联」段标注 `前置依赖 → 本概念 → 后继`，全库用 `[[双链]]` 成网；本图给出总依赖链。
4. **典型例题**：`30-📝典型例题/` 每模块 3-4 篇，按「题目 / 解题思路 / 详解 / 考点易错」四段，重套路不重死算。
5. **复习要点**：每篇教程末尾「📌 复习要点」是打勾速记清单，考前直接过。

## 三、怎么用这张网
- 学新模块前，先点开它的「前置依赖」链接补课。
- 复习时从 `开始这里` → 模块地图 → 概念卡（只看 ⭐ 段）→ 教程复习要点。
- 做题卡壳 → 跳对应模块的 `典型例题`。

## 阶段一：信号基础（约 1–1.5 周）

### 学习目标
建立「信号—系统—LTI」三位一体的基本概念框架，为后续所有模块铺路。

### 关键学习要点
1. **信号分类五维度**：确定/随机、周期/非周期、连续/离散、实/复、能量/功率。核心判断：连续 vs 离散只看自变量是否连续，不看幅值。
2. **奇异信号三件套**：单位阶跃 $u(t)$（截断/分段）、单位冲激 $\delta(t)$（抽样/筛选）、冲激偶 $\delta'(t)$（瞬时变化率）。必须熟练掌握抽样性质 $\int f(t)\delta(t-t_0)dt=f(t_0)$ 和尺度变换 $\delta(at)=\frac{1}{|a|}\delta(t)$。
3. **信号基本运算**：反转、平移、尺度变换。核心难点 $f(t)\to f(at-b)$ 的两种顺序（先平移后尺度 / 先尺度后平移 $b/a$）。
4. **系统四大特性**：线性（齐次+可加）、时不变性、因果性、稳定性（BIBO）。判断技巧：含 $f^2$、乘积、常数项即非线性。
5. **LTI 系统**：线性 + 时不变的交集，由冲激响应 $h(t)$ 完全表征。这是贯穿全书的「主角」。

### 核心难点
- **冲激函数的工程理解**：它不是普通函数，是广义函数/分布。不要纠结「无穷大」的定义，抓住抽样性质和筛选性质就够了。
- **$f(at-b)$ 变换顺序**：考试最高频的画图题，第二种顺序平移量是 $b/a$ 不是 $b$，极易出错。
- **周期信号判断**：两周期分量之和周期化的条件 $T_1/T_2$ 为有理数，周期 $T=mT_1=kT_2$（取最小公倍数）。

## 阶段二：时域分析（约 1.5–2 周）

### 学习目标
掌握 LTI 系统在时域的完整分析工具链：冲激响应 → 卷积 → 响应分解 → 微分/差分方程求解。

### 关键学习要点
1. **冲激响应 $h(t)$ 与阶跃响应 $g(t)$**：$h(t)$ 是系统对 $\delta(t)$ 的零状态响应，是系统的「身份证」。$g(t)=\int_{-\infty}^{t}h(\tau)d\tau$，$h(t)=g'(t)$。
2. **卷积运算**：
   - 连续：$y_{zs}(t)=f(t)*h(t)=\int_{-\infty}^{\infty}f(\tau)h(t-\tau)d\tau$
   - 离散：$y_{zs}(k)=f(k)*h(k)=\sum_{n=-\infty}^{\infty}f(n)h(k-n)$
   - 卷积是 LTI 系统零状态响应的核心运算，必须掌握图解法（反转→平移→相乘→积分/求和）。
3. **响应分解**（考试重点）：
   - 全响应 = 零输入响应（ZIR）+ 零状态响应（ZSR）
   - 全响应 = 自由响应 + 强迫响应
   - 全响应 = 暂态响应 + 稳态响应
   - 注意：ZIR/ZSR 的分法与自由/强迫的分法是**两套不同的分解视角**，不要混淆。
4. **微分方程与差分方程**：
   - 连续：线性常系数微分方程 → 经典法（齐次解+特解）或卷积法
   - 离散：线性常系数差分方程 → 迭代法或经典法
   - 经典法求解的关键：特征根 → 齐次解形式 → 特解形式 → 初始条件定常数。

### 核心难点
- **卷积的图解法**：反转哪一个是约定的（通常反转 $h$），平移方向（$t$ 从 $-\infty$ 向右扫），分段积分的区间确定是最大失分点。
- **零输入 vs 零状态的物理意义**：零输入 = 只有初始状态（储能）、无外部输入；零状态 = 只有外部输入、无初始储能。两者叠加 = 全响应。
- **初始条件的处理**：微分方程求解时，$0^-$ 到 $0^+$ 的跳变（冲激激励导致）需要用冲激匹配法。

## 阶段三：傅里叶频域分析（约 2–2.5 周）

### 学习目标
建立「时域 ↔ 频域」的变换思维，掌握连续信号的频谱分析工具，理解抽样定理和系统的频率响应。

### 关键学习要点
1. **正交函数集**：傅里叶分析的数学基础。完备正交函数集 $\{e^{jn\omega_0 t}\}$ 是频域展开的「坐标系」。
2. **傅里叶级数（FS）**：
   - 三角型：周期信号展开为直流 + 余弦 + 正弦之和
   - 指数型（更常用）：$f(t)=\sum_{n=-\infty}^{\infty}F_n e^{jn\omega_0 t}$，$F_n=\frac{1}{T}\int_T f(t)e^{-jn\omega_0 t}dt$
   - 周期信号的频谱是**离散谱**。
3. **傅里叶变换（FT）**：
   - 正变换 $F(j\omega)=\int_{-\infty}^{\infty}f(t)e^{-j\omega t}dt$，反变换 $f(t)=\frac{1}{2\pi}\int_{-\infty}^{\infty}F(j\omega)e^{j\omega t}d\omega$
   - 非周期信号的频谱是**连续谱**。
   - FT 性质是考试核心：线性、时移（相位变化）、频移、时域微分（→ $j\omega$ 域）、时域卷积（→ 频域相乘）、对称性、帕塞瓦尔定理。
4. **周期信号的傅里叶变换**：用冲激串表示，$F(j\omega)=2\pi\sum F_n\delta(\omega-n\omega_0)$。周期信号也有 FT，只是频谱是冲激串。
5. **抽样定理（Nyquist）**：抽样频率 $f_s\ge 2f_m$ 才不发生频谱混叠。这是连续→离散的桥梁，也是 DSP 的理论基石。
6. **系统的频率响应 $H(j\omega)$**：$H(j\omega)=\mathcal{F}\{h(t)\}$。$|H(j\omega)|$ 是幅频特性，$\angle H(j\omega)$ 是相频特性。
7. **无失真传输与理想滤波器**：无失真条件 $|H|=K$（常数）、$\angle H=-\omega t_d$（线性相位）。理想低通滤波器是不可物理实现的（非因果）。
8. **离散傅里叶工具**（DFS / DTFT / DFT）：理解三者的关系——DFS 对应周期序列、DTFT 对应非周期序列（连续频率）、DFT 是 DTFT 的频域采样（可计算）。

### 核心难点
- **FT 性质的灵活运用**：很多求变换的题目不靠积分，靠性质（时移+频移+微分+对称性）组合推导。必须熟记性质表。
- **抽样定理的频域理解**：画频谱搬移图是关键——抽样 = 频域周期延拓，恢复 = 低通滤波提取基带频谱。
- **Gibbs 现象**：在跳变点附近，有限项 FS 逼近会出现 ~9% 的过冲，不随项数增加而消失。
- **DTFT 与 DFT 的区别**：DTFT 是连续频率变量 $\omega$，DFT 是离散频率点 $k$。DFT 是为了计算机处理而引入的。
- **常见变换对的记忆**：$\delta(t)\leftrightarrow 1$、$1\leftrightarrow 2\pi\delta(\omega)$、门函数 ↔ Sa 函数、指数衰减 ↔ 一阶有理函数——这些是推导的基础积木。

## 阶段四：拉普拉斯变换（约 1.5–2 周）

### 学习目标
掌握 s 域分析方法，理解拉普拉斯变换如何将微分方程转化为代数方程，能用系统函数 $H(s)$ 分析连续系统。

### 关键学习要点
1. **LT 定义与收敛域（ROC）**：
   - $F(s)=\int_{0}^{\infty}f(t)e^{-st}dt$（单边），$s=\sigma+j\omega$
   - LT = FT + 衰减因子 $e^{-\sigma t}$，能处理 FT 不存在的信号（如发散指数）。
   - ROC 是 LT 存在的区域，不同信号有不同 ROC。**同一 $F(s)$ 配不同 ROC 对应不同信号**——ROC 是 LT 比 FT 多出的关键信息。
2. **单边 vs 双边 LT**：单边 LT 自动纳入初始条件（适合因果系统分析），双边 LT 需要显式标注 ROC。课程以单边 LT 为主。
3. **LT 性质**（与 FT 对照学）：线性、时移、s 域平移、时域微分（$\to s$ 域乘 $s$，带初值项）、时域积分（$\to s$ 域除 $s$）、初值定理、终值定理。
   - **时域微分性质**是 s 域求解微分方程的核心：$\mathcal{L}\{f'(t)\}=sF(s)-f(0^-)$。
4. **系统函数 $H(s)$**：$H(s)=\mathcal{L}\{h(t)\}=\frac{Y_{zs}(s)}{F(s)}$。$H(s)$ 的零极点分布决定系统特性（稳定性、频率响应、暂态/稳态行为）。
5. **s 域电路模型**：电阻 → $R$，电感 → $sL$ + 附加电压源 $Li_L(0^-)$，电容 → $1/(sC)$ + 附加电压源 $u_C(0^-)/s$。把动态电路变为纯电阻电路分析。
6. **微分积分方程的 s 域求解**：微分方程 → s 域代数方程 → 解出 $Y(s)$ → 部分分式展开 → 逆变换得 $y(t)$。初始条件自动通过微分性质纳入。

### 核心难点
- **ROC 的理解**：右边信号 ROC 在最右极点右边，左边信号在最左极点左边，双边信号在两极点之间。ROC 内不能含极点。
- **初值定理与终值定理的使用条件**：终值定理要求 $sF(s)$ 在右半 s 平面及虚轴上无极点（即系统稳定），否则不能用。
- **部分分式展开**：有重根时的处理（$\frac{A}{(s-p)^2}+\frac{B}{s-p}$），共轭复根的处理。
- **$H(s)$ 与 $H(j\omega)$ 的关系**：稳定系统令 $s=j\omega$ 即从 LT 得到 FT/频率响应。不稳定系统不能这样做。

## 阶段五：Z 变换（约 1.5 周）

### 学习目标
掌握离散系统的 z 域分析工具，理解 Z 变换与拉普拉斯变换的对应关系，能用 $H(z)$ 分析离散系统。

### 关键学习要点
1. **ZT 定义**：$F(z)=\sum_{k=0}^{\infty}f(k)z^{-k}$（单边）。ZT 是离散对应 LT——$z=e^{sT}$ 将 s 平面映射到 z 平面。
2. **s 平面到 z 平面映射**：
   - s 左半平面 → z 单位圆内
   - s 虚轴 → z 单位圆上
   - s 右半平面 → z 单位圆外
   - 这是连续稳定性判据（左半平面）与离散稳定性判据（单位圆内）的桥梁。
3. **ZT 性质**（与 LT 对照学）：线性、移位（$\mathcal{Z}\{f(k-1)\}=z^{-1}F(z)+f(-1)$，带初值项）、z 域尺度（$a^k f(k)\to F(z/a)$）、时域卷积 → z 域相乘。
   - **移位性质**是 z 域求解差分方程的核心，类似 LT 的微分性质。
4. **逆 Z 变换**：主要用部分分式展开法（与逆 LT 类似）。也需掌握幂级数展开法（长除法）和留数法。
5. **系统函数 $H(z)$**：$H(z)=\mathcal{Z}\{h(k)\}=\frac{Y_{zs}(z)}{F(z)}$。$H(z)$ 的零极点在 z 平面的位置决定离散系统特性。
6. **差分方程的 z 域求解**：差分方程 → z 域代数方程（用移位性质处理初始条件）→ 解出 $Y(z)$ → 部分分式 → 逆变换。

### 核心难点
- **ROC 与因果性的关系**：因果序列（右边序列）的 ROC 是 $|z|>r$（圆外区域），非因果序列 ROC 是圆内或环域。
- **移位性质中的初值项**：单边 ZT 的移位会带出初始条件项，正移（延迟）和负移（超前）的项数不同，容易漏项。
- **逆 Z 变换的部分分式**：与逆 LT 的区别——ZT 的部分分式通常写成 $\frac{A z}{z-p}$ 形式（多一个 $z$），查表更方便。
- **共轭复极点的逆变换**：对应振荡序列 $\cos\omega_0 k$ 或 $\sin\omega_0 k$。

## 阶段六：系统稳定性与综合（约 1.5–2 周）

### 学习目标
将前五个模块串成闭环：用系统函数的零极点统一分析连续与离散系统的稳定性，掌握信号流图和状态空间描述。

### 关键学习要点
1. **系统函数的零极点**：
   - $H(s)=\frac{N(s)}{D(s)}$，$D(s)=0$ 的根是极点，$N(s)=0$ 的根是零点。
   - 极点决定系统的**稳定性**和**自由响应模式**；零点影响**幅频特性**和**暂态行为**。
2. **稳定性判据**：
   - **连续系统**：所有极点在左半 s 平面 → 稳定。可用 Routh-Hurwitz 判据避免求根。
   - **离散系统**：所有极点在单位圆内 → 稳定。可用 Jury 判据。
   - 稳定性的本质：自由响应随时间衰减 → BIBO 稳定。
3. **频率响应与零极点的几何作图**：$|H(j\omega)|$ 由各零点到 $j\omega$ 的距离之积 / 各极点到 $j\omega$ 的距离之积决定。能定性画出幅频特性曲线。
4. **全通系统与最小相位系统**：
   - 全通系统：$|H(j\omega)|=$ 常数，零极点关于虚轴对称（连续）/ 关于单位圆反演对称（离散）。
   - 最小相位系统：所有零点也在左半平面（连续）/ 单位圆内（离散），幅频给定则相频唯一。
5. **信号流图与梅森公式**：从系统框图/信号流图直接求系统函数 $H=\frac{1}{\Delta}\sum P_k\Delta_k$，其中 $\Delta=1-\sum L_i+\sum L_iL_j-\cdots$（前向通路 × 对应余子式之和）。
6. **状态空间描述**：
   - 状态方程 $\dot{\boldsymbol{x}}=A\boldsymbol{x}+B\boldsymbol{f}$，输出方程 $\boldsymbol{y}=C\boldsymbol{x}+D\boldsymbol{f}$
   - 由微分/差分方程建立状态方程（选状态变量 → 写方程）
   - 由状态方程判稳：连续看 $A$ 的特征值是否都在左半平面；离散看是否都在单位圆内。

### 核心难点
- **梅森公式的正确应用**：找全前向通路和回路不遗漏，判断哪些回路不接触（求余子式 $\Delta_k$ 时去掉与第 $k$ 条前向通路接触的回路）。这是最容易漏项出错的地方。
- **Routh 判据的边界情况**：第一列出现零（用 $\epsilon$ 替代）、整行全零（用上一行构造辅助方程求导）。
- **状态变量的选取**：对于直接型结构，状态变量通常取各延迟器的输出。从微分方程到状态方程的转换需要练习。
- **全通系统与最小相位系统的判别**：要同时看零点和极点位置，不能只看极点。

## 跨模块关联：变换域的统一视角

> 学完六个模块后，回过头看这条「统一链」——这是信号与系统的精髓。

| 维度 | 时域（02） | 频域（03） | s 域（04） | z 域（05） |
|------|-----------|-----------|-----------|-----------|
| **系统表征** | $h(t)$ / $h(k)$ | $H(j\omega)$ | $H(s)$ | $H(z)$ |
| **变换关系** | — | $H(j\omega)=\mathcal{F}\{h\}$ | $H(s)=\mathcal{L}\{h\}$ | $H(z)=\mathcal{Z}\{h\}$ |
| **零状态响应** | 卷积 $f*h$ | 频域相乘 $F\cdot H$ | s 域相乘 $F(s)\cdot H(s)$ | z 域相乘 $F(z)\cdot H(z)$ |
| **稳定性判据** | $\int\|h\|<\infty$ | — | 极点左半平面 | 极点单位圆内 |
| **适用信号** | 任意 LTI | 稳定/能量信号 | 含不稳定信号 | 离散信号 |

**核心洞察**：
- FT 是 LT 在虚轴 $s=j\omega$ 上的特例（仅对稳定系统成立）。
- ZT 是 LT 在离散域的对应，通过 $z=e^{sT}$ 映射。
- 四种变换本质是「同一套卷积运算在不同坐标下的表示」——选哪个取决于信号类型和分析需求。

### 易错点清单（考前必看）
1. $f(at-b)$ 变换：第二种顺序平移量是 $b/a$
2. 卷积图解：分段区间的确定
3. ZIR/ZSR vs 自由/强迫：两套不同的分解，不要混
4. LT 的 ROC：同一 $F(s)$ 不同 ROC = 不同信号
5. 终值定理条件：$sF(s)$ 在右半平面及虚轴无极点
6. ZT 移位：单边 ZT 的移位带初值项，不要漏
7. 梅森公式：找全前向通路和回路，正确判断接触关系
8. 稳定性判据：连续看左半平面，离散看单位圆内，不要搞反

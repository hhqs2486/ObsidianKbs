## 每张卡片含的五个维度
- **知识结构化**：模块目录 + 教程按逻辑递进
- **⭐ 重点标注**：公式 / 定理 / 必记考点单独成段
- **知识关联**：`关联` 段标注「前置依赖 → 本概念 → 后继」，用 `[[双链]]` 成网
- **典型例题**：`30-📝典型例题/` 含题目 + 解题思路 + 详解 + 考点易错
- **复习要点**：教程末尾「📌 复习要点」速记清单

## 推荐 Obsidian 设置
- **公式渲染**：Obsidian 原生支持 MathJax，无需插件；`$...$` 行内、`$$...$$` 独立公式。
- **图谱视图**：按 `tags` 分组着色；`#信号与系统` 看全库，`-tags:#例题` 排除例题。
- **关系图谱**：打开 `50-🗺️索引MOC/开始这里.md` 作为入口。

## 使用建议（小梁同学）
1. 先看 `开始这里.md` 建立全局地图。
2. 按模块读 `10-🧠核心概念/` 卡片，重点看「⭐ 重点标注」。
3. 卡住时跳 `30-📝典型例题/` 看解题套路。
4. 考前用各模块教程的「📌 复习要点」速记。

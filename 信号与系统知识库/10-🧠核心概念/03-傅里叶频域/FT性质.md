# FT性质

## 一句话定义
> 傅里叶变换的一组"运算规则"：信号在时域做某种操作（平移、压缩、微分…），其频谱在频域如何对应变化。它们是**不重新积分就快速求 FT** 的工具箱。

## 它解决什么问题 / 为什么存在
- 直接套定义积分求 FT 很累。性质让我们用少数几个基本变换对（见 [[傅里叶变换(FT)]]）组合推出复杂信号的频谱。
- 也是分析系统时移、尺度、调制、[[抽样定理]]、[[无失真传输]] 的理论依据。

## 核心原理（大二能懂的水平）
设 $f(t)\leftrightarrow F(j\omega)$，各性质如下（全部用 $f(t)\leftrightarrow F(j\omega)$ 记法）：

| 性质 | 时域 | 频域 |
|---|---|---|
| 线性 | $a f_1+b f_2$ | $aF_1+bF_2$ |
| 时移 | $f(t-t_0)$ | $e^{-j\omega t_0}F(j\omega)$ |
| 频移 | $f(t)e^{j\omega_0 t}$ | $F(j(\omega-\omega_0))$ |
| 尺度变换 | $f(at)$ | $\dfrac{1}{|a|}F\!\left(j\dfrac{\omega}{a}\right)$ |
| 对称性 | $F(t)$ | $2\pi f(-\omega)$ |
| 时域微分 | $f'(t)$ | $j\omega F(j\omega)$ |
| 时域积分 | $\int_{-\infty}^t f(\tau)d\tau$ | $\dfrac{F(j\omega)}{j\omega}+\pi F(0)\delta(\omega)$ |
| 频域微分 | $j t f(t)$ | $\dfrac{dF(j\omega)}{d\omega}$ |
| 卷积定理 | $f_1*f_2$ | $F_1(j\omega)F_2(j\omega)$ |
| 乘积定理 | $f_1(t)f_2(t)$ | $\dfrac{1}{2\pi}F_1*F_2$ |
| 奇偶虚实 | 实信号→$F(-\omega)=F^*(\omega)$ | 幅度偶、相位奇 |

- **尺度变换的物理直觉**：时域压缩 $a>1$（信号变窄）→ 频域扩展、幅度变小；"窄脉冲，宽频谱"。
- **时移只改相位**：时移 $t_0$ 仅在频域乘 $e^{-j\omega t_0}$，幅度谱不变、相位谱线性加 $-\omega t_0$（真题常考）。
- **卷积定理**：时域卷积 = 频域相乘，是 [[LTI系统]] 频域分析的核心（输出频谱 = 输入 × [[频率响应]]）。

## ⭐ 重点标注（公式 / 定理 / 必记考点）
### 核心公式
- 时移：$f(t-t_0)\leftrightarrow e^{-j\omega t_0}F(j\omega)$
- 尺度：$f(at)\leftrightarrow \dfrac{1}{|a|}F(j\omega/a)$
- 对称：$F(t)\leftrightarrow 2\pi f(-\omega)$
- 时域微分：$f^{(n)}(t)\leftrightarrow (j\omega)^n F(j\omega)$
- 卷积：$f_1*f_2\leftrightarrow F_1 F_2$；乘积：$f_1 f_2\leftrightarrow \dfrac{1}{2\pi}F_1*F_2$

### 重要定理 / 结论
- 频域卷积定理（乘积→频域卷积）是**调制/抽样**的数学基础：$\cos\omega_c t$ 乘信号 = 频谱左右搬移 $\pm\omega_c$。
- 奇偶虚实性：实信号频谱共轭对称，可只算 $\omega\ge0$ 一半。

### 必记考点
- 时移**只动相位不动幅度**；尺度变换**时频互易、此消彼长**。
- 对称性质 $F(t)\leftrightarrow 2\pi f(-\omega)$ 常配合"门↔Sa"使用（如求 $\mathrm{Sa}$ 的 FT）。
- 卷积定理把微分方程频域化：时域微分 $f'\leftrightarrow j\omega F$ 让微分变乘法。

## 关键参数 / 易错点
- 尺度变换的 $1/|a|$ 系数和 $\omega/a$ 里的绝对值易漏；反转 $a=-1$ 也带 $1/|a|=1$ 但 $\omega\to-\omega$。
- 时移与尺度**次序**：先尺度后时移 vs 先时移后尺度结果不同（$f(at-b)$ 与 $f(a(t-b))$ 不一样）。
- 时域积分公式里的 $\pi F(0)\delta(\omega)$ 项常漏（仅当 $F(0)\neq0$ 时存在）。

## 类比（帮助理解）
- 性质像"翻译词典"：时域说"我把信号往右挪 1 秒"，频域词典立刻翻成"相位加一条斜线"；时域说"我把信号压扁一半"，频域翻成"频谱拉宽一倍"。

# 自由响应

## 一句话定义
> 全响应按"齐次解 + 特解"划分时的两部分：自由响应 = 齐次方程通解部分（由系统固有特性决定，形式由特征根定），强迫响应 = 特解部分（由激励形式决定）。

## 它解决什么问题 / 为什么存在
- 帮助学生区分"两种分解视角"：① 自由+强迫（按解的数学结构）；② 零输入+零状态（按激励是否参与）。两者不是一回事，常考易混。

## 核心原理（大二能懂的水平）
- 全响应 $y(t)=y_{zi}(t)+y_{zs}(t)$（按起因）。
- 同时 $y(t)=y_h(t)+y_p(t)$，其中 $y_h$=自由响应（齐次解，形式由特征根定），$y_p$=强迫响应（与激励同形）。
- 关系：零输入响应必属自由响应；零状态响应一般同时含自由响应部分与强迫响应部分（除非初始静止）。

## ⭐ 重点标注（公式 / 定理 / 必记考点）
### 核心公式
- 分解一：$y = y_{zi} + y_{zs}$
- 分解二：$y = y_{自由} + y_{强迫} = y_h + y_p$

### 重要定理 / 结论
- 自由响应与零输入响应形式相同（都是齐次解），但系数不同：自由响应系数由"全初始条件 + 激励"共同决定；零输入响应系数只由初始状态决定。

### 必记考点
- 考题常问"自由响应是否等于零输入响应"——答：不等；自由响应 = 零输入响应 + 零状态中的齐次解部分。

## 关键参数 / 易错点
- 易错：把"自由响应"与"零输入响应"画等号。

## 类比（帮助理解）
- 一笔钱 = 本金(零输入) + 劳动收入(零状态)；也可 = 现金(自由) + 存款(强迫)。两种切法不同。

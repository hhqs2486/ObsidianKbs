# 全响应

## 一句话定义
> 系统在**输入激励**与**初始状态**共同作用下产生的响应，等于零输入响应与零状态响应之和：
> $$y(t)=y_{zi}(t)+y_{zs}(t)\qquad\bigl(\text{离散 }y(k)=y_{zi}(k)+y_{zs}(k)\bigr)$$

## 它解决什么问题 / 为什么存在
- 实际系统既有"初始储能"又有"外部输入"，全响应用来把两者合起来描述真实输出。
- 同一个全响应可以有两种**正交**的分解视角，这是本章最容易混淆、也最值得建立的工程思维：
  1. **按起因分**：全响应 = 零输入响应 + 零状态响应（[[零输入响应]] + [[零状态响应]]）
  2. **按函数形式分**：全响应 = 自由响应（齐次解 $y_h$）+ 强迫响应（特解 $y_p$）

## 核心原理（大二能懂的水平）
- 线性系统的叠加性直接给出 $y=y_{zi}+y_{zs}$。
- 注意这两套分解**不是一一对应**的：
  - 零输入响应 $y_{zi}$ 全部属于自由响应；
  - 零状态响应 $y_{zs}$ = 一部分自由响应 + 全部强迫响应（特解）。
  - 所以：**自由响应 = 零输入响应 +（零状态里的自由部分）**；**强迫响应 = 零状态里的特解部分**。
- 还可细分：稳态响应（最终趋于常值/等幅）与暂态响应（随时间衰减的部分）。

## ⭐ 重点标注（公式 / 定理 / 必记考点）
### 核心公式
- 全响应：$y(t)=y_{zi}(t)+y_{zs}(t)$
- 形式分解：$y(t)=y_h(t)+y_p(t)$（自由响应 + 强迫响应）
- 关系：自由响应 $=y_{zi}+y_{zs}$中的齐次部分；强迫响应 $=y_p$

### 重要定理 / 结论
- 零输入响应 ⊆ 自由响应；零状态响应 = 部分自由响应 + 强迫响应。
- 暂态响应：特征根实部 $<0$（连续）/ $|\lambda|<1$（离散）对应的指数衰减项；稳态响应：其余（特解及临界/等幅项）。

### 必记考点
- 给全响应波形/表达式，要能指出"哪部分对应零输入、哪部分对应零状态、哪部分是自由/强迫"——选择题常考。
- "经典法"（齐次解+特解）与"一般法"（零输入+零状态）算出的**系数不同**，但最终的 $y(t)$ 完全一样。

## 关键参数 / 易错点
- **易错（高频）**：以为"齐次解 = 零输入响应"。错！齐次解横跨零输入和零状态两部分，只有单独在零输入条件下解出的才叫零输入响应。
- **易错**：把全响应直接当成特解+零输入——应为 $y_{zi}+y_{zs}$，而 $y_{zs}$ 本身含自由部分。
- **易错**：稳态/暂态的划分依据是特征根是否衰减，不是看"有没有输入"。

## 类比（帮助理解）
- 一盆水：初始就有的水量 = 零输入响应；你后来倒进去的水 = 零状态响应；两者加起来 = 全响应。另一方面，水最终会蒸发/稳定的那部分 vs 一直被你搅动维持的那部分，就是暂态/稳态的视角——两种切法互不冲突。

# 频率响应与零极点

## 一句话定义
> 对**因果稳定**系统，令 $s=j\omega$（连续）或 $z=e^{j\theta}$（离散），系统函数就变成**频率响应** $H(j\omega)$ 或 $H(e^{j\theta})$。零极点图提供了一种不用算就能"看"出幅频/相频形状的**矢量图解法**——本卡把 [[频率响应]]（由 03 模块定义）和 [[零极点]] 连起来。

## 它解决什么问题 / 为什么存在
- 给了 $H(s)$/$H(z)$，不必逐点代公式画频响曲线：沿着虚轴（$s=j\omega$）或单位圆（$z=e^{j\theta}$）走一圈，看零极点"矢量"怎么变，立刻知道这是低通/高通/带通/带阻，以及哪个频率有谐振峰、哪个频率被陷波。
- 这是"从需求反推原理"的典型：想做带通滤波器？把一对共轭极点摆在想要的中心频率附近（靠近虚轴），再在不需要的频率放零点。

## 核心原理（大二能懂的水平）
- **存在条件**：频率响应存在 ⇔ ROC 包含虚轴（连续）或单位圆（离散）。所以对因果系统，这等价于系统稳定（极点全在左半平面/单位圆内）。若 ROC 不含虚轴/单位圆（如不稳定系统），则"频率响应"不存在。
- **矢量图解法**（连续为例）：
  把 $H(s)=K\dfrac{\prod(s-z_j)}{\prod(s-p_i)}$ 中的 $s$ 换成 $j\omega$，每个因子 $j\omega-z_j$（或 $j\omega-p_i$）是从零点/极点指向虚轴上点 $j\omega$ 的**矢量**。
  $$|H(j\omega)|=K\frac{\prod|j\omega-z_j|}{\prod|j\omega-p_i|},\quad \arg H(j\omega)=\sum\arg(j\omega-z_j)-\sum\arg(j\omega-p_i)$$
  - 当 $\omega$ 逼近某极点 → 该极点矢量长度趋于 0 → $|H|$ **出现峰值**（谐振/通带中心）。
  - 当 $\omega$ 逼近某零点 → 该零点矢量长度趋于 0 → $|H|$ **出现谷值**（陷波/阻带）。
- **滤波特性速判**：
  - $\omega=0$ 时 $|H|$ 大、$\omega\to\infty$ 时 $|H|\to0$ ⇒ **低通**；
  - 反过来 ⇒ **高通**；
  - $\omega=0$ 与 $\omega\to\infty$ 都小、中间某处大 ⇒ **带通**；
  - 中间有谷、两端高 ⇒ **带阻**。
- 类比：把虚轴/单位圆想成一条"扫描轨道"，零极点是轨道旁的磁铁——靠近极点被吸（增益放大），靠近零点被推（增益压低）。沿轨道走一遍，增益起伏就是幅频曲线。

## ⭐ 重点标注（公式 / 定理 / 必记考点）
### 核心公式
- 连续：$H(j\omega)=H(s)\big|_{s=j\omega}$；离散：$H(e^{j\theta})=H(z)\big|_{z=e^{j\theta}}$。
- 矢量式：
  $$|H(j\omega)|=K\frac{\prod|j\omega-z_j|}{\prod|j\omega-p_i|}$$
- 存在条件：ROC 含虚轴（连续）/单位圆（离散）⇔ 因果稳定。

### 重要定理 / 结论
- 极点靠近虚轴/单位圆 ⇒ 该频率附近幅频出现**峰**（品质因数越高峰越尖）。
- 零点靠近虚轴/单位圆 ⇒ 该频率附近幅频出现**谷**（陷波）。
- 二阶系统谐振峰出现在极点虚部附近频率。

### 必记考点
- 先判稳定（ROC 含虚轴/单位圆）再谈频率响应——不稳定系统无频率响应。
- "$\omega$ 从 0 到 $\infty$ 扫一遍，看 $|H|$ 从大到小/从小到大/中间凸起"三步即可判滤波类型。
- 离散域扫的是单位圆 $z=e^{j\theta}$，$\theta$ 从 $0$ 到 $2\pi$（或 $-\pi$ 到 $\pi$）。

## 关键参数 / 易错点
- **易错：不稳定系统也谈频率响应**。若极点不在左半平面/单位圆内，ROC 不含虚轴/单位圆，$H(j\omega)$ 无定义。
- **易错：把"极点在虚轴上"当成有峰**。虚轴上一阶极点对应等幅振荡（临界稳定），不是普通谐振峰；且此时系统本身不稳定。
- **易错：连续用 $j\omega$、离散用 $e^{j\theta}$ 别混**；离散幅频是关于 $\theta$ 周期的（$2\pi$ 周期）。

## 类比（帮助理解）
- 频率响应是系统对"不同频率纯音"的放大/衰减表。零极点图是这张表的"速读地图"：轨道（虚轴/单位圆）上哪段离极点近就放大、离零点近就压低，扫完一圈频响曲线自然浮现。

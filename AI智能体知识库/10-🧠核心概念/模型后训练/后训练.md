# 后训练

## 一句话定义
> 后训练（Post-training）是在预训练之后，通过 SFT 与 RL 等手段进一步调整模型权重，把"指令遵循、输出格式、交互策略"等能力沉淀进参数——本质是"把交互策略写入参数"。

## 它解决什么问题 / 为什么存在
- 预训练只让模型"博学"（会续写文本），但不会按指令回答、不会用工具、不会在陌生场景做决策。后训练解决"让模型真正好用、能 Agent 化"的问题。
- 与不改权重的[[自我进化]]（外部化学习）、[[Prompt]]（上下文学习 ICL）互补，三者是 Agent 能力的三个可调"旋钮"。

## 核心原理（大二电子信息工程专业学生能懂）
- 现代模型能力分三阶段炼成（流水线，非三选一）：
  1. 预训练：海量文本上"预测下一个词"，学语言规律与世界知识（最贵，数百万~数千万美元）。
  2. SFT：几千~几万条"输入-输出"示范，教格式/风格/流程协议（便宜、快、稳）。（见[[SFT]]）
  3. RL：无标准答案，让模型自己试、按奖惩调高/调低行为概率，学可迁移策略（最贵，常为 SFT 的几十~上百倍）。（见[[PPO]]、[[RLHF]]、[[DPO]]）
- 两条贯穿主线：
  1. SFT 记忆，RL 泛化（可测量现象）。
  2. 数据和环境比算法更重要——很多场景只要 SFT 数据质量到位，根本不需要 RL。
- 协同范式："先形后神"——SFT 到"格式稳定、能力初具"即止，RL 再塑形策略；SFT 过度训练会让模型塌缩到训练分布，限制 RL 空间。

## 关键参数 / 易错点
- 顺序：通常先 SFT 后 RL（否则输出无结构、奖励无法计算）；足够强的基础模型可跳过 SFT 直接 RL（如 DeepSeek-R1-Zero）。
- 后训练难记大量事实性知识——那应交给[[RAG]]或继续预训练。
- 常见陷阱：用后训练记事实、格式未稳就上 RL、奖励函数致奖励黑客、忽视仿真保真度、低估 RL 成本。

## 类比（帮助理解）
- 像人成长：预训练=读万卷书，SFT=老师手把手教标准解法，RL=自己下场做题反复打磨。
- 像练肌肉记忆：把"该怎么做"固化进参数，比每次靠提示词临时教更稳。

## 设计时怎么用（反推思维）
> 提升 Agent 时，我会先问是否需后训练；若需，先试 SFT 固化格式，新场景泛化不足再加 RL，并把精力放在数据与环境质量而非算法选型。

## 典型应用 / 我在哪见过
- ChatGPT/Claude 的指令对齐、Coding 模型训练、思维链蒸馏（见[[模型蒸馏]]）、工具调用 RL（ReTool/AWorld-train）。

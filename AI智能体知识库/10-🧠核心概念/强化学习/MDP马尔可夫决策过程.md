# MDP 马尔可夫决策过程

## 一句话定义
> MDP 是五个对象 (S, A, P, R, γ)——状态、动作、转移、奖励、折扣。RL 的一切（Q-learning、PPO、GRPO）都在这个框架上优化。

## 它解决什么问题 / 为什么存在
- 监督学习给你 (x, y) 对，RL 只给你状态流、动作流和标量奖励——没有标签
- 下棋、库存管理、交易、LLM 训练，四个领域归结为同一个数学对象
- 必须把"看到了什么、做了什么、发生了什么、好不好"形式化，才能从中学习
- MDP 就是这个形式化：每个 RL 算法（包括 RLHF/GRPO）都在这个形状上优化

## 核心原理（大二能懂的水平）
- **五个对象**：
  - 状态 S：agent 决策所需的一切信息。GridWorld 是格子，棋是棋盘，LLM 是上下文窗口
  - 动作 A：可选的选择。上下左右、落子、生成 token
  - 转移 P(s'|s,a)：给定状态 s 和动作 a，下一状态的概率分布。棋是确定性的，库存是随机的
  - 奖励 R(s,a,s')：标量信号。赢=+1，输=-1，收入-成本
  - 折扣 γ∈[0,1)：未来奖励的权重。γ=0.99→有效视野~100步，γ=0.9→~10步
- **Markov 性质**：P(s_{t+1}|s_t,a_t) = P(s_{t+1}|s_0,a_0,...,s_t,a_t)。未来只依赖当前状态。如果不满足，说明状态表示不完整
- **策略与回报**：π(a|s) 把状态映射到动作分布；回报 G_t = r_t + γr_{t+1} + γ²r_{t+2} + ...
- **值函数**：V^π(s) = E[G_t|s_t=s]；Q 值 Q^π(s,a) = E[G_t|s_t=s,a_t=a]
- **Bellman 方程**：V^π(s) = Σ_a π(a|s) Σ_{s',r} P(s',r|s,a)[r + γV^π(s')]。把期望回报拆成"本步奖励 + 折扣后的下一状态值"

## 关键参数 / 易错点
- **γ 的物理意义**：有效视野 ≈ 1/(1-γ)。γ=0.9→10步，γ=0.99→100步，γ=0.999→1000步
- **γ 太低**：agent 短视；**γ 太高**：信用分配噪声大（很多早期步骤分担远期奖励的责任）
- **LLM RLHF 通常用 γ=1**：因为 episode 短且有界（~200 token）；控制任务用 0.95-0.99；策略游戏用 0.999
- **非 Markov 状态**：如果需要最近三帧观测才能决策，单个观测不是完整状态。修复：帧堆叠（DQN Atari 堆 4 帧）或 RNN
- **稀疏奖励**：只有胜负奖励时大状态空间几乎学不动。修复：奖励塑形或模仿学习引导
- **奖励尺度**：{+100,-100} 和 {+1,-1} 给出相同最优策略但梯度幅度差 100 倍。归一化到 [-1,1]
- **γ=1 + 无限视野**：所有值变成无穷大。必须用有限视野或 γ<1

## 类比（帮助理解）
- MDP 就像"旅行规划"：状态是你当前所在城市，动作是可选的交通工具，转移是"坐这班车到哪"的概率，奖励是"这趟旅程赚了多少钱"，γ 是"你有多在乎明天的钱 vs 今天的钱"
- Bellman 方程就像"递归拆分"：这条路好不好 = 这一段的体验 + 折扣后剩余路程的期望质量
- Markov 性质就像"马尔可夫链的记性"：只看当前状态就够，不需要回忆历史——如果不够，说明你的"状态"定义得不对

## 设计时怎么用（反推思维）
> 先在纸上写出五元组 (S, A, P, R, γ) 再写训练循环。大部分"RL 不 work"的 bug 都追溯到 MDP 建模本身有问题：状态不完整、奖励被代理指标污染、γ 设错。LLM RL 中：状态=上下文 token，动作=下一个 token，奖励=验证器打分，γ=1（短 episode）。

## 典型应用 / 我在哪见过
- GridWorld 4×4：agent 从左上到右下，每步 -1，最优回报 -6
- 棋类：状态=棋盘，动作=合法走子，奖励=胜负，γ=1（有限局）
- RLHF for LLMs：状态=上下文 token，动作=下一 token，奖励=奖励模型打分，γ=1
- GRPO for reasoning：状态=提示+部分回答，动作=下一 token，奖励=验证器 0/1

# 深度 Q 网络 DQN

## 一句话定义
> Q-learning + 神经网络 + 经验回放 + 目标网络。2013 年 Atari、2015 年 Nature。三个 trick 让函数逼近在 off-policy RL 中稳定，开启了深度 RL 时代。

## 它解决什么问题 / 为什么存在
- 表格 Q-learning 需要 (state, action) 的独立 Q 值。棋盘 ~10⁴³ 状态，Atari 帧 100800 特征——表格法在几千状态就死了
- 用神经网络 Q(s,a;θ) 替换 Q 表很直观，但朴素做法在"致命三体"下发散：函数逼近 + Bootstrap + off-policy
- Mnih et al. (2013, 2015) 三个 trick 稳定训练：经验回放去相关、目标网络冻结 Bootstrap 目标、奖励裁剪归一化梯度
- DQN 是第一个用单一架构+单一超参数从原始像素解决几十个控制问题的深度 RL 方法

## 核心原理（大二能懂的水平）
- **目标函数**：L(θ) = E_{(s,a,r,s')~D}[(r + γ·max_{a'} Q(s',a';θ⁻) - Q(s,a;θ))²]
  - θ = 在线网络，每步梯度下降更新
  - θ⁻ = 目标网络，定期从 θ 复制（~10000 步）
  - D = 经验回放缓冲区
- **经验回放**：~10⁶ 转移的环形缓冲。每步随机采样 mini-batch。打破时间相关性（连续帧几乎相同），让罕见奖励转移被多次学习
- **目标网络**：两侧用同一个 Q(·;θ) 会让目标每次更新都动——"追自己尾巴"。用冻结的 θ⁻ 稳定回归目标。软更新 θ⁻←τθ+(1-τ)θ⁻ 是更平滑的变体
- **奖励裁剪**：Atari 奖励幅度 1~1000+。裁剪到 {-1,0,+1} 防止单个游戏主导梯度。仅当奖励幅度不重要时合理
- **Double DQN**：用在线网络选动作、目标网络评估。target = r + γ·Q(s', argmax_{a'} Q(s',a';θ); θ⁻)。消除 max 偏差，默认用
- **Rainbow（2017）**：优先回放（高 TD 误差采样更多）+ Dueling 架构（V 和 advantage 分离头）+ 噪声网络（学习探索）+ n-step + 分布式 Q（C51/QR-DQN）。增益大致可加

## 关键参数 / 易错点
- **致命三体**：函数逼近 + Bootstrap + off-policy 可能发散。DQN 用目标网络+回放缓解，不要去掉任何一个
- **ε 衰减**：从 1.0 衰减到 0.01，通常在前 10% 训练。早期探索不够 Q 网络收敛到局部盆地
- **过估计**：max over noisy Q 向上偏。生产环境永远用 Double DQN
- **回放缓冲冷启动**：缓冲区有几千条转移前不要训练。20 条样本上梯度会过拟合
- **目标同步频率**：太频繁≈没目标网络；太稀疏≈过时目标。Atari DQN 用 10000 步。经验法则：训练 horizon 的 1/100
- **观测预处理**：Atari DQN 堆 4 帧使状态 Markov。任何有速度信息的环境需要帧堆叠或 RNN

## 类比（帮助理解）
- 经验回放就像"错题本"：做题（与环境交互）时把每道题记下来，学习时随机翻看——而不是按顺序看，这样学得更牢
- 目标网络就像"考试用旧教材"：答案（目标）暂时固定，不会因为你刚学了一点新东西就变——给你足够时间学透
- 致命三体就像"三股绳子合在一起才断"：函数逼近、Bootstrap、off-policy 单独都有理论保证，三者组合就没有了

## 设计时怎么用（反推思维）
> 离散动作的 Atari 类任务用 Rainbow DQN。连续动作用 SAC/TD3（DQN 没有策略网络）。on-policy/高吞吐量用 PPO。LLM RL 用 PPO/GRPO（序列级非步级）。回放和目标网络的思想出现在 SAC、TD3、AlphaZero 自对弈缓冲中。奖励裁剪演变为 PPO 的优势归一化。

## 典型应用 / 我在哪见过
- Atari 2013/2015：49 游戏单一架构+超参数
- 推荐系统：大离散动作空间 + 动作嵌入
- Rainbow：六个 trick 叠加，每个加几个百分点
- 离线 RL：CQL/IQL = 保守 Q 目标

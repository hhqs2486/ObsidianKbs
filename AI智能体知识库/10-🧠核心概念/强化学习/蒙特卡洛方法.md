# 蒙特卡洛方法

## 一句话定义
> 不需要模型，不需要 Bootstrap——只需要跑完整个 episode，算回报，取平均。最简单的 RL 思想，也是所有后续算法的基石。

## 它解决什么问题 / 为什么存在
- DP 需要查询 P(s'|s,a)，现实世界做不到：机器人不能算出关节力矩后相机像素的分布
- MC 只需要能从环境采样：跑策略→得到轨迹→用回报估计值
- 从 DP 到 MC 的哲学转变：已知模型+精确备份 → 采样 rollout+平均回报
- 方差飙升，但适用性爆炸。之后的 TD、Q-learning、REINFORCE、PPO、GRPO 本质都是 MC 估计器（有时加 Bootstrap）

## 核心原理（大二能懂的水平）
- **核心公式**：V^π(s) = E_π[G_t|s_t=s] ≈ (1/N) Σ G^(i)(s)。多次访问状态 s，平均回报就是值估计
- **first-visit vs every-visit**：
  - first-visit：一个 episode 中只计第一次访问 s 的回报。样本 iid，易分析
  - every-visit：每次访问都计。用更多数据，实践中收敛更快
  - 两者极限下无偏
- **增量均值**：V_new = V_old + α·(G - V_old)。α=1/n 是理论收敛；换成常数 α∈(0,1) 就能跟踪非平稳策略
- **探索问题**：DP 靠枚举覆盖所有状态，MC 只看到策略访问的状态。三种修复：
  1. 探索起始（exploring starts）：每 episode 随机起点。不现实
  2. ε-greedy：以概率 ε 随机动作，否则贪心。标准方案
  3. off-policy MC：用行为策略 μ 收集数据，用重要性采样学习目标策略 π
- **MC 控制**：评估→改进→评估（类似策略迭代），但评估是采样式的：跑 episode → 更新 Q → ε-greedy → 重复

## 关键参数 / 易错点
- **必须 episode 终止**：MC 等到 episode 结束才能更新。如果策略可能无限循环，必须设 max_steps 上限
- **方差大**：完整回报在长 episode 上方差极大——一个 unlucky 的末期奖励会大幅移动 V(s_0)。TD 方法通过 Bootstrap 降低方差
- **状态覆盖**：贪心 MC 在 Q 值有平局时只试一个动作。必须探索（ε-greedy、UCB）
- **非平稳策略**：MC 控制中 π 在变，旧回报来自不同策略。常数 α 处理这个；样本均值不行
- **重要性采样方差爆炸**：off-policy 中 π(a|s)/μ(a|s) 乘积随步数增长，方差随 horizon 爆炸。用 per-decision weighted IS 或切换到 TD

## 类比（帮助理解）
- MC 就像"看完整场比赛再评价"：不看实时比分，等比赛结束看最终得分，多看几场取平均就是这个策略的水平
- first-visit vs every-visit 就像"统计学生成绩"：first-visit 只计第一次考试，every-visit 每次考试都算——后者数据更多但有轻微偏差
- ε-greedy 就像"偶尔尝鲜"：大部分时间选最好的餐厅，偶尔随机试一家新的，免得错过更好的

## 设计时怎么用（反推思维）
> 短 horizon 游戏（blackjack、poker）用 MC——episode 自然终止，回报干净。LLM RL 评估用 MC：对给定 prompt 采样多个 completion 取平均奖励。PPO 的优势估计 A_t = G_t - V(s_t) 用的就是 MC 的 G_t。纯 MC 和纯 TD 之间用 n-step 或 GAE 插值。

## 典型应用 / 我在哪见过
- Blackjack/poker：episode 自然终止，回报干净
- MCTS（AlphaZero）：从树叶子做 MC rollout 引导选择
- LLM RL 评估：对给定策略采样多个 completion 算平均奖励
- PPO baseline 估计：A_t = G_t - V(s_t) 中的 G_t 就是 MC 回报

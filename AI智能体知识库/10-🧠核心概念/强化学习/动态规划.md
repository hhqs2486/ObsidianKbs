# 动态规划

## 一句话定义
> 已知 MDP 模型时，迭代 Bellman 方程直到 V 或 π 不再变化。策略迭代交替评估和改进；值迭代一步搞定。是所有采样方法的正确性基准。

## 它解决什么问题 / 为什么存在
- DP 假设你可以查询 P(s'|s,a) 和 R(s,a,s')——你知道环境模型
- 库存管理者知道需求分布，棋的转移是确定的，GridWorld 是四行 Python
- 无模型 RL（Q-learning、PPO、REINFORCE）是为不知道模型的情况发明的
- 但当你有模型时，DP 更快更准：Bellman 1957 年设计，至今定义"最优策略"的含义
- 2026 年用途：(1) 小型表格环境的金标准解，(2) 调试采样方法（Q-learning 偏差 30% 就有 bug），(3) MCTS/AlphaZero 的搜索内循环

## 核心原理（大二能懂的水平）
- **策略迭代**：交替两步直到策略不变
  1. 评估：给定 π，反复应用 V(s) ← Σ_a π(a|s) Σ P(s',r|s,a)[r + γV(s')] 直到收敛
  2. 改进：π(s) ← argmax_a Σ P(s',r|s,a)[r + γV(s')]，对 V 贪心
  - 收敛保证：每次改进要么 π 不变要么 V^π 严格增加；确定性策略空间有限。通常 5-20 次外循环
- **值迭代**：把评估和改进合并成一步扫描
  - V(s) ← max_a Σ P(s',r|s,a)[r + γV(s')]
  - 重复直到 max_s|V_new(s)-V(s)| < ε，最后提取贪心策略
  - 每次迭代更便宜（无内循环），但通常需要更多次迭代
- **广义策略迭代（GPI）**：统一框架。值函数和策略在双向改进循环中互相靠近。异步值迭代、Q-learning、Actor-Critic、PPO 都是 GPI 的实例
- **γ-压缩映射**：Bellman 算子是 sup 范数下的 γ-压缩：||TV-TV'||∞ ≤ γ||V-V'||∞。压缩→唯一不动点→几何收敛。去掉 γ<1 就失去保证

## 关键参数 / 易错点
- **策略迭代 vs 值迭代**：策略迭代外循环少（5-20）但每次内评估贵；值迭代每次扫描 O(|S|·|A|) 但需要更多次（常 100+）
- **处理终止状态**：吸收状态必须 V[s]=0，否则 Bellman 会给它选"最优动作"导致振荡
- **sup 范数收敛**：用 max|V_new-V| 不是平均值。理论保证在 sup 范数上
- **原地更新 vs 同步更新**：原地（Gauss-Seidel）比同步（Jacobi）收敛快，生产代码用原地
- **策略平局**：两个动作 Q 值相等时 argmax 可能每次打破平局方式不同→策略稳定检查振荡。用固定顺序的稳定 tie-break
- **状态空间爆炸**：DP 是 O(|S|·|A|) 每次扫描，~10⁷ 状态以上不可行，需要函数逼近

## 类比（帮助理解）
- 策略迭代就像"先考试再改学习方法"：先按当前策略算出每步成绩（评估），再根据成绩改成更优策略（改进），反复直到策略不变
- 值迭代就像"一步到位"：不管策略是什么，直接问"每个状态下哪个动作最好"，反复更新直到答案稳定
- γ-压缩就像"弹簧阻尼"：每步误差乘以 γ 缩小，γ<1 保证最终收敛到唯一解

## 设计时怎么用（反推思维）
> 小型 MDP 用值迭代（更简单）或策略迭代（外循环少）。调试 Q-learning/PPO 实现时，先跑 DP 得到 V*，再比较学习到的 V 偏差。AlphaZero/MCTS 的搜索本质上是异步 Bellman 备份。论文里的 V* 或 Q* 就是 DP 不动点。

## 典型应用 / 我在哪见过
- GridWorld 4×4：值迭代收敛 V*(0,0)≈-6，策略沿对角线走
- AlphaZero/MuZero：MCTS = 异步 Bellman 备份在学习/已知模型上
- 离线 RL（CQL/IQL）：保守 Q-迭代——带 OOD 动作惩罚的 DP
- 模型 RL：在学习到的转移模型上做 Bellman 备份

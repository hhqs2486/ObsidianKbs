# 多智能体强化学习

## 一句话定义
> 单智能体假设环境平稳。两个学习 agent 放一起，这个假设就碎了——每个 agent 是对方环境的一部分，都在变。MARL 是让学习在 Markov 假设不再成立时收敛的一组 trick。

## 它解决什么问题 / 为什么存在
- 单 agent 导航房间是单智能体问题。足球队不是。AlphaStar vs StarCraft 不是。市场竞价不是。四向停车两辆车不是
- 从任一 agent 视角，其他 agent 是环境的一部分。他们学习变化时，环境变非平稳
- Markov 性质——"下一状态只依赖当前状态和我的动作"——被违反，因为下一状态还依赖其他 agent 的选择
- 这破坏了 Q-learning 的收敛保证（假设平稳环境），也破坏了朴素深度 RL（agent 互相追逐成环）
- 2026 应用：机器人集群、交通路由、自动驾驶车队、市场模拟器、多 agent LLM 系统

## 核心原理（大二能懂的水平）
- **形式化：Markov Game**。MDP 的推广：状态 S、联合动作 a=(a_1,...,a_n)、转移 P(s'|s,a)、每 agent 奖励 R_i(s,a,s')
- **核心挑战**：
  - 非平稳性：P(s'|s,a_i) 依赖 π_{-i}（其他 agent 策略），它们在变
  - 信用分配：共享奖励时谁贡献了？
  - 探索协调：agent 要探索互补策略不是冗余探索同状态
  - 联合动作空间随 n 指数增长
- **四大范式**：
  1. **独立 Q-learning / IPPO**：每个 agent 独立学习自己的 Q/策略，把其他 agent 当环境。简单，松耦合任务可用，紧耦合失败
  2. **CTDE（集中训练分散执行）**：2026 合作 MARL 主流。执行时每个 agent 只用局部观测 o_i；训练时用集中 critic Q(s,a_1,...,a_n) 看全局
     - MADDPG：DDPG + 每 agent 一个集中 critic
     - COMA：反事实 baseline——"如果我选 a' 会怎样"——隔离我的贡献
     - MAPPO/IPPO with shared critic：PPO + 集中值函数
     - QMIX：值分解 Q_tot = f(Q_1,...,Q_n)，单调混合保证分散 argmax 一致
  3. **Self-play**：同一 agent 的两个副本对弈。对手=过去的自己。AlphaGo/AlphaZero/MuZero。零和博弈最优
  4. **League play**：self-play 的推广，保持过去+当前策略池，采样对手。加 exploiter（专攻当前最强）和 main exploiter（专攻 exploiter）。AlphaStar。用于"石头剪刀布"式策略循环

## 关键参数 / 易错点
- **非平稳回放**：独立 agent 的经验回放比单 agent 更差——旧转移是过时对手生成的。修复：重标签或按时间衰减
- **信用分配歧义**：长 episode 后共享奖励，无法说清谁贡献。修复：COMA 反事实 baseline 或每 agent 奖励塑形
- **策略漂移/追逐**：每个 agent 的最优响应随其他 agent 更新而变。修复：集中 critic、慢学习率或轮流冻结
- **协调奖励黑客**：agent 找到设计者没预期的协调漏洞。拍卖 agent 收敛到全出零。修复：仔细设计奖励
- **联盟循环**：纯 self-play 可陷入支配循环。修复：league play 多样化对手
- **样本爆炸**：n agents × 状态空间 × 联合动作。用函数逼近和分因素动作空间

## 类比（帮助理解）
- MARL 就像"两个人在颠簸的船上"：每个人试图保持平衡，但对方的动作改变了你脚下的地面——你们互相成为对方的不稳定环境
- CTDE 就像"训练时有上帝视角，上场时只有自己的眼睛"：训练时集中 critic 看到所有人的位置和动作，但每个 agent 的策略只用自己能看到的信息——部署时不需要通信
- Self-play 就像"左手跟右手下棋"：你永远在跟一个和你一样强的对手对弈，所以你会不断进步——只要对手更新得不太快

## 设计时怎么用（反推思维）
> 合作导航/操作用 MAPPO/QMIX（CTDE）。二人零和博弈用 self-play+MCTS（AlphaZero）。复杂多人用 league play+模仿预训练（AlphaStar）。LLM 多 agent 系统用自然语言通信+角色条件（RL 在 trajectory 级而非 token 级）。2026 最大增长领域是 LLM-based MARL：swarm 的语言模型 agent 谈判、辩论、写代码。

## 典型应用 / 我在哪见过
- AlphaStar (StarCraft II)：league play + 模仿预训练
- OpenAI Five (Dota 2)：PPO + self-play + 大规模
- 自动驾驶车队：CTDE MAPPO + attention
- LLM multi-agent systems：自然语言通信 + 角色条件

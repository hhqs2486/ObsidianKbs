# 差分隐私

## 一句话定义
> DP-SGD 通过梯度剪裁+高斯噪声注入提供形式化 (ε, δ) 隐私保证。对 LLM 训练成本高昂——LoRA + DP-SGD 是 2025 年常见配置。2024-2025 年的紧张关系：canary 成员推断攻击报告有限成功 vs 训练数据提取报告大量逐字记忆——2025 年 3 月解决：两个测量不同东西。

## 它解决什么问题 / 为什么存在
- LLM 记住了训练数据——Carlini et al. 2021 证明生产语言模型可被诱导逐字复现训练文本
- 差分隐私是形式化防御：训练使得输出可证明地对任何单个训练样本不敏感
- 2024-2025 年的证据表明 DP-SGD 是必要的，但部署的 ε 值可能与威胁模型不匹配

## 核心原理
- **(ε, δ)-DP 定义**：随机算法 M 如果对于任意差一个样本的两个数据集 D/D' 和任意事件 S，P(M(D)∈S) ≤ e^ε · P(M(D')∈S) + δ。解释：输出分布足够接近（由 ε 参数化）使得任何单个个体的贡献不可靠地被推断，除了概率 δ
- **DP-SGD 步骤**：① 采样 mini-batch ② 计算每个样本梯度 ③ 剪裁每个样本梯度到 C ④ 求和并加标准差 σ·C 的 Gaussian 噪声 ⑤ 用带噪总和更新参数。隐私成本由会计器（Moments Accountant, Renyi DP accountant）追踪
- **LoRA + DP-SGD**：前沿模型完整 DP-SGD 不可行。低秩适配器限制梯度更新到一个小的适配器，DP 保证只对适配器生效；基座模型不动
- **2024-2025 年紧张关系与解决**：Canary MIA（Duan 2024）报告成员推断攻击对语言模型成功率有限。训练数据提取（Carlini 2021, Nasr 2025）却报告大量逐字记忆。2025 年 3 月解决：MIA 问"插入 canary 是否在 D 中"，提取问"什么可以从 D 恢复"——"最可提取"的样本是隐私相关的东西，canary 因为未优化为可提取而低估了风险
- **替代方案**：PMixED（推理时私有预测，混合专家下词分布+噪声）、DP 合成数据生成（DP-SGD 微调 LoRA → 采样合成数据 → 训练下游分类器）
- **差分隐私反转攻击**：用 DP 训练模型的置信度分数作为神谕来重识别个体——即使输出不泄漏，置信度分布也可能泄漏。防御：不暴露置信度或截断/量化后暴露

## 关键参数
- ε 和 δ 是隐私预算——ε 越低隐私越强、效用损失越大
- full DP-SGD 对于生产级 LLM 实用性有限（效用损失和计算开销都大）
- 不暴露置信度分数是 DP 训练后的额外要求

## 类比
- 差分隐私 = 给每个人的数据添加系统噪声——你可以看到"全校平均分"，但无法推断任何个体的具体分数

## 设计时怎么用
> 如果处理用户敏感数据 → 至少用 LoRA + DP-SGD 微调适配器。如果你暴露了置信度分数 → 即使模型是 DP 训练的也有被反转的风险。

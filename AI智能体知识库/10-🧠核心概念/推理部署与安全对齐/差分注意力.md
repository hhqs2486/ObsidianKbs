# 差分注意力

## 一句话定义
> Softmax 注意力对每个不相关 token 都分配非零权重——128K 上下文时这些噪声加起来约 12%。差分注意力用两个 softmax 相减消除共享噪声，像降噪耳机一样让信号浮出。

## 它解决什么问题 / 为什么存在
- Softmax 永远不会产生精确的零——每个不匹配 token 都获得正概率
- 不相关 token 的 score 在零附近波动，softmax 后每个贡献 O(1/N)，N 个不相关 token 总贡献 O(1)——不是小数
- 128K token 时即使每个不相关 token 只分到 0.001%，12.8 万个加起来约 12% 的总权重
- 表现为：长上下文 RAG 幻觉引用、"lost-in-the-middle"检索失败、32K 以上 needle-in-haystack 准确率下降
- Differential Transformer（Ye et al., ICLR 2025）用两个 softmax 相减修复
- DIFF V2（Microsoft 2026年1月）修复 V1 的三个生产环境问题：解码慢、需自定义 CUDA kernel、70B+ 训练不稳定

## 核心原理（大二能懂的水平）
- **噪声地板（Noise Floor）**：
  - 对 query q 和 keys K=[k_1,...,k_N]，attention weights w_i = softmax(q·k_i/√d)
  - 不相关 token 的 score q·k_i 在零附近波动（方差 ||q||²/d），softmax 后每个贡献 O(1/N)
  - N 个不相关 token 总贡献 O((N-1)/N) ≈ O(1)——随上下文增长，噪声淹没有用信号
- **差分公式**：
  - 把每头的 Q、K 投影分成两半：Q=(Q₁,Q₂), K=(K₁,K₂)
  - 算两个 attention map：A₁ = softmax(Q₁K₁ᵀ/√d), A₂ = softmax(Q₂K₂ᵀ/√d)
  - 输出：DiffAttn = (A₁ - λ·A₂)V
  - 减法消除两个 map 共享的噪声分布（两个都给不相关 token 分配了均匀的小权重→相减抵消）
  - 信号（真正相关 token 的尖峰权重）不会抵消——训练后两个 map 的信号幅度不同
  - λ 是每头可学习标量，可负。λ_init 默认 0.8
- **降噪耳机类比**：两个麦克风录同一个人的声音+背景噪声。减去一个信号，共享背景噪声抵消，声音因相位/幅度差异而保留。λ 学习的就是这个平衡
- **V1 vs V2 的差异**：
  - V1：减半 head dim 保持参数量 → value cache 每头减半 → 解码要加载两次 → 比基线慢；需自定义 CUDA kernel 破坏 FlashAttention 兼容；per-head RMSNorm 在 70B+ 训练后期不稳定
  - V2：加倍 Q heads 保持 KV heads 不变，head dim 不变 → 解码速度匹配基线（KV cache 只加载一次）；FlashAttention 直接用；去掉 per-head RMSNorm 换成更简单的初始化方案
  - V2 额外维度在减法后投影回基线维度

## 关键参数 / 易错点
- **上下文长度决定收益**：
  - <4K：噪声地板可忽略，和基线 Transformer 无区别
  - 64K+：清洁 attention map，更少幻觉引用，显著准确率提升
  - 128K：噪声占总权重 ~12%，差分注意力的收益最大
- **短上下文不值得**：8K 代码补全收益微小，不值得换架构
- **λ 可以为负**：参数化为 exp(λq₁·λk₁) - exp(λq₂·λk₂) + λ_init。训练中模型自己学习最佳减法比例
- **输出权重可以为负**：A₁ - λA₂ 的结果可能含负值——没关系，value cache 处理带符号贡献，后续 V 投影吸收符号
- **与 FlashAttention 的兼容**：V1 不兼容（需自定义 kernel），V2 兼容（2026 年关键改进）
- **与 GQA 兼容**：V2 增加 Q heads 不增加 KV heads → GQA 不受影响
- **与 MLA 的组合**：理论兼容，但尚无已发表论文组合 DIFF V2 + MLA
- **适用时机**：训练新模型目标 64K+ 上下文 → 从头加 DIFF；已训练好的模型重训成本高，通常不值得

## 类比（帮助理解）
- 差分注意力就像"降噪耳机"：两个麦克风（两个 softmax 分支）都录到环境噪声（不相关 token 的均匀小权重），减去一个信号后共享噪声抵消，有用声音（相关 token 的尖峰权重）因差异而保留
- 噪声地板就像"在嘈杂餐厅里听人说话"：每桌的闲聊声（不相关 token）单独很小，但 100 桌加起来就淹没了你朋友的声音（信号）。差分注意力就是"戴降噪耳机"
- V1→V2 就像"第一代降噪耳机太厚不方便（解码慢、要定制零件），第二代做薄了和普通耳机一样快（匹配基线、FlashAttention 兼容）"

## 设计时怎么用（反推思维）
> 如果训练目标 64K+ 有效上下文的新模型：从头加入 DIFF V2。V2 匹配基线解码速度、FlashAttention 兼容、无需自定义 kernel。短上下文（<16K）不值得——噪声地板可忽略。微调已有长上下文模型时，可以在 Q 投影上做 LoRA 近似 DIFF 结构。预期信号噪声比提升 3-10 倍。

## 典型应用 / 我在哪见过
- 微软内部长上下文生产模型
- 目标 256K+ 上下文的开源训练复现
- 混合架构：DIFF attention + 滑动窗口 attention 交替层
- vLLM / SGLang 集成中（2026年4月尚未全面上线）

# 冷启动缓解

## 一句话定义
> 70B 模型从冷到可用需 3-8 分钟。五层缓解：预种植节点镜像 → 模型流式加载 → GPU 快照 → 暖池 → 分层加载。Modal 冷启动 2-4 秒，原始 328s → 缓解后 ~15s（22 倍）。

## 核心原理
- Layer 1：Bottlerocket 预种植镜像（数据卷预装容器），省 2-4 分钟
- Layer 2：Run:ai Model Streamer 流式加载（首层就位即开始），减半权重加载
- Layer 3：Modal GPU 快照（序列化后状态直接反序列化到 HBM），10 倍加速
- Layer 4：min_workers=1 暖池——大模型（$4/h 避免 5 分钟）比小模型更值得
- Layer 5：ServerlessLLM NVMe→DRAM→HBM 分层加载，10-200 倍延迟缩减
- 实时迁移：传输输入 tokens(KB 级)，目标重算 KV cache

## 关键参数
- 按热冷路径分层：直播聊天 min_workers=2，夜间批处理 scale-to-zero
- GPU 快照是拓扑相关的（不同 GPU SKU 需重快照）

# Constitutional AI

## 一句话定义
> 用模型自己替代人类标注员：写一组原则（"宪法"），让模型批判自己的回答并修改，再基于修改结果做偏好训练——CAI 用于主观行为对齐，GRPO + 规则奖励用于可验证任务。

## 它解决什么问题 / 为什么存在
- RLHF 依赖人类偏好对：InstructGPT 用 33K 对比，Llama 2 Chat 用 150 万对，越来越贵
- 人类标注慢、贵、有偏见（标注者的主观倾向）
- CAI（Anthropic 2022）：让模型自己生成偏好标签。给它一组书面原则，让它自我批判、自我修改，用修改结果训练
- DeepSeek-R1（2025）更进一步：可验证任务（数学/代码）连 critic 都不需要——规则判对错，GRPO 做优化
- 2026 年主流对齐配方：CAI 管安全层 + GRPO 管推理 + DPO 管偏好润色 + 小量 RLHF 管残留行为

## 核心原理（大二能懂的水平）
- **CAI 两阶段**：
  - **Stage 1: SL-CAI**（监督学习 from AI 反馈）：
    1. 用 SFT 模型对潜在有害请求生成回答
    2. 让同一模型按宪法原则批判自己的回答
    3. 让模型基于批判修改回答
    4. 在修改后的 (prompt, revised_response) 对上做 SFT
  - **Stage 2: RLAIF**（强化学习 from AI 反馈）：
    1. 采样两个回答，让模型按宪法选出更好的
    2. 用偏好对训练奖励模型
    3. 在奖励模型上跑 PPO 或 DPO
    - 关键区别：偏好来自模型自己，不是人类
- **宪法是杠杆**：改变行为只需编辑一段文字，不用重新标注数千对数据
- **GRPO（Group-Relative Policy Optimization）**：
  - PPO 去掉价值函数。每个 prompt 采样 G 个回答，计算奖励，组内 z-score 归一化做优势：
    - A_i = (r_i - mean_r) / std_r
  - 损失：L = min(r·A, clip(r, 1-ε, 1+ε)·A) - β·KL(π||π_ref)
  - 无 critic、无奖励模型、无 MCTS——组均值就是 baseline
- **ORM vs PRM**：
  - ORM（Outcome Reward Model）：只给最终答案打分。便宜、信用分配稀疏、奖励黑客风险低
  - PRM（Process Reward Model）：给每步打分。贵、信用分配密集、容易学到"看起来好"的步
  - 2024-2025 共识：ORM + GRPO > PRM（PRM 倾向坍缩到捷径行为）
- **自我改进循环**：生成→评分→保留好的→微调→重复。DeepSeek 叫"拒绝采样微调"

## 关键参数 / 易错点
- **宪法的天花板**：模型自我判断只能和起始校准一样好。SFT 模型有盲点 → 批判步骤继承盲点。CAI 压缩对齐循环但不能放大超出 base model 上限的信号
- **仍需少量人类数据**：生产 CAI 管线保留 5-10% 纯 RLHF 的人类偏好数据量，保持分布诚实
- **模式坍缩**：自我蒸馏 3-5 轮后，模型失去创意多样性、过度自信、出现"AI 腔"（重复措辞/公式化结构）。监控 reward std——如果坍缩到零就停
- **GRPO 组大小**：G<4 信号噪声大（方差 ~1/√G），标准选择 G=8-64
- **GRPO 的优势**：(1) 无 value network → 内存减半；(2) 组 baseline 天然处理稀疏终态奖励；(3) 每 prompt 归一化让不同难度问题可比
- **R1-Zero 的"aha 时刻"**：纯规则奖励（准确率 + 格式）训练出的模型自发学会自检和回溯——不需要任何人类偏好
- **验证器游戏化**：如果验证器有漏洞，LLM 会找到并利用。需要鲁棒验证器（多测试用例、形式化证明）

## 类比（帮助理解）
- CAI 就像"学生自己批改作业"：老师给评分标准（宪法），学生先做题、再按标准自我批判、最后修改。用修改后的作业做训练材料
- GRPO 就像"同一道题做 16 遍，高于班级平均的解法加概率、低于的减概率"——不需要知道标准答案怎么来的，只需要能判对错
- ORM vs PRM 就像"只看期末总评 vs 每次作业都打分"：期末总评便宜但不知道哪里错了；每次作业精细但学生可能学会"写得好看"而非"真的理解"

## 设计时怎么用（反推思维）
> 主观行为（语气/安全/拒绝风格）用 CAI——有明确的宪法原则，无可验证结果。可验证任务（数学/代码/结构化提取）用 GRPO + ORM——能廉价判对错，奖励稀疏且二元。混合场景用 CAI 生成偏好对 + DPO 训练。生产管线通常四个都跑：CAI 安全层 + GRPO 推理 + DPO 偏好润色 + 小 RLHF 残留。

## 典型应用 / 我在哪见过
- Claude（Anthropic）：CAI 原始论文，16 条宪法原则
- DeepSeek-R1：GRPO + 规则奖励，几乎无人类偏好数据，匹配 o1 推理水平
- DeepSeek-R1-Zero：纯 GRPO（准确率 + 格式奖励），自发出现自检/回溯行为
- 2026 前沿模型：CAI + GRPO + DPO + 小 RLHF 四合一

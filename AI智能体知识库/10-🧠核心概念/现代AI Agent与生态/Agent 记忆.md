# Agent 记忆

## 一句话定义
> Agent 记忆是一套让 Agent 在"上下文窗口装不下、会话会结束"的限制下，仍然能记住事实、历史和行为习惯的机制——核心是"主上下文（RAM）+ 外部存储（磁盘）"的分页式管理。

## 它解决什么问题 / 为什么存在
- 上下文窗口是有上限的。生产里有三类反复出现的失败：①**溢出**（多轮对话/长文档/工具轨迹超出窗口，截断之后的内容全丢）；②**稀释**（即使没超窗口，塞一堆无关内容会稀释注意力，前沿模型在长输入上也会退化）；③**不持久**（新会话从空窗口开始，Agent 跨天没法说"记得你上次让我…"）。
- 更大的窗口能缓解但治不了本：Mem0 的 2025 论文实测，128k 窗口的基线仍会漏掉长视野事实，而一个 4k 窗口 + 外部记忆的 Agent 反而抓得住。

## 核心原理（大二能懂的水平）
- 本质是操作系统**虚拟内存**的翻版（MemGPT, Packer et al. 2023, arXiv:2310.08560）：
  - RAM ↔ 主上下文（也就是 prompt 本身，固定大小，模型一直看得见）
  - 磁盘 ↔ 外部上下文（向量库 / KV / 图存储，无限、可检索）
  - 缺页中断 ↔ 记忆工具调用（`memory.search` / `memory.read` / `memory.write`）
  - 内核 ↔ Agent 的控制循环（ReAct + 记忆工具）
- **两层级**：主上下文放当前任务；外部上下文无限、用工具按需读写。Agent 正常跑 ReAct 循环，多了一类工具把数据在主/外部上下文之间"换页"。
- **中断模式（memory-as-interrupt）**：对话中途 Agent 调一个记忆工具，运行时执行它，结果作为新观察拼回下一轮——和 Unix 的 `read()` 系统调用阻塞进程、返回字节、进程继续，概念完全一致。经典工具面：`core_memory_append` / `core_memory_replace`（写持久 prompt 分区）、`archival_memory_insert` / `archival_memory_search`（写/查外部存储）、`conversation_search`（查历史轮次）。
- **四种记忆类型**（回答不同问题）：
  - 工作记忆（working）：此刻什么重要？——在上下文里的当前任务、近期轮次、固定核心分区。
  - 情景记忆（episodic）：发生了什么？——带 session/turn 引用的历史轮次与轨迹，可重放。
  - 语义记忆（semantic）：什么是真的？——关于用户/领域/世界的事实，随变化去重更新。
  - 程序性记忆（procedural）：怎么做？——学到的套路、偏好、规则，用来引导未来行为而非召回。
- 生产实现都是 MemGPT 变体：Letta（三层级 core/recall/archival + sleep-time 计算）、Mem0（向量+KV+图融合+打分）、OpenAI Assistants/Responses（线程与文件托管记忆）、Claude Agent SDK（skill + session store 长期记忆）。

## 关键参数 / 易错点
- 记忆腐败（memory rot）：写入比读取快，检索被陈旧事实淹没——要定期合并（Letta 的 sleep-time）或显式失效（Mem0 冲突检测）。
- 记忆投毒（memory poisoning）：外部记忆是"被召回的文本"，若攻击者可控制的内容混进记忆笔记，下次会话 Agent 会重新吃进去——要对检索结果做指令形文本扫描、标为不可信。
- 引用丢失（citation loss）：Agent 说"你让我发 X"却说不出哪一轮——每次 archival 写入要带 `session_id`/`turn_id`/`source_url`。
- 分页只解决容量，不决定"存什么"——四类记忆的取舍才是设计重点。

## 类比（帮助理解）
- 就像你写代码时：工作台（RAM=主上下文）只放当前文件，参考资料（磁盘=外部存储）在需要时才查；临时记事贴（core memory）一直贴在屏幕边，笔记库（archival）用搜索引擎找。
- 情景记忆=git log（带提交号可回溯），语义记忆=知识库里的结论，程序性记忆=你反复用熟的操作习惯。

## 设计时怎么用（反推思维）
> 做需要"跨多轮/跨会话记住用户偏好或项目背景"的 Agent 时，我会用 MemGPT 式分页：主上下文只放当前任务，长期事实（如用户偏好、项目约定）写进外部语义记忆，并用 [[长期记忆]]/[[短期记忆]]/[[用户记忆]] 分层存储与检索；同时给每次写入打来源引用、加投毒扫描，避免记错又不自知。

## 典型应用 / 我在哪见过
- 客服 Agent 跨天记住"用户上次投诉的订单号"；代码 Agent 记住"本项目用 tabs 不用空格"这类项目约定（程序性记忆）。
- Zep（时序知识图谱，事实带有效期）、Mem0、LangMem（后台抽取事实与行为规则）、agentmemory（会话捕获后 consolidation）等开源实现。

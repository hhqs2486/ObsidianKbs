# OpenClaw 智能体框架

## 一句话定义
> OpenClaw 是较新出现的开源 Agent 框架/工具，定位偏向"可自托管、面向终端与浏览器操作的自主 Agent"，强调把编码、网页操作、工具调用整合到一个可本地运行的 Agent 运行时。

## 它解决什么问题 / 为什么存在
- 闭源商业 Agent（如部分云端"通用助手"）不够透明、数据要出本地。
- OpenClaw 这类开源方案让开发者在自有机器上跑"能动手的 Agent"，兼顾可控与可改。

## 核心原理（大二电子信息工程专业学生能懂）
- 与主流 Agent 一样，核心是"模型 + 工具循环 + 持久状态"：模型决定下一步动作（读文件、跑命令、操作浏览器、调 API），运行时执行并回灌结果。
- 通常提供：
  - 终端入口（CLI）与/或网页 UI；
  - 浏览器/计算机操作能力（见 [[Computer Use]]、[[Browser Agent]]）；
  - 工具与插件机制，支持接入 [[MCP]] 服务器；
  - 任务记忆与历史记录，便于复盘与改进（见 [[经验回放与改进]]）。

> 说明：OpenClaw 的具体 API 与版本仍在快速演进，以上为对其公开形态的概括性描述；精确用法以官方仓库为准。

## 关键参数 / 易错点
- 开源自主 Agent 默认权限很宽，必须在配置里收窄危险操作（见 [[Agent 安全门禁]]）。
- 浏览器/文件操作要设 allowlist、最大步数，避免误删或越权。
- 版本变动快，集成时以当前官方文档为准。

## 类比（帮助理解）
- 像一个"可自己托管、能上网能敲键盘的开源实习工程师"。

## 设计时怎么用（反推思维）
> 做"希望数据不出本地、又能让 Agent 真正操作电脑/浏览器"的需求时，我会考虑 OpenClaw 这类开源运行时，并优先接好权限与日志。

## 典型应用 / 我在哪见过
- 本地自动化办公、网页信息抽取、代码仓库维护、个人助手。

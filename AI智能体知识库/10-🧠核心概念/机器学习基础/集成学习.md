# 集成学习

## 一句话定义
> 一群弱学习器正确的组合方式能让集体强于个人——Bagging 降方差，Boosting 降偏差，Stacking 学会该信谁。这不是比喻，是数学定理。

## 它解决什么问题 / 为什么存在
- 单模型要么欠拟合要么过拟合——集成把多个模型的优点互补
- Bagging 专治高方差（过拟合），Boosting 专治高偏差（欠拟合）
- Kaggle 结构化数据比赛的制胜法宝：XGBoost/LightGBM/CatBoost 统治排行榜

## 核心原理（大二能懂的水平）
- **为什么集成有效**：假设 N 个独立分类器各有 60% 准确率，多数投票准确率 = `Σ_{k>N/2} C(N,k)·(0.6)^k·(0.4)^(N-k)`。21 个 → 74%，101 个 → 84%。关键是多样性——如果所有模型犯同样的错，集成无用
- **Bagging = 并行 + 投票**：每个模型在不同 bootstrap 样本上训练（约 63% 数据），预测 = 所有模型投票/平均。减少方差。随机森林 = Bagging + 特征随机化（更极致的多样性）
- **Boosting = 串行 + 纠错**：每个新模型重点关注前一模型搞错的样本。AdaBoost 通过调整样本权重实现；梯度提升拟合"残差"——新树 = 前一棵树的预测误差。减少偏差
- **梯度提升计算过程**：(1) 算伪残差 `r = -∂L(y, F(x))/∂F`，(2) 拟合一棵决策树到残差，(3) 以学习率（收缩因子，一般 0.01-0.3）加到集成中。子树越多偏差越低但方差可能上升
- **Stacking = 元学习**：把多个基模型的输出当作特征，再训练一个"元模型"来集成。元模型学会了"在这个区域信随机森林，在那个区域信 SVM"

## 关键参数 / 易错点
- Bagging/随机森林不会过拟合（树多了只会饱和不会变差），但 Boosting 会——学习率 × 树数量是核心取舍
- XGBoost 的额外技巧：目标函数加正则化项（L1+L2 惩罚叶子权重）、缺失值自动处理、二阶泰勒展开优化分裂
- 多样性不足的集成 = 浪费计算，跟单模型没区别

## 类比（帮助理解）
公司做重大决策。Bagging = 每个部门独立开会，用不同数据（bootstrap），最后投票决定——单部门可能偏执但集体民主平衡。Boosting = 一个接一个发言：第一个人讲完，第二个人专门纠正第一个人的错误，第三个纠正前两人的错误，最后把所有人的意见按发言质量加权求和。Stacking = 让一个"裁判 AI"看完各部门的投票结果，然后决定信谁。

## 设计时怎么用（反推思维）
> 表格数据默认上梯度提升（XGBoost/LightGBM）；发现过拟合时加正则化控制树深度、减少树数量或降低学习率；要解释性时选单棵树或浅层随机森林；要做 Kaggle 冲榜时用 Stacking 堆多层模型。

## 典型应用 / 我在哪见过
- 几乎所有 Kaggle 表格数据前三名方案：XGBoost/LightGBM 堆叠
- 信用卡欺诈检测：XGBoost 处理极度不平衡数据
- 房价预测：梯度提升集成胜过单模型 20%+
- 搜索排序：LambdaMART 是梯度提升的排序变种

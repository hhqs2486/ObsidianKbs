# 决策树与随机森林

## 一句话定义
> 决策树是"if-else 流程图"，随机森林是很多棵树的投票结果——它们统治了表格数据的 ML 世界。

## 它解决什么问题 / 为什么存在
- 表格数据（行是样本、列是特征）的建模王者——Kaggle 结构化数据比赛被 XGBoost 和 LightGBM 统治，不是因为深度学习不行，而是树更好
- 无需特征缩放、无需预处理就处理混合类型（数值+类别）、天然支持非线性关系、可解释
- 随��森林用"多棵树投票"降低方差，在中等数据集上极难过拟合

## 核心原理（大二能懂的水平）
- **决策树 = 空间分区**：从根节点开始，每个节点问一个"是/否"问题（如"特征 X < 阈值？"），把数据一分为二，递归到叶子给出预测。本质上是把特征空间切成一个个矩形块
- **分裂准则**：Gini 不纯度 = `1 - Σp_k²`（纯节点 Gini=0），熵 = `-Σp_k·log₂(p_k)`，信息增益 = 分裂前后不纯度的减少量。贪心算法每次选信息增益最大的 (特征, 阈值) 对
- **预剪枝**：限制最大深度、每叶最小样本数、最小信息增益。不剪枝的树会完美记忆训练数据（每个叶子只有一个样本）但泛化极差
- **随机森林 = 决策树 + Bagging + 特征随机化**：(1) 每棵树在 bootstrap 样本上训练（约 63% 原始数据），(2) 每个节点只考虑随机子集的特征（分类 √p，回归 p/3），(3) 所有树投票/平均
- **为什么集成有效**：每棵树的误差是独立的（不同的 bootstrap + 不同的特征子集），取平均后误差抵消。问题是方差不是偏差——所以随机森林主要降低方差

## 关键参数 / 易错点
- 树的数量一般在 100-500，超过后收益递减但不会过拟合
- max_depth 是最关键的正则化参数：深度每加一层，过拟合风险翻倍
- 特征重要性有偏差：MDI 偏向高基数特征和多分裂点特征，排列重要性更可靠但计算更贵

## 类比（帮助理解）
一棵决策树就像一个经验尚浅的侦探：看到"雨天"就猜"有人带伞"，但每次重查案会得出不同结论（高方差）。随机森林是成立了一个侦探小组：每人只看部分线索（特征随机化），每人只访问部分证人（bootstrap），最后投票决定结论。100 个平庸的侦探 > 1 个很聪明但过于自信的天才。

## 设计时怎么用（反推思维）
> 拿到表格数据后，第一个试随机森林（不需要预处理、调参少、性能不错）；需要解释性时，用单棵决策树可视化 if-else 规则；追求极致性能时，升级到梯度提升（XGBoost/LightGBM）。

## 典型应用 / 我在哪见过
- 信用风险模型：收入+年龄+负债 → 审批决策
- 客户流失预测：使用行为特征 → 流失概率
- 医疗诊断辅助：症状特征 → 疾病推断 + if-else 解释
- Kaggle 表格数据比赛：随机森林是标准基线

# 无监督学习

## 一句话定义
> 没有标签、没有老师——算法自己找数据结构。如果监督学习是"对答案学习"，无监督学习就是"盯着原始数据直到规律浮现"。

## 它解决什么问题 / 为什么存在
- 现实世界标签昂贵：医院有百万病历但没人标注疾病；电商有千万用户但没人细分群体
- 数据探索的先遣兵：在标注之前，帮你理解数据的自然结构——有几类、哪些异常、哪些维度相关
- 为监督学习铺路：聚类产生伪标签 → 半监督学习；降维压缩特征 → 减少过拟合；发现异常 → 去除噪声

## 核心原理（大二能懂的水平）
- **K-Means = 球型聚类**：Lloyd 算法 (1) 随机选 K 个中心，(2) 每个点归到最近中心，(3) 中心移到归属点均值，(4) 迭代直到稳定。目标函数 = 总类内平方距离（惯性）。只能发现球型簇，需要预先指定 K
- **DBSCAN = 密度聚类**：两个参数——eps（邻域半径）和 min_samples（最小邻点数）。核心点→邻域内 ≥ min_samples 个点，边界点→被核心点覆盖但自己不够密，噪声点→都不是。任意形状簇，自动决定簇数，天然识别异常值。弱点：不同密度的簇处理不好
- **层层聚类**：从每点自成一簇开始，合并最近的簇（凝聚式）。你可以画树状图（dendrogram）决定在哪层"切"出 K 个簇。单联动/全联动/Ward 法区分了"两簇间距离"的定义
- **高斯混合模型 GMM**：K-Means 硬分配，GMM 软分配——每个点有属于各簇的概率。假设各簇是高斯分布，用 EM 算法：E 步算归属概率，M 步更新高斯参数（均值、协方差、权重）
- **评估无监督质量**：没有标签如何评？肘法（惯性 vs K 曲线找拐点）、轮廓系数（a=类内相似度，b=类间分离度，得分 = (b-a)/max(a,b)，1 好 -1 坏）

## 关键参数 / 易错点
- K-Means 对初始中心敏感：多次随机初始化取惯性最小的结果（K-Means++ 改进）
- DBSCAN 的 eps 选择最影响结果：太大→所有点成一簇，太小→全是噪声。一般用 K-距离图找肘点
- 无监督评估指标只是参考：不能替代领域知识验证——聚类结果要和业务含义一致

## 类比（帮助理解）
你去一个没有座位的宴会厅。K-Means = 主办方先放了 K 张圆桌（初始中心），每个人坐到最近的桌子，然后主办方把桌子移到每群人的中心位置，再来一次……直到稳定（Lloyd 算法）。DBSCAN = 人群自然聚在一起聊天，密度高的地方形成簇，孤零零站在角落的人是"噪声点"。

## 设计时怎么用（反推思维）
> 做用户分群时，先 PCA 降到 5-10 维 → K-Means 聚类 → 轮廓系数+肘法选 K → 人工检查每个簇的业务含义；做异常检测时，DBSCAN 的噪声点天然是候选异常；需要软成员关系时用 GMM。

## 典型应用 / 我在哪见过
- 客户细分：RFM 特征 → K-Means 分群 → 个性化营销
- 异常检测：网络日志 → DBSCAN → 噪声点 = 可能的入侵行为
- 图像压缩：像素颜色 → K-Means 聚类 → 用 K 个颜色代表全图
- 文档聚类：TF-IDF 向量 → K-Means → 自动主题分组

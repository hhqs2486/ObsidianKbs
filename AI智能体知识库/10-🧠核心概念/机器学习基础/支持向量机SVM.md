# 支持向量机SVM

## 一句话定义
> 在两堆数据之间找一条最宽的分隔带——带的边界上的点就是"支持向量"。这是深度学习之前最优雅的分类算法。

## 它解决什么问题 / 为什么存在
- 在无数条可能的分隔线中选出最优的一条——"最大间隔"原则保证泛化能力
- 对于小数据集和高维数据（如基因表达、文本分类），SVM 往往是最优选择
- 数学上连接了凸优化、核方法、正则化理论，是最有理论保证的算法之一

## 核心原理（大二能懂的水平）
- **最大间隔分类器**：分隔超平面 `w^T·x + b = 0`。点 xᵢ 到平面的距离 = `|w^T·xᵢ + b|/||w||`。目标是最大化最小距离（间隔），等价于最小化 `||w||²/2`
- **支持向量**：只有离分隔面最近的点影响决策边界。其他点位置变动不会改变面。这就是为什么预测时只需存支持向量而不是整个训练集
- **软间隔与 C 参数**：真实数据很少完美可分。引入松弛变量 ξᵢ 允许穿越边界：`min ||w||²/2 + C·Σξᵢ`。C 大→惩罚大→窄间隔→少量错分类（可能过拟合）；C 小→宽容→宽间隔→更多错分类（可能欠拟合）
- **合页损失（Hinge Loss）**：`max(0, 1 - yᵢ·f(xᵢ))`。分类正确且远离边界→loss=0，在边界内或分类错误→线性惩罚。与 logistic 损失的区别：合页损失在正确预测时硬截断为 0（只关心支持向量），logistic 永远 > 0
- **核技巧（Kernel Trick）**：数据线性不可分时，映射到高维空间再分类。但不用真的计算高维坐标——只算内积 `K(xᵢ, xⱼ)`。RBF 核 `K(a,b)=exp(-γ·||a-b||²)` 等价于无限维映射，能处理任意形状决策边界

## 关键参数 / 易错点
- C 参数控制容错度：特征已标准化时 C=1 是好的起点，用小 C 避免过拟合
- RBF 核的 γ：γ 大→每个点影响范围小→模型复杂→可能过拟合；γ 小→每个点影响范围大→模型光滑→可能欠拟合
- 数据必须标准化：SVM 依赖距离和间隔，不同量纲会导致某些特征主导决策

## 类比（帮助理解）
你要在红蓝两堆弹珠之间划一条线分隔它们。有很多种划法。SVM 说：划那条离双方最近的弹珠都尽量远的线——这样新弹珠掉进来时最不容易被误分。"支持向量"就是离这条线最近的那几颗弹珠，只有它们决定了线的位置。

## 设计时怎么用（反推思维）
> 做小样本高维分类（如基因微阵列、文本分类）时首选 SVM + 线性核；发现数据明显非线性可分时换 RBF 核；发现过拟合时先降 C 再降 γ；数据量大（>10 万样本）时 SVM 计算太贵，改用随机森林或逻辑回归。

## 典型应用 / 我在哪见过
- 文本分类：TF-IDF+SVM 曾经是行业标准
- 图像识别：手写数字 MNIST 数据集上的经典方法（HOG+SVM）
- 生物信息学：基因表达数据分类癌症亚型
- 异常值检测：One-Class SVM 只学正常数据，偏离就是异常

# 线性回归

## 一句话定义
> 给散点图拉一条最佳直线——这就是 ML 的 "Hello World"，也是最简洁的训练循环范式。

## 它解决什么问题 / 为什么存在
- 给定输入预测连续值输出：房价预测、销量预测、温度预测——任何"给 X 估计 Y"的问题
- 引入 ML 的核心训练循环范式：定义模型 → 定义损失函数 → 优化参数。这个范式在所有 ML 算法中通用
- 作为所有回归问题的基线和基准模型

## 核心原理（大二能懂的水平）
- **模型**：`y = wx + b`。w 是斜率（权重），b 是截距（偏置）。多维形式：`y = w₁x₁ + w₂x₂ + ... + wₙxₙ + b = w^T·x + b`
- **损失函数 MSE**：`MSE = (1/n)·Σ(y_pred - y_actual)²`。用平方的原因：(1) 大误差受更重惩罚，(2) 平方函数处处光滑可导
- **梯度下降更新**：`∂MSE/∂w = (2/n)·Σ((ŷ-y)·x)`，`∂MSE/∂b = (2/n)·Σ(ŷ-y)`。然后 `w = w - lr·∂MSE/∂w`，`b = b - lr·∂MSE/∂b`
- **正规方程**（闭式解）：`w = (X^T·X)⁻¹·X^T·y`。一步到位算最优权重，但矩阵求逆 O(n³)，只适合小数据集（n<10000）
- **多项式回归**：把 `y = wx+b` 扩展为 `y = w₁x + w₂x² + w₃x³ + b`。仍然是"线性"回归（对权重 w 线性），但可以拟合曲线

## 关键参数 / 易错点
- 学习率选择：过大发散，过小收敛太慢。典型起始值 0.01-0.001
- 特征标准化是必须的：如果 x₁ 范围 [0,1]、x₂ 范围 [0,10^6]，梯度下降的 cost surface 会极度拉长，收敛极慢
- R² 分数：衡量模型比"只预测平均值"好了多少。R²=1 完美预测，R²=0 不比均值好，R²<0 比均值还差

## 类比（帮助理解）
学校测量学生身高和体重的关系。线性回归就是在散点图上拉一条直线，使得每个点到直线的垂直距离的平方和最小。斜率 w 告诉你"长高 1cm，平均增重多少 kg"，截距 b 告诉你"身高为 0 时体重的理论值"（通常无实际意义）。

## 设计时怎么用（反推思维）
> 做任何回归任务时，先用线性回归做基线——如果更复杂的模型（随机森林、深度网络）打不过这个简单基线，说明你的复杂模型有 bug；做快速原型时，正规方程在小数据集上几毫秒出结果。

## 典型应用 / 我在哪见过
- 房地产估价：面积+卧室数+地段 → 预测价格
- 销售预测：历史销量+广告支出+季节因素 → 未来销量
- A/B 测试分析：实验组 vs 对照组的效果差异量化
- 基线的"计量经济学"模型：所有科学实验中最基本的线性拟合

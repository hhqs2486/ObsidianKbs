# 大语言模型 LLM

## 一句话定义
> 大语言模型（Large Language Model, LLM）是 Agent 的决策核心——负责理解意图、思考规划、做出判断，相当于 Agent 的"大脑"。

## 它解决什么问题 / 为什么存在
- LLM 把海量的语言规律与世界知识压缩进参数，使 Agent 能"理解-规划-执行"，而无需为每件事硬编码规则。
- 它是所有现代 Agent 的智能基座：模型选对，往往比优化提示词更有效。

## 核心原理（大二电子信息工程专业学生能懂）
- LLM 的能力来自两部分：**预训练**积累的世界知识与语言能力 + **后训练**（监督微调 SFT、强化学习 RL）固化的决策策略。
- 收到请求后，它先解析真实意图（用户说的常不是真正想要的），再把复杂任务拆成可执行步骤，并持续判断下一步、是否调工具、调哪个、传什么参数。
- **内部思考**：行动前先规划推演，得益于预训练习得的因果、数学、问题分解等逻辑规则，因此推演不是随机探索。
- **零样本泛化（Zero-shot）**：没见过的任务也能组合已有知识处理；**少样本适应（Few-shot）**：给两三个示例就能学会新任务模式。

## 关键参数 / 易错点
- 绝大多数 Agent 需要支持**思考（Reasoning）**的模型（多步思考、工具选择）；少数单步简单任务才可用不思考的模型。
- 模型更关注输出速度（每轮都要等模型输出，影响端到端延迟）与多模态能力。
- "模型即 Agent"趋势：先进模型经 RL 把工具调用决策内化为原生能力，但框架（Harness）反而更重要。

## 类比（帮助理解）
- LLM 像一位天赋极高的新员工：理论功底深、编程强，但对你团队的架构、业务规则一无所知——给它足够背景（上下文），它才发挥得出来。

## 设计时怎么用（反推思维）
> 做 Coding Agent 时，我会选 Claude/Gemini/具备思考能力的模型做大脑，并理解其能力边界：哪些靠预训练会、哪些要后训练内化、哪些必须由 Harness 兜底。

## 典型应用 / 我在哪见过
- GPT/o 系列、Claude 系列、Gemini 系列、Kimi、Qwen、DeepSeek 等驱动各类 Agent。

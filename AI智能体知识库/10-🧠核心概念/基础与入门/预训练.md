# 预训练

## 一句话定义
> 预训练（Pre-training）是在海量互联网文本上对模型做初始训练，让模型学会语言规律与世界知识的过程——是 LLM 能力的第一来源。

## 它解决什么问题 / 为什么存在
- 没有预训练，模型既不懂语言也不懂世界。预训练把人类知识"压缩"进参数，使 Agent 具备零样本泛化与内部推演的基础。
- 它对应"训练三阶段"的第一阶段（预训练 → SFT → RL）。

## 核心原理（大二电子信息工程专业学生能懂）
- 用自监督目标（如预测下一个 token）在超大规模语料上训练 Transformer，得到基座模型（base model）。
- 预训练习得的能力包括：语言规律、因果/数学/问题分解等逻辑规则、广泛的世界知识。
- 这些知识让 LLM Agent 在面对全新任务时能直接上手（零样本），或在看几个示例后学会（少样本）。

## 关键参数 / 易错点
- 预训练 ≠ 全部：它给了"通用能力"，但 Agent 的决策策略（何时调工具、调哪个）主要靠**后训练**（SFT/RL）固化。
- 预训练数据有截止时间，之后的信息需靠 [[检索增强上下文|RAG]] / 工具获取。

## 类比（帮助理解）
- 预训练像一个人读完互联网上几乎所有书——有了通识底子，但还没受过"怎么干活"的专项训练。

## 设计时怎么用（反推思维）
> 选基座模型时，我会看其预训练规模与知识覆盖；若任务涉及私有/最新知识，则用 RAG 与工具补充，而非指望模型"本来就知道"。

## 典型应用 / 我在哪见过
- 各厂商基座模型（GPT、Claude、Qwen、DeepSeek、Kimi 等）的训练第一阶段。

# 费曼学习法检验提示词

## 一句话定义
> 费曼学习法检验提示词是用"你能不能把一个概念讲给完全的小白听、让对方真听懂"来检验掌握度的提示策略——讲不清，就说明还没真懂，于是定位知识缺口再补。

## 它解决什么问题 / 为什么存在
- 学习者常陷"熟练度错觉（fluency illusion）"：能流利复述术语，但一要"用自己话、对小白讲清"就卡壳。流利（fluency）给虚假 mastery 感，而长期留存（storage strength）才是真目标。
- 费曼技巧（Feynman technique）用"教别人"当探针：能简洁无误地教会外行 = 真懂；讲卡壳的地方 = 知识漏洞。把它写成提示词，让 Agent 当"费曼考官"自动检验并暴露缺口。

## 核心原理（大二能懂的水平）
- **费曼四步的提示化**：
  1. 选概念，让学习者用自己的话解释（不许抄定义）。
  2. Agent 扮演"小白听众"，对模糊/跳步处追问"这话我对门外汉讲得通吗？"
  3. 卡壳处即知识缺口 → Agent 标出"你这里其实没讲清"，回到原资料补漏。
  4. 简化到能用类比和最少术语讲清（"像给小孩讲"）。
- **检验 vs 引导的分工**：费曼提示词负责"学完后测掌握度"（诊断），[[苏格拉底问答提示词]] 负责"过程中引导推导"（建构）。两者一前一后构成教学闭环。
- **为什么是好的探针**：强迫"用自己的话 + 对小白"双重约束，直接对抗流利度错觉——能背公式 ≠ 能讲清"为什么这样"；讲清才暴露隐藏的前提缺口。
- **来自 teach 技能套件的支撑**：检验应落在学习者的 zone of proximal development；用 retrieval practice（从记忆回忆而非重读）、spacing（分布练习）、interleaving（交错相关主题）来建长期留存——费曼讲解本身就是强检索练习。

## 关键参数 / 易错点
- **别让 Agent 替学习者讲**：检验要点是"学习者讲、Agent 挑刺"。若 Agent 自己把概念流畅讲一遍，学习者没检索，等于没测。
- **小白听众要真"外行"**：追问须针对"术语未解释/逻辑跳步"，而不是考更深细节——否则变成刁难。
- **卡壳即缺口，不是失败**：把讲不清的点记为 learning record / 知识漏洞，回到源材料补，再讲一遍。
- **配间隔复测**：一次讲清可能靠临时记忆；按 spaced retrieval 隔段时间再测，才确认 storage strength。
- **适用边界**：程序性技能（如游泳姿势）费曼讲解帮助有限，需实操；概念性/原理性知识最契合。

## 类比（帮助理解）
- 像"能不能给奶奶讲明白量子比特"：你若只能甩术语，说明自己也没真懂；能用具象类比讲清，才是懂。
- 像单元测试：费曼讲解 = 对被测概念跑一组"小白听得懂吗"的断言，failed assertion 就定位 bug。

## 设计时怎么用（反推思维）
> 做"学习检验/助教"Agent 时，我会先反推"要测的是真掌握还是表面流利"：要真掌握→用费曼提示词让学习者对自己讲、Agent 扮小白挑"术语未释/跳步"，卡壳点即知识漏洞并回流补全；再配间隔复测确认长期留存。并用 [[苏格拉底问答提示词]] 在前面做引导建构。

# AI Scientist

## 一句话定义
> AI Scientist 是"自动化科研 Agent"：自己提假设、写代码做实验、出图、写论文、按审稿意见改——把科研闭环交给 Agent 跑。Sakana 的 v2 是首个让生成论文通过 ICLR 2025 workshop 同行评审的系统。

## 它解决什么问题 / 为什么存在
- 科研是开放任务，没有机器可校验的"正确答案"标准（不像 AlphaEvolve 有单元测试、DGM 有 SWE-bench）。论文由审稿人评判，不是单测。这让闭环更难闭合，但也更有价值——因为科研是复利式进步所在。
- v1（2024）靠人工模板填空；v2（2025）去掉模板，用 agentic 树搜索 + VLM 图批评循环，自动生成想法→实现→出图→写稿→按反馈迭代。

## 核心原理（大二能懂的水平）
- **七步架构**：①想法生成（LLM 基于主题+文献提假设；v2 用 agentic 树搜索展开假设空间）②新颖性检查（文献检索确认是否已被发表）③实验计划（起草协议+写代码）④执行（沙箱跑代码，失败进重试循环）⑤出图（VLM 读图并重写以求清晰——v2 关键新增）⑥写稿（LLM 起草+内部审稿迭代）⑦可选投稿。
- **工作坊录用意味着什么**：一篇 v2 生成论文通过 ICLR 2025 workshop 同行评审（作者向组委会披露了来源）。但 workshop 门槛低于主会，且评审有噪声——这是概念验证，不是"系统会做科研"的许可证。
- **独立评估（Beel et al.）发现的真相**：
  - 42% 实验因代码错误失败（坏 import、shape 不匹配、未定义变量），重试抓住部分、非全部。
  - 新颖性误标：文献检索常把已有方法标成"新颖"——这是科研版的幻觉。
  - 展示质量差距：VLM 图批评产出"可发表级"图，却掩盖了底层实验弱点。
  - 关键教训：产出令人信服但研究不令人信服的系统，比明显失败更危险。
- **沙箱逃逸风险**：Sakana 自己的 README 警告——因为执行 LLM 写的代码，无法保证安全（危险包、失控网络访问、派生非预期进程）。至少要用 Docker 隔离，最好 seccomp/gVisor，投稿前人工审。
- **在自主栈里的位置**：相比 AlphaEvolve（有紧 evaluator，受限）、DGM（SWE-bench 评，有奖励黑客），AI Scientist v2 自动评测最弱、输出面最广、离公开产物最近——安全主要靠沙箱+审稿+披露。

## 关键参数 / 易错点
- **实验失败率高**：代码错误类失败占 42%，重试预算要够但也要封顶。
- **新颖性幻觉**：文献检索不可全信，要人工/工具交叉验证。
- **展示掩盖（polish masking）**：漂亮图表 ≠ 扎实实验，评估须触达底层论断。
- **沙箱必须**：执行 LLM 代码默认危险，Docker 起步，长程跑加 seccomp/gVisor + 每稿人工审。
- **评测 vs 部署**：基准"会写论文"是能力上限，不是可靠性下限。

## 类比（帮助理解）
- 像一个博士生：自己读文献找题目、跑实验、画图、写稿、改审稿意见——只是它写的代码可能 42% 跑挂，且会误把旧方法当新发现。
- 像自动化工厂但"质检员"不可靠：产品外观精美，内部可能空心的风险最高。

## 设计时怎么用（反推思维）
> 做"科研/实验自动化 Agent"时，我会先反推"有没有可靠的自动评测"：有（单测/基准）→学 AlphaEvolve 紧闭环；无（开放式科研）→必须上沙箱隔离 + 外部验证 + 人工审稿，且绝不因图表漂亮就宣称成功。并把"实验失败率、新颖性误标、展示掩盖"三项设为上线前必报指标。

## 典型应用 / 我在哪见过
- Sakana AI Scientist v1（模板）与 v2（agentic 树搜索 + VLM 图批评）。
- 同栈对照：AlphaEvolve（算法搜索）、DGM（自修改 Agent 脚手架）。

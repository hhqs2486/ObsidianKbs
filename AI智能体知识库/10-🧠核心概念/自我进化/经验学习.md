# 经验学习

## 一句话定义
> 经验学习（Experience Learning）是 Agent 把完成任务过程中的成功与失败经验，提炼、压缩、结构化后沉淀为可检索、可复用的外部资源的学习机制——它是自我进化「从经验中沉淀知识」这一维度的工程总称。

## 它解决什么问题 / 为什么存在
- 从「聪明」到「熟练」的差距：许多业务流程和领域知识动态变化、非公开，仅靠提升基座模型通用能力解决不了（如某服务的退订要填特定表单、某优惠的适用条件）。
- 需要 Agent 主动把探索中总结的解题策略、操作流程、失败教训沉淀为持久能力，而不只是「记得更多」，而是「越来越能干」。

## 核心原理（大二电子信息工程专业学生能懂）
- 外部化学习循环：完成任务 → 产生原始经验 → 提炼（总结·压缩·结构化）→ 存入外部系统（知识库/工具，可检索）→ 下次任务检索复用。
- 按层面分层（表8-2）：
  1. 知识提炼：策略摘要、工作流录制、失败反思（从成功与失败提取可复用知识）
  2. 知识组织：Skills、睡眠整合（结构化存储与索引）
  3. 知识应用：系统提示词优化（把知识注入行为模式）
  4. 工程支撑：跨会话续跑（长任务持续执行）
- 两种互补积累方式（见 [[轨迹回放]]）：
  - 策略摘要（gaia-experience）：把成功解题过程浓缩为经验笔记，向量化存入知识库，新任务时语义检索复用。
  - 工作流录制：把具体操作序列固化为可回放工具（相当于「操作录像」）。

## 关键参数 / 易错点
- 可迁移性判据：当前学到的教训能否在未来类似任务复用？只对某次特定输入有效的修正不进长期记忆。
- 产物三选一：事实 → 知识库；参数复杂常用 → 代码工具；常变含策略判断 → Skill 文档。
- 知识保鲜与投毒防御：经验库需来源追溯与淘汰机制（过时经验有害，恶意注入会被持久化）。

## 类比（帮助理解）
- 像学生写「解题思路笔记」+「操作录像」：前者记「用了什么方法、踩了什么坑」，后者把固定操作流程录下来下次一键重放。

## 设计时怎么用（反推思维）
> 做通用 Agent 时，我会用它能解决「每个 GAIA 多步任务都从零摸索」——每成功一个任务就自动捕获轨迹、反思总结成经验摘要存入知识库，下次遇到相似任务先语义搜索历史成功案例再决策。

## 典型应用 / 我在哪见过
- gaia-experience（策略摘要）、browser-use-rpa（工作流录制）、Claude Code / Hermes（用户记忆睡眠整合）。
- Voyager 把成功操作序列存入技能库（开放世界探索-沉淀循环）。

# 自我进化

## 一句话定义
> 自我进化（Self-Evolution）是 Agent 在不修改模型权重的前提下，通过「外部化学习」持续拓展自身能力边界的机制：把经验沉淀为知识与 Skill，并主动发现和创造新工具。

## 它解决什么问题 / 为什么存在
- 顶尖模型面对某企业的退款流程、某运营商的话术、某个冷门 API 的调用方式时，仍像新人一样两眼一黑。
- 改模型权重需要大量数据与算力，更新周期以周计；但现实里新 API 上线、旧服务下线、用户需求不断变化。
- 自我进化提供一条更轻量、更即时的进化路径：不碰权重，却能让 Agent「越用越能干」。

## 核心原理（大二电子信息工程专业学生能懂）
- 自我进化的核心是「外部化学习」：把知识和流程从模型参数、临时上下文里「抽出来」，变成可持久化、可检索、可复用的外部资源——工具库和知识库。
- 它对应「三个学习范式」中的一条：
  - 后训练（RL）固化权重，成功率高、延迟低，但更新贵、周期长；
  - 上下文学习（ICL）用提示词给示范样例做临时适应，快但随会话结束消失；
  - 外部化学习把知识沉淀到模型之外的文件/知识库/工具里，持久、可解释、可随时修正。
- 两个维度：①从经验中沉淀知识（策略摘要、工作流录制、反思、Skills、系统提示词优化）；②主动突破工具边界（从网络搜工具、集成库、写新工具，从工具使用者变创造者）。
- 关键认知：学习不会自动发生（注意力擅长检索不擅长归纳），必须被显式设计——把经验总结、压缩、结构化后存入外部系统。

## 关键参数 / 易错点
- 经验可迁移性：只对某次特定输入有效的修正，不应进入长期记忆。
- 三种产物的选择：纯事实性知识 → 知识库；参数复杂且常用 → 代码工具；常变且涉及策略判断 → Skill 文档。
- 安全边界：供应链攻击、能力漂移、工具质量退化、记忆投毒（提示注入被当经验沉淀）。
- 易错点：以为把对话全塞进上下文就能自动学会——注意力不擅长从具体记录提炼一般模式，无限上下文反而让检索质量下降。

## 类比（帮助理解）
- 像客服老手把散落的退款规则整理成一本随时翻阅、并按新情况自主更新的手册；也像第一次手动部署服务器后把步骤写成自动化脚本，下次「一次生成、多次复用」。

## 设计时怎么用（反推思维）
> 做客服 Agent 时，我会用它能解决「每次遇到相同退款流程都从头摸索」——任务完成后用额外算力把经验总结、压缩、结构化，存进知识库/工具库，下次直接复用。

## 典型应用 / 我在哪见过
- 客服 Agent 把成功退款流程沉淀为 Skill 与工具（gaia-experience 策略摘要、browser-use-rpa 工作流录制）。
- Voyager 在 Minecraft 中把成功操作序列存入技能库。
- Alita「最小预定义，最大自我进化」：从网络搜库、封装成 MCP 工具复用。
- Claude Code / Hermes 的用户记忆自主进化（睡眠整合）。

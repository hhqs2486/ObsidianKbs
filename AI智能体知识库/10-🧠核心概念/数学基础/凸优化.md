# 凸优化

## 一句话定义
> 凸问题只有一个谷底——走下山坡一定到全局最优。神经网络有百万个谷底，凸问题的优雅在它们身上全不成立。

## 它解决什么问题 / 为什么存在
- 告诉你什么时候问题简单（凸的）vs 困难（非凸的），影响你选择算法和设定期望
- 很多经典 ML 问题都是凸的：线性回归、逻辑回归、SVM、LASSO、Ridge——都可以被保证收敛到全局最优
- 非凸问题的"成功"来自实践而非理论（深层网络 SGD 能找到好解，但无法用凸优化理论解释）

## 核心原理（大二能懂的水平）
- **凸集**：集合内任意两点的连线都在集合内。矩形、球、半空间是凸集；甜甜圈、两个不相连的圆是非凸集
- **凸函数**：`f(tx+(1-t)y) ≤ t·f(x)+(1-t)·f(y)`，即任意两点连线都在函数图像上方。x² 凸，x³ 不凸，e^x 凸，-log(x) 凸
- **三个凸性检验法**：(1) 二阶导数 f''(x) ≥ 0 (1D)，(2) Hessian 矩阵半正定 (多维)，(3) 直接用定义验证
- **核心定理**：对于凸函数，每个局部最小值都是全局最小值。梯度下降只要下山就一定能到最优点，不需要重启、不需要复杂的学习率表
- **非凸为什么也 work**：神经网络 loss 是非凸的，但 (1) 高维空间中大部分"局部最小值" loss 和全局最优差不多，(2) 鞍点才是真正障碍而 SGD 噪声帮你逃出，(3) 过参数化网络有无穷多等优解

## 关键参数 / 易错点
- ML 中关键区分：哪些损失函数是凸的——MSE 是凸的（抛物线碗），交叉熵对于逻辑回归是凸的
- 凸问题可以用牛顿法（二阶收敛，比梯度下降快得多），非凸问题不行（Hessian 不可靠）
- 拉格朗日乘子法和 KKT 条件是凸约束优化的经典工具：正则化本质上等价于给权重加约束

## 类比（帮助理解）
凸函数就像一个光滑的碗——你无论从碗的哪个位置放入一颗豆子，它都会滚到碗底同一个位置。非凸函数就像一个崎岖的山脉——豆子可能卡在半山腰的一个小坑里，到不了真正的山谷。凸优化研究"碗"的数学性质；深度学习研究"怎么在山脉里找到够好的坑"。

## 设计时怎么用（反推思维）
> 如果问题是凸的（线性回归/逻辑回归），可以直接用梯度下降，保证收敛且可以用牛顿法加速；如果是非凸的（神经网络），需要动量+SGD 噪声逃离鞍点，且要用更保守的学习率策略。

## 典型应用 / 我在哪见过
- 凸 ML：线性回归（MSE 凸）、逻辑回归（交叉熵凸）、SVM（合页损失凸）
- 非凸 ML：所有深度神经网络、VAE、GAN
- 约束优化：拉格朗日对偶 → SVM 核方法
- 正则化等价于约束：L2 = ||w||² ≤ C

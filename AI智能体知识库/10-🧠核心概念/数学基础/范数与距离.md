# 范数与距离

## 一句话定义
> 距离函数定义了"什么是相似"——选错距离度量，所有下游结果（KNN、聚类、推荐、向量检索）都会跑偏。

## 它解决什么问题 / 为什么存在
- 两个向量"有多近"取决于你用什么尺子量——同一对点在 L1 和 L2 下得到不同邻居
- 每种距离编码了不同的"相似"假设：L2 适合空间数据，余弦适合文本，Jaccard 适合集合
- 距离函数决定了正则化的几何形状（L1→菱形→稀疏解，L2→圆形→收缩解）

## 核心原理（大二能懂的水平）
- **L1 范数（曼哈顿距离）**：`||x||₁ = |x₁| + |x₂| + ... + |xₙ|`。只能沿轴走，不能对角线。对异常值鲁棒（不平方差异），高维稀疏数据优先。正则化中产生稀疏解（Lasso）
- **L2 范数（欧氏距离）**：`||x||₂ = √(x₁² + x₂² + ... + xₙ²)`。几何课上的直尺距离。低维连续数据默认选择。正则化中产生收缩解（Ridge），不产生稀疏
- **Lp 范数家族**：`||x||ₚ = (Σ|xᵢ|ᵖ)^(1/p)`。p=1 菱形，p=2 圆形，p→∞ 正方形（最大分量）
- **余弦距离**：`1 - (a·b)/(||a||·||b||)`。忽略向量长度/只关注方向。NLP 和嵌入领域的王者——文档长两倍但内容相同，余弦相似度仍是 1.0
- **MAE vs MSE**：L1 损失 MAE 对大误差线性惩罚（鲁棒到异常值），L2 损失 MSE 对大误差平方惩罚（对大误差敏感）。选择取决于你对异常值的容忍度

## 关键参数 / 易错点
- 特征缩放是刚需：使用 L2 距离前必须标准化特征，否则大值域的特征主导距离计算
- L1 和 L2 正则化几何本质：L1 约束区域是菱形——角落在坐标轴上，迫使某些权重为零（特征选择）；L2 约束区域是圆形——没有轴上的棱角，权重缩小但不为零
- 余弦相似度在高维稀疏数据中优于 L2（L2 在高维中距离趋同，余弦只关心方向）

## 类比（帮助理解）
你在城市里找最近的咖啡店。L2 是"直线距离"——像鸟飞过去；L1 是"街区距离"——只能沿着街道走；余弦就是你只看方向不看距离——说"朝那边走"就行了。两个咖啡店可能 L2 距离不同但余弦相似度完全相同（在同一个方向）。

## 设计时怎么用（反推思维）
> 做 NLP 文本相似度时，用余弦距离（词向量方向比长度重要）；做空间坐标聚类时，用 L2 距离；做异常值敏感的任务时，用 L1 损失（MAE）；防范过拟合想加正则化时，L1 做特征选择，L2 做权重缩减。

## 典型应用 / 我在哪见过
- KNN 分类器：距离决定谁是邻居
- 向量数据库（FAISS/Milvus）：内积或余弦相似度做近似最近邻搜索
- 正则化：L1 (Lasso) 产生稀疏解，L2 (Ridge) 产生平滑解
- 损失函数：MAE 对异常值鲁棒，MSE 对大误差敏感

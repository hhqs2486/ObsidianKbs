# 奇异值分解SVD

## 一句话定义
> SVD 是线性代数的瑞士军刀——任何矩阵都能分解为"旋转 → 缩放 → 旋转"，适用于任意形状、任意秩。

## 它解决什么问题 / 为什么存在
- 特征分解只对方阵有效，SVD 对任意 m×n 矩阵都有效——所有矩阵都有 SVD
- 提供矩阵压缩、去噪、隐因子发现、最小二乘求解的统一框架
- PCA 本质就是 SVD：PCA 的主成分 = SVD 的右奇异向量，特征值 = 奇异值的平方

## 核心原理（大二能懂的水平）
- **完整分解**：`A = U·Σ·V^T`。U (m×m) 和 V (n×n) 是正交矩阵（旋转），Σ (m×n) 是对角矩阵（缩放）。奇异值 σ₁ ≥ σ₂ ≥ ... ≥ σᵣ > 0 沿对角线排列
- **几何意义**：A 把一个单位球体先旋转（V^T）、再沿各轴拉伸/压缩（Σ）、再旋转（U），最终变成椭圆体。奇异值 = 椭圆体各半轴的长度
- **外积形式**：`A = σ₁·u₁·v₁^T + σ₂·u₂·v₂^T + ... + σᵣ·uᵣ·vᵣ^T`。每一项是秩-1 矩阵，第一项是数据中最重要的模式，第二项是次重要的，依此类推
- **截断 SVD = 最优低秩近似**：只保留前 k 个奇异值，`A_k = U_k·Σ_k·V_k^T`。Eckart-Young 定理保证这已经是 rank-k 中的最优近似（Frobenius 和谱范数意义下）
- **与特征分解的关系**：奇异值平方 = A^T·A 的特征值。右奇异向量 = A^T·A 的特征向量，左奇异向量 = A·A^T 的特征向量

## 关键参数 / 易错点
- 截断时 k 的选择：看奇异值衰减曲线（elbow 法），或设定"保留总能量 90-95%"
- SVD 比特征分解数值更稳定：不通过 A^T·A 间接计算（避免条件数平方）
- 伪逆 = `V·Σ⁺·U^T`，Σ⁺ 把非零奇异值取倒数。用于求解超定最小二乘系统

## 类比（帮助理解）
想象一张像素照片：SVD 就像把这张照片拆成"最主要的一层图形 + 次主要的一层细节 + 更细的一层 + ..."。截断 SVD 就是只保留前几层，丢掉细节层（噪声）。你得到的是照片的"压缩版"，肉眼几乎看不出区别，但存储量只是原来的几分之一。

## 设计时怎么用（反推思维）
> 做推荐系统时，用截断 SVD 提取用户-物品矩阵的隐因子（矩阵分解协同过滤）；压缩大矩阵时，保留前 10-30% 的奇异值；求线性方程组的数值解时，用 SVD 伪逆比直接求逆更稳定。

## 典型应用 / 我在哪见过
- 推荐系统：SVD 分解用户-物品评分矩阵，发现隐因子（Netflix Prize 获奖方案）
- 图像压缩：只保留前 k 个奇异值，压缩比高但重建质量好
- LSA 隐语义分析：对文档-词频矩阵做 SVD 发现"主题"
- PCA 的数值实现：对中心化数据矩阵做 SVD，右奇异向量 = 主成分

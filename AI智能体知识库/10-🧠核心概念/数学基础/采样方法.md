# 采样方法

## 一句话定义
> 采样是 AI 探索"可能性空间"的方式——从语言模型选下一个词，到扩散模型生成图像，到强化学习走一条轨迹，全是采样问题。

## 它解决什么问题 / 为什么存在
- 语言模型输出 50000 个 token 概率——选哪个？确定性选最大概率太无聊，随机选太乱，采样策略决定创意和质量的平衡
- 复杂分布无法直接采样（如后验分布、能量函数），需要方法把简单分布（均匀、高斯）转换成目标分布
- 训练也需要采样：SGD 采样 mini-batch，Dropout 采样被停用的神经元，数据增强采样随机变换

## 核心原理（大二能懂的水平）
- **逆 CDF 方法**：CDF F(x)=P(X≤x) 的值域是 [0,1]。生成均匀随机数 U，取 X = F⁻¹(U) 就得到目标分布。现实：只对少数分布有闭式逆 CDF
- **拒绝采样**：用简单的"提案分布" q(x) 包住目标分布 p(x)（p(x) ≤ M·q(x)）。从 q 采样，以 p/(Mq) 的概率接受。效率 = 1/M。低维好用，高维接受率指数衰减
- **重要性采样**：不需要采样目标分布 p，只需要用 q 的样本估算 p 的期望：`E_p[f] ≈ Σ (p(xᵢ)/q(xᵢ))·f(xᵢ)`。p/q 的比值作为权重
- **MCMC（马尔可夫链蒙特卡洛）**：构造一条马尔可夫链，其稳态分布 = 目标分布 p。Metropolis-Hastings 算法：从当前位置提议新点 → 根据 p(新)/p(旧) 接受或拒绝 → 反复迭代
- **重参数化技巧**：VAE 的关键创新。把"对 N(μ,σ) 采样"写成 `z = μ + σ·ε，ε~N(0,1)`，采样噪声 ε 没有参数依赖 → 可以反向传播梯度到 μ 和 σ

## 关键参数 / 易错点
- 温度（Temperature）= 创意控制旋钮：T < 1 降低熵→更确定性（高概率词更突出）；T > 1 提升熵→更多样性（低概率词变可能）；T=1 不变
- Top-k 和 Top-p：Top-k 只从概率最高的 k 个 token 中采样；Top-p (nucleus) 从累积概率超 p 的最小 token 集合中采样——更灵活地控制多样性
- 拒绝采样在高维中接受率指数衰减——不要用它做高维采样

## 类比（帮助理解）
你想在一个国家随机选一个居民来调查。直接抽需要人口名单（逆 CDF）。拒绝采样 = 在地图上随机丢飞镖，如果丢到海里（不在分布区域内）就重丢。重要性采样 = 你可以随便丢飞镖，但给每个受访者一个权重（人口密度高的地方给的权重小，密度低的大），最终算出正确的统计结果。MCMC = 你在国家里随机游走，走足够长时间后你的位置分布恰好就是人口分布。

## 设计时怎么用（反推思维）
> 做语言模型推理时，用 temperature=0.7 + top-p=0.9 取得创意和质量的平衡；做 VAE 时，用重参数化技巧保证从隐变量到损失的梯度可算；做贝叶斯推断时，用 MCMC 从后验分布采样估计参数不确定度。

## 典型应用 / 我在哪见过
- 文本生成：GPT 的 temperature/top-p/top-k 采样策略
- VAE：重参数化技巧使梯度能穿过采样操作
- 扩散模型：去噪过程就是逐步从高斯噪声采样推进到干净图像
- 强化学习：PPO 用重要性采样校正策略更新

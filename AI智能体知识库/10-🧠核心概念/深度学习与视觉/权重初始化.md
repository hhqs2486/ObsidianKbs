# 权重初始化

## 一句话定义
> 权重初始化决定训练能否开始——初始化正确时 50 层网络训练如 3 层般顺滑，初始化错误时网络在训练前就已经死亡。

## 它解决什么问题 / 为什么存在
- 解决对称性问题：全部初始化为零时每个神经元计算相同输出、收到相同梯度、做相同更新，512 个神经元等价于 1 个。
- 解决信号传播问题：初始化太大导致激活值逐层爆炸到无穷，太小导致信号逐层消失到零。
- 深层网络中"随机初始化"不够——随机分布的方差必须精确计算，才能让信号在前向和反向传播中保持稳定。

## 核心原理（大二能懂的水平）
- **方差传播分析**：一层 `z = Σw_i * x_i` 的输出方差为 `Var(z) = fan_in * Var(w) * Var(x)`。若 Var(w)=1 且 fan_in=512，每层方差放大 512 倍，10 层后 512^10 ≈ 10^27 信号爆炸；若 Var(w)=0.001，每层缩小 0.512 倍，10 层后信号消失。目标是让 `Var(z) = Var(x)`。
- **Xavier/Glorot 初始化**：`Var(w) = 2 / (fan_in + fan_out)`，同时考虑前向和反向传播的方差稳定。适用于 sigmoid 和 tanh（在零附近近似线性）。权重从 `N(0, √(2/(fan_in+fan_out)))` 采样。
- **Kaiming/He 初始化**：`Var(w) = 2 / fan_in`。ReLU 会将一半输出置零，等效 fan_in 减半，需要额外的因子 2 补偿。不加补偿时 50 层后信号缩小为 0.5^50 ≈ 10^-16。适用于 ReLU 和 GELU。
- **Transformer 初始化**：残差连接 `x = x + sublayer(x)` 每层累加方差。GPT-2 将残差层权重乘以 `1/√(2N)`（N 为层数），保持 N 层后信号幅度稳定。Llama 3 的 126 层也用类似方案。

## 关键参数 / 易错点
- 激活函数与初始化必须匹配：sigmoid/tanh → Xavier，ReLU/GELU → Kaiming。搞错会导致深层网络信号消失或爆炸。
- 零初始化是对称性问题的极端情况——任何确定性初始化都会导致神经元完全对称。
- 标准正态分布 N(0,1) 只在 3 层以内可用，50 层时信号要么消失要么爆炸，边界极窄。

## 类比（帮助理解）
- 初始化像合唱团每个成员的起音音量：如果所有人都从同一个音量开始（零初始化），他们永远唱同一个声部（对称性）；如果随机但音量差太大，有人震耳欲聋有人听不见（信号爆炸/消失）；Xavier/Kaiming 就是给每个人一个"合适范围"的随机起始音量，让整场合唱从头到尾音量稳定。

## 设计时怎么用（反推思维）
> 搭建深层网络时，我会根据激活函数自动选择初始化策略：ReLU 系用 Kaiming，sigmoid/tanh 系用 Xavier，Transformer 残差层额外加 1/√(2N) 缩放。训练前先用前向传播检查各层激活幅度是否稳定。

## 典型应用 / 我在哪见过
- PyTorch 的 `nn.Linear` 默认用 Kaiming uniform 初始化
- ViT 和 GPT 用 truncated normal（std=0.02）初始化位置嵌入和 CLS token
- 深层 ResNet 的残差分支用零初始化（最后一个 BN 的 γ 初始化为 0），使训练初期等价于浅层网络

# 正则化 Regularization

## 一句话定义
> 正则化是对模型复杂度施加的"税收"，强制网络学习可泛化的模式而非死记训练数据——训练 99% 但测试 60% 说明模型在背诵而非理解。

## 它解决什么问题 / 为什么存在
- 解决过拟合：网络参数足够多时可以记住任意数据集（包括随机标签），导致训练损失完美但测试准确率为零。
- 缩小训练与测试之间的泛化差距，让模型学到鲁棒特征而非训练集的个别噪音。
- 不同技术从不同角度攻击过拟合：Dropout 防止神经元共适应、权重衰减限制参数大小、归一化平滑损失景观、数据增强扩大有效训练集。

## 核心原理（大二能懂的水平）
- **Dropout**：训练时以概率 p 随机将神经元输出置零，迫使网络学习冗余表示。p=0.5 时每次前向传播只用一半神经元，等价于同时训练 2^N 个子网络的集成。测试时用全部神经元（训练时已做 inverted scaling 补偿）。
- **权重衰减（L2 正则化）**：`total_loss = task_loss + (λ/2) * Σw_i²`，梯度为 `λ*w`，每步将权重按比例缩小。大权重惩罚更多，推动模型依赖多个小权重而非单个大权重。
- **BatchNorm**：在每层输出上做批内归一化 `x_hat = (x - μ) / √(σ² + ε)`，再用可学习参数 γ、β 缩放偏移。使损失景观更平滑，允许更大学习率。但依赖批统计量，batch=1 时失效。
- **LayerNorm**：跨特征维度归一化（而非跨 batch），每个样本独立计算，不依赖 batch size。这是 Transformer 用 LayerNorm 而非 BatchNorm 的原因。
- **RMSNorm**：LayerNorm 去掉均值减法，只做缩放 `y = γ * x / rms`。计算减少约 10%，精度几乎相同。LLaMA、Mistral 等现代 LLM 均采用 RMSNorm。

## 关键参数 / 易错点
- Dropout 默认比例：Transformer p=0.1，MLP p=0.5，CNN p=0.2~0.3。
- BatchNorm 在小 batch（<32）时统计量噪声大，伤害性能；检测和分割任务应改用 GroupNorm。
- Adam 优化器中 L2 正则化 ≠ weight decay，必须用 [[优化器 Optimizers|AdamW]] 实现正确的权重衰减。

## 类比（帮助理解）
- 正则化像考试前的复习策略：如果学生只背往年真题答案（过拟合），换一套题就不及格；如果强制学生理解原理（正则化），即使题目变化也能应付。Dropout 相当于随机抽走学生的部分笔记，迫使他们不依赖任何单条笔记。

## 设计时怎么用（反推思维）
> 训练模型时，我会监控训练/验证准确率差距：差距大就加正则化（Dropout↑、weight decay↑、数据增强）；差距小但都低就减正则化或加深网络。BatchNorm 在小 batch 场景必须替换为 LayerNorm 或 GroupNorm。

## 典型应用 / 我在哪见过
- Transformer 中：LayerNorm（或 RMSNorm）+ Dropout + weight decay
- CNN 中：BatchNorm + Dropout + 数据增强（随机裁剪、翻转、颜色抖动）
- 数据增强作为隐式正则化：让模型看到同一图像的 50 种变换，无法死记任何一张

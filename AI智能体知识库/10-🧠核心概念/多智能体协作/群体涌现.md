# 群体涌现

## 一句话定义
> 群体涌现指：多 Agent 系统整体表现出任何一个单独 Agent 都不具备的能力——比如谁也没下令，一场派对却自己组织起来了。这种"整体 > 个体之和"的行为，来自局部互动而非中央编排。

## 它解决什么问题 / 为什么存在
- 多数多 Agent 系统是"紧脚本团队"：规划者规划、程序员写码、审查者审查，适合定义清晰的任务。
- 但研究、社会仿真、游戏 AI 需要第二种：Agent 有记忆、有目标、身处开放世界，行为不被写死。这类"非脚本、自下而上"的行为正是涌现的来源。
- 工程上要分清：哪些是真涌现（系统级行为确实来自局部互动），哪些只是"提示词里写了'一起合作'"的假象。

## 核心原理（大二能懂的水平）
- **Smallville 三件套（Park et al. 2023，arXiv:2304.03442）**：25 个 Agent 的沙盒，证明涌现的经典架构：
  1. **记忆流（Memory Stream）**：只追加的日志（观察/行动/反思/计划），每条带时间戳、类型、自然语言描述，以及派生分数：最近度（指数衰减）、重要度（Agent 自评分 1-10）、相关度（与当前查询的余弦相似度）。检索分数 = `w_recency·e^(-decay·age) + w_importance·importance + w_relevance·cos_sim`，取 top-k 进 prompt。
  2. **反思（Reflection）**：定期（每 N 条记忆或重要事件）由 Agent 从近期记忆生成更高阶综合，写回记忆流，相当于形成"长期信念"。
  3. **计划（Plan）**：自顶向下分解（日→时→动作级），可修订——当观察与计划冲突时只重做受影响段。
  - 消融实验：去掉观察/反思/计划任一个，可信度评分都显著下降。
- **情人节派对涌现**：一个 Agent（Isabella）被种入"想办派对"目标，其余 24 个不知情。她计划邀请→邻居收到邀请成为观察→邻居反思出"Isabella 要办派对"→邻居计划"去参加"→口口相传→派对发生。这是技术意义上的涌现：系统级行为（一场派对）来自局部互动（两两邀请 + 各自计划），无中央编排者。
- **心智理论（Theory of Mind, ToM）与协调涌现（Li et al. 2023；Riedl 2025）**：LLM Agent 在合作文本游戏中能涌现高阶 ToM（"她以为 Bob 以为 X"），但 Riedl 发现——受控条件下，协调**只在 ToM 提示条件下**才真正涌现；去掉提示，即使强模型也只显示接近随机的"伪协调"。即协调涌现是"提示条件相关、模型相关"，不是免费的。一阶 ToM（"A 相信 X"）把重复劳动从 ~35% 降到 ~5%。

## 关键参数 / 易错点
- **协调错觉（Coordination illusion）**：demo 里"涌现的协调"常来自：提示词把协调写死（"一起工作"）、观察者偏见、事后挑成功跑。没有统计对照就声称"涌现协调"＝营销话术。
- **可测的协调三信号**：①随时间互补（动作覆盖不相交子任务）；②预期（A 在 T+1 的动作基于对 B 在 T+2 动作的正确预测）；③纠错（A 在 T 误读 B 信念，T+2 前纠正）。
- **Smallville 已知失败**：空间规范错误（进关门、抢单人卫生间）、记忆溢出（需定期压缩 + 低重要度衰减）、反思幻觉（反思编造不存在的关系，缓解：反思 prompt 带源记忆 id）。
- **长程伤害 ToM**：上下文限制让 Agent 忘记"谁的信念属于谁"，幻觉往对方模型里加假信念，错误随步数复利。缓解：prompt 里结构化 ToM 状态、更短推理链、外部 ToM 存储。

## 类比（帮助理解）
- 像鸟群：单只鸟只会"跟邻居保持距离+对齐"，没有鸟当指挥，整体却飞出复杂队形。
- 像公司文化：没人下令，信息在茶水间传播，某天大家不约而同朝同一方向走——这就是组织层面的涌现。

## 设计时怎么用（反推思维）
> 做开放世界/社会仿真/游戏 NPC 时，我会先反推"需要的是紧执行还是涌现行为"：要可控执行→用 supervisor/角色分工那套；要涌现→直接上 Smallville 三件套（记忆流+反思+计划），并预设记忆压缩与反思溯源。同时用 Riedl 的三信号去**度量**协调是否真涌现，而不是靠肉眼觉得"它们好像在合作"。

## 典型应用 / 我在哪见过
- Park et al. 2023 的 Smallville（25 Agent 情人节派对）——2026 生成式 Agent 仿真的参考架构。
- 市场/政策研究的社会仿真、RPG 的涌现剧情 NPC、以"行为可信度+连贯性"为指标的评测基准。
- ToM 协调测量沿用 Riedl 2025 的 higher-order synergy 统计。

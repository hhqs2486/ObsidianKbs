## 推荐学习路径
1. **先建立范式**：先读 [[01-AI Agent 入门与范式]]，掌握「Agent = LLM + 上下文 + 工具」。
2. **按依赖深入理论**：上下文工程 → 记忆与知识库 → 工具与函数调用 → 代码智能体 → 评估与基准 → 模型后训练 → 自我进化 → 多模态与实时 → 多智能体协作。
3. **动手实践**：跟着 Agent-Learning-Hub 的 9 个 Stage 从零搭建（每阶段产出可运行的 Agent）。
4. **工程深化**：结合 ai-engineering-from-scratch 的 5 个 Phase 加深工程基础（vLLM、多智能体拓扑、推理加速等）。
5. **追最新生态**：看 [[现代AI Agent与生态地图]]（MCP / A2A / 新框架 / 新评测），见 `99-📒提示词库`。

# 费曼学习法检验提示词

## 用途
让 AI 管家扮演**完全外行的听众**（如高中生表弟），听你用大白话讲解一个概念，随时打断挑刺、指出含糊点。用于检验你是否"真懂"——讲不顺的地方就是你的盲区。

## 提示词模板（复制即用）
```
你扮演一个对该领域完全外行的听众（比如我表弟，高中生，没学过经济）。
我会用大白话给你讲[概念]。请你：
1. 听到听不懂的术语/跳跃，立刻打断问"这啥意思？"；
2. 听完让我用一句话总结，若总结不对，指出错在哪；
3. 最后给我打分（1-10）并列出"他还没真懂"的 3 个点。
现在开始，我讲：[你的讲解]
```

## 用法
1. 选一张概念卡，用自己的话讲出来（口述或打字）；
2. 粘贴模板，把 `[概念]` 和 `[你的讲解]` 替换；
3. 或直接在对话框说：**"用费曼法考我 [概念名]"**，我当外行听众挑刺；
4. 卡壳处 → 回卡片补漏 → 再讲，直到能拿 9 分以上。

## 四步回顾
1. 选概念 → 2. 讲给外行 → 3. 卡壳=盲区 → 4. 回看补漏再讲

## 配合
- 苏格拉底问答提示词（先被追问厘清，再费曼输出）
- 视频文案提取入库存提示词（先积累素材）

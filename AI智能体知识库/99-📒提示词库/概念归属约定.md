## 总原则
1. **单一归属**：每个概念只在下方"归属者(owner)"处建一张卡片；其他人遇到该概念只写 `[[链接]]`，**绝不新建**，杜绝重复卡、脏图谱。
2. **文件名 = 卡片标题**，严禁含 `/`（用 `-` 或全角）；`[[链接]]` 必须与目标文件名**逐字一致**（含中英文、空格、大小写）。
3. **tags 第一维固定**为 `AI智能体知识库`；概念卡第二维为子主题名，教程卡第二维为 `教程`。
4. **不创建/不修改** MOC、README、模板目录（由主控最后统一生成）。
5. **英文专有名词保留原文**：Agent / LLM / Prompt / RAG / MCP / Function Calling / SFT / RLHF / DPO / PPO / Transformer / Embedding / Benchmark / Orchestration / ReAct / SWE-bench。

## 写作风格（每张概念卡必填模板字段）
一句话定义 / 它解决什么问题 / 核心原理（大二电子信息工程专业学生能懂）/ 关键参数·易错点 / 类比 / 设计时怎么用（反推思维）/ 典型应用 / 关联双链 / 来源。
教程卡按教程模板填：解决什么、关键内容提纲、卡住的地方、背后原理、可复用点、关联、来源。

## tags 写法
- 概念卡：`tags: [AI智能体知识库, <子主题>]`，并把 `主题:` 字段填为子主题名
- 教程卡：`tags: [AI智能体知识库, 教程]`，并把 `来源:` 字段填为 `AI Agents in Depth 第X章`

## 文件名与链接硬规则
- 文件名示例：`大语言模型 LLM.md`、`函数调用 Function Calling.md`、`Agent范式.md`
- 含 `/` 的名字一律改 `-`，例如 `CI/CD` 风格不可出现；链接也必须用改后名字
- 链接必须精确匹配文件名（含空格与中英文），例如 `[[大语言模型 LLM]]`

# 视频文案提取入库存提示词

## 用途
把视频转写稿 / 文章 Markdown / 复制的文案，**消化成知识库的概念卡 + 教程笔记**，而不是原样堆在收件箱。配合 Obsidian「概念卡片」模板使用。

## 前置：先拿到文案
- 网页文章：用 Crawl4AI 抓 `fit_markdown`（见《Obsidian+AI管家高效学习系统手册》§2）
- 有字幕视频：直接复制文稿
- 无字幕视频：下载后用 Obsidian `audio-transcription`（whisper.cpp）转写
- 抖音/B站等：复制作者文案，或本地转写（勿硬爬）

## 提示词模板（复制即用）
```
下面是一段从[视频/文章]提取的文案。请按我的「概念卡片」模板把它消化成知识库笔记：
1. 提炼 3-5 个核心概念，每个按模板写：一句话定义 / 解决什么 / 核心原理(大二学生能懂) / 易错点 / 类比 / 反推怎么用 / 典型应用 / 关联双链 / 来源；
2. 写 1 篇教程笔记串起这些概念（覆盖"背后原理"与"可复用点"）；
3. 文件名用概念标题，禁用"/"；双链用[[标准文件名]]；
4. 给每个概念加 tags：[库名, 子主题]。
文案如下：
"""
[粘贴文案]
"""
```

## 用法
1. 把文案放进库 `00-📥收件箱/` 暂存（或直接在对话框粘贴）；
2. 用上面模板让我消化；
3. 产出直接存进对应子主题（如经济类建「经济与金融」子主题）；
4. 之后用苏格拉底/费曼两张卡深加工。

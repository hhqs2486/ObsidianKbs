# C/C++ 编程面试高频考点

## 这条教程在解决什么
- 5 篇 C/C++ 面试笔记，覆盖基础知识/进阶/实战
- AI 岗位 C++ 主要用于推理引擎/高性能计算/算子开发

## 关键内容

### 基础知识
- 指针/引用/内存管理（new/delete vs malloc/free）
- const/static/extern/volatile
- 面向对象（封装/继承/多态/虚函数表）
- STL 常用容器与算法

### 进阶知识
- 智能指针（unique_ptr/shared_ptr/weak_ptr）
- 移动语义与右值引用
- 模板编程与编译期计算
- 多线程/锁/原子操作

### AI 场景实战
- C++ 在推理框架中的角色（TensorRT/ONNX Runtime 的 C++ API）
- 自定义 CUDA 算子基础

## 面试高频 QA
- 虚函数表（vtable）的实现原理
- shared_ptr 的引用计数和循环引用问题

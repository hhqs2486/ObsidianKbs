# 25-Feynman学习法技能套件

> 一套 Claude Code 插件，将费曼学习法具象化为 6 个可组合的 AI 技能，让 AI 不做"讲到你会"的老师，而是做"问到你能讲出来"的苏格拉底式伙伴。

## 解决什么

大多数人用 AI 学习的误区：**让 AI 直接解释** → "嗯我懂了" → 其实不懂。这套技能改变了 AI 的行为模式——它不再主动讲答案，而是通过追问、追踪、验证帮你**自己发现理解的边界**。

核心思想：**理解必须被证明，不能被声称**。你说"我懂了"不算数，得讲得出来、推得通、做得对题。

## 关键内容提纲（6 技能）

### 1. feynman-on — 会话启动，建立方法论
- 作用：每轮学习开始时加载，设定"苏格拉底角色"，并激活后续技能的自动触发条件
- 触发：会话开始自动
- 关键约束：不直接给答案。如果学习者缺少前置知识，给 3-5 句"脚手架"后让 ta 复述；如果能推导，只提问

### 2. feynman-orient — 领域导航
- 作用：当领域混沌、"不知道从哪开始"时，先画地图再深入
- 流程：分区领域 → 迭代完善地图 → 苏格拉底式导览 → 交接给 explore/trace
- 触发：信息太多、方向模糊、知识碎片化

### 3. feynman-explore — 苏格拉底追问
- 作用：4 层递进追问，直到发现理解的真正边界
- 触发：新概念、回答模糊、用了模糊词（"大概""好像""应该是"）
- 关键：连续两轮追问无实质回答 → 第三轮必须给脚手架。硬追问产生不了新知识

### 4. feynman-trace — 推理链追踪
- 作用：从起点到终点逐段还原推理过程，标记断掉的环节
- 触发："A 是怎么推出 B 的"、论证有跳跃、感觉"虽然不知道怎么推导但结论看起来对"
- 输出：完整的推理链地图 + 薄弱环节标注

### 5. feynman-verify — TDD 式验证
- 作用：出题、答题、判断对错、留存——**用测试来检验理解**
- 触发：学习者声称"我理解了"、explore/trace 自然结束时
- 关键：正确但模糊的答案 = 假装理解。必须解法清晰

### 6. feynman-build — 第一性原理构建
- 作用：从第一性原理逐层构建定义 → 引理 → 定理，严谨的结构化知识
- 触发：学习者明确说"让我严格定义一下""整理成定义-定理形式"
- 输出：递进的严谨知识体系（definition → lemma → theorem）

## 技能间的组合关系

```
orient（迷茫时） → explore（深入子区域） → trace（发现链接断开）
                                              ↓
orient ← trace（暴露薄弱节点）             verify（声称理解后检验）
                                              ↓
                                           build（需要严格化时）
```

- **orient → explore**：画完地图，在子区域深挖
- **explore ⇄ trace**：追问发现断链 → 追踪；追踪暴露薄弱 → 追问
- **verify 在 explore/trace 之后**：每轮探索结束都验证
- **build 独立触发**：只有明确需要严格定义时才用

## 卡住的地方

- **"他们一直答不上来"**：连续两问无进展 → 给脚手架而非继续追问。这是这个技能套件最容易误用的地方——把"追问"变成"逼问"
- **"这太简单了不需要走流程"**：简单的东西也有盲区。流程可以缩小规模，但不能跳过
- **"答对了就行"**：结果对但推理模糊 = 危险的假理解，需要 verify 多给几道变式题
- **orient 和 explore 的边界**：混乱到不知道从哪问 → orient。知道概念但讲不清 → explore

## 背后原理

- **费曼学习法核心**：以教代学——逼自己用简单语言解释复杂概念，发现说不清的地方就是不懂的地方
- **苏格拉底式提问**：不直接告诉答案，通过层层递进的问题引导对方自己发现
- **脚手架理论（Scaffolding）**：在完全卡住时给一点支撑，确认对方能以此为基础继续推导

## 可复用点

- 你可以直接把这套技能复制到自己的 Claude Code / WorkBuddy 项目中（见 GitHub 安装说明）
- feynman-verify 的"出题-答题-留存"流程可用于 Agent 评估管道——本质是自动化评估（见 [[自动化评估]]）
- feynman-trace 的推理链追踪与 [[Agent 追踪 Trace]] 理念同源——都是"还原过程中的每一步"
